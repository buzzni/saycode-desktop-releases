# Spec — v0.1.91 가이드북·README 개정과 영어 화면 스크린샷 도입

- 작성일: 2026-11-17
- 대상 저장소: `buzzni/saycode-desktop-releases` (README 4개 언어, `docs/GUIDE*.md`, `docs/assets/`, 신규 `docs/assets/en/`, `docs/guidebook/`, `tools/guidebook/`)
- 기준 앱: Saycode Desktop **v0.1.91** (소스 `aplus-dev-studio-desktop@024ea4ba95`)
- 이전 갱신: [2026-11-01 v0.1.81](2026-11-01-v0.1.81-guidebook-refresh.md)

## 1. 왜

v0.1.82 ~ v0.1.91 (10개 릴리스) 사이에 v0.1.89의 전체 UI 스타일 통일로 화면이 모두 달라졌고, 기획 모드·컨텍스트 압축·하단 터미널·파일 직접 편집·개발자 모드·사용 연결(say플랜·내부 AI)·배포 같은 기능이 추가됐습니다. 이름이 바뀐 버튼(`지금 반영`, `보관 해제`, `입력창에 담기`, `개인 사용 종료`)과 단축키(작업 강도 ⌘⇧L)도 많습니다. 또 영어판 가이드가 한국어 화면 스크린샷을 쓰고 있어 영어 화면을 따로 찍었습니다.

## 3. 만든 방법

1. **변경 정리** — 릴리스 노트 10개를 화면 단위로 정리하고, 나중 릴리스가 앞 릴리스를 뒤집은 항목은 최신 상태로 합쳐 장별 수정 계획과 촬영 목록을 만들었습니다.
2. **실화면 촬영** — v0.1.91 릴리스 커밋을 스크래치 폴더에서 빌드하고(런타임은 v0.1.91 배포판에서 가져옴), 격리 프로필의 **개인 사용** 모드를 Playwright로 조작해 촬영했습니다. 같은 장면 스크립트를 한국어·영어 프로필에 각각 돌렸습니다. 실제 AI 작업은 언어별 20턴 안팎입니다(데모: 팀 장비 대여 현황 보고서, 커피 구독 랜딩 페이지, 장비 대여 대시보드).
3. **집필** — 릴리스 노트 기준 1차 원고를 쓴 뒤, 촬영 기록(실제 라벨·위치·개수)과 대조해 고친 2차 원고를 확정했습니다. 화면과 릴리스 노트가 다르면 화면을 따랐습니다. 영어판은 앱 번역 카탈로그와 영어 화면 기록에서 라벨을 가져와 한국어판과 같은 내용으로 다시 썼습니다.
4. **검수** — 가이드가 쓰는 모든 스크린샷을 눈으로 확인하고, 링크 앵커·이미지 존재 여부는 빌드로 검증했습니다.

## 4. 개인정보·보안 확인

- 촬영 중 렌더러 텍스트 마스크를 적용했습니다(호스트명 → `my-macbook`, 홈 경로 → `/Users/me`, 이메일 → `alex@example.com`). 모바일 연결 QR은 블러 처리했고, AI 사용량 창의 계정 이름은 가짜 이름으로 바꿨습니다.
- 커밋 전 Apple Vision OCR로 가이드·README가 쓰는 PNG 전부와 GIF에서 1초 간격으로 뽑은 프레임을 검사해 실명·호스트명·이메일·실제 홈 경로 **0건**을 확인했습니다.
- 터미널 화면은 프롬프트를 `$ `로 바꾼 뒤 찍었습니다.

## 5. 알아 둘 점

- **미리보기 탭·앱 안 브라우저·요소 주석(주석 트레이)·디자인 조정·AI 브라우저**는 v0.1.91에서 일부 조직에만 보입니다(개인 사용·일반 계정에는 메뉴가 없음). 가이드 9장은 그 조건을 밝히고 짧게 줄였고, README의 "보면서 고치기" 소개는 누구나 쓸 수 있는 기능(기획 모드·대화에 붙이기) 소개로 바꿨습니다. `annotation-tray.gif`, `browser-panel.png`는 더 쓰지 않습니다.
- 로그인·조직이 필요한 화면(조직 콘솔, say플랜·내부 AI 선택, 배포, 예약 만들기, 커넥터, 스킬, 메신저 채널)은 이번에도 새로 찍지 못해 글로만 설명합니다. `org-console.png`만 예전 그림이 남아 있습니다.
- 개인 사용에서 **파일 복원지점**을 켜면 대화가 시작되지 않아(v0.1.91) 패널 그림 없이 릴리스 노트 기준으로 설명했습니다.
- 몇몇 그림은 설치본과 같게 보이도록 화면 글자를 고쳐 찍었습니다: `CPU 측정 중…`이 오래 남은 시작 화면 6장의 CPU 값, `Saycode 정보`의 업데이트 문구·사용자 데이터 경로(비패키지 빌드에서만 다르게 나오는 값).
- 소개 영상(MP4)은 v0.1.81 화면 그대로입니다. v0.1.89에서 화면 스타일이 바뀌었으므로 다음에 다시 만들 대상입니다.
- 일본어·중국어 README는 영어 화면 스크린샷을 씁니다(해당 언어 화면은 찍지 않음).
- 릴리스 노트(`docs/releases/`)와 `<!-- release-notes -->` 블록은 자동 발행 파이프라인 소유라 손대지 않았습니다.

## 6. 범위 밖 / 후속

- 소개 영상 재제작(v0.1.89 이후 스타일).
- 로그인 계정으로만 볼 수 있는 화면의 신규 촬영.
- 촬영·검수 중 발견한 앱 이슈는 별도 보고서로 정리했습니다(저장소에는 넣지 않음).
