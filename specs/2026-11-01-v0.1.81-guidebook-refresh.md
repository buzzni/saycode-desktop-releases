## 1. 왜

v0.1.51 ~ v0.1.81 (31개 릴리스) 사이에 화면 구조가 다시 크게 바뀌었습니다. 환경설정 → **내 설정(일반/개발)**, 머신 → **작업PC**, 홈 탭(Chat/Build/Develop) → **사이드바 Chat/Project**, 작업 마무리 허브 → **입력창 위 메뉴**, AI·모델 버튼 → **한 버튼(AI 자동)**, 헤더 AI 잔량 칩 → **입력창 아래 AI 잔여량**이 대표적입니다. README와 가이드의 스크린샷은 대부분 다른 앱처럼 보이는 상태였습니다.

이번에는 스크린샷과 소개 문구를 갱신하면서, **누구나 브라우저나 PDF로 편하게 읽을 수 있는 가이드북**을 함께 만듭니다.

### 가이드북 작성 규칙 (요약 — 자세한 것은 `tools/guidebook/README.md`)

- `##` = 장(PDF에서 새 쪽), `###` = 절. 목차는 자동 생성.
- 이미지는 `<img src="assets/…" alt="캡션">`을 단독 문단으로. alt가 그림 캡션이 됩니다.
- 안내 상자는 GitHub 문법 `> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`.
- 버전·날짜는 `<!-- guidebook: version=… date=… -->`.
- 내용을 고친 뒤 `cd tools/guidebook && npm run build`로 HTML·PDF를 다시 만들어 함께 커밋합니다. 없는 이미지를 참조하면 빌드가 실패합니다.

## 3. 만든 방법

1. **변경 정리** — v0.1.51~0.1.81 릴리스 노트 전체를 화면 단위로 정리하고, 바뀐 라벨·낡은 장·촬영 목록(약 50항목)을 뽑았습니다.
2. **실화면 촬영** — v0.1.81 소스를 격리 worktree에서 빌드하고(런타임은 v0.1.81 릴리스 DMG에서 가져옴), 격리 프로필(`APLUS_DESKTOP_USER_DATA_DIR`, `APLUS_STANDALONE_HAPPY_HOME_DIR`)로 **개인 사용** 모드를 처음부터 따라가며 Playwright(`webContents.capturePage`)로 촬영했습니다. 실제 AI 작업은 6턴(데모: "사내 장비 대여 현황" 대시보드, 커피 구독 랜딩 페이지, Chat HTML 보고서)만 돌렸습니다.
3. **집필** — 한국어 원고를 먼저 쓰고, 촬영 결과(화면 목록·실제 라벨)와 대조해 고친 뒤, 영어판은 앱의 영어 UI 문자열을 대응시켜 번역했습니다. 영어판 스크린샷은 한국어 UI 그대로입니다(첫 화면만 영어판).
4. **독립 리뷰** — 별도 리뷰어가 화면과 문장의 일치, 초보자 관점의 따라 하기 가능성, 구조, 개인정보를 검토했고 지적 사항(필수 14 · 권장 24)을 반영했습니다.

## 4. 개인정보·보안 확인

- 모든 프레임에서 렌더러 텍스트 마스크를 적용했습니다(호스트명 → `my-macbook`, 홈 경로 → `/Users/me`, 이름 → `Alex`, 이메일 → `alex@example.com`). 모바일 연결 QR·링크는 블러 처리했습니다.
- 커밋 전 Apple Vision OCR로 최종 PNG 전부와 GIF에서 뽑은 고유 프레임 전부를 검사해 실명·호스트명·이메일·실제 홈 경로 **0건**을 확인했습니다.
- 터미널 패널(캔버스 렌더링, 텍스트 마스크 불가)은 촬영하지 않았습니다.
- 로그인이 필요한 화면(조직 콘솔, 커넥터 서비스 목록, 예약 만들기, 공개 링크, 메신저 채널, PR 올리기)은 이번에 새로 찍지 않았고, 가이드에서는 글로 설명합니다.
