## 변경된 기능

### 필요할 때만 여는 대화 내 찾기

대화 내 검색창은 평소 숨겨지고 대화 헤더에 돋보기만 표시됩니다. 검색창을 오른쪽 위의 작은 팝오버로 바꾸고 검색 결과를 노란색으로 강조합니다. 이전·다음 결과로 이동하거나 같은 검색어를 전체 대화 검색으로 넘길 수 있습니다.

#### 사용 방법

대화에서 Cmd/Ctrl+F 또는 헤더 돋보기를 누르세요. Escape로 닫을 수 있습니다. 전체 대화 검색은 Cmd/Ctrl+Shift+F를 사용하거나 대화 내 찾기의 ‘전체 대화에서 검색’을 누르세요. 단축키는 환경설정에서 바꿀 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/952)

## 수정된 문제

### 대화 검색 색인이 같은 페이지를 다시 받지 않게

대화 검색 색인을 쓰는 두 경로(새 메시지 색인과 유휴 시간 백필)가 같은 대화를 동시에 건드리면 한쪽이 실패하면서, 이미 받아 둔 대화 페이지를 버리고 같은 페이지를 다시 내려받았습니다. 이제 앞서 있는 색인 뒤에 이어 쓰므로 중복 다운로드 없이 색인이 진행됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/954)

### 모노레포 하위 폴더 프로젝트의 반복 작업 사본 생성

저장소의 하위 폴더를 프로젝트로 등록했을 때, 두 번째 작업 사본(worktree)부터 "프로젝트 폴더 밖" 오류로 생성이 실패하던 문제를 수정했습니다.

#### 사용 방법

모노레포의 하위 폴더를 프로젝트로 등록한 뒤 새 대화(작업 사본)를 여러 번 시작합니다. 최초 1회 확인 이후에는 추가 확인 없이 계속 생성됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/957)

### 모노레포 하위 폴더 프로젝트의 작업 사본 시작 위치

저장소의 하위 폴더를 프로젝트로 등록했을 때, 작업 사본 세션(새 대화 열기, 병렬 실행, 재전송·보관 대화 이어가기 포함)이 저장소 전체 최상위가 아니라 등록한 프로젝트 폴더에서 시작하도록 수정했습니다. 함께 동기화되는 환경 변수 파일도 이제 그 위치에 반영됩니다.

#### 사용 방법

모노레포의 하위 폴더를 프로젝트로 등록한 뒤 새 대화(작업 사본)를 시작합니다. 터미널과 채팅의 파일 경로, `::preview` 상대 경로가 등록한 프로젝트 폴더 기준으로 표시됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/957)

### 앱이 "준비 중" 화면에서 멈춰 있지 않게

앱 화면을 불러오지 못했을 때 준비 중 화면이 영원히 떠 있던 문제를 고쳤습니다. 이제 한 번 자동으로 새로고침해 보고, 그래도 실패하면 "앱을 불러오지 못했어요" 안내와 [다시 시도] 버튼이 나타납니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 안내가 보이면 [다시 시도]를 누르면 됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/954)

### 웹에서 끊은 워크트리 연결이 데스크탑에서 되살아나지 않게

웹에서 채팅의 워크트리 연결을 해제한 뒤에도, 데스크탑이 대화 속 브랜치 언급과 남아 있는 폴더를 근거로 이전 워크트리를 다시 연결하던 문제를 고쳤습니다. 서버가 해제한 연결은 데스크탑을 다시 실행해도 해제된 채로 유지됩니다. 같은 워크트리의 이름·기준 브랜치가 서버에서 바뀌면 데스크탑에도 반영됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/955)

### 웹에서 사용하던 채팅 워크트리를 데스크탑에서도 유지

웹에서 워크트리를 사용한 채팅을 데스크탑에서 열 때 같은 작업 폴더와 브랜치를 복원합니다. 여러 채팅이 같은 워크트리를 사용하는 경우에도 연결 정보를 유지하며, 웹에서 연결을 옮기거나 해제하면 Desktop에 남은 이전 경로도 정리합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 기존 채팅이 열린 프로젝트를 다시 열거나 새로고침하면 서버에 저장된 워크트리 연결을 불러옵니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/951)
