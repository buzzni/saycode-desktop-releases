## 새 기능

### 작업PC 저장공간이 부족하면 대화 입력창에서 안내

작업PC의 홈 폴더가 있는 디스크를 95% 이상 사용했고 남은 공간이 5GB 이하이면 프로젝트 대화와 Chat의 입력창 위에 저장공간 경고와 남은 공간을 표시합니다. 프로젝트 대화에서 저장소 바가 펼쳐져 있으면 안내는 그 위에 나타납니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 안내 오른쪽의 X를 누르면 이번 부족 상태의 경고를 닫을 수 있습니다.

### 프로젝트 설정에서 등록 작업PC를 관리해요

조직이 이 기능을 쓰도록 설정된 프로젝트에서는 프로젝트 설정의 작업PC 탭에 등록 작업PC 카드가 생겨요. 같은 조직의 다른 작업PC를 등록하면 온라인 저장소에서 프로젝트 사본을 준비하고, 준비 상태를 보며 실패한 준비를 다시 하거나 등록을 해제할 수 있어요.

#### 사용 방법

프로젝트 설정 → 개발 → 작업PC → 등록 작업PC에서 작업PC를 고르고 등록을 누르세요. 준비됨이 되면 새 대화에서 그 작업PC를 고를 수 있어요.

### 프로젝트에 등록한 다른 작업PC에서 새 대화를 시작할 수 있어요

조직이 이 기능을 쓰도록 설정된 프로젝트에서는 새 작업트리를 프로젝트에 등록한 다른 작업PC에 만들고, 대화도 그 작업PC에서 시작할 수 있어요. 온라인 저장소의 브랜치에서 시작하며, 기본 작업PC에만 있는 커밋과 저장 안 한 파일은 빠진다는 안내를 먼저 보여 줘요. 그 대화의 오른쪽 파일 패널도 그 작업PC의 폴더를 보여 줘요.

#### 사용 방법

새 대화에서 작업트리를 켜고 조절 아이콘(작업트리 · 방식)을 눌러 방식이 새로 만들기인지 확인한 뒤, 실행 작업PC에서 등록한 작업PC를 고르고 메시지를 보내세요.

### Help 메뉴에서 키보드 단축키를 바로 찾을 수 있어요

어떤 단축키가 있는지 알기 어려웠어요. 이제 Mac의 앱 메뉴 막대 Help에 "키보드 단축키"가 생겨, 누르면 단축키를 찾고 바꿀 수 있는 내 설정의 단축키 화면이 바로 열려요. 대화 머리글의 "터미널 열기" 버튼에 마우스를 올리면 단축키가 함께 보이고, 탭 줄의 "새 대화 열기" 버튼은 고정된 "Cmd + T" 대신 지금 쓰는 키를 Windows·Mac에 맞게 보여 줘요.

#### 사용 방법

Mac은 앱 메뉴 막대에서 Help → "키보드 단축키"를 누릅니다. Windows는 메뉴 막대가 없으므로 내 설정 → 일반 → 단축키로 엽니다. 열린 화면에서 동작 이름이나 키로 검색하고, 오른쪽 키 버튼을 눌러 바꿀 수 있어요.

## 변경된 기능

### 개인 Chat의 최근 작업물 버튼 높이와 여백 조정

개인 Chat 상단에서 최근 작업물의 파일명이나 개수를 보여 주는 버튼의 높이를 줄이고, 버튼 위 여백을 늘렸습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 봇 탭에서 예약을 지우고, 다음 실행 시각이 늘 보입니다 (실험)

봇에게 부탁해 만든 예약을 봇 탭에서 바로 지울 수 있습니다. 예약 줄의 휴지통을 누르면 줄 안에서 한 번 더 확인하고 지웁니다. 봇 프로젝트는 Project 목록에 없어 다른 곳에서는 지울 방법이 없었습니다. 또 켜져 있는 매일·매주 예약이 "다음 실행 없음"으로 보이던 문제를 고쳐, 서버가 다음 시각을 알려 주지 않아도 작업PC의 시간대로 계산한 다음 실행 시각을 보여 줍니다. 시간대를 알 수 없으면 틀린 시각 대신 표시하지 않습니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켜고 봇 탭 목록 아래 **예약**에서 예약 줄의 휴지통 → **지우기**를 누릅니다.

### 조직 계정이 아직 없는 PC에서 새 대화가 적용 뒤 한 번 자동으로 시작됨

관리자가 조직 AI 배정을 바꾼 직후에는 이 컴퓨터에 새 계정이 아직 없어 새 대화 시작이 실패할 수 있었습니다. 이때 앱은 계정 적용을 시작했지만, 적용이 끝난 뒤에도 다시 시도를 직접 눌러야 했습니다. 이제 새 대화의 첫 시작이 이 이유로 실패하면, 계정 적용이 끝난 뒤 같은 요청을 한 번 자동으로 다시 보냅니다. 대화 화면을 보고 있을 때만 다시 보내며, 두 번째 실패나 적용 실패는 지금처럼 오류와 다시 시도 버튼으로 보입니다. 이미 진행 중인 대화를 이어갈 때는 자동으로 다시 보내지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 한 번 연결한 조직 AI는 앱을 다시 켠 뒤에도 배정 변경을 따라감

조직 AI는 처음 한 번 `조직 계정 연결하기`를 눌러야 연결되고, 그 뒤 배정 변경은 앱이 켜져 있는 동안에만 자동으로 반영됐습니다. 앱을 다시 켜면 다시 누르기 전까지 새 배정이 이 컴퓨터에 오지 않아, 관리자가 계정을 바꾸면 대화 시작이 실패할 수 있었습니다. 이제 이 컴퓨터에서 조직 계정 연결을 한 번이라도 진행했다면, 앱을 시작할 때부터 배정 변경을 확인하고 자동으로 받습니다. 한 번도 연결하지 않은 컴퓨터는 지금처럼 `조직 계정 연결하기`를 눌러야 연결됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

## 수정된 문제

### 바뀐 조직 AI 배정을 받기 전에는 연결됨으로 보이지 않음

관리자가 조직 AI 배정을 바꾼 직후, 이 컴퓨터가 새 배정을 아직 받지 않았는데도 시작준비의 AI 도구 단계에 `인증세트 연결됨`이 보일 수 있었습니다. 이제 이 상태에서는 "바뀐 배정을 아직 이 컴퓨터에 받지 않았어요"라고 보이고, `조직 계정 연결하기`로 받을 수 있습니다. 이전에 받은 계정으로 대화를 시작하는 동작은 그대로입니다.

#### 사용 방법

내 설정 > 시작준비 > AI 도구에서 안내가 보이면 `조직 계정 연결하기`를 누릅니다.

### 봇의 연결 안내가 버튼으로 보입니다 (실험)

봇이 연결하지 않은 서비스를 안내할 때 커넥터 설정을 여는 버튼 대신 `::saycode-open{...}` 같은 글자가 그대로 보이던 문제를 고쳤습니다. 봇 규칙이 버튼 줄을 따로 떨어진 문단으로 쓰게 바뀌었고, 이미 만든 봇도 봇 탭을 열면 새 규칙으로 바뀝니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 오래 걸리는 도구 실행 중에 응답 기다리기를 10분 만에 멈추지 않습니다

AI가 출력 없이 오래 걸리는 도구(브라우저 자동화 등)를 실행하면, 작업PC가 정상으로 연결돼 있어도 앱이 10분 뒤 "대화가 10분째 조용해요"라며 응답 기다리기를 멈췄습니다. 이제 도구가 아직 실행 중이고 작업PC 연결 신호가 계속 오면 최대 60분까지 응답 중 표시를 유지합니다. 연결 신호가 끊기거나 실행 중인 도구가 없으면 지금처럼 10분 뒤 기다리기를 멈춥니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 이 컴퓨터의 AI 로그인이 풀렸으면 AI 계정 화면도 연결됨으로 보이지 않습니다

외부 연동과 AI Models의 AI 계정 화면은, 예전에 연결한 기록만 있으면 이 컴퓨터의 Claude·ChatGPT 로그인이 풀린 뒤에도 `연결됨`으로 보였습니다. 그런데 입력창의 공급사 메뉴는 실제 로그인을 확인해 `연결하기`를 보여서, 두 화면이 서로 달랐습니다. 이제 로그인이 풀렸으면 AI 계정 화면도 "이 컴퓨터에서 로그인이 풀렸어요 · 계정. 다시 연결해 주세요"와 `연결` 버튼을 보입니다.

#### 사용 방법

외부 연동 › AI 계정(또는 내 설정 › AI Models)에서 로그인이 풀린 계정의 `연결`을 눌러 다시 로그인하면 됩니다.

### 조직 계정 연결하기가 응답 없는 PC에 묶여 기다리지 않음

이 PC가 응답하지 않아 조직 AI 연결이 멈춰 있으면, `조직 계정 연결하기`를 누르거나 대화 시작이 계정 적용을 요청해도 최대 15분 동안 아무 일도 일어나지 않았습니다. 이제 누르는 즉시 연결 중으로 표시되고, 이 PC가 상태 확인에 60초 안에 답하지 않으면 그 시도를 실패로 끝낸 뒤 기다리던 요청으로 다시 연결합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### Windows 빠른 업데이트가 다시 몇 초 만에 끝납니다

Windows에서 앱을 업데이트할 때 빠른 업데이트(설치 폴더 교체)가 매번 "다른 프로세스가 사용 중"으로 실패했습니다. 그래서 전체 설치 파일을 받아 설치하느라 10분 가까이 걸렸습니다. 업데이트를 맡은 도우미가 설치 폴더를 작업 폴더로 붙잡고 있던 것이 원인이었습니다. 이제 도우미가 그 폴더를 놓아 빠른 업데이트가 끝까지 됩니다.

#### 사용 방법

이 수정이 들어간 버전으로 한 번 업데이트하면, 그다음 업데이트부터 빠르게 적용됩니다.
