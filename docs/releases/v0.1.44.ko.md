## 새 기능

### 복구 패스키 Desktop 안내

계정 보안 설정에 복구 패스키(WebAuthn PRF) 안내가 추가되었습니다. Desktop 앱은 아직 복구 패스키 등록·관리를 지원하지 않아, 웹 브라우저 설정에서 등록·관리할 수 있도록 안내합니다.

#### 사용 방법

계정 보안 설정에서 안내 카드의 버튼을 눌러 웹 설정을 열고 복구 패스키를 등록·관리합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/946)

### 예약·API 실행 스크립트 관리

프로젝트 자동화에서 Node.js 스크립트를 등록하고 예약 또는 외부 API로 실행할 수 있습니다. 코드 버전, 실행 계정과 머신 상태, 실행 이력·로그를 확인하고 전체 실행과 예약만 각각 중지할 수 있습니다.

#### 사용 방법

실행 → 자동화의 스크립트 등록에서 코드와 예약을 저장하세요. 이력·API key에서 수동 실행과 키 발급·교체·폐기를 관리합니다. 서버와 격리 runner가 script protocol 5 기능을 제공해야 합니다. 키 원문은 발급 화면에서 한 번만 표시됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/928)

## 수정된 문제

### 내장 Happy 데몬이 다른 프로그램의 상태 파일 덮어쓰기에 종료되던 문제 해결

내장 Happy runtime을 갱신해, 같은 컴퓨터의 다른 프로그램(예: 테스트 도구)이 데몬 상태 파일을 덮어쓰면 데몬이 "다른 데몬이 떴다"고 오인해 스스로 종료하고 로컬 작업이 오프라인이 되던 문제를 고칩니다. 이제 데몬은 실제로 데몬 잠금을 가진 프로세스만 다른 데몬으로 인정하고, 그 외의 덮어쓰기는 되돌립니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/936)

### 독립 리뷰 결과로 리뷰어의 마지막 잡담이 전달되던 문제 수정

독립 리뷰가 여러 리뷰 에이전트를 나눠 실행한 경우, 리뷰어가 최종 보고를 낸 뒤 뒤늦게 도착한

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 기존에 잘못 확정된 리뷰는 다시 실행해야 올바른 결과를 받습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/934)

### 머신 이름 표시 일관성

새 채팅의 머신 선택과 대화 목록, 세션 시작 실패 안내가 설정의 머신 목록과 다른 이름(원시 호스트명이나 식별자)을 보여주던 문제를 수정했습니다. 이제 모든 화면이 사용자가 붙인 이름을 동일하게 표시합니다.

#### 사용 방법

새 대화를 시작할 때 머신 선택 목록과 대화 목록의 머신 표시가 설정 > 머신 화면과 같은 이름으로 보입니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/945)

### 원장이 없는 프로젝트에서 자식 세션 생성이 거절되던 문제 수정

워크트리 세션에서 `happy agent spawn`이 처음 실행될 때 리눅스 머신에서 "spawn ledger is unwritable"로
