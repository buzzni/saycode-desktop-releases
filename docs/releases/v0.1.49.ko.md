### 설정에서 GitHub·GitLab 계정 연결·해제

설정에 "Git 계정" 탭이 추가되어 GitHub와 GitLab 연결 상태(연결된 계정, GitLab 호스트)를 한곳에서 확인하고 연결하거나 해제할 수 있습니다. 새 프로젝트 화면에 들어가지 않아도 됩니다. 토큰은 서버에만 보관됩니다.

#### 사용 방법

설정 → Git 계정에서 "연결"을 누르면 브라우저에서 승인 페이지가 열립니다. 승인 후 앱 창으로 돌아오면 상태가 갱신됩니다. 연결을 끊으려면 "연결 해제"를 누르고 한 번 더 확인합니다. 개인 액세스 토큰(PAT)은 기존처럼 보안 탭에서 관리합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1070)

### 에이전트 답변이 쓰이는 대로 바로 보입니다

지금까지는 에이전트가 문단 하나를 다 쓸 때까지 기다린 뒤에야 답변이 한꺼번에 나타났습니다. 이제 에이전트가 답을 쓰는 동안 글자가 생성되는 대로 대화 끝에 바로 표시됩니다. 답변이 저장되면 같은 자리에서 정식 메시지로 자연스럽게 바뀌며, 연결이 끊겨 일부 내용이 빠지면 불완전한 글을 보여 주지 않고 저장된 답변을 기다립니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 에이전트가 텍스트로 답하는 대화에서 동작합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1073)

### 응답에서 만든 새 산출물 찾기

프로젝트의 새 완료 응답에 명시되고 파일 접근 범위에서 확인된 산출물을 파일 패널에 표시합니다. 과거 대화는 새 산출물로 표시하지 않으며, 파일 뷰어에서 성공적으로 열람한 버전만 표시를 해제합니다.

#### 사용 방법

프로젝트 대화의 파일 패널에서 새 산출물을 선택합니다. 패널을 닫았다 열어도 미열람 표시는 유지되며, 다운로드만 하면 표시가 유지됩니다. 호환되는 온라인 macOS daemon의 파일 확인 기능이 필요합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1102)

### 프로젝트 없이 시작하는 Work와 문서 템플릿

사이드바에서 프로젝트와 Work를 구분하고 로그인하지 않은 로컬 작업공간에서도 Work 대화를 저장하고 이어갈 수 있습니다. 문서 형식과 기본·개인 템플릿을 선택해 원본 서식과 작성 지침을 실제 작업에 전달합니다.

#### 사용 방법

Work 탭 하단의 새 워크를 누르세요. 입력창 아래 문서 선택 버튼이나 + 메뉴에서 문서 형식을 고르면 템플릿 목록이 열립니다. 템플릿을 고르면 입력창에 선택한 이름과 작성 안내가 표시됩니다. 교체하거나 해제해도 직접 작성한 내용은 유지됩니다. 내 템플릿 만들기로 기존 Office 파일과 지침을 저장할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1084)

### 프로젝트 파일 내용 검색

파일 패널에서 현재 목록의 파일명을 필터링하거나 프로젝트·worktree 안의 텍스트 내용을 검색할 수 있습니다. 결과를 누르면 같은 머신의 파일과 해당 행을 엽니다. 내용 검색에는 호환되는 온라인 macOS daemon이 필요하며, 다른 머신에서도 파일명 필터와 기존 파일 탐색을 유지합니다.

#### 사용 방법

파일 패널의 검색 방식을 고르고 검색어를 입력합니다. 내용 검색은 Enter로 실행하며 숨김·무시·빌드 경로를 제외합니다. 상한에 도달한 결과는 일부 결과로 표시합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1102)

### 한 컴퓨터에서 연결한 Telegram 봇을 같은 계정의 다른 컴퓨터에서도 씁니다

한 컴퓨터에서 Telegram 봇을 연결하고 페어링하면, 같은 계정으로 로그인한 다른 컴퓨터도 토큰을 다시 입력하거나 다시 페어링하지 않고 같은 봇을 씁니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 다른 컴퓨터에도 Telegram 기능(확장)이 설치돼 있어야 하며, 설정 → AI → 메신저 채널 → Telegram에서 설치하고 켜면 바로 연결됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1090)

### Work를 기존 폴더에서 시작할 수 있습니다

Work의 추가 메뉴에서 현재 컴퓨터의 기존 폴더를 선택하면 해당 폴더를 작업 경로로 사용합니다. 선택 경로는 입력창에 표시되고, 대화를 다시 열거나 세션을 재생성해도 같은 컴퓨터에서 유지됩니다.

#### 사용 방법

Work 입력창의 `+`를 누르고 `폴더 추가` 아래의 `기존 경로에서 시작`을 선택하세요. 폴더를 고른 뒤 메시지를 보내면 그 폴더에서 작업을 시작합니다. 다른 컴퓨터의 머신에는 선택 경로를 적용하지 않습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1115)

## 변경된 기능

### 내장 Happy 런타임을 1.1.10-aplus.245로 올렸습니다

Desktop에 내장된 Happy 런타임을 `1.1.10-aplus.245`로 올렸습니다. 종료된 대화를 다시 이어갈 때 사이드바에 새로 등록하거나 해제한 추가 디렉터리가 대화의 쓰기 권한에 반영됩니다. 이 밖에 데몬 시작 때 빠진 설치 산출물을 복구하고, 자동화 1회 실행이 백그라운드 작업을 끝까지 기다리며, 첫 턴의 교훈 회수가 유지되도록 고친 내용이 함께 들어옵니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 이미 실행 중인 대화에는 적용되지 않으니, 새 대화를 시작하거나 종료된 대화를 다시 이어가세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1094)

### 대화 상태 확인에 쓰는 데이터가 크게 줄었습니다

앱은 사이드바에 보이는 대화들의 상태(작업 중 여부, 제목 등)를 몇 초마다 서버에 확인합니다. 지금까지는 확인할 때마다 모든 대화의 전체 정보를 받아 한 번에 수 MB가 오갔습니다. 이제는 변경 여부를 알려주는 작은 정보만 받고, 실제로 바뀐 대화만 전체 정보를 다시 받습니다. 바뀐 것이 없어 보여도 1분이 지난 대화는 전체 정보를 다시 받아, 암호화 키가 교체된 대화도 1분 안에 열립니다. 네트워크 사용량과 서버 부하가 줄어듭니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1122)

### 다른 조직 창을 함께 열어도 메신저 연결이 끊기지 않습니다

한 앱에서 조직이 다른 창 두 개를 열어 두면, 창이 로그인 정보를 다시 읽을 때마다 메신저 채널이 그 창의 조직으로 넘어갔습니다. 그 과정에서 연결이 계속 닫혔다 열려 봇이 메시지를 받지 못했고, 로그에는 `CHANNEL_CONNECTION_NOT_HYDRATED` 가 남았습니다. 이제 메신저 채널을 쓰는 조직의 창이 열려 있는 동안에는 다른 조직 창 때문에 넘어가지 않습니다. 창이 하나뿐일 때 조직을 바꾸면 지금처럼 따라갑니다.

#### 사용 방법

다른 조직에서 메신저 채널을 쓰려면 그 조직 창의 설정 → AI → 메신저 채널에서 「이 조직으로 전환」을 누르세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1134)

#### 사용 방법

설정 → 메신저 채널에서 안내가 보이면 "이 조직으로 전환"을 누르세요.
