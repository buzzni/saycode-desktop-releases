## 새 기능

### 사이드바에서 Chat 예약 작업을 관리할 수 있습니다

사이드바의 예약 작업에서 매일·분 단위 반복 업무를 등록하고 편집·일시정지·재개·삭제할 수 있습니다. 업무 예시는 초안을 준비하며 저장 전에는 실행되지 않습니다. 실행 이력에서 시작과 실패를 구분하고 실제 대화를 확인할 수 있습니다.

#### 사용 방법

예약 메뉴는 테스트 기간에 기본 숨김입니다. 개발자 기능 설정의 `예약 메뉴 보이기`를 켜면 사이드바에 표시됩니다. 메뉴를 숨겨도 이미 만든 예약은 계속 실행됩니다. 예약 작업에서 새 예약이나 업무 예시를 선택하세요. 할 일과 시간을 확인하고 예약하기를 누릅니다. 기존 자료가 있는 대화나 다른 PC는 세부 설정에서 선택합니다. 예약 시간은 해당 작업 PC의 시간대 기준이며 PC와 AI 연결이 준비되어 있어야 실행됩니다. 주간 특정 요일 예약은 이번 Desktop 계약에 포함되지 않습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1488)

### 첨부 자료로 Chat 작업을 더 쉽게 시작합니다

새 Chat에 파일을 첨부하면 핵심 요약·할 수 있는 일을 선택해 요청을 준비할 수 있습니다. 여러 자료는 비교도 제공합니다. 선택한 요청은 입력창에서 확인·수정한 뒤 직접 보냅니다.

#### 사용 방법

파일을 넣고 제안을 선택하거나 직접 요청을 입력하세요. 결과 파일의 저장이 실패하면 다시 저장을 누르세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1501)

### 홈에서 프로필 이름을 바로 변경

시작화면의 사진·이름·인사를 누르면 프로필 설정으로 이동합니다. 이름을 저장하면 홈 인사에 바로 반영하며 긴 이름은 말줄임표와 전체 이름 툴팁으로 표시합니다. 표시 이름은 최대 20자로 입력하고 현재 글자 수를 확인할 수 있습니다. 프로필 사진 업로드 영역은 잠시 숨깁니다.

#### 사용 방법

시작화면의 인사를 누르거나 내 설정 > 일반 > 계정 > 프로필에서 표시 이름을 수정하고 저장하세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1485)

### Chat에서 쉽게 업무 시작하기

웹 체험하기의 다섯 가지 작업과 여섯 가지 서비스 연결 안내를 새 Chat 화면에 추가했습니다. 그림과 짧은 예시를 보고 요청과 샘플 파일을 준비할 수 있습니다. 입력창 아래 작업 카드는 80%, 서비스 연동은 60% 너비로 가운데 표시됩니다.

#### 사용 방법

새 Chat에서 작업을 고른 뒤 내 파일을 올리거나 예시로 시작하세요. 작성 중인 요청을 바꿀 때는 확인 버튼을 바로 보여주며 내 파일은 보존합니다. 서비스 상태 확인과 연결 후에는 선택한 예시로 자동 진행합니다. 내용을 확인하고 전송하면 작업을 시작합니다. 활성 카드와 예시는 회색 배경 없이 표시하며, 계정 없이 쓰는 모드에서는 서비스 연결 안내를 표시하지 않습니다.

## 변경된 기능

### 모바일 연결을 독립 설정 메뉴로 제공

프로필 아래에 있던 모바일 로그인 QR을 모바일 연결 페이지로 옮겼습니다. 지원되는 계정에서 해당 페이지를 열 때 QR을 만들고 페이지를 떠나거나 설정을 닫으면 미사용 QR을 폐기합니다. 발급 실패 시 새 QR 만들기로 재시도할 수 있습니다.

#### 사용 방법

내 설정 > 일반 > 계정 > 모바일 연결에서 QR을 확인하세요. 개인 사용 모드의 기존 모바일 연결도 같은 메뉴에서 이용합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1485)

### 알아보기 쉬운 대화 이름

대화 이름에 내부 ID가 나타나지 않도록 개선했습니다. 제목이 아직 없으면 첫 요청을 짧게 보여주고, 요청도 없으면 새 대화로 표시합니다. 사이드바·대화 탭·검색·작업보드·알림에 같은 이름을 사용하며 직접 정한 제목은 유지합니다.

#### 사용 방법

평소처럼 대화를 시작하세요. 대화 이름으로 요청한 작업을 찾아 다시 열 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1482)

### 저장 안내를 파란 토스트로 표시

프로필 저장 성공 안내를 화면 상단의 토스트로 표시해 입력창 위치가 바뀌지 않게 했습니다. 안내 토스트는 라이트·다크 테마에 맞는 파란 배경을 사용합니다. 전체 공통 토스트에 연한 테두리·은은한 그림자와 여백을 적용해 화면 위에 떠 있는 느낌으로 표시합니다. 저장 안내는 4초 후 자동으로 사라지고 닫기 버튼으로도 닫을 수 있습니다.

#### 사용 방법

프로필 이름을 저장하면 자동으로 표시됩니다. 안내를 바로 닫으려면 토스트의 닫기 버튼을 누르세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1485)

### AI 브라우저 안내 표시 설정

대화 상단의 AI 브라우저 안내를 기본으로 숨기고 개발자 기능 설정에서 켠 경우에만 표시합니다. 선택은 앱을 다시 실행해도 유지하며 명칭을 AI 브라우저로 통일했습니다.

#### 사용 방법

프로필 메뉴에서 개발자 기능 설정을 열고 `AI 브라우저 안내 보이기`를 켜세요. 개인·프로젝트 대화에 함께 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1493)

### 시작준비의 자동 설치·계정 준비 복원

간소한 시작준비 화면을 유지하면서 기존 준비 기능을 뒤에서 실행합니다.

#### 사용 방법

시작준비에서 조직을 선택하고 다음을 누르면 자동으로 진행합니다.

### 알림 안내를 확인하면 온보딩 완료 표시가 바로 반영됩니다

온보딩에서 알림 안내를 열면 즉시 초록색 완료 체크가 표시됩니다. 테스트 알림을 보내거나 마지막 완료 버튼을 누르지 않아도 확인한 상태가 저장되며, 다시 열어도 유지됩니다. 완료된 항목은 선택 중에도 초록색으로 표시합니다.

#### 사용 방법

온보딩 체크리스트에서 알림 단계를 열어 안내와 설정을 확인합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1490)

### 오프라인 머신 이후 메신저 호스트 선택을 복구합니다

이전에 메신저를 실행하던 머신이 오프라인이 된 뒤에도 연결 초안이 남아 있으면, 설정 화면에서 온라인 머신을 다시 선택할 수 없고 Telegram 봇 연결이 실패할 수 있었습니다. 이제 완료되지 않은 연결 초안에서는 사용 가능한 온라인 머신을 다시 선택할 수 있습니다. 온라인으로 표시돼도 데몬이 중지됐거나 원격 제어를 지원하지 않는 머신은 선택지에서 제외됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. Telegram 설정을 다시 열고 온라인으로 표시된 머신을 선택해 연결을 완료하면 됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1503)

### 좁은 화면에서도 프로젝트 상단을 한 줄로 표시합니다

프로젝트 이름·설정, 작업 모드, 더보기를 같은 줄에 표시합니다. 파일 패널을 열거나 창을 좁혀도 상단 높이를 유지하고 긴 이름은 줄여 표시합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1501)

### 첫 시작은 시작준비에 집중

처음 설치해 실행한 동안에는 Aplus CLI 업데이트 모달이 시작준비를 가리지 않습니다. 시작준비를 완료하거나 화면을 새로고침해도 자동으로 열리지 않으며, 앱을 종료하고 다시 실행하면 기존 조건에 따라 안내합니다.

#### 사용 방법

첫 실행에서도 업데이트가 필요하면 사이드바의 업데이트 아이콘을 누르세요. 기존 설치의 업데이트 안내와 하루동안 안보기는 그대로 사용할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1484)

### 첫 AI 연결이 막혀도 쉽게 다시 진행

시작준비를 이 컴퓨터 등록·온라인 확인과 AI 연결 확인으로 나눕니다. 서버에서 이미 적용한 내 PC의 조직 계정은 다시 적용하지 않고 확인하며, 기존 PC의 연결 키와 대화 신원을 보존합니다. 조직의 Claude 연결이 아직 준비되지 않아도 사용할 수 있는 배정 Codex가 있으면 이어갑니다. AI 준비가 실패하면 홈으로 돌아가거나 AI 연결 설정을 바로 열 수 있고, 브라우저 로그인 대기에서는 로그인 취소 후 다시 연결할 수 있습니다. 완료 화면과 이 컴퓨터 등록 화면의 안내도 간결하게 정리합니다.

#### 사용 방법

첫 시작 안내에서 다음을 눌러 이 컴퓨터를 준비합니다. PC 등록·온라인 확인이 끝나면 다음을 한 번 더 눌러 AI 연결을 확인하세요. 로그인 대기에는 로그인 취소, AI 준비가 실패하면 다시 연결·나중에 하기·AI 연결 설정을 사용하세요. 준비 완료 버튼은 기존대로 완료입니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1483)

#### 사용 방법

별도 설정 없이 모든 공통 토스트에 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1489)

### 회사 Windows PC의 로그인 정보 저장 개선

처음 설치한 회사 Windows PC에서 다른 계정의 폴더 권한 때문에 로그인 정보를 저장하지 못하는 경우, Windows 사용자별 보호 저장소를 확인해 로그인과 작업PC 연결 정보를 저장합니다. 회사 폴더 권한은 변경하지 않습니다. 기존 정보가 있는 경로는 안전성을 확인하며, 확인할 수 없는 키나 작업PC 신원을 새로 만들지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 보호 저장소를 사용할 수 없는 회사 정책은 추가 확인이 필요합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1481)

### AI 계정 선택과 연결 복구 개선

AI 사용량의 조회 설명과 계정 제목을 간소화하고 개수 배지를 제거했습니다. Codex 계정이 하나일 때도 계정 이름·사용 상태·두 사용량 열을 같은 형식으로 보여줍니다. 계정 이메일은 최대 앞 5글자와 ***만 표시하며 툴팁과 자동 전환 안내에서도 전체 주소를 숨깁니다.

#### 사용 방법

기존처럼 AI 사용량을 열어 남은 사용량을 확인하거나 사용 가능한 다른 계정 행을 선택하세요. 계정 이름이 전달되지 않는 단일 Codex 연결은 `현재 Codex 계정`으로 표시합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1494)
