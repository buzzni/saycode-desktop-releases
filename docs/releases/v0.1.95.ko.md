## 새 기능

### 대시보드에서 공간컨텐츠 만들기

대시보드 맨 아래에서 공간컨텐츠 제작 화면을 열 수 있어요.

#### 사용 방법

대시보드 맨 아래의 **공간컨텐츠 만들기**를 누르세요. 공간컨텐츠 확장이 활성화돼 있으면 제작 화면이 바로 열려요. 설치나 활성화가 필요하면 안내에서 확장 설정을 여세요.

### 사이드바 대시보드: 오늘 내 차례, 나의 작업 방식, 우리 팀 소식

사이드바 외부 연동 아래에 대시보드가 생겼어요. 오늘에서는 질문·승인·확인 안 한 결과·CI가 통과한 PR이 오래 기다린 순서로 모이고, 선택지가 있는 간단한 질문은 대화를 열지 않고 바로 답할 수 있어요. 지금 일하는 AI와 AI 사용 한도(지금 속도면 언제 바닥나는지)도 함께 보여요. 나에서는 이 컴퓨터에서만 계산한 작업 스타일, 최근 4주 작업 리듬, AI를 기다리게 한 시간, 매번 같은 승인, 오늘의 흐름을 볼 수 있어요. 이 기록은 서버로 보내지 않고 관리자도 볼 수 없으며, 요청 내용·명령 인자·경로·대화 제목은 저장하지 않아요. 조직에서는 우리 팀에서 이번 주 팀 합계, 마지막 방문 이후 바뀐 함께 하는 프로젝트, 진행 중인 작업 요청, 방금 배포된 서비스와 공지를 봐요. 순위나 사람 사이 비교는 없어요.

#### 사용 방법

사이드바 위쪽 메뉴에서 대시보드를 누르세요. 내 차례가 있으면 메뉴에 수가 표시돼요. 나 탭의 분석은 기록이 3일 쌓인 뒤에 보여요. 우리 팀 탭은 조직을 쓸 때만 있어요. 지금은 buzzni 조직에서만 보여요.

### 알림 센터가 웹·모바일과 같은 알림을 보여 줍니다

데스크탑에서 받은 대화 완료·실패·취소 알림과 자동화 알림(일시정지, GitHub 트리거, 머지 확인)이 이제 서버의 알림 기록에도 남아 웹과 모바일 알림 센터에서 보입니다. 반대로 웹·모바일에서 생긴 알림도 데스크탑 알림 센터에 함께 보이고, 한 기기에서 읽거나 지운 알림은 다른 기기에서도 읽음·삭제로 맞춰집니다. 데스크탑에서 한 배포의 결과는 서버 배포 알림과 합쳐 한 줄로만 보입니다. 데스크탑 OS 알림·알림음과 모바일 푸시를 보내는 조건은 바뀌지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 서버가 이 기능을 지원하면 알림 센터를 열거나 앱 창으로 돌아올 때 다른 기기의 알림을 새로 가져옵니다. 모두 지우기는 다른 기기의 알림 센터까지 비우니 확인 후 누르세요.

### 한도에 걸린 터미널 화면에서 열린 셸 관리

터미널 한도에 도달하면 사용량을 확인할 수 있습니다. 지원되는 연결에서는 본인 소유가 확인된 터미널을 하나 골라 종료하고 방금 요청한 터미널을 다시 엽니다. 다시 한도에 걸리면 새 목록을 표시합니다.

#### 사용 방법

한도 안내에서 열린 터미널 관리를 누릅니다. 종료할 터미널을 고르고 이 터미널을 종료하고 새로 열기를 누릅니다. 선택한 터미널 종료 요청이 표시되는 연결에서는 종료를 요청한 뒤 다시 열기를 누릅니다.

### say플랜에 신규 가입자 Starter 무료 기간이 보입니다

신규 가입자가 받는 say플랜 무료 기간이 Starter 등급이면, say플랜 사용량 팝오버와 대화의 한도
안내에 등급이 Starter 로 보입니다. 팝오버 첫 줄은 이번 달 대신 무료 기간 전체 사용률과 종료일을
보여 줍니다. 무료 이용이 끝나면 웹의 설정 > 사용량에서 Basic 결제를 신청하라는 안내가 나옵니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 서버가 무료 기간 정보를 보내지 않는 이전 버전에서는 기존과 같게 보입니다.

## 변경된 기능

### 대시보드 한 페이지와 더 자세한 내 활동 분석

오늘 할 일, 내 활동 분석, 우리 팀 소식을 한 페이지에서 볼 수 있어요. 내 활동 분석에는 최근 7일 일별 제출 요청 수와 직전 7일 대비 변화, 요청을 제출한 날 수와 최장 연속 요청일, 대화별 AI 작업 시간 합계, 승인·질문 대기가 끝난 횟수가 추가됐어요. 분석은 이 컴퓨터의 활동 기록으로 계산해요.

#### 사용 방법

사이드바에서 대시보드를 열고 아래로 스크롤하세요. 내 활동 분석은 기록이 3일 쌓이면 볼 수 있고, 요청 수 비교는 직전 7일 전체가 기록 범위에 있을 때 표시돼요.

### 대시보드에서 할 일을 더 쉽게 훑어봐요

대시보드에서 반복되는 카드 테두리를 줄였어요. `내 차례`는 상태, 대화 제목, 필요한 행동을 한 행에서 볼 수 있는 목록으로 표시돼요. 내 활동 분석과 우리 팀도 제목과 여백을 중심으로 정리했어요.

#### 사용 방법

사이드바에서 대시보드를 열고 내 차례 목록의 버튼으로 질문, 승인, 결과, PR을 확인하세요.

### 대화 안 AI 위임에서 GPT-6.2 Sol·Astra를 고를 수 있습니다

Desktop에 내장된 Happy 런타임을 `1.1.10-aplus.428`로, 함께 들어 있는 Saycode CLI를 `0.9.19`로 올렸습니다. 대화 안에서 다른 AI에게 일을 맡길 때(`happy agent`) Codex 모델 목록에 GPT-6.2 Sol·GPT-6.2 Astra가 나오고, 이 모델을 지정해 맡길 수 있습니다. 이전에는 목록에 없어 지정하면 거절됐습니다.

#### 사용 방법

대화에서 "Codex GPT-6.2 Astra high로 리뷰를 맡겨 줘"처럼 모델을 지정해 요청하면 됩니다. 앱을 업데이트한 뒤 작업PC 런타임이 새 버전으로 다시 시작되면 적용됩니다.

### 사이드바 대화 상태를 한 줄에서 확인

대화 제목 아래 상태 줄을 없애고 같은 줄의 아이콘으로 상태를 표시합니다. 포인터나 키보드 초점이 있어도 상태 아이콘이 보입니다.

#### 사용 방법

상태 이름과 입력 대기 시간은 대화 행에 마우스를 올려 확인할 수 있습니다.

### 사이드바 상단에서 아이콘으로 실행 중·입력 대기 표시

실행 중과 입력 대기를 각각 스피너와 말풍선으로 표시합니다. 상태 버튼의 크기와 위치는 옆 버튼에 맞췄습니다.

#### 사용 방법

사이드바 상단의 상태 버튼을 눌러 상태별 개수, 대화 목록과 작업보드 입구를 확인합니다.

### 새 대화는 항상 기존 방식으로 시작합니다

이전에는 내부 AI 연결을 한 번 고르면 그 선택이 앱 기억에 남아 앱을 다시 연 뒤에도 다음 새 대화로 자동 이어졌습니다. 그래서 앞의 대화에서 내부 AI를 쓴 뒤 새 대화를 열면 모르는 사이에 그 연결로 시작하는 경우가 있었습니다. 이제 새 대화는 항상 기존 방식으로 시작합니다. 지금 입력창에서 고른 연결은 그 대화가 시작되기 전까지 그대로 유지되고, 그 사이 대상 PC를 바꿔도 선택이 유지되지만, 다음 새 대화로 이어지지는 않습니다. 연결마다 기억되는 모델 선택은 그대로 유지되고, 내부 AI 탭을 명시적으로 열 때 마지막 사용 연결이 기본으로 먼저 제시되는 동작도 그대로입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 새 대화에서 내부 AI를 쓰려면 보내기 전에 AI도구 메뉴 › 내부 AI에서 연결을 고르면 됩니다.

### 새 대화의 Git 확인 및 기본 시작 폴더 표시를 간결하게 변경

새 프로젝트 대화에서 Git 확인 상태와 기본 시작 폴더는 각각 아이콘으로 표시됩니다.

#### 사용 방법

입력창 위 저장소 상태 아이콘과 폴더 아이콘의 툴팁에서 세부 상태와 기본 시작 경로를 확인할 수 있습니다.

### 시작준비에서 손쉬운 사용을 설정하고 Ego Lite를 다운로드할 수 있어요

컴퓨터·브라우저 제어 단계에서 Chrome 확장 설정 대신 브라우저 조작용 Ego Lite 다운로드를 제공해요. macOS 권한 안내에서 CuaDriver를 목록에 추가하고 켜는 순서를 확인할 수 있어요.

#### 사용 방법

손쉬운 사용 옆의 허용 요청을 눌러 시스템 설정을 열어요. 목록에 CuaDriver가 없으면 안내창의 아이콘을 끌어다 놓고, 목록에서 CuaDriver를 켜 주세요. Saycode로 돌아와 허용 상태를 확인해요. 브라우저 조작이 필요하면 Ego Lite 다운로드를 눌러요.

### 작업 마무리에서 PR을 올릴 수 없는 이유 바로 표시

PR 올리기를 쓸 수 없으면 아이콘과 이름을 회색으로 표시하고 그 아래에 이유를 보여 줍니다.

#### 사용 방법

입력창 위 작업 마무리 메뉴를 열고 PR 올리기 아래를 확인합니다.

### 프로젝트 이어가기에서 AI 연결 선택

프로젝트 대화의 맥락을 같은 작업PC와 작업 폴더에서 새 대화로 이어갈 때, AI 계정·say플랜·사용 가능한 내부 AI 중에서 고를 수 있습니다.

#### 사용 방법

프로젝트 대화 머리글에서 **대화 이어가기** → **다른 AI도구로 이어가기**를 엽니다. **사용 연결**과 모델, 넘길 대화 범위를 고른 뒤 **이어가기**를 누릅니다.

### 프로젝트 홈의 폴더 가져오기 카드 간소화

프로젝트가 없는 Develop 홈에서 기존 폴더를 연결하는 방법을 짧게 안내하고, 가져오기 카드를 옅은 파란색으로 표시합니다.

#### 사용 방법

buzzni 조직에 프로젝트가 없고 이 컴퓨터가 작업PC로 등록되어 온라인이면 Project → Develop → 내 폴더 가져오기를 누릅니다.

### 하단 터미널 출력도 대화에 추가할 수 있어요

하단 터미널(Cmd+J)에서 출력을 선택하면 작업 영역 터미널처럼 `대화에 추가` 버튼, 오른쪽 클릭 메뉴의 `대화에 추가`, 단축키(기본 Cmd+L, Windows는 Ctrl+L)를 쓸 수 있습니다. 하단 터미널은 특정 대화에 속하지 않으므로, 지금 가운데에 보이는 프로젝트 대화의 입력창에 `터미널 · N줄` 카드로 넣습니다. 화면을 나눴으면 포커스가 있는 대화에 넣고, 화면에 프로젝트 대화가 없으면 아무 데도 넣지 않고 알려 줍니다.

#### 사용 방법

프로젝트 대화를 연 채 Cmd+J로 하단 터미널을 열고, 보낼 출력을 드래그해 선택한 뒤 `대화에 추가`를 누르거나 Cmd+L을 누르세요.

### say플랜 모델을 say토큰으로 표시

say플랜에서 사용하는 say토큰이 새 대화와 진행 중인 대화의 모델 메뉴, 사용량 팝오버, 모델별 사용 비중 목록에 같은 이름으로 표시됩니다. AI가 모델을 하나만 제공하면 첫 메뉴에서 바로 고를 수 있습니다. 모델 메뉴의 한도 도달 안내는 한 문장으로 표시됩니다.

#### 사용 방법

새 대화의 모델 메뉴에서 say플랜 탭을 열고 say토큰을 고르세요. Sol·Luna처럼 모델이 여러 개면 해당 AI의 하위 메뉴에서 고릅니다. 이미 시작한 대화는 입력창의 모델 메뉴와 입력창 아래 say플랜 사용량에서 확인할 수 있습니다.

### say플랜에서 GPT-6.2 Sol·GPT-6.2 Astra를 고를 수 있습니다

say플랜이 등급에 주는 모델의 같은 계열 새 버전도 함께 제공합니다. Plus 이상 등급에서 GPT-6.2 Sol을, Pro·Max 등급에서 GPT-6.2 Astra를 고를 수 있습니다. 새 모델은 이전 버전과 같은 사용량 묶음에서 차감됩니다. 작업PC의 실행기가 새 모델을 지원하지 않으면 메뉴에 업데이트 필요가 표시됩니다. 이전 버전이 제공되면 ‘이전 모델’에서 고를 수 있습니다.

#### 사용 방법

홈·Chat 또는 Project의 새 대화 입력창에서 AI·모델 메뉴를 열고 맨 아래 say플랜 탭을 고른 뒤 Codex 모델 목록에서 GPT-6.2 Sol 또는 GPT-6.2 Astra를 고릅니다.

## 수정된 문제

### 개인 Chat에서 이전 메시지를 불러와도 읽던 위치가 유지돼요

개인 Chat에서 이전 메시지를 불러와도 읽던 위치가 유지됩니다. 기다리는 중에 최신 답변으로 이동하면 조회가 끝난 뒤에도 최신 위치를 유지합니다.

#### 사용 방법

개인 Chat에서 위로 스크롤해 ‘이전 메시지 더 보기’를 누르세요. 최신 위치로 돌아가려면 ‘최신 답변 보기’를 누르세요.

### 개인 Chat을 열면 최신 답변까지 내려가요

개인 Chat을 처음 열거나 다시 들어갈 때 입력창이나 본문 영역의 높이가 바뀌어도 스크롤이 최신 답변 끝까지 내려갑니다. 개인 Chat과 프로젝트 대화에서 답변이 완료되거나 위쪽 이미지가 뒤늦게 표시돼도 읽던 위치를 유지합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 게스트 비밀번호 재설정 창의 제목과 닫기 버튼 정렬을 맞췄습니다

개인 사용 중 여는 비밀번호 재설정 창에서 제목과 닫기 버튼이 같은 높이에 표시됩니다.

#### 사용 방법

개인 사용 중 계정 메뉴에서 `로그인`을 선택한 뒤 `비밀번호 찾기`를 누릅니다.

### 공간컨텐츠 작성 내용을 지켜요

편집기 바깥을 눌러도 작성 중인 내용이 유지돼요. 작성한 내용이 있을 때 닫기 전에 확인하고, 예시 불러오기를 취소할 수 있어요. 제한을 넘는 스토리 파일은 현재 입력을 유지한 채 이유를 보여 줘요.

#### 사용 방법

대시보드 맨 아래에서 **공간컨텐츠 만들기**를 누르세요. 설치가 필요하면 준비한 공간컨텐츠 확장 파일을 **로컬 파일 설치**에서 선택하세요. 새 작성 보호 기능은 공간컨텐츠 확장 0.1.1부터 제공돼요.

### 공용 작업PC에서 컴퓨터 제어를 켤 때 실제 이유 안내

공용 작업PC나 다른 사람이 등록한 작업PC에서 `이후 대화의 컴퓨터 제어 허용`을 누르면, 원인과 상관없는 "권한·Chrome 설치·확장 활성화를 확인하고 다시 시도하세요" 안내가 떠서 무엇을 고쳐야 하는지 알 수 없었습니다. 이제 컴퓨터 제어는 내가 직접 등록한 개인 작업PC나, 내가 등록하고 나에게 배정된 전용 작업PC에서만 쓸 수 있다고 정확히 알려 줍니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 기존 폴더 프로젝트도 같은 GitHub 저장소의 대화를 우선 찾습니다

기존 폴더로 만든 프로젝트에 코드 저장소 연결 정보가 비어 있으면 작업 폴더의 Git 원격을 확인합니다. 같은 GitHub 저장소를 쓰는 프로젝트는 이름이 달라도 조직의 다른 프로젝트보다 먼저 검색합니다.

#### 사용 방법

Project 대화에서 찾을 대화 제목을 AI에게 알려 주세요. 작업PC가 연결되어 원격을 확인할 수 있으면 자동으로 적용됩니다.

### 답변 속 대화 링크 열기 수정

답변에 있는 대화 링크를 누르면 같은 Saycode 창에서 해당 대화가 열립니다. 답변의 표 안에 있는 링크에도 적용됩니다.

#### 사용 방법

답변의 대화 제목 링크를 누르거나, 링크에 초점을 맞추고 Enter를 누르세요.

### 대화 안 AI가 내 다른 대화를 알아보지 못하던 문제를 고쳤습니다

Desktop에 내장된 Happy 런타임을 `1.1.10-aplus.429`로 올렸습니다. 대화 안 AI가 `happy agent`로 다른 대화를 볼 때, 내가 연 다른 대화도 "누구의 대화인지 모름"으로 표시되던 문제를 고쳤습니다. 런타임이 더 이상 쓰이지 않는 내부 표시 값을 요구해 서버에 소유 확인을 묻지 않고 있었습니다. 이제 서버가 확인해 주면, 같은 작업PC의 내 다른 대화와 연결한 다른 작업PC에서 내가 연 대화를 AI가 내 대화로 알아보고 읽거나 이어서 물을 수 있습니다. 개인 계정의 개인 작업PC에서만 적용되며, 서버의 소유 확인 기능이 켜져 있어야 합니다.

#### 사용 방법

앱을 업데이트한 뒤 작업PC 런타임이 새 버전으로 다시 시작되면 적용됩니다. 대화에서 "다른 PC에서 하던 대화 확인해서 이어서 물어봐"처럼 부탁하면 됩니다.

### 문서 작업 안내가 빠진 턴에서 Claude가 다시 시작되지 않음

Desktop은 메시지마다 문서(DOCX·PPTX·XLSX·PDF) 작업 안내를 붙이는데, 안내 파일 준비가 늦어지거나 계정 설정을 잠깐 확인하지 못하면 그 턴에는 안내가 빠졌습니다. 안내가 빠진 턴에서는 Claude가 다시 시작돼 응답 시작이 몇 초씩 늦었습니다. 이제 그런 턴에도 같은 작업 폴더라면 그 대화에서 마지막으로 쓴 안내를 그대로 붙여 Claude가 다시 시작되지 않습니다. 설정에서 안내를 끄면 모든 대화에서 바로 빠집니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 빈 응답에 남는 안내 문구 숨김

AI가 표시할 답변 없이 작업을 끝낼 때 남기던 `(No user-visible text.)`, `[No visible output]` 같은 안내 문구를 대화, 목록 미리보기, 대화 내 검색에서 숨깁니다. 프로젝트 대화의 작업 요약은 펼쳐 볼 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 사이드바 로고 옆 아이콘 정렬 개선

사이드바 로고 옆 아이콘의 크기, 색상, 간격을 맞췄습니다. 첫 아이콘은 평소 파형으로 표시되고, 입력을 기다리는 대화가 있으면 점 세 개 말풍선, 실행 중인 대화만 있으면 회전 아이콘으로 바뀝니다.

#### 사용 방법

점 세 개 말풍선이나 회전 아이콘을 누르면 입력 대기 및 실행 중인 대화 목록을 볼 수 있습니다.

### 삭제된 런타임이 온라인으로 남는 문제를 줄였습니다

앱이나 작업 공간을 옮기거나 지워 런타임 실행 파일이 2분 동안 사라지면 해당 데몬이 종료됩니다. 실행 파일이 없는 작업PC가 온라인으로 남아 대화 시작에 계속 실패하는 상황을 방지합니다.

#### 사용 방법

앱을 업데이트하고 작업PC 런타임이 새 버전으로 다시 시작되면 자동으로 적용됩니다.

### 시간 초과된 파일 검색의 작업PC 프로세스를 정리합니다

대화에서 파일 이름을 찾거나 파일 목록을 불러오다 시간이 초과되면, 작업PC에 남던 검색 프로세스와 임시 파일을 정리합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 이 컴퓨터에서 개인 사용 중에도 자식 대화를 시작할 수 있어요

이 컴퓨터에서 개인 사용 중 일반 자식 대화를 시작할 때 조직 머신 키를 요구하던 문제를 고쳤습니다.

#### 사용 방법

개인 대화에서 자식 대화를 시작하거나 작업을 맡겨 보세요.

### 컴퓨터 제어 권한 상태와 확인 오류를 구분해 안내해요

CuaDriver가 실행되지 않아 권한을 읽지 못하면 확인할 수 없는 상태로 표시합니다. OS 권한 확인 중에는 권한 상태를 따로 조회하지 않습니다. Chrome 프로필에 접근할 수 없어도 CuaDriver 상태를 확인하고 컴퓨터 제어를 설정할 수 있습니다. 등록이나 연결에서 막히면 원인에 맞는 안내를 보여 주고, 로컬 진단에는 확인 단계, 알려진 오류 코드, macOS 백그라운드 등록 명령의 종료 코드만 기록합니다.

#### 사용 방법

컴퓨터·브라우저 제어에서 CuaDriver 실행을 확인할 수 없다는 안내가 보이면 OS 권한 확인을 누르세요. 실패하면 화면 안내를 확인하거나 문제 해결에서 진단 정보를 저장할 수 있습니다.

### macOS 권한을 확인할 수 없어도 CuaDriver 아이콘을 끌어 놓을 수 있어요

컴퓨터 제어에서 macOS 권한 상태를 읽지 못해도 설치된 CuaDriver를 시스템 설정에 추가할 수 있도록 드래그 안내를 표시합니다.

#### 사용 방법

`확인할 수 없음`이 표시된 권한 줄에서 `시스템 설정 열기`를 누르고, 화면 오른쪽 아래의 CuaDriver 아이콘을 열린 권한 목록으로 끌어 놓으세요.

### Saycode 실행 파일이 지워진 작업PC에서 대화 시작 실패 안내 개선

Saycode 앱을 다른 폴더로 옮기거나 지운 뒤에도 그 앱이 띄운 작업PC 연결이 남아 있으면, 대화를 시작하거나 이어갈 때 내부 파일 경로가 담긴 오류만 보였습니다. 이제 어느 작업PC의 실행 파일이 지워졌는지와 앱을 다시 실행하라는 안내를 보여 줍니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 안내가 보이면 해당 작업PC를 연결한 Saycode 앱을 다시 실행한 뒤 대화를 시작해 주세요.
