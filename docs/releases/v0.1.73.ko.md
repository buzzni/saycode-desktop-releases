## 새 기능

### 대화 이미지를 한 화면에서 넘겨 보고 복사·저장

대화 속 이미지(AI 도구가 보여 준 이미지와 내가 보낸 이미지 첨부)를 하나의 크게 보기 화면에서 차례로 넘겨 볼 수 있습니다. 화면 위에 지금 위치(예: 2 / 5)가 보이고, 이미지를 클립보드에 복사하거나 내 PC에 저장할 수 있습니다. PNG가 아닌 이미지도 복사할 때 PNG로 바꿔 넣습니다. 지금 화면에 불러온 메시지의 이미지만 포함하며, `이전 메시지 보기`로 더 불러오면 함께 넘겨 볼 수 있습니다.

#### 사용 방법

대화에서 이미지 썸네일이나 보낸 이미지 첨부 이름을 누르면 크게 보기가 열립니다. 왼쪽/오른쪽 화살표 키나 양옆 버튼으로 넘기고, 위쪽의 복사·저장 버튼을 씁니다. 보낸 첨부는 `파일 열기`로 기존 파일 보기에서도 열 수 있습니다. Esc를 누르면 닫히고 처음 누른 자리로 돌아갑니다.

### 사용량 한도에 막힌 요청을 한도가 풀리는 시각에 다시 보내도록 예약할 수 있습니다

가장 최근 답변이 사용량 한도 오류로 끝나면 그 줄에 **"{시각}에 다시 시도"** 버튼이 생깁니다. 누르면 남은 시간이 보이고, 한도가 풀리는 시각에 같은 요청을 한 번 다시 보냅니다. 리셋 시각은 AI 잔여량 표시가 켜져 있으면 그 사용량 정보로, 아니면 오류 문구에 적힌 시각으로 정합니다.

#### 사용 방법

한도 오류 줄에서 "{시각}에 다시 시도"를 누릅니다. 예약은 이 대화를 열어 두는 동안만 유지되고, 예약 취소를 누르거나 다른 메시지를 보내거나 대화를 떠나거나 앱을 닫으면 취소됩니다. 리셋 시각을 알 수 없거나 약 24일보다 먼 경우에는 버튼이 나타나지 않습니다.

### 예약 결과와 실패를 메신저로 받기

예약이 끝나면 답변 앞부분(최대 1,500자)을, 실패하면 이유 한 줄을 페어링한 Telegram·Slack 대화로 받을 수 있습니다. 결과는 페어링한 사람과의 개인 대화(Telegram 개인 대화, Slack DM)로만 가고 그룹·채널로는 가지 않습니다. 앱을 꺼 두어도 예약을 실행한 PC가 직접 보냅니다. 같은 이유로 계속 실패하면 처음 한 번 알리고, 그 뒤에는 하루에 한 번만 다시 알립니다. 성공하거나 실패 이유가 바뀌면 처음부터 다시 셉니다. 메신저로 가는 것은 예약 이름·답변 앞부분·실패 이유뿐이고, 도구 출력이나 비밀값은 보내지 않습니다. 답변은 Claude 대화만 보내고 다른 AI의 대화는 실패 알림만 받습니다.

#### 사용 방법

예약 → 새 예약(또는 행의 더보기 → 편집) → 고급에서 `결과 보내기`로 받을 대화를 고르고, `실패 알림`은 `결과와 같은 곳`이나 다른 대화를 고른 뒤 저장합니다. 둘 다 처음에는 꺼져 있습니다. 예약을 실행하는 PC에서 동작 중인 메신저 연결만 고를 수 있고, 그 PC의 Saycode가 이 기능을 지원해야 합니다. 회사의 공유·전용 PC에서는 아직 고를 수 없습니다. 다른 기기가 받고 있는 연결은 고를 수 없고 `메신저 설정에서 옮기기`로 안내합니다. 대화를 이어 가지 않는 예전 예약은 `실패 알림`만 고를 수 있습니다. 이전 버전 앱이나 대화 속 예약 도구로 예약을 고치면 이 설정이 꺼질 수 있으니 다시 켜 주세요.

### 일시적인 API 오류의 자동 재시도를 남은 시간과 함께 보여 주고 취소할 수 있습니다

Claude가 일시적인 API 오류(503·529·시간 초과 등)로 답을 시작하지 못하면 작업PC가 잠시 뒤 자동으로 다시 시도합니다. 이제 대화 안 안내 줄에 "일시적 API 오류(503) — 자동으로 다시 시도해요 (1/5)"가 보이고, 그 아래에 다시 시도까지 남은 시간이 1초마다 줄어듭니다. **취소**를 누르면 대기 중인 재시도만 멈추고 AI는 그대로 대기합니다. 취소했거나 작업PC가 재시도하지 못하면 안내 줄이 "자동 재시도를 멈췄어요"로 바뀌고 실패 원문과 **다시 시도** 버튼이 보입니다. 실패한 시도마다 남던 "API Error" 원문 줄은 안내 줄로 합쳐 보이고, 끝내 포기한 마지막 실패의 원문은 그대로 남습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 재시도를 멈추려면 안내 줄 아래 취소를 누르거나 새 메시지를 보냅니다. 작업PC의 happy-cli가 자동 재시도를 지원해야 보입니다.

### 편집한 파일에 마우스를 올리면 변경 일부 미리보기

AI가 편집한 파일 목록에서 파일 이름에 마우스를 잠시 올리거나 키보드로 이동하면, 작은 카드에 첫 변경 부분이 몇 줄 보입니다. 전체 diff 창을 열지 않아도 무엇이 바뀌었는지 훑어볼 수 있습니다. 누르면 지금처럼 전체 변경을 엽니다.

#### 사용 방법

대화의 `파일 N개를 편집했습니다` 카드를 펼친 뒤 파일 이름 위에 마우스를 올리거나 Tab 키로 이동합니다. Esc를 누르면 카드가 닫힙니다. 터치 화면에서는 카드 없이 누르면 바로 전체 변경이 열립니다.

## 수정된 문제

### 조직 AI 자동 공유를 기다리며 연결해요

시작준비에서 조직 키 자동 배포를 기다리는 동안 실패 대신 AI 연결 중으로 표시합니다. 최대 5분 동안 10초마다 공유 여부를 확인하고 키를 받으면 자동으로 연결을 다시 시도합니다. 시간이 지나면 지연 안내와 다시 확인을 제공합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 기다리지 않으려면 나중에 하기를 누르고, 시간이 지난 뒤에는 다시 확인하거나 홈으로 갈 수 있습니다.
