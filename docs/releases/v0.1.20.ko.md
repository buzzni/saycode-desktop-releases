## 새 기능

### 미리보기를 설정하지 않은 프로젝트에서도 포트포워딩

원격 머신에서 실행 중인 포트를 프로젝트 채팅 화면 상단 배지로 보여주고, 클릭 한 번으로 내 컴퓨터에서 열 수 있는 터널을 만듭니다. 이전에는 미리보기 포트를 등록해 둔 프로젝트에서만 "로컬로 열기" 영역이 나타나서, 이미 직접 서버를 띄워 둔 프로젝트에서는 포트포워딩 기능 자체가 화면에 보이지 않았습니다.

#### 사용 방법

프로젝트 채팅 화면 상단의 포트 배지를 누르면 터널이 열립니다. 미리보기 탭을 열어두지 않아도 되고, 미리보기 포트를 등록하지 않은 프로젝트에서도 동작합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/348)

## 변경된 기능

### 포트 배지를 누르면 내 컴퓨터의 브라우저도 함께 열림

포트 배지를 눌러 터널이 연결되면 앱 안의 브라우저 패널뿐 아니라 사용 중인 컴퓨터의 기본 브라우저에서도 해당 주소가 새 탭으로 열립니다. 이전에는 앱 안에서만 조용히 열려서 포트포워딩이 실제로 되었는지 확인하기 어려웠습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 터널 연결에 성공한 경우에만 브라우저가 열립니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/349)
