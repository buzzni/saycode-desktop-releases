## 수정된 문제

### 왼쪽 상단 로고로 창을 이동할 수 있습니다

macOS에서 왼쪽 상단 사이드바 로고 아이콘을 드래그해 앱 창을 이동할 수 있게 했습니다. 워드마크를 눌러 홈으로 이동하는 기존 동작은 유지합니다.

#### 사용 방법

왼쪽 상단의 로고 아이콘을 누른 채 원하는 위치로 끌어 창을 이동하세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1510)

### Windows 조직 setup-token 연결 실패 원인을 바로잡습니다

Windows에서 일반 `cswap`가 설치되어 있으면 조직 setup-token 연결을 지원하지 않는데도 CLI가 준비된 것으로 표시될 수 있었습니다. 이제 Saycode setup-token capability를 실제로 확인하고, 지원하지 않는 runtime은 Happy가 고정한 runtime을 설치한 뒤 다시 검증합니다. 연결 상태도 setup-token runtime, Desktop daemon, 전용 머신 문제를 구분해 안내합니다.

#### 사용 방법

Desktop을 업데이트한 뒤 조직 AI 연결에서 다시 시도하세요. 기존 runtime이나 credential은 자동으로 강제 교체하지 않습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1509)

### Windows에서 브라우저 제어 연결 안내 개선

Windows에서 브라우저 제어를 처음 연결할 때 Saycode가 Native Messaging 연결과 Cua Driver 상태를 단계별로 확인합니다. 확장 프로그램, Native host, Cua Driver daemon 또는 운영체제 권한 중 어디에서 준비가 멈췄는지 화면에 구체적으로 표시하고, 필요한 경우 Cua Driver daemon을 다시 시작합니다.

#### 사용 방법

Saycode의 컴퓨터 제어 온보딩에서 브라우저 연결을 선택하면 안내된 확장 프로그램 설치와 운영체제 권한 승인을 완료한 뒤 다시 시도합니다. 별도 설정 없이 준비된 항목은 자동으로 확인됩니다.
