## 변경된 기능

### 장시간 반복 작업의 실행 기반 개선

내장 Happy runtime을 갱신해 서버가 관리하는 반복 작업을 에이전트 머신에서 계속 처리할 수 있는 실행 기반을 포함합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 반복 리뷰의 Desktop 화면 연동은 별도 업데이트에서 제공됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/800)

## 수정된 문제

### 앱을 종료해도 반복 리뷰 계속 실행

최신 상시 실행 에이전트가 연결된 프로젝트에서는 반복 셀프 리뷰를 시작한 뒤 Desktop 앱을 완전히 종료해도 남은 리뷰 라운드가 계속 실행됩니다. 앱을 다시 열면 현재 라운드와 완료 상태를 복원하며, 기존 환경에서는 앱이 실행 중일 때 이어지는 방식으로 자동 호환됩니다.

#### 사용 방법

리뷰 화면에서 현재 에이전트 리뷰의 반복 횟수를 2회 이상 선택해 시작하세요. 상시 실행 에이전트가 최신 버전이면 별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/804)
