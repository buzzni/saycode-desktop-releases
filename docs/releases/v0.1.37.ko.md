## 새 기능

### 대화를 다른 에이전트로 이어가기

진행 중인 대화의 맥락을 그대로 담아 다른 에이전트(Claude ↔ Codex 등)로 새 대화를 시작할 수 있습니다. 새 대화는 원래 대화와 같은 작업 폴더에서 시작하고, 원래 대화는 그대로 남습니다. 넘길 범위는 "최근 대화만"과 "대화 전체" 중에 고를 수 있으며, 전체를 고르면 대화 기록이 작업 폴더에 파일로 저장되고 새 에이전트가 그 파일을 읽고 이어서 작업합니다.

#### 사용 방법

대화 헤더 오른쪽의 이어가기(갈림길) 아이콘을 누릅니다. 헤더가 좁으면 더보기(⋯) 메뉴 안에 있습니다. 이어받을 에이전트와 넘길 대화 범위를 고른 뒤 "이어가기"를 누릅니다. 사용할 수 있는 에이전트는 그 머신의 로그인·설치 상태에 따라 표시됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/619)

데스크탑 로그인 화면에는 로그인 폼만 있어, 계정이 없는 사람이 처음 앱을 켜면 다음에 무엇을 해야 하는지 알 수 없었습니다. 회원가입과 회사 조직 참여는 모두 saycode.ai 웹에서만 가능하지만 그 사실이 어디에도 적혀 있지 않았습니다.

### 프로젝트 목록에서 바로 삭제 · 사이드바 조직 홈 버튼

프로젝트 삭제가 "프로젝트 설정 → 삭제"에만 있어 찾기 어려웠습니다. 이제 조직 홈의 프로젝트 카드에서 곧바로 삭제할 수 있습니다. 삭제 아이콘은 내가 소유한 프로젝트 카드에만 나타나며, 누르면 프로젝트 이름을 다시 확인하는 창이 뜹니다. 확인해야만 삭제되고, 실패하면 창이 닫히지 않고 이유를 보여줍니다. 기존 설정 화면의 삭제도 그대로 남아 있습니다.

#### 사용 방법

조직 홈의 "최근 프로젝트" 카드에서 제목 오른쪽 휴지통 아이콘을 누르고, 확인 창에서 "삭제"를 선택하세요. 조직 홈으로 이동하려면 사이드바 조직 이름 오른쪽의 집 모양 버튼을 누르세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/608)

### 한 프로젝트에 관련 디렉터리 추가하기

한 프로젝트의 작업이 폴더 하나로 끝나지 않는 경우가 많습니다. 예를 들어 앱 코드는 이 프로젝트에 있지만 배포 설정은 `k8s-manifests` 같은 다른 저장소에 있습니다. 지금까지는 매번 Claude에 `/add-dir`를 치거나 `.claude/settings.local.json`을 손으로 고쳐야 했고, 그 방법은 Claude에서만 통했습니다.

#### 사용 방법

프로젝트를 연 뒤 사이드바에서 "프로젝트 파일" 탭을 선택하고, "추가 디렉터리" 오른쪽의 폴더 추가 버튼을 누릅니다. 폴더를 고른 다음 용도(예: "배포 매니페스트")를 적고 읽기 전용 또는 읽기·쓰기를 선택해 등록하세요. 등록을 되돌리려면 목록에서 해당 항목 오른쪽의 × 버튼을 누릅니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/614)

### GitHub 이슈 열림 트리거와 모델 지정, 이슈 해결 프리셋

프로젝트 설정 "실행 → GitHub 트리거"에서 **이슈 열림** 이벤트에도 트리거를 걸 수 있습니다. 세션을 시작하는 트리거에는 실행 에이전트(Claude/Codex/opencode/Grok)에 더해 **모델과 추론 강도(effort)**를 지정할 수 있습니다. 새 이슈가 열리면 이슈를 분석해 코드를 수정하고, 스스로 리뷰를 최대 5회 반복한 뒤(medium 이상 문제가 없어질 때까지) PR을 올리는 **"이슈 해결 → PR" 프리셋**이 기본 제공됩니다. PR 본문에는 셀프 리뷰 라운드별 발견·개선 내역과 남은 리스크가 함께 남습니다.

#### 사용 방법

프로젝트 설정 → 실행 → GitHub 트리거에서 "트리거 추가"를 누르고 이벤트를 "이슈 열림"으로 선택하거나, 프롬프트 템플릿의 "이슈 해결 → PR" 프리셋 버튼을 누릅니다. 액션이 "세션 시작"일 때 에이전트 아래에서 모델과 추론 강도를 고를 수 있습니다(모델 지정 시 신규 런타임부터 첫 턴에 적용).

### 로컬 전용 모드에서 "내 채팅" 숨김

로컬 전용(standalone) 모드에서 "내 채팅" 화면에 붉은 오류 메시지가 항상 떠 있었습니다. "내 채팅"은 saycode.ai 서버에서만 동작하는 기능인데, 로컬 전용 모드의 내장 서버에는 그 기능이 없어 목록 조회도 새 채팅 만들기도 실패하던 상태입니다. 게다가 "내 채팅"이 앱의 기본 시작 화면이라, 로컬 전용 모드에서는 앱을 켤 때마다 이 화면에 떨어졌습니다.

#### 사용 방법

로컬 전용 모드로 실행하면 사이드바에 "내 채팅"이 나타나지 않고, 앱을 켜면 프로젝트 목록에서 시작합니다. 로컬 전용 모드의 시작 설정은 환경설정의 "온보딩 다시 보기"에서 열 수 있습니다.
