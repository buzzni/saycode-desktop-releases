## 새 기능

### 알림 소리

에이전트가 입력을 기다릴 때와 작업을 끝냈을 때 서로 다른 소리로 알려 줍니다. 입력 요청 소리는 해당 대화를 보고 있어도 울리고, 완료 소리는 화면을 보고 있지 않을 때만 울립니다. 완료 소리는 잠깐 기다렸다가 그 사이 대화를 열어 보거나 새 작업이 시작되면 울리지 않습니다.

#### 사용 방법

설정의 알림 화면에서 입력 요청 소리와 완료 소리를 각각 켜고 끕니다. 처음에는 입력 요청 소리만 켜져 있습니다. 특정 대화의 소리만 끄려면 대화 오른쪽 위 더보기 메뉴에서 알림 소리 끄기를 선택하고, 프로젝트 전체를 끄려면 프로젝트 설정에서 끕니다. 모든 소리를 한 번에 끄려면 설정의 알림 소리 전체 끄기를 사용합니다. 현재 소리 재생은 macOS에서만 동작합니다.
