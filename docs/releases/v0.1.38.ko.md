## 새 기능

### 답변 안에서 바로 보는 HTML 미리보기

에이전트가 만든 HTML 파일을 대화 답변 안에서 바로 볼 수 있습니다. 답변에 `::preview{file="..."}` 한 줄이 있으면 그 자리에 파일 내용이 **살아 있는 화면**으로 그려집니다 — 차트나 버튼처럼 문서 안에서 동작하는 내용도 그대로 움직이고, 미리보기 높이는 내용에 맞춰 자동으로 맞춰집니다. 미리보기는 격리된 영역에서 열리므로 앱의 로그인 정보나 저장된 데이터에 접근하지 못하고, 외부 네트워크로 나가지도, 다른 주소로 빠져나가지도 못합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 에이전트가 답변에 미리보기 줄을 넣으면 답변이 끝난 뒤 그 자리에 화면이 나타납니다. HTML이 아닌 파일이거나 파일을 읽지 못하면 대신 파일 카드가 표시되고, 카드를 누르면 기존 파일 뷰어로 열립니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/689)

### 대화 실패 원인과 복구 버튼 안내

대화가 실패했을 때 오류 원문만 덩그러니 남던 화면이 바뀝니다. 어느 단계에서 실패했는지 "Provider 오류 / 런타임 오류 / 인증 오류" 배지로 알려 주고, 그 자리에서 바로 할 수 있는 조치를 함께 보여 줍니다. 다시 시도해서 해결될 수 있는 실패에는 다시 시도 버튼이, 인증 문제에는 자격증명 설정을 여는 버튼이 붙습니다. 자격증명을 고치기 전에는 같은 실패가 반복되므로 인증 오류에는 다시 시도를 권하지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 프로젝트 대화와 내 채팅 양쪽에서 동일하게 보입니다. 다시 시도 버튼은 실패 직전에 보냈던 요청을, 지금 고른 모델 설정 그대로 다시 보냅니다. 대화가 응답 중이거나 다른 조직에서 만들어진 대화라면 보내기와 마찬가지로 다시 시도도 잠깁니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/690)

### Standalone 프로젝트의 새 대화와 Worktree 복구

로그인하지 않고 사용하는 Standalone 모드에서도 프로젝트를 연 뒤 새 대화와 Git Worktree를 만들고, 기존 대화와 Worktree를 다시 불러오거나 삭제할 수 있습니다. 로그인 서버 전용 기능은 사용할 수 없는 메뉴를 숨기거나 안내를 표시하고, 숨겨진 Preview·Memory Layer background 요청도 시작 전에 차단해 반복 404가 남지 않습니다. 환경변수를 모두 지웠을 때 기존 `.env` 파일의 값이 남는 문제와 Intel Mac에서 로컬 서버가 잘못된 Prisma 엔진을 찾는 문제도 함께 수정했습니다.

#### 사용 방법

Standalone 모드에서 로컬 Git 프로젝트를 연 뒤 평소처럼 새 대화를 시작합니다. 로그인과 클라우드 연결이 필요한 기능은 로그인 모드에서 사용할 수 있습니다.
