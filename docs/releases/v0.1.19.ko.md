> 이 문서는 첫 배포인 v0.1.0(2026-06-25)부터 v0.1.19까지 쌓인 기능을 영역별로 묶은 요약입니다.
> 버전별 개별 문서는 v0.1.20부터 제공됩니다.

## 새 기능

### 대화와 작업 공간

여러 대화를 탭으로 열고, 채팅·터미널·브라우저를 좌우 또는 상하로 분할해 함께 볼 수 있습니다. 분할은 단축키와 우클릭으로도 실행되고, 패널 크기를 원래대로 되돌리는 균등화 버튼이 있습니다. 단축키는 설정에서 직접 바꿀 수 있습니다.

대화마다 별도의 작업 사본(worktree)에서 작업할 수 있고, 최근에 고른 작업 사본을 기억합니다. 오래되었거나 병합이 끝난 작업 사본은 자동으로 정리합니다.

### 에이전트 보드

여러 대화의 진행 상태를 한 화면에서 칸반 형태로 보고 관리합니다. 카드에서 바로 지시를 보내고, 응답 중인 최신 메시지를 확인하고, 완료 처리를 해제해 이어서 작업할 수 있습니다. 보드 전용 단축키와 세션 검색을 제공합니다.

오토파일럿을 켜면 작업 완료 이후 독립 리뷰까지 자동으로 진행하고, 지적 사항이 없을 때만 Commit & PR을 실행합니다. 필요할 때 끌 수 있습니다.

### 코드 리뷰와 작업 마무리

작업한 변경 사항을 별도의 에이전트에게 맡겨 독립적으로 리뷰받을 수 있습니다. 서브모듈 안의 변경과 작업 사본이 없는 대화도 리뷰 대상이 됩니다. 리뷰 결과는 항목별로 골라 수정 요청으로 보낼 수 있고, 전달·적용 상태가 표시됩니다. 리뷰와 Commit & PR은 작업 마무리 허브 하나로 모았습니다.

### 미리보기와 내장 브라우저

앱 안에서 만든 결과물을 바로 볼 수 있는 브라우저 패널이 있습니다. 원격 머신에서 실행 중인 포트를 자동으로 찾아 후보로 보여주고, 내 컴퓨터에서 열 수 있는 localhost 터널을 연결합니다. 모바일 화면 크기와 터치 동작을 흉내 내는 뷰포트 프리셋, 시스템 브라우저의 쿠키 가져오기, 별도 창으로 띄우기를 지원합니다.

### 프로젝트 만들기와 배포

빈 프로젝트, Git 저장소, 이미 있는 폴더 중에서 고를 수 있고, 검증된 시작점을 모은 템플릿 갤러리와 첫 프롬프트 자동 입력을 제공합니다. GitHub·GitLab 계정을 연결하면 저장소를 목록에서 골라 가져올 수 있습니다.

배포가 끝나면 주소를 카드로 보여주고 바로 복사할 수 있습니다. 조직 홈에서는 조직이 배포한 서비스를 한눈에 봅니다. 프로젝트 설정에서 MCP 연결과 환경변수 그룹을 관리합니다.

### 검색과 메모리

모든 대화의 본문을 이 컴퓨터 안의 색인으로 검색합니다. 의미 기반 검색도 함께 제공하며, 실패한 경우 이유를 화면에 표시합니다. claude-memory-layer와 연동해 과거 작업 맥락을 불러옵니다.

### 알림

작업이 끝나거나 입력이 필요할 때 알림함과 OS 알림으로 알려줍니다. macOS에서는 알림의 버튼으로 바로 답할 수 있습니다. 다른 조직의 알림을 누르면 그 조직으로 전환해 열고, 앱을 재시작해도 알림 기록이 유지됩니다.

### 음성 입력과 파일 작업

말하는 대로 실시간으로 받아 적는 음성 입력을 지원합니다. 프로젝트 파일 탐색기에서 이름 변경, 복사본 만들기, 삭제, 새 파일·폴더 만들기, 업로드와 드래그 앤 드롭을 할 수 있고, 마크다운과 HTML은 미리보기로 렌더링됩니다.

### 모델과 사용량

기본적으로 Opus로 진행하다가 작업이 막혔을 때만 상위 모델로 올리는 방식으로 비용을 줄입니다. 새 대화에서 Opus 5를 고를 수 있고, 서비스별 사용량을 아이콘으로 표시합니다. 새 대화 화면에는 로그인되어 실제로 쓸 수 있는 에이전트만 나타납니다.

### 조직 관리와 커넥터

조직 관리 콘솔과 슈퍼 관리자 콘솔을 앱 안에서 사용합니다. Notion과 Slack을 커넥터로 연결해 대화 중 참고할 수 있습니다.

## 변경된 기능

### 설치와 업데이트

Apple Silicon과 Intel(x64) Mac을 모두 지원하는 서명·공증된 DMG를 배포합니다. DMG 파일 이름에 버전이 들어가 오래된 설치본을 잘못 설치하는 일을 막습니다. 새 버전이 나오면 사이드바와 Dock 배지로 눈에 띄게 알리고, 앱 안에서 내려받아 재시작으로 설치합니다.

### 용어와 화면 정리

영어 전문용어를 한글로 통일하고 용어집을 정리했습니다. 사이드바를 자주 사용·최근으로 나누고 대화·프로젝트 모드를 분리했으며, 상단 영역의 중복된 도구모음을 탭 스트립으로 합쳤습니다.

## 수정된 문제

### 성능과 안정성

창을 여러 개 띄우고 오래 사용할 때 메모리가 급격히 늘어나던 문제, 앱이 배경에서 서버에 과도한 요청을 보내던 문제, 원격 터미널을 닫아도 프로세스가 남던 문제를 수정했습니다. 화면에 보이지 않는 창의 갱신과 애니메이션을 낮춰 전체 부하를 줄였습니다.

### 그 밖의 수정

완료된 대화를 다시 이어갈 때 대화가 중복 생성되던 문제, 계획 승인 후 승인 요청이 다시 뜨던 문제, 알림을 확인해도 알림함에서 사라지지 않던 문제, 배포할 파일을 찾지 못한다는 오류, 패키징된 앱에서 일부 구성 요소가 빠져 실행되지 않던 문제 등을 수정했습니다.
