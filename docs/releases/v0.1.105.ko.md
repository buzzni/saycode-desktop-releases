## 변경된 기능

### 라이트 테마에서 우측 패널 터미널도 밝은 색으로 표시

라이트 테마에서도 우측 작업 패널의 터미널은 늘 어두운 색이었습니다. 이제 하단 터미널처럼 앱 테마를 따라 라이트 테마에서는 흰 바탕의 밝은 터미널로 표시하고, 터미널 상태 줄과 분할 탭도 같은 색을 씁니다. 다크 테마는 이전과 같습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 내 계정 메뉴의 `다크 모드`를 끄면 우측 패널 터미널도 밝게 바뀝니다.

### 시작 화면에서 프로젝트 대화를 시작하면 바로 새 탭에서 진행 상태가 보입니다

시작 화면의 Project 탭에서 프로젝트를 골라 보내면, 대화가 만들어질 때까지 입력창에서 기다리지 않고 바로 그 프로젝트의 새 탭이 열립니다. 첫 메시지 아래에 `대화를 준비하는 중`, `채팅 시작 중`이 차례로 보이고, 다른 화면에 갔다 돌아와도 그 상태가 남습니다. 시작 화면 입력창은 바로 비워져 다른 대화를 이어서 시작할 수 있습니다. Build로 새 프로젝트를 시작할 때도 새 프로젝트 탭에서 같은 단계가 보입니다.

#### 사용 방법

시작 화면에서 Project 탭을 열고 입력창 아래 줄의 프로젝트 선택에서 프로젝트를 고른 뒤 보냅니다. 실패하면 그 탭에서 다시 시도를 누릅니다.

## 수정된 문제

### 개인 ChatGPT 계정 Codex에서 새 모델이 거절되면 Codex를 자동으로 업데이트

개인 ChatGPT 계정으로 연결한 Codex의 버전이 오래되면(0.166.0 미만) GPT-6.2 Sol·GPT-6.2 Astra가 "현재 AI에서 사용할 수 없는 모델이에요" 오류로 거절되고, 버전이 맞지 않을 때 나와야 할 자동 업데이트도 동작하지 않았습니다. 이제 이 경우 "Codex CLI가 오래되어 자동 업데이트 중입니다" 안내와 함께 작업 PC의 Codex를 업데이트하고 같은 요청을 한 번 다시 보냅니다. Codex가 이미 최신인데도 거절되면 요금제 문제로 보고 업데이트하지 않습니다.

#### 사용 방법

앱을 업데이트한 뒤 작업 PC의 런타임이 다시 시작되면 자동으로 적용됩니다.

### 조직의 UltraFast 기본 모델을 새 대화에 적용

조직이 DeepSeek V4.1 Flash UltraFast를 기본으로 지정하면, Plus 이상 구성원이 지원 작업PC에서 새 say플랜 대화를 시작할 때 적용합니다. 직접 고른 모델이 우선합니다. 대화 AI 목록에서 숨긴 AI의 모델은 기본으로 적용하지 않습니다.

#### 사용 방법

새 대화의 AI·모델 메뉴에서 say플랜을 선택합니다. Basic 또는 UltraFast를 지원하지 않는 작업PC에서는 조직이 함께 제공한 호환 모델을 사용할 수 있습니다.

### 하단 터미널이 패널을 채우지 않아 클릭이 안 먹고 입력 중 화면이 지워지던 문제 수정

연결된 하단 터미널이 패널 높이를 다 채우지 못하고 작게 줄어들 수 있었습니다. 그래서 글자가 그려진 줄을 정확히 눌러야만 입력 커서가 잡혔고, 특히 Windows에서는 연결 안내가 나타났다 사라질 때 터미널 크기가 바뀌면서 입력 중 화면이 지워지고 처음 상태로 돌아가는 것처럼 보였습니다. 이제 하단 터미널은 항상 패널 전체를 채우고, 터미널 안 아무 곳이나 눌러도 입력 커서가 잡힙니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### Windows 작업 PC에서도 파일 내용 검색 지원

Windows 작업 PC에서는 프로젝트 파일 내용 검색이 동작하지 않았습니다. 이제 Mac처럼 Windows 작업 PC에서도 파일 내용을 검색할 수 있습니다. 링크·정션으로 프로젝트 밖 파일에 닿는 경로는 검색하지 않습니다.

#### 사용 방법

앱을 업데이트한 뒤 작업 PC의 런타임이 다시 시작되면 자동으로 적용됩니다.
