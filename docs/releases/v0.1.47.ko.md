## 수정된 문제

### 끊은 메신저 연결이 혼자 되살아나 다시 수신하던 문제

메신저 채널 연결이 소유권을 잃으면 앱이 그 소유권을 반납합니다. 반납이 진행 중일 때 연결 끊기(또는 앱 종료)가 도착하면, 끊기 요청은 반납 중인 연결을 찾지 못해 아무것도 하지 못했고 반납이 끝난 뒤 연결이 스스로 소유권을 다시 가져와 수신을 재개했습니다. 사용자가 끊은 채널이 최대 1분 뒤 혼자 되살아났습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

#### 사용 방법

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1039)

### 로컬 서버 시작 실패 원인을 더 정확하게 표시합니다

로컬 서버가 강제 종료됐을 때 종료 원인을 표시하고, 재시도할 때 이전 오류가 반복해서 붙지 않도록 수정했습니다. 개발용 서버 런타임 빌드에도 실행 파일 서명 검증을 추가했습니다.

#### 사용 방법

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1022)
