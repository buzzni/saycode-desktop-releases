## 새 기능

### 머신 플러그인 관리 패널과 컴포저 슬래시 자동완성

채팅 입력창에서 `/`를 입력하면 사용할 수 있는 명령이 자동완성으로 나타납니다. 그중 `/plugin`은 연결된 머신에 설치된 플러그인 목록을 읽어 켜고 끌 수 있는 관리 패널을 엽니다. 터미널에서만 쓸 수 있던 플러그인 관리를 앱 안에서 처리할 수 있습니다.

#### 사용 방법

채팅 입력창에 `/`를 입력해 명령을 고르거나, `/plugin`을 입력해 플러그인 관리 패널을 엽니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/360)

### 반복 작업 자동화와 GitHub 이벤트 트리거

정해진 시각이나 주기에 에이전트를 자동으로 실행하는 예약 자동화와, GitHub PR 이벤트(열림, 리뷰 준비, 병합, 닫힘)에 반응해 알림을 보내거나 세션을 시작하는 트리거를 추가했습니다. 감시 스크립트를 먼저 실행해 조건에 맞을 때만 에이전트를 깨우는 방식이라, 아무 일도 없을 때는 세션이 만들어지지 않습니다. 지난 예정은 소급 실행하지 않고, 이전 실행이 진행 중이면 건너뛰며, 연속 3회 실패하면 자동으로 일시정지하고 알려줍니다.

#### 사용 방법

프로젝트 설정의 자동화 및 GitHub 트리거 섹션에서 등록합니다. 실행 결과는 완료 알림함에서 확인합니다. 앱이 켜져 있는 동안 동작합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/353)

### 프로젝트 Memory Hub

프로젝트 상세 화면에서 그 프로젝트에 쌓인 메모리를 볼 수 있는 Memory Hub를 추가했습니다. 프로젝트별 메모리 이벤트와 동기화 상태, 최근 7일 유용성 지표를 보여주고, 검색 결과에서 연결된 대화를 바로 열 수 있습니다.

#### 사용 방법

프로젝트 상세 화면에서 Memory Hub 진입점을 누릅니다. 전체 대시보드로 이동하는 링크도 함께 제공됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/357)

### Google Drive·Gmail 커넥터

기존 Notion·Slack 커넥터에 이어 Google Drive와 Gmail을 연결할 수 있습니다. 연결하면 대화 중 에이전트가 해당 서비스의 내용을 참고할 수 있습니다.

#### 사용 방법

환경설정의 커넥터에서 Google Drive 또는 Gmail을 선택해 연결합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/361)

### KNOI API Key 커넥터

KNOI를 API key로 연결할 수 있습니다. 키 입력·교체·해제를 지원하고, 회의 요약을 바로 시작할 수 있는 프롬프트를 함께 제공합니다.

#### 사용 방법

환경설정의 커넥터에서 KNOI를 선택하고 API key를 입력합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/362)

## 변경된 기능

### 자동 업데이트를 주기적으로 다시 확인

앱을 켠 직후 한 번만 하던 업데이트 확인을 4시간마다 백그라운드에서 다시 하고, 창을 다시 활성화할 때도 최소 30분 간격으로 확인합니다. 앱을 오래 켜두어도 새 버전을 놓치지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/351)

### 추천 질문이 표시되지 않는 이유를 입력창에 안내

답변 뒤에 뜨던 추천 질문이 사라지는 경우가 있었는데, 원인은 계정의 최근 사용량이 경고 임계를 넘으면 추천 생성이 건너뛰어지기 때문이었습니다. 이제 그 상태일 때 입력창에 이유를 표시해, 기능이 고장난 것인지 사용량 때문인지 알 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/352)

보드에서 질문이나 계획 승인에 답한 뒤에도 카드가 계속 입력 대기 상태로 표시되던 문제를 수정했습니다. 응답이 처리되면 해당 카드가 응답 중 상태로 바르게 넘어갑니다.
