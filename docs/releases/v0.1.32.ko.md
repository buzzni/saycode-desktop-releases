## 새 기능

### 오래된 작업 사본 안전 정리

대기 상태로 남은 오래된 작업 사본(worktree)을 만든 시각과 마지막 대화 활동을 기준으로 자동 정리합니다. 작업 사본 관리 창에서는 삭제 가능한 항목을 미리 검사한 뒤 한 번에 정리할 수 있고, 삭제·보호·실패 결과를 함께 보여줍니다. 잠겨 있거나, 활성·응답 중·입력 대기 중인 대화에 연결되어 있거나, 열린 PR이 있거나, 커밋·푸시하지 않은 변경이 남아 있거나, 머신이 오프라인이라 확인할 수 없으면 삭제하지 않습니다. 브랜치는 지우지 않습니다.

#### 사용 방법

작업 사본 관리 창에서 일괄 정리를 실행합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/469)

### 이미지 파일 미리보기

오른쪽 파일 뷰어에서 이미지를 볼 수 있습니다. PNG, JPG, GIF, WebP, BMP, AVIF, SVG, ICO를 지원하고, 이미지는 비율을 유지한 채 뷰어 크기에 맞춰 표시되며 작은 이미지를 억지로 확대하지 않습니다.

#### 사용 방법

프로젝트 파일이나 내 채팅 파일에서 이미지를 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/468)

### Codex 백그라운드 작업 상태를 채팅에 표시

Codex가 배경에서 실행하는 작업의 진행 상태를 채팅 안 카드로 보여줍니다. 같은 작업의 갱신은 카드 하나에 모아 표시하고, 대화를 다시 열어도 같은 모습으로 복원됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/466)

## 변경된 기능

### 새 대화의 작업 사본 기본값 초기화

새 대화를 시작할 때마다 작업 사본 방식이 새로 만들기로 초기화되고, 기준 브랜치는 그 프로젝트의 기본 브랜치로 다시 계산됩니다. 이전 대화에서 고른 작업 사본 경로가 그대로 남아 다른 프로젝트에 잘못 적용되던 상황을 막습니다. 작업 사본 사용 여부와 선호 에이전트는 그대로 유지됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/464)

### 화면 분할이 현재 패널 종류를 따름

분할 버튼을 누르면 지금 보고 있는 종류(채팅, 터미널, 브라우저)로 분할합니다. 이전에는 현재 화면과 상관없이 정해진 종류로 열렸습니다.

#### 사용 방법

분할 버튼을 누릅니다. 다른 종류로 열려면 옆의 메뉴에서 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/463)

## 수정된 문제

### 줄 번호가 있는 파일 링크가 빈 화면이 되던 문제

줄 번호가 포함된 파일 링크를 열면 내용이 잠깐 보였다가 빈 변경 화면으로 바뀌던 문제를 수정했습니다. 줄 이동을 위해 만들어지는 내부 표시를 실제 변경 내용으로 오인한 것이 원인이었습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/465)

### Git 프로젝트 경로와 복구 보강

프로젝트의 기본 체크아웃 경로를 로그인한 사람이 아니라 프로젝트 소유자 기준으로 통일했습니다. 새 Git 가져오기는 대상 머신에 실제 저장소가 만들어졌는지 확인한 뒤에만 성공으로 처리합니다. 이전에 실패한 프로젝트는 폴더가 없거나 비어 있을 때만 안전하게 다시 가져올 수 있습니다.

#### 사용 방법

이전에 실패한 프로젝트는 프로젝트 설정 화면에서 다시 가져오기를 실행합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/467)
