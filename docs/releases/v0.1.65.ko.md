## 수정된 문제

### 새 PC에서 조직 기본 AI 계정 확인이 몇 분간 실패하던 문제 수정

종단간 암호화로 시작한 새 PC에서 조직의 기본 AI 계정을 적용한 뒤, 앱이 이 PC의 키를 아직 받지 못해 AI 로그인 확인이 몇 분 동안 계속 실패하고 `AI_CONNECTION_CHECK_FAILED`만 보였습니다. 로그아웃 후 다시 로그인해야 풀리는 경우도 있었습니다. 이제 확인 전에 받은 조직 키를 바로 반영해 이 PC의 키를 열고 진행하며, 이 계정에 조직 키가 없으면 그 원인을 그대로 안내합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 조직 키가 없다는 안내가 나오면 조직 관리자에게 이 계정에 조직 키 배포를 요청하세요.

### 회사망에서 GitHub 다운로드가 막혀 uv 설치가 실패하던 문제 수정

Windows 시작 준비에서 uv를 GitHub에서 내려받지 못하거나 회사 보안 장비가 다른 내용으로 바꿔 보내면 uv 설치가 실패하고, 이어서 claude-swap도 준비되지 않았습니다. 이제 같은 버전의 uv를 PyPI에서 다시 받아 설치합니다. 두 곳 모두 내용이 고정된 값과 일치할 때만 설치합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 시작 준비에서 다시 시도를 누르면 됩니다.

### PC 등록이 바뀌었을 때 시작 준비가 네트워크 문제로 안내하던 문제 수정

이 PC가 이 계정의 조직 전용 PC로 등록되어 있지 않아 회사 공용 AI 인증이 거절되면, 이전에는 "네트워크 연결을 확인"하라고 안내했습니다. 이제 이 PC가 이 계정의 전용 PC로 등록되어 있지 않다고 알리고 조직 관리자에게 다시 등록을 요청하도록 안내합니다. PC 연결이 서버에서 거절된 경우(등록이 바뀌었거나 삭제됨)도 원인을 알 수 없는 오류 대신 그 원인을 표시합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 해당 안내가 나오면 조직 관리자에게 조직 관리 → PC에서 이 PC의 등록을 확인해 달라고 요청하세요.
