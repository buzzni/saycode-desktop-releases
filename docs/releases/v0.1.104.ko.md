## 새 기능

### 업데이트 뒤 앱 다시 시작 중 창에서 이 컴퓨터를 다시 확인할 수 있습니다

업데이트 뒤 "앱을 다시 시작하는 중입니다" 창이 45초가 지나도 닫히지 않으면 다시 확인 버튼이 보입니다. 누르면 이 컴퓨터를 다시 확인하고, 실행기가 꺼져 있으면 다시 켭니다. 연결되면 창은 그대로 저절로 닫힙니다.

#### 사용 방법

업데이트 뒤 뜨는 "앱을 다시 시작하는 중입니다" 창에서 다시 확인을 누릅니다.

### 이 컴퓨터 등록 창에서 연결이 끊긴 이 컴퓨터를 다시 연결할 수 있습니다

이 컴퓨터 등록 창에서 CLI는 설치됐는데 이 컴퓨터가 연결되지 않았으면, 조직 작업 시작이 비활성인 채로 다시 연결할 방법이 없었습니다. 이제 안내와 다시 연결 버튼이 보이고, 누르면 이 컴퓨터를 다시 확인해 꺼진 실행기를 다시 켭니다. 연결되면 조직 작업 시작을 누를 수 있습니다.

#### 사용 방법

이 컴퓨터 등록 창에서 다시 연결을 누릅니다.

### 작업PC 메뉴에서 연결이 끊긴 이 컴퓨터를 다시 연결할 수 있습니다

이 컴퓨터가 연결되지 않았으면 계정 메뉴의 작업PC 목록 아래에 안내와 다시 확인 버튼이 보입니다. 누르면 이 컴퓨터의 연결을 다시 확인하고, 실행기가 꺼져 있으면 다시 켭니다. 목록이 비었을 때의 안내 문구도 다른 줄과 같은 여백으로 정리했습니다.

#### 사용 방법

왼쪽 아래 계정 메뉴 → 작업PC → 다시 확인을 누릅니다.

## 변경된 기능

### 개인 AI 계정 연결 창은 시작준비를 마칠 때만 저절로 열립니다

say플랜은 Claude나 ChatGPT 계정 없이도 쓸 수 있어서, 새 대화를 만들 때마다 개인 AI 계정 연결 창이 열리지 않게 했습니다. 시작준비를 마친 뒤 한 번 열리는 것은 그대로이고, 연결 버튼이나 설정에서 직접 여는 것도 그대로입니다.

#### 사용 방법

개인 AI 계정을 연결하려면 새 대화의 AI 메뉴에서 AI 계정 탭의 연결하기를 누릅니다.

### Chat과 Project는 같은 입력창처럼

시작 화면의 Chat과 Project 탭(사이드바 Chat·Project 포함)을 오가도 쓰던 글과 첨부가 그대로 따라가고, Project에도 Chat과 같은 내 프롬프트 도구가 있어요. 프로젝트 칩은 Project 탭에만 있어요. 사이드바 Project로 들어오면 Build가 켜진 채로, 시작 화면에서 Project 탭으로 바꾸면 꺼진 채로 열려요. 제목은 프로젝트를 골라도 Chat과 같은 "어떤 작업을 도와드릴까요?"이고, Build가 꺼져 있으면 안내 문구도 Chat과 같으며 프로젝트 없이 보내면 새 프로젝트를 만들어 작업모드 대화로 시작해요(Build를 켜면 기획으로 시작). Build를 켜면 "기획으로 프로젝트 시작해보세요"로 바뀌고 기획부터 시작해요. 꺼진 Build에 마우스를 올리면 "Build를 켜면 기획 단계부터 시작할 수 있어요"가 보여요.

#### 사용 방법

시작 화면에서 Chat과 Project 탭을 오가며 쓰거나, Project에서 프로젝트를 고르거나 Build를 켜고 보내세요.

## 수정된 문제

### 이 컴퓨터 등록의 다시 확인이 꺼진 실행기를 다시 켭니다

실행기가 갑자기 꺼져도 서버는 한동안 이 컴퓨터를 연결된 것으로 보여 줍니다. 그동안 이 컴퓨터 등록 화면의 다시 확인을 눌러도 실행기가 다시 켜지지 않아, 앱을 껐다 켜야만 연결됐습니다. 이제 다시 확인은 이 컴퓨터의 실행기가 실제로 켜져 있는지 확인하고, 꺼져 있으면 다시 켭니다.

#### 사용 방법

내 설정의 시작준비에서 이 컴퓨터 등록 단계의 다시 확인을 누릅니다.
