## 변경된 기능

### 고정된 대화 조회 실패 알림 제거

Project 사이드바에서 고정된 대화를 불러오지 못해도 토스트 없이 프로젝트 목록을 계속 사용할 수 있습니다.

#### 사용 방법

고정 목록을 불러오지 못하면 잠시 후 앱 창으로 돌아왔을 때 다시 확인합니다. 그 사이 고정이나 해제를 시도하면 저장하지 못했다고 알리고 목록을 다시 확인합니다.

### 대화 보관 알림 간소화

대화 보관 알림에서 되돌리기 버튼을 제거했습니다.

#### 사용 방법

알림에서 ‘보관함’을 눌러 보관된 대화를 확인할 수 있습니다. 알림이 떠 있는 동안 입력칸 밖에서 Cmd+Z(Windows 및 Linux는 Ctrl+Z)를 눌러 보관을 되돌릴 수 있습니다.

### 도구 실행 확인이 시간 초과되면 보안 프로그램 허용을 먼저 안내

Windows 시작 준비에서 설치한 도구의 실행 확인이 제한 시간을 넘기면, 이제 "몇 분 뒤 다시 시도" 대신 보안 프로그램(V3 등) 알림에서 Saycode 도구 실행을 허용한 뒤 다시 시도하라고 먼저 안내합니다. 일부 보안 프로그램은 새 실행 파일을 분석하는 동안 사용자가 허용할 때까지 실행을 멈춰 두기 때문입니다.

#### 사용 방법

시작 준비에서 도구 오류 상세를 열면 안내가 보입니다. 화면이나 작업 표시줄의 보안 프로그램 알림에서 허용한 뒤 "다시 시도"를 누르세요.

### 시작준비가 꼭 필요한 도구만 설치하고 여러 계정용 도구는 원할 때 설치

로그인 후 시작준비는 이제 Node.js, Git, Claude Code, Codex 네 가지 필수 도구만 설치하고, 이 도구들이 준비되면 바로 다음 단계로 넘어갑니다. 여러 계정을 바꿔 쓸 때 필요한 uv, claude-swap, codex-multi-auth는 선택 도구로 바뀌어, 설치되지 않았거나 설치에 실패해도 시작준비를 막거나 오류로 표시하지 않습니다. 앱을 업데이트하거나 다시 설치한 뒤에도 선택 도구가 없다는 이유로 시작준비가 다시 열리지 않습니다.

#### 사용 방법

시작준비 화면의 `도구 준비 상세` 옆에 `필수 4/4`처럼 필수 도구 수가 보입니다. 펼치면 필수 도구와 선택 도구 목록이 나오고, `선택 도구 설치`를 누르면 선택 도구를 설치합니다. 개인 사용의 `추가 도구` 목록도 같은 기준으로 `필수 n/n`만 세고, 설치되지 않은 선택 도구는 `설치 안 됨`으로 보입니다. 내 설정 > 시작준비의 도구 목록 버튼도 `선택 도구 설치`로 바뀌었습니다.

### 시작준비에서 조직 AI 연결 확인 단계를 빼고 필수 설정만 진행

조직 계정의 첫 시작준비는 이제 이 컴퓨터가 준비되면 `완료`로 끝나며, 그 뒤에 이어지던 조직 AI 연결 확인 단계가 없어졌습니다. 그래서 조직 AI 연결 문제로 "조직 AI 연결을 하지 못했어요"에서 멈추지 않습니다. 내 설정 > 시작준비의 `이 단계부터 자동 진행`도 필수 설정(Saycode CLI, 이 컴퓨터 등록)만 진행하고 필수 도구만 설치하며, AI 도구 단계는 `AI 연결 확인` 버튼을 눌렀을 때만 연결을 확인합니다. 시작준비는 조직 AI 배정 정보도 읽지 않아, 배정 조회 실패로 멈추지 않습니다. 사이드바의 시작준비 진행률도 필수 설정만 셉니다.

#### 사용 방법

첫 시작준비에서 `이 컴퓨터가 준비됐어요`가 나오면 `완료`를 누릅니다. AI 연결은 내 설정 > 시작준비의 `AI 도구` 단계에서 `AI 연결 확인`을 눌러 확인합니다.

### AI 계정 연결은 이 컴퓨터에 이미 로그인돼 있으면 브라우저 없이 바로 연결

Claude나 ChatGPT의 `연결`을 누르면 먼저 이 컴퓨터에 그 AI가 로그인돼 있는지 확인합니다. 이미 로그인돼 있으면 브라우저를 열지 않고 바로 연결되며, 로그인돼 있지 않을 때만 지금처럼 브라우저에서 로그인합니다. 조직이 배정한 Claude 계정은 개인 계정으로 등록하지 않고 브라우저 로그인으로 진행합니다.

#### 사용 방법

AI 고르기 창, 내 설정 > AI Models, 외부 연동의 AI 계정, 시작준비 AI 도구 단계에서 `연결`을 누릅니다.

### Chat 추가 메뉴에서 문서 형식 선택 항목을 숨겨요

Chat 입력창의 추가 메뉴에 있던 문서·스프레드시트·프레젠테이션·PDF 문서 작성 항목을 당분간 숨겼어요. 문서 작업은 입력창에 원하는 내용을 직접 적어 요청하면 돼요. 폴더 추가 등 다른 메뉴 항목은 그대로예요.

#### 사용 방법

별도 설정은 없어요. Chat 입력창의 추가 버튼을 누르면 문서 형식 항목 없이 나머지 항목만 보여요.

### Google 로그인 확인 코드가 더 크게 표시돼요

브라우저에 입력할 8자리 확인 코드를 테두리 박스 안에 크게 표시하고, 위의 안내를 한 문장으로 줄였어요.

#### 사용 방법

`Google로 계속하기`를 누른 뒤 박스에 표시된 코드를 브라우저에 입력하고 승인해요.

### Happy CLI 런타임 갱신

Windows에서 Happy가 백그라운드 명령을 실행할 때 콘솔 창이 뜨는 문제를 줄였습니다. 에이전트 앱에서 시작한 Claude 대화에는 Saycode의 대화 제목 생성 지시를 추가하지 않습니다.

#### 사용 방법

앱을 업데이트한 뒤 작업 PC 런타임이 새 버전으로 다시 시작되면 적용됩니다.

### Starter 무료 이용 종료 안내 간소화

Starter 무료 이용이 끝나면 왼쪽에 개인 AI 계정으로 새 대화를 시작할 수 있다는 안내를, 오른쪽에 `개인 AI계정` 버튼을 표시합니다.

#### 사용 방법

입력창의 Starter 안내에서 `개인 AI계정`을 누릅니다. Basic 결제를 신청하려면 새 대화의 `AI도구 → say플랜`이나 기존 플랜 대화의 `say플랜` 사용량 메뉴에서 `웹에서 Basic 결제 신청`을 선택합니다.

## 수정된 문제

### 기획으로 시작한 프로젝트의 기획모드·작업모드 탭이 다시 가운데에 보입니다

기획으로 시작한 프로젝트의 대화 머리글에서 기획모드·작업모드 탭이 가운데가 아니라 프로젝트 이름과 설정(⚙) 바로 옆에 붙어 보였습니다. 이제 탭이 대화 영역 머리글의 가운데에 놓이고, 프로젝트 이름은 왼쪽, 배포·더보기(⋮)는 오른쪽에 그대로 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 다른 Git 작업이 끝나기를 기다렸다가 새 대화의 작업 공간을 만듭니다

같은 저장소에서 코드 받아오기 같은 Git 작업이 도는 동안 새 대화를 시작하면 "다른 Git 작업이 진행 중이에요. 끝난 뒤 다시 시도해 주세요."가 곧바로 나타났습니다. 이제 그 작업이 끝날 때까지 약 1분 동안 기다렸다가 작업 공간을 만들고, 그 사이에 같은 저장소로 시작한 대화들은 잠금을 두고 부딪히지 않고 순서대로 만들어집니다. 개인 작업 공간도 함께 적용되고, 기다리는 동안 시작을 취소하면 더 기다리지 않고 바로 멈춥니다. 1분이 지나도 저장소가 사용 중이면 지금처럼 같은 안내와 다시 시도 버튼이 나옵니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 안내가 계속 나오면 다른 Git 작업이 끝난 뒤 다시 시도를 누르세요.

### 대화 입력창 오류를 토스트로 표시

Chat·프로젝트 대화와 홈 기획에서 입력창 주변의 오류를 화면 상단 토스트로 표시합니다. 오류가 떠도 입력창과 작성 중인 요청은 제자리에 있습니다.

#### 사용 방법

오류 토스트에서 안내를 확인하세요. 계정 연결이나 지금 보내기가 함께 표시되면 토스트에서 바로 이어갈 수 있습니다.

### 대화 컨텍스트를 원형 아이콘으로 표시

AI 잔여량과 쉽게 구분할 수 있도록 대화 입력창 아래의 컨텍스트 표시에서 퍼센트 숫자를 빼고 원형 아이콘만 보여 줍니다.

#### 사용 방법

컨텍스트 아이콘을 누르면 정확한 사용률과 토큰 수를 볼 수 있습니다.

### 새 대화의 조직 AI 연결 안내를 토스트로 표시

새 대화에서 조직 AI 계정 연결 문제가 생기면 토스트에서 다시 연결하거나 작업PC 키 확인 화면을 열 수 있습니다. say플랜을 선택한 상태에서는 조직 AI 계정 안내가 표시되지 않습니다.

#### 사용 방법

조직 AI 계정 오류가 뜨면 토스트에서 다시 연결을 누르세요. 작업PC 키 확인이 필요하면 토스트에 표시된 설정 버튼을 사용하세요.

### 실패한 작업을 펼쳤을 때 긴 오류 코드가 대화를 가로로 늘리지 않습니다

검색 같은 도구 아래의 `작업 실패` 줄을 펼치면 결과와 전체 결과가 보입니다. 이 결과에 띄어쓰기 없는 긴 오류 코드(요청 ID, 토큰 등)가 있으면 펼친 영역이 그 폭만큼 넓어져 대화 영역 전체에 가로 스크롤바가 생겼습니다. 이제 펼친 영역은 대화 폭 안에 머물고, 긴 오류 코드는 줄바꿈되며 전체 결과는 상자 안에서 스크롤됩니다. 프로젝트 대화와 Chat 모두 같습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 원격 branch가 많은 저장소에서도 작업트리를 켤 수 있어요

원격 branch가 수천 개인 저장소에서 새 대화의 작업트리를 켜면 기준 branch 목록을 제한 시간 안에 읽지 못해 "확인 실패"가 뜨고 보낼 수 없었어요. 특히 보안 프로그램이 파일 접근을 검사하는 Windows PC에서 자주 생겼어요. 이제 branch 목록을 훨씬 빠르게 읽어요. 원격 기본 branch(origin/HEAD)가 `origin`이라는 branch로 목록에 섞여 보이던 문제도 함께 고쳤어요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 프로젝트 새 대화에서 작업트리를 켜면 기준 branch가 바로 표시돼요.

### 이미 참여한 조직의 초대가 조직 선택과 겹쳐 보이지 않습니다

이미 참여 중인 조직에서 온 초대가 `받은 조직 초대` 카드로 다시 표시되어, 아래 조직 선택과 같은 조직이 두 번 보이던 문제를 고쳤습니다. 이제 이런 초대는 화면에 표시하지 않고 조용히 정리하며, 조직은 선택 목록에 한 번만 나옵니다. 아직 참여하지 않은 조직의 초대와 관리자 권한 초대는 지금처럼 사용자가 직접 수락하거나 거절합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 작업PC 재등록 뒤 암호화 자동 복구

같은 작업PC를 다시 연결한 뒤 키 지문이 나타나지 않아 새 대화를 시작할 수 없는 경우를 고쳤습니다. 앱이 작업PC에 준비된 키와 서버에 등록된 키가 일치하는지 확인하고, 실행 중인 대화가 없을 때 암호화 전환을 이어서 진행합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 전환 후 웹에서 새 키 확인을 요청하면 작업PC와 웹에 표시된 지문을 비교해 확인하세요.

### 조직 AI 계정이 이 컴퓨터에 실제로 있을 때만 연결됨으로 표시

조직 AI 계정이 이 컴퓨터에 들어오지 않았는데도 서버 기록만 보고 `인증세트 연결됨`으로 표시되던 문제를 고쳤습니다. 이제 서버의 적용 기록과 이 컴퓨터의 Claude·Codex 로그인 상태가 모두 확인돼야 연결됨으로 보입니다. 조직이 배정한 setup-token Claude 계정은 이 컴퓨터가 받은 기록(영수증)으로 확인합니다. `조직 계정 연결하기`로 연결한 직후에도 같은 확인을 거치고, 회사 공용 AI 계정도 이 컴퓨터에서 확인되지 않으면 연결 실패로 알려 줍니다.

#### 사용 방법

내 설정 > 시작준비 > AI 도구에서 `AI 연결 확인`을 누릅니다. `이 컴퓨터에서 확인되지 않았어요`가 보이면 `조직 계정 연결하기`를 눌러 계정을 다시 받습니다.

### Windows 시작 준비가 보안 프로그램 검사로 늦게 뜨는 도구 때문에 실패하지 않게 개선

보안 프로그램이 새 실행 파일을 검사하느라 실행이 늦어지는 Windows PC에서 시작 준비가 실패하던 문제를 고쳤습니다. uv 같은 필수 도구를 설치한 뒤 사용자 Path에 등록하는 단계와 claude-swap용 Python 설치 확인 단계도 이제 다른 실행 확인처럼 최대 2분을 기다리고, 시간이 초과되면 한 번 더 시도합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### Windows에서 "재시작해서 업데이트"를 누르면 몇 초 안에 새 버전으로 다시 열립니다

Windows의 빠른 업데이트는 새 버전 폴더를 미리 준비해 두고, 재시작할 때 폴더만 바꿔 몇 초 안에 끝나도록 만든 기능입니다.
그런데 폴더를 바꾸는 단계가 실행되지 않아서, 재시작을 누르면 앱이 꺼진 채 다시 켜지지 않았습니다.
다음 시도에서는 전체 설치 파일로 넘어가 다시 켜질 때까지 몇 분이 걸렸습니다.

이제 앱을 끄기 전에 폴더 바꾸는 단계가 실제로 실행되는지 먼저 확인합니다.
확인되지 않으면 앱을 끄지 않고 전체 설치 파일을 받기 시작합니다.
종료하는 순간 그 단계가 사라졌다면 지금 버전을 다시 엽니다.
전체 설치 파일로 업데이트할 때는 설치가 끝날 때까지 "업데이트를 설치하고 있어요" 창이 떠 있습니다.
설치가 끝났는데 새 버전이 열리지 않으면 지금 버전을 열 수 있는 버튼이 나옵니다.
업데이트 뒤 남아 있던 준비 폴더(`Saycode.next-…`)도 이제 제대로 지워집니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 이 수정은 이 수정이 들어간 버전에서 다음 버전으로 업데이트할 때부터 적용됩니다.

## 업데이트 시 주의사항

### 이 컴퓨터에 로그인만 된 개인 AI는 연결을 눌러야 사용

이 컴퓨터에 Claude Code나 Codex가 로그인돼 있어도, Saycode에서 `연결`을 누르기 전에는 그 개인 계정으로 대화하지 않습니다. 사용자가 연결하지 않은 계정을 앱이 알아서 쓰지 않도록 바꾼 것입니다. 버즈니 계정에서 기존 로그인을 계정 전환 목록에 자동으로 등록하던 동작도 없앴습니다. 내 설정 > AI Models와 외부 연동의 AI 계정도 같은 기준으로, 연결하지 않은 로그인은 `이 컴퓨터에 로그인돼 있지만 Saycode에 연결되지 않았어요`로 보입니다. 조직이 배정한 AI는 그대로 사용합니다.

#### 사용 방법

업데이트 뒤 개인 AI로 대화가 시작되지 않으면 AI 계정의 `연결`을 한 번 누르거나, AI Models에서 그 계정 행의 … 메뉴 > `Saycode에 다시 연결`을 누릅니다. 이미 로그인돼 있으므로 브라우저 없이 바로 연결됩니다.

### 조직 AI는 조직 계정 연결하기를 눌렀을 때만 연결

로그인한 뒤 앱이 조직 AI 계정을 스스로 확인하거나 이 컴퓨터에 적용하지 않습니다. 내 설정 > 시작준비의 AI 도구 단계에서 `조직 계정 연결하기`를 누르면 나에게 배정된 조직 계정을, 배정이 없으면 회사 공용 AI 계정을 이 컴퓨터에 연결합니다. 연결된 뒤에는 앱이 켜져 있는 동안 배정 변경을 확인하고, 대화를 시작할 때 조직 계정 적용이 필요하면 그때 다시 적용합니다. say플랜은 대화마다 회사·계정 기준으로 연결되므로 영향이 없습니다.

#### 사용 방법

업데이트 뒤 조직 AI로 대화가 시작되지 않으면 내 설정 > 시작준비 > AI 도구에서 `AI 연결 확인`을 누른 뒤 `조직 계정 연결하기`를 누릅니다.
