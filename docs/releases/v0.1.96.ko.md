## 새 기능

### 대화 소유권 증명을 실험으로 켜기

호환되는 작업PC에서 새 대화의 소유권을 증명하는 실험 기능을 제공합니다. 기본은 꺼짐입니다.

#### 사용 방법

계정 메뉴에서 개발자 기능 설정을 열고 대화 소유권 증명(실험)을 켭니다. 꺼두면 일반 대화 생성 경로를 사용합니다.

### 대화를 봇에게 맡기고 입력창에서 @봇으로 할 일을 넘깁니다 (실험)

사이드바 대화 줄의 ⋮ 메뉴에 **봇에게 맡기기…**가 생겼습니다. 봇을 고르고(없으면 **새 봇…**) 원하는 결과를 적어 맡기면, 원래 대화는 그대로 둔 채 그 봇에 할 일이 생깁니다. 할 일 제목은 대화 제목이고 설명은 원하는 결과와 대화의 마지막 요청 앞부분이며, 할 일 상세의 **원래 대화**로 돌아갈 수 있습니다. 봇의 작업PC가 오프라인이면 맡기기가 꺼지고 이유가 보입니다. 입력창에서 @를 입력하면 **봇** 묶음에서 봇을 골라 알약으로 넣을 수 있습니다. 보내면 그 봇에 할 일이 먼저 만들어지고, 알약은 "(봇 이름의 할 일 #번호(으)로 넘김)" 문구로 바뀌어 보내집니다. 할 일을 만들지 못하면 메시지를 보내지 않고 초안과 알약을 그대로 둔 채 이유를 알립니다. 응답 중이라 대기열에 넣은 메시지는 실제로 보낼 때 할 일을 만듭니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켭니다. 대화 줄 ⋮ → **봇에게 맡기기…**, 또는 입력창에서 @ → **봇** 묶음에서 봇을 고르고 보냅니다.

### 봇 질문에 칩으로 바로 답하고 나를 기다리는 대화를 봇 탭에서 봅니다 (실험)

봇이 할 일에 남긴 질문이 할 일 상세에 **봇의 질문** 카드로 보입니다. 선택지는 칩으로 보이며, 추천은 채운 칩이고 마지막에 **직접 입력**이 있습니다. 질문이 여럿이면 하나씩 넘기며 고르고, 마지막 질문을 고르면 모든 답이 한 메시지로 그 할 일을 맡은 봇 대화(없으면 Home 대화)에 보내집니다. 확인 창은 없습니다. 대신 화면을 그린 뒤 봇이 그 할 일을 고쳤다면 보내지 않고 다시 불러옵니다. 대화가 응답 중이면 기존 대기열에 들어가 응답이 끝난 뒤 보내지고, 대화에는 **봇 기능에서 보냄**으로 표시되며 폴더 권한을 주지 않습니다. Alt(⌥)를 누른 채 칩을 누르면 보내지 않고 댓글 입력에 넣습니다. 권한 승인·질문·계획 확인을 기다리는 봇 대화는 봇 탭 **나에게 요청** 맨 위와 사이드바 봇 줄의 호버 카드에 이유와 함께 보이고, 누르면 그 대화가 열립니다. 할 일 상세에서는 ⌥⌘↓ / ⌥⌘↑(단축키 설정에서 변경)로 나에게 요청 항목 사이를 옮겨 다니며, 항목마다 쓰던 댓글이 남아 있습니다.

#### 사용 방법

봇 탭에서 할 일을 누르고 **봇의 질문** 카드의 칩을 누릅니다. 나에게 요청 항목 사이는 댓글 입력 옆의 ↑↓ 버튼이나 ⌥⌘↓ / ⌥⌘↑로 옮겨 다닙니다.

### 봇 탭에서 봇의 할 일을 보고 맡깁니다 (실험)

봇 프로젝트의 대화를 열면 오른쪽 작업 패널에 **봇** 탭이 생깁니다. 봇이 `.bot/items/`에 적은 할 일이 **나에게 요청·진행 중·예정·미룸·오래됨·닫힘**으로 묶여 한 줄씩 보이고, 앞의 두 묶음만 펼쳐집니다. 줄에 마우스를 올리면 완료·미루기·더보기가 나오고, 줄을 누르면 설명·활동·댓글이 있는 상세가 열립니다. 상세의 **봇에게 맡기기**는 봇의 AI로 새 대화를 시작해 그 할 일을 넘깁니다. 5일 넘게 움직임이 없는 할 일은 **오래됨**에 모이고, 이유를 남긴 채 한 번에 취소할 수 있습니다(파일은 지우지 않습니다). 봇 설정에서 오래됨 기준과 닫힌 항목 보관 기간을 바꾸고 봇을 해제할 수 있습니다. 대화 머리의 봇 이름을 누르면 봇 탭이 열리고, 사이드바 봇 줄에는 나를 기다리는 할 일 수가 보입니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켠 뒤 사이드바 봇 줄을 누르면 Home 대화와 봇 탭이 함께 열립니다. 다른 대화에서는 작업 패널 더보기(⋮)의 **봇**이나 대화 머리의 봇 이름으로 엽니다. 할 일을 누르고 **봇에게 맡기기**를 누르면 새 대화가 시작됩니다. 봇 프로젝트는 Project 목록에 따로 보이지 않으니, 봇 줄 오른쪽 화살표로 펼쳐 **새 대화**를 시작하거나 **프로젝트 열기**를 누릅니다.

### 봇 할 일을 작업트리 대화로 맡깁니다 (실험)

봇 탭 할 일 상세의 **봇에게 맡기기** 옆에 **작업트리에서 맡기기**가 생겼습니다. 누르면 봇 폴더는 그대로 둔 채 새 작업트리에서 일하는 대화가 시작되고, 할 일이 진행 중으로 바뀌며 그 대화가 연결됩니다. 작업트리는 새 대화의 작업트리 시작과 같은 방식으로 만들어져 원격의 최신 기본 브랜치에서 갈라집니다. 대화의 첫 메시지가 봇 폴더의 위치를 알려 주므로 AI가 쓴 할 일과 기억은 봇 탭에 그대로 보입니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켭니다. 봇 탭에서 할 일을 눌러 상세를 열고 **작업트리에서 맡기기**를 누릅니다. 봇 프로젝트가 Git 저장소여야 합니다.

### 사이드바에서 봇을 만들고 상태를 봅니다 (실험)

개발자 기능 설정에 **봇 보이기 (실험)** 스위치가 생겼습니다(기본 꺼짐). 켜면 사이드바 Project 목록 위에 봇 섹션이 나타납니다. 봇은 자기 폴더·성격(SOUL.md)·기억(MEMORY.md)을 가진 프로젝트이고, 봇 줄에서 지금 무엇을 하는지와 나를 기다리는 대화를 바로 볼 수 있습니다. 새 봇은 창 하나에서 이름·아바타·하는 일·작업PC·AI와 모델·템플릿(고객지원·릴리스 노트·운영 점검·빈 봇)을 정해 만들고, 만들면 봇의 Home 대화가 열립니다. 기존 프로젝트를 봇으로 바꿀 수도 있으며, 이미 있는 파일은 지우거나 덮어쓰지 않습니다. 봇 규칙은 봇 폴더의 코드를 함부로 고치지 말고 코드 수정은 작업트리 대화에서 하라고, 최신 코드는 받아 오기(fetch)만 한 뒤 원격 브랜치에서 읽으라고 안내합니다. 이미 만든 봇도 봇 탭을 열면 새 규칙으로 바뀝니다.

#### 사용 방법

내 이름(계정) 버튼 → **개발자 기능 설정** → **봇 보이기 (실험)**를 켭니다. 사이드바 봇 섹션의 **+** 버튼에서 **새 봇…**, **템플릿에서 만들기…**, **기존 프로젝트를 봇으로…** 중 하나를 고릅니다. 봇 줄을 누르면 Home 대화가 열리고, 줄에 마우스를 올리면 나를 기다리는 대화가 보입니다.

## 변경된 기능

### 공간컨텐츠를 설치하고 예시로 시작하기

공간컨텐츠 설치본이 Desktop에 포함돼 있어요. 대시보드에서 한 번에 설치하고 제작 화면을 열 수 있어요.

#### 사용 방법

대시보드 맨 아래에서 **공간컨텐츠 만들기**를 누르고 **설치하고 시작**을 선택하세요. 확장이 꺼져 있다면 **켜고 시작**을 누르세요. 빈 편집기에서 **예시로 시작**을 누르면 오피스 투어를 바로 체험할 수 있어요.

### 공간컨텐츠의 실사 3D 장면 편집

공간컨텐츠 확장 0.1.4를 동봉합니다. 실사 로비를 걸어보며 직원의 배치·동작·대사를 따로 바꿀 수 있습니다. 3D 환경과 인물은 GLB 파일로, 스토리는 TXT·MD로 추가할 수 있습니다. 조직이 생성 서비스를 연결하면 세 파트에 AI 생성도 사용할 수 있습니다.

#### 사용 방법

대시보드 맨 아래에서 공간컨텐츠 만들기를 누릅니다. 처음에는 설치하고 시작, 기존 0.1.2를 사용 중이면 업데이트하고 시작을 누릅니다. 실사 3D 샘플 열기로 로비를 열고, 걸어보기에서 직원에게 다가간 뒤 여기서 수정으로 편집합니다.

### 대시보드에서 공간컨텐츠 업데이트하고 시작하기

새 공식 버전이 준비되면 대시보드에서 공간컨텐츠를 업데이트하고 제작 화면을 바로 열 수 있어요.

#### 사용 방법

대시보드 하단에서 **공간컨텐츠 만들기**를 누르고 **업데이트하고 시작**을 선택하세요.

### 동료 초대 안내를 조직 관리 툴팁으로 이동

시작 화면의 동료 초대 안내가 조직 관리 버튼 위 툴팁으로 표시됩니다.

#### 사용 방법

동료 초대 안내를 받을 수 있는 조직 소유자는 시작 화면 왼쪽 아래의 조직 관리 버튼에 마우스를 올리거나 키보드로 초점을 맞추면 문구를 볼 수 있습니다.

### 비밀번호 재설정 완료 화면 간소화

비밀번호를 재설정하면 완료 제목과 파란색 로그인하기 버튼을 표시합니다. 암호화된 데이터의 추가 복구가 필요한 경우에는 해당 안내도 표시합니다.

#### 사용 방법

비밀번호 재설정 완료 화면에서 로그인하기를 눌러 로그인 화면으로 돌아갑니다.

### 사이드바에서 연 대화 제목을 굵게 표시

사이드바에서 지금 열어 둔 대화의 제목이 굵게 보입니다. 옅은 배경과 함께 표시되어 어느 대화를 보고 있는지 더 쉽게 찾을 수 있습니다. 제목 색이나 행 테두리는 그대로입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. Project·Chat 목록에서 대화를 열면 그 행의 제목이 굵게 표시됩니다.

### 새 대화에서 say플랜 사용량 확인

say플랜을 고르면 대화를 보내기 전에도 입력창 왼쪽 아래에서 플랜 사용량을 볼 수 있습니다. 모델 버튼에는 모델 이름만 표시되며, AI 계정으로 바꾸면 작업PC의 AI 사용량이 다시 표시됩니다. say플랜 팝오버에는 등급과 한도별 사용률이 먼저 보이고, 모델별 비중과 토큰 수치는 펼쳐 볼 수 있습니다.

#### 사용 방법

새 대화의 AI도구 메뉴에서 say플랜을 선택하고, 입력창 아래의 say플랜 버튼을 누릅니다. 모델별 비중이나 토큰 수치는 ‘사용량 자세히’를 누르면 볼 수 있습니다.

### 시작준비 실패 화면에서 다른 계정으로 로그인 버튼을 뺐습니다

조직 시작준비에서 이 컴퓨터 준비에 실패한 화면에는 `다른 계정으로 로그인` 버튼이 더 이상 보이지 않습니다. 대신 `이 PC 나중에 등록`으로 앱에 들어가거나 다시 시도할 수 있습니다. 조직 선택 화면에서는 그대로 쓸 수 있습니다.

#### 사용 방법

다른 계정으로 바꾸려면 시작준비 실패 화면에서 `이 PC 나중에 등록`을 눌러 앱에 들어간 뒤 왼쪽 아래 계정 메뉴에서 로그아웃합니다.

### 업데이트 후 릴리스 노트를 직접 열 수 있어요

업데이트를 마친 뒤 앱을 다시 열면 작업 화면으로 바로 돌아갑니다. 릴리스 노트는 필요할 때 열어 볼 수 있습니다.

#### 사용 방법

내 설정 → Saycode 정보 → 릴리스 노트를 누르세요. 메뉴 막대가 보이면 Help → 릴리스 노트에서도 열 수 있습니다.

### 이 PC 나중에 등록 버튼은 준비에 실패했거나 연결 확인을 물을 때만 보입니다

조직 시작준비 화면의 `이 PC 나중에 등록` 버튼과 그 아래 안내 문구가 이제 이 컴퓨터 준비에 실패했거나 `PC 연결 확인`에서 연결 동의를 물을 때만 보입니다. 준비가 진행 중일 때는 보이지 않아 준비를 끝까지 기다리는 흐름이 분명해졌습니다. 연결 확인에서는 이 컴퓨터를 연결하지 않고 시작할 수 있습니다.

#### 사용 방법

시작준비 중 오류나 `PC 연결 확인`이 표시되면 화면 아래쪽의 `이 PC 나중에 등록`을 누릅니다. 나중에 내 설정 → 작업PC에서 현재 컴퓨터를 등록할 수 있습니다.

### 작업트리 관리와 브랜치 선택

관리 중인 작업트리와 앱 밖에서 만든 작업트리를 탭으로 나눕니다. 브랜치 이름을 누르면 목록을 유지한 채 전환을 확인할 수 있습니다.

#### 사용 방법

입력창 위 브랜치 메뉴에서 작업트리 관리를 엽니다. 관리 중인 탭에서 대화를 시작하고, 앱 밖에서 만든 작업트리는 외부 탭에서 선택해 채택할 수 있습니다.

### 조직 선택 화면 간소화

기본 조직이 표시되는 화면의 제목을 `조직을 선택하세요`로 바꿨어요. `이 PC 나중에 등록` 버튼과 안내는 시작준비 단계에서 표시해요.

#### 사용 방법

조직 로그인 뒤 조직을 확인하고 `다음`을 눌러 시작준비를 시작하세요.

### 개인 Claude 계정 확인 안내에서 설정 열기

### 긴 경로가 있는 작업 완료 줄이 대화를 가로로 늘리지 않습니다

백그라운드 작업이 끝나면 대화에 `작업 완료` 줄이 하나 생깁니다. 그 요약에 띄어쓰기 없는 긴 경로(예: macOS 임시 폴더의 `L=/private/tmp/…` 명령)가 들어오면, 요약이 말줄임되지 않고 대화 영역 밖까지 늘어나 가로 스크롤바가 생겼습니다. 작업 완료 줄과 백그라운드 작업 카드 두 곳 모두에서 같은 문제가 있었고, 이제 두 줄 모두 대화 폭 안에 머물며 요약만 줄임표로 잘립니다. 한 줄 높이·아이콘·펼침 버튼은 그대로이고, 펼친 결과·사용량·작업 ID는 이전처럼 모두 보입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 잘린 요약 전체를 보려면 그 줄을 눌러 펼칩니다.

### 내장 CLI 작업PC의 원격 업데이트 알림 제외

Aplus CLI 업데이트 창에는 npm으로 설치한 CLI를 원격으로 갱신할 수 있는 온라인 작업PC만 표시합니다. 내장 CLI 작업PC만 있으면 업데이트 창과 사이드바 아이콘이 나타나지 않습니다. 업데이트를 누른 뒤 작업PC 정보를 잠시 확인하지 못해도 해당 행에서 다시 시도할 수 있습니다.

#### 사용 방법

내장 CLI는 해당 작업PC의 Saycode 앱에 업데이트가 나왔을 때 앱과 함께 갱신됩니다.

### 누구나 say플랜 탭을 열 수 있어요

플랜이 없는 기존 가입자도 새 대화에서 say플랜 탭을 열 수 있습니다. 열린 탭에서 플랜을 이용할 수 없는 이유를 확인할 수 있습니다. 안내를 읽는 동안 현재 초안의 연결과 AI 선택은 유지됩니다.
