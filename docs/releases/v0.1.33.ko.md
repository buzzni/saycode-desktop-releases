## 새 기능

### 머신 상세 정보와 업데이트 관리

등록된 머신의 상세 상태를 확인하고 지원되는 머신의 Happy CLI 업데이트를 Desktop에서 실행할 수 있습니다.

#### 사용 방법

환경설정의 머신 목록에서 머신을 선택해 상세 정보를 엽니다. 업데이트가 표시되면 대상 머신을 확인하고 업데이트 동작을 실행합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/498)

### 모바일 로그인 QR

Desktop 프로필에서 모바일 기기의 Saycode 로그인을 연결할 수 있는 QR 코드를 제공합니다.

#### 사용 방법

프로필의 모바일 로그인 영역을 열고 표시된 QR 코드를 모바일 기기로 스캔합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/490)

### 세션 누적 토큰 사용량

각 대화 세션에서 지금까지 사용한 누적 토큰을 확인할 수 있습니다.

#### 사용 방법

대화를 열고 대화 헤더의 누적 토큰 사용량 표시를 확인합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/514)

### 예약 자동화 실행

프로젝트 작업을 지정한 일정에 자동으로 시작하고 실행 상태를 확인할 수 있습니다.

#### 사용 방법

프로젝트의 자동화 설정에서 실행할 지시와 일정을 등록합니다. 등록된 자동화의 다음 실행 시각과 최근 실행 결과는 같은 화면에서 확인합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/472)

### 채팅 슬래시 명령어

채팅 입력창에서 Desktop이 제공하는 명령어를 검색하고 실행할 수 있으며, 지원하는 명령은 로컬에서 즉시 처리됩니다.

#### 사용 방법

채팅 입력창에 `/`를 입력하고 표시되는 명령을 선택합니다. 필요한 인자를 이어서 입력한 뒤 전송합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/503)

### 터미널 작업 알림과 후속 요청 관리

터미널에서 실행 중인 작업의 알림을 받고, 대기 중인 후속 요청을 확인하거나 바로 보낼 수 있습니다.

#### 사용 방법

터미널 작업을 시작한 뒤 알림과 후속 요청 목록을 확인합니다. 즉시 전달할 요청은 보내기 동작을 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/454)

### 프로젝트 대화 제목 편집

프로젝트 안의 기존 대화 제목을 알아보기 쉬운 이름으로 바꿀 수 있습니다.

#### 사용 방법

대화를 연 뒤 제목 편집 동작을 선택하고 새 제목을 입력해 저장합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/473)

### 프로젝트 코드 저장소 연결 설정

프로젝트 설정에서 기존 GitHub 저장소를 연결하거나 권한이 있는 조직에 새 저장소를 만들어 연결할 수 있습니다.

#### 사용 방법

프로젝트를 열고 프로젝트 설정의 코드 저장소 영역에서 연결된 계정과 저장소를 선택합니다. 새 저장소를 만들 수 있는 자격이 있으면 같은 화면에서 저장소 이름을 입력해 생성할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/470)

### Cmd+W로 현재 채팅 탭 닫기

macOS의 표준 `Cmd+W` 단축키로 현재 활성 채팅 탭을 닫을 수 있습니다. 마지막 탭에서는 기존처럼 창 닫기 동작을 유지합니다.

#### 사용 방법

닫으려는 채팅 탭을 활성화하고 `Cmd+W`를 누릅니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/513)

### GitHub 자동화 실행 조건 확장

GitHub 이벤트 자동화에 작성자와 변경 파일 경로 조건을 추가해 필요한 이벤트만 실행할 수 있습니다.

#### 사용 방법

자동화의 GitHub 트리거 설정에서 허용할 작성자 또는 파일 경로 조건을 입력하고 저장합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/480)

### Happy CLI 일괄 업데이트

업데이트가 필요한 온라인 머신 여러 대의 Happy CLI를 한 번에 업데이트할 수 있습니다.

#### 사용 방법

환경설정의 머신 목록에서 업데이트할 머신을 선택하고 일괄 업데이트를 실행한 뒤 각 머신의 결과를 확인합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/504)

## 변경된 기능

### 계정과 환경설정 탐색 개선

사이드바에서 계정 메뉴와 환경설정을 바로 열 수 있고, 환경설정 안에서 원하는 항목을 검색할 수 있습니다.

#### 사용 방법

사이드바 아래쪽의 계정 영역에서 환경설정을 선택합니다. 환경설정 검색창에 기능 이름이나 관련 단어를 입력하면 해당 설정 항목을 찾을 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/487)

### 대화 사용량과 브랜치 기본 표시

현재 대화가 사용하는 Git 브랜치와 AI 사용량 정보를 대화 화면에서 바로 확인할 수 있습니다.

#### 사용 방법

프로젝트 대화를 열고 대화 헤더의 브랜치 및 사용량 표시를 확인합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/502)

### 머신 삭제 권한 표시 개선

머신 삭제 버튼은 해당 작업 권한이 있는 소유자와 관리자에게만 표시됩니다.

#### 사용 방법

환경설정의 머신 상세 화면을 엽니다. 삭제 권한이 있는 계정은 안전 확인을 거쳐 머신을 삭제할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/478)

### 선택한 조직의 머신만 표시

머신 관리 화면에서 현재 선택한 조직에 속한 머신만 표시해 다른 조직의 머신과 혼동하지 않도록 개선했습니다.

#### 사용 방법

조직을 선택한 뒤 환경설정의 머신 목록을 열면 해당 조직의 머신만 확인할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/500)

### 슬래시 명령어 메뉴 가독성 개선

슬래시 명령어 자동완성 메뉴에서 명령 이름, 설명, 현재 선택 항목을 더 쉽게 구분할 수 있습니다.

#### 사용 방법

채팅 입력창에 `/`를 입력하고 방향키 또는 포인터로 원하는 명령을 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/515)

### 앱 시작 시 대화 화면 빠른 표시

앱 시작 시 전체 워크스페이스 데이터가 준비될 때까지 기다리지 않고 대화 입력 화면을 먼저 표시합니다.

#### 사용 방법

별도 설정 없이 앱을 실행하면 개선된 시작 화면이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/517)

### 에이전트 보드 초기 표시 개선

에이전트 보드의 카드를 준비되는 순서대로 표시해 프로젝트가 많을 때도 첫 화면을 더 빠르게 확인할 수 있습니다.

#### 사용 방법

에이전트 보드를 열면 준비가 끝난 카드부터 자동으로 표시됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/509)

### 오토파일럿 사용 불가 사유 표시

Worktree가 없는 프로젝트 카드에서는 오토파일럿을 숨기지 않고 사용할 수 없는 이유를 표시합니다.

#### 사용 방법

에이전트 보드 카드의 오토파일럿 상태를 확인합니다. Worktree가 필요하다는 안내가 보이면 Worktree를 사용하는 새 대화에서 작업을 시작합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/510)

### 응답 완료 후 파일 미리보기 동작 변경

에이전트 응답이 완료되어도 파일 미리보기가 자동으로 열리지 않아 현재 작업 화면과 선택한 파일이 갑자기 바뀌지 않습니다.

#### 사용 방법

응답에 표시된 파일 링크를 직접 선택하거나 프로젝트 파일 목록에서 파일을 선택해 미리보기를 엽니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/516)

### 프로젝트 폴더 경로 자동완성

기존 폴더로 프로젝트를 만들 때 경로 후보가 자동으로 표시되고 폴더 선택 동작을 더 쉽게 찾을 수 있습니다.

#### 사용 방법

새 프로젝트에서 기존 폴더를 선택한 뒤 경로를 입력하거나 표시되는 후보를 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/486)

### Desktop 탐색 밀도와 메뉴 개선

프로젝트와 대화를 더 많이 한 화면에서 확인할 수 있도록 탐색 영역의 밀도와 넘침 메뉴가 개선되었습니다.

#### 사용 방법

사이드바에서 프로젝트와 대화를 탐색하고, 공간이 부족할 때 표시되는 더보기 메뉴에서 추가 동작을 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/492)

### PDF 미리보기 성능 개선

페이지가 많은 PDF를 열 때 보이는 페이지를 우선 렌더링해 초기 표시와 스크롤 반응이 빨라졌습니다.

#### 사용 방법

프로젝트 파일에서 PDF를 선택하면 별도 설정 없이 개선된 미리보기가 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/496)

### PR 리뷰 프리셋 강화

PR 리뷰 작업의 기본 지시와 후속 수정 흐름을 강화해 리뷰 결과를 실제 수정과 검증까지 더 안정적으로 이어갑니다.

#### 사용 방법

PR 리뷰 프리셋으로 대화를 시작하고 검토할 변경 대상을 지정합니다. 발견된 문제가 있으면 같은 흐름에서 수정과 재검증을 진행합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/482)

## 수정된 문제

### 공유 머신 자동화 실행 복구

공유 머신의 일부 기능 정보가 이전 형식으로 전달되어도 지원되는 예약 자동화를 실행할 수 있도록 호환성을 복구했습니다.

#### 사용 방법

공유 머신을 선택해 자동화를 등록하거나 실행하면 지원 여부가 자동으로 확인됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/518)

### 공유 프로젝트 자동화 키 오류 수정

회사·공유 프로젝트에서 자동화 암호화 키가 개인 계정 키와 달라 자동화 목록이 열리지 않던 문제를 수정했습니다. 서버 기반 자동화가 활성화된 프로젝트에서는 기존 로컬 파일 자동화를 다시 가져오거나 중복 실행하지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 기존 서버 자동화가 다른 키로 암호화되어 있으면 데이터 보호를 위해 안내 메시지를 표시합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/521)

### 과거 작업 검색 결과 연결 복구

과거 작업을 의미 기반으로 검색할 때 결과가 원래 대화 세션과 올바르게 연결되도록 수정했습니다.

#### 사용 방법

과거 작업 검색 결과를 선택하면 관련 대화의 맥락을 확인할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/491)

### 새 대화 모델 선택 복구

Claude 기능 지원 여부를 확실히 판단할 수 없는 머신에서도 새 대화를 시작할 때 사용 가능한 선택지가 사라지지 않도록 수정했습니다.

#### 사용 방법

새 대화 화면에서 원하는 에이전트와 모델을 선택합니다. 머신 상태 확인이 지연되어도 제공 가능한 선택지는 계속 표시됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/477)

### 새로고침 후 중복 탭 생성 방지

대화 탭을 연 상태에서 앱을 새로고침할 때 같은 탭이 중복으로 생성되는 문제를 수정했습니다.

#### 사용 방법

기존처럼 앱을 새로고침하면 열려 있던 대화 탭이 하나씩 복원됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/481)

### 오래된 Worktree 정리 복구

오래된 Worktree를 정리하다 일부 항목이 실패해도 원인을 확인하고 다시 정리할 수 있도록 복구 동작이 개선되었습니다.

#### 사용 방법

프로젝트의 Worktree 관리 화면에서 오래된 항목 정리를 실행합니다. 실패한 항목이 표시되면 안내된 상태를 확인한 뒤 정리를 다시 실행합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/494)

### 자동화 단일 실행 복구

Claude와 Codex 자동화가 한 번의 트리거에서 중복 시작될 수 있던 문제를 수정했습니다.

#### 사용 방법

등록된 자동화를 기존처럼 실행하면 각 트리거마다 한 번만 작업이 시작됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/501)

## 업데이트 시 주의사항

### 민감한 작업의 안전 확인

머신 삭제처럼 되돌리기 어려운 작업은 대상과 영향을 다시 확인한 뒤 실행하도록 안전 확인 단계가 추가되었습니다.

#### 사용 방법

민감한 작업 버튼을 누르면 표시되는 대상 정보를 확인하고 확인 대화상자에서 작업을 한 번 더 승인합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/489)

### 프로젝트 파일 접근 범위 보호

새 작업은 선택한 프로젝트 또는 Worktree 범위 안에서 파일을 다루도록 보호되며, 호환되지 않는 구버전 머신에서는 안전한 안내를 표시합니다.

#### 사용 방법

새 대화를 시작할 때 프로젝트와 Worktree 선택을 확인합니다. 머신 업그레이드 안내가 나타나면 머신 관리 화면에서 Happy CLI를 업데이트한 뒤 다시 시작합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/499)
