## 새 기능

### 내 채팅 — 프로젝트 없이 바로 쓰는 AI 작업공간

프로젝트를 만들지 않아도 바로 대화를 시작할 수 있는 내 채팅을 추가했습니다. 사이드바의 대화·프로젝트 모드 토글과는 다른 별도 기능으로, 프로젝트에 묶이지 않은 독립 대화 목록을 가집니다. 딥링크나 복원할 대화가 없이 앱에 들어오면 내 채팅이 기본 화면으로 열리고, 대화 목록은 위쪽에 새 채팅 작성 영역은 화면 하단에 고정되어 입력에 바로 집중할 수 있습니다.

#### 사용 방법

사이드바에서 내 채팅을 선택합니다. 새 채팅 작성란에 바로 입력해 시작하고, Enter로 전송, Shift+Enter로 줄바꿈합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/377)

### 내 채팅 파일 첨부

내 채팅의 새 채팅과 대화 화면에서 파일을 첨부할 수 있습니다. 파일 선택, 드래그 앤 드롭, 붙여넣기를 모두 지원하고 첨부만 보내는 것도 가능합니다.

#### 사용 방법

내 채팅 입력란에 파일을 끌어다 놓거나 붙여넣거나, 클립 아이콘으로 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/381)

### 보드 실행 모델 선택, 정체 알림, 외부 웹훅

에이전트 보드의 지시·리뷰 대화상자에서 실행할 모델과 effort를 고를 수 있습니다. 세션이 오래 진전 없이 멈춰 있으면 알려주고, 작업 결과를 외부 시스템으로 보내는 웹훅을 설정할 수 있습니다. 함께, 보드에서 보낸 요청이 채팅에서 고정해 둔 모델 설정을 무시하던 기존 문제도 수정했습니다.

#### 사용 방법

보드의 지시·리뷰 대화상자에서 모델과 effort를 선택합니다. 웹훅은 설정 화면에서 등록합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/374)

### 새 탭으로 여는 작업 공간

브라우저처럼 Cmd/Ctrl+T와 탭 바의 + 버튼으로 새 작업 탭을 엽니다. 최근에 무엇을 하고 있었는지에 따라 프로젝트의 새 대화 또는 내 채팅 초안 중 알맞은 쪽으로 열립니다.

#### 사용 방법

Cmd/Ctrl+T를 누르거나 탭 바의 + 버튼을 누릅니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/387)

### 요소 스크린샷 첨부, 디프 코멘트, Quick Open, CI 실패 자동 수정

앱 안 브라우저에서 화면 요소를 골라 스크린샷으로 채팅에 첨부할 수 있고, 코드 변경 화면에 남긴 줄 단위 코멘트가 저장되어 다시 열어도 유지됩니다. 파일과 명령을 이름으로 빠르게 찾아 여는 Quick Open과, CI가 실패했을 때 그 로그를 바탕으로 수정을 요청하는 진입점도 추가했습니다.

#### 사용 방법

브라우저 패널의 요소 선택 버튼, 변경 화면의 줄 코멘트, Quick Open 단축키, CI 실패 카드의 수정 요청 버튼을 각각 사용합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/375)

### 첨부한 이미지를 크게 보기

전송하기 전 첨부한 이미지의 작은 썸네일을 눌러 원본 크기로 볼 수 있습니다. 닫기 버튼, 바깥 클릭, Escape로 닫을 수 있고 닫아도 첨부와 작성 중인 내용은 유지됩니다.

#### 사용 방법

입력창에 첨부한 이미지 썸네일을 클릭하거나 키보드로 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/389)

## 변경된 기능

### 대화를 열 때 현재 탭 재사용

대화 목록, 검색, 알림, 에이전트 보드에서 대화를 열면 새 탭을 계속 쌓지 않고 지금 보고 있는 탭에서 엽니다. 이미 열려 있는 대화는 중복해서 열지 않고 그 탭을 활성화합니다.

#### 사용 방법

새 탭으로 열려면 Command/Ctrl 클릭, 가운데 클릭, 또는 우클릭 메뉴를 사용합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/384)

### 마지막에 보던 작업으로 복원

앱을 다시 열면 마지막에 사용하던 영역에 따라 프로젝트의 새 대화 또는 마지막 내 채팅 대화를 복원합니다. 응답·질문·권한 요청이 진행 중인 프로젝트 세션만 정확히 이어서 재개하고, 삭제되었거나 접근할 수 없는 대상이면 내 채팅 새 채팅 화면으로 안전하게 넘어갑니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/379)

### 새 대화 첫 화면 정리

새 대화 첫 화면 위쪽에 있던 에이전트·모델·작업 사본 설정 도구모음을 없애고, 실행 설정을 입력창 바로 위로 옮겼습니다. 시작 카드는 화면 성격에 맞는 4개로 고정했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 에이전트와 모델은 입력창 바로 위에서 고릅니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/380)

### 작업 마무리와 파일 첨부를 입력창에 바로 노출

메뉴 안에 있던 작업 마무리(Commit & PR)를 개발 진행 버튼 바로 옆으로 꺼내고, 파일 첨부를 클립 아이콘과 이름표가 붙은 버튼으로 통일했습니다.

#### 사용 방법

채팅 입력창에서 바로 누릅니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/390)

### 프로젝트 목록으로 돌아가는 흐름 정리

프로젝트 상세 화면 위쪽에 모든 프로젝트 / 프로젝트명 형태의 위치 경로를 추가하고, 메인과 사이드바에서 돌아가는 동작을 통일했습니다. 상세 화면을 다녀와도 목록의 검색어·구분·스크롤 위치가 유지됩니다. 프로젝트 열기와 새 대화 시작도 서로 분리했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 상세 화면 위쪽의 모든 프로젝트를 눌러 목록으로 돌아갑니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/392)

### 프로젝트 중심 사이드바와 단순해진 채팅 화면

사이드바의 첫 번째 목적지를 프로젝트, 에이전트 보드, 내 채팅으로 정리하고 전체 대화·머신·조직 홈은 더보기로 옮겼습니다. 프로젝트 대화 하나만 열었을 때는 중복되던 탭과 패널 머리 부분을 하나의 헤더로 합치고, 자주 쓰지 않는 입력창 기능은 메뉴 안으로 넣었습니다. 화면을 분할해 여러 패널을 쓰는 경우에는 기존 화면 구성이 그대로 유지됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 기존 메뉴는 사이드바 더보기에서 찾을 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/386)

### 프로젝트·대화 목록 불러오기 속도 개선

프로젝트 목록과 열린 대화 목록을 서버가 정리해 내려주는 방식으로 바꿔, 프로젝트 수에 비례해 늘어나던 요청과 계정 전체 대화를 통째로 받아오던 동작을 없앴습니다. 목록 정렬도 대화 정보를 다 불러오기 전에 정확하게 표시됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/371)

## 수정된 문제

### 다른 조직 알림을 누를 때마다 새 창이 쌓이던 문제

알림함에서 현재 조직이 아닌 알림을 클릭하면 그 조직 창이 이미 열려 있어도 매번 새 창을 만들던 문제를 수정했습니다. 이제 열려 있는 창을 찾아 그 창에서 대화를 엽니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/373)

### 독립 리뷰 기록이 사라지고 디스크가 차던 문제

독립 리뷰를 실행해도 기록이 남지 않던 문제를 수정했습니다. 기록은 리뷰용 임시 작업 폴더를 회수하는 유일한 단서였기 때문에, 기록이 사라지면 임시 폴더가 계속 쌓여 디스크를 차지했습니다. 저장 실패가 조용히 무시되던 경로와 여러 창이 서로의 기록을 덮어쓰던 문제를 함께 고쳤습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/370)

### 독립 리뷰가 완료인데 결과가 비어 있던 문제

독립 리뷰 카드가 완료로 표시되는데 지적 사항이 하나도 없어, 리뷰어 대화에서 결과를 직접 복사해 붙여넣어야 했던 문제를 수정했습니다. 중간 보고 시점의 상태가 최종 결과로 고정되던 것이 원인이었습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/376)

### 로그아웃하면 등록한 자동화가 사라지던 문제

로그아웃할 때 등록해 둔 자동화가 모두 삭제되던 문제를 수정하고, 다시 로그인하면 예정 시각을 현재 기준으로 다시 계산하도록 했습니다. 자동화가 등록한 시각에 실행되지 않는다는 신고의 실제 원인이었습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 자동화는 앱 창이 열려 있는 동안 동작하며, 꺼져 있던 동안 지난 예정은 소급 실행하지 않습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/372)
