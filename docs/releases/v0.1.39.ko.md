### 채팅 폴더 첨부

프로젝트 대화와 Personal Chat에 폴더를 끌어놓으면 하위 폴더 구조와 빈 파일을 유지해 업로드하고, 입력창에는 폴더 하나로 간결하게 표시합니다. 일부 파일이 실패하거나 크기 제한을 넘으면 성공한 파일은 유지한 채 실패·건너뜀 개수와 진행 상황을 알려주며, 업로드 가능한 파일이 없는 폴더도 조용히 무시하지 않습니다.

## 변경된 기능

### 자식 Agent 호출·내부 작업 위임·결과물 미리보기 기본 유지

Saycode 기본 행동 지시를 사용하지 않더라도 자식 Agent 호출, 내부 작업 위임과 결과물 인라인 미리보기는 기본으로 계속 켜집니다. 최초 선택 화면에서 이 동작과 해제 경로를 함께 안내합니다. 자식 Agent를 호출할 때는 선택한 agent·model·effort를 검증해 그대로 전달하며, 지원하지 않는 조합을 기본값으로 조용히 바꾸지 않습니다.

#### 사용 방법

원하지 않는 항목은 **환경설정 → 시스템 프롬프트 → 개별 지시 선택**에서 각각 끌 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/720)

### 텍스트 파일 미리보기 크기 상한을 8MB로 확대

프로젝트 파일 편집기, Personal Chat 파일 미리보기, 답변 안 HTML 인라인 미리보기(`::preview`)에서
