## 새 기능

### 내 PC를 공유하고 프로젝트에 함께 작업하기

본인이 등록하고 배정받은 조직 전용 PC를 공용으로 변경하고, 같은 조직에서 사용할 사람을 선택할 수 있습니다. 공용 PC의 접근 권한이 없는 사람을 프로젝트에 초대하면 권한 추가를 확인한 뒤 초대를 보냅니다. 함께 작업 중인 사람의 접근을 막는 변경은 거절합니다. 일부 관리형 AI 인증이 연결된 PC는 유형 변경이 제한됩니다.

#### 사용 방법

내 설정 → 개발 → 작업PC에서 PC 공유 설정을 엽니다. 프로젝트 설정 → 함께 작업에서도 본인 전용 PC를 공용으로 변경하거나, 초대 대상의 PC 접근 권한 추가를 확인할 수 있습니다.

## 변경된 기능

### 다시 로그인해야 하는 계정을 사용량 목록에서 숨김

AI 사용량 목록에서 ‘다시 로그인 필요’ 상태인 계정을 숨깁니다. 재로그인 후 정상 상태가 확인되면 다시 표시합니다. 나머지 계정의 잔여량 정렬과 선택 동작은 유지합니다.

#### 사용 방법

AI 계정·사용량 목록을 열면 자동 적용됩니다.

### 더보기 아이콘 통일

사이드바, 대화·프로젝트, 입력창 옵션, 파일·예약·터미널 등의 더보기 아이콘을 세로 세 점으로 통일했습니다. 기존 메뉴 기능과 버튼 크기는 유지됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 사용 가능한 AI 계정을 잔여량 순으로 표시

AI 사용량 목록에서 현재 사용 중이거나 선택 가능한 계정을 먼저 표시합니다. 각 그룹은 5시간 잔여량이 많은 순으로 정렬하고, 같으면 7일 잔여량을 비교합니다. 미확인 값은 뒤로 보내며 잔여량이 같으면 기존 순서를 유지합니다. 로그인 필요·선택 제외·조직 관리 계정은 아래에 표시합니다.

#### 사용 방법

AI 계정·사용량 목록을 열면 자동 적용됩니다.

### 사이드바 메뉴와 목록 탐색 개선

상단 Chat·Project 메뉴에서 새 채팅 입력 또는 Build/Develop 시작 화면을 엽니다. Project는 큐브 아이콘을 사용하며 중복 홈 메뉴는 제거했습니다. 목록은 별도의 Chat/Project 탭으로 전환하고, 탭을 바꿔도 오른쪽 화면·대화·초안은 유지합니다. 외부 연동과 예약 메뉴를 열어도 선택한 목록 탭을 유지합니다. 탭과 검색 버튼은 스크롤해도 고정되며 이전 슬라이드 애니메이션을 적용했습니다. 메뉴 아래 간격과 탭 배경의 라운드도 맞췄습니다. 하단 생성 버튼을 제거하고 선택한 목록 탭 오른쪽에는 작은 중립색 검색 아이콘만 표시합니다. 빈 검색을 닫아도 추가 목록 조회가 유지되며 검색 단축키를 다시 누르면 입력창에 포커스합니다. 두 목록의 검색어는 유지되며 프로젝트 보기 옵션은 펼친 검색 입력 옆에 있습니다.

상세 화면에서는 상단 메뉴가 선택되지 않고 현재 목록 항목만 선택됩니다. 더보기는 작은 중립색 텍스트로, 사이드바 너비 조절선은 균일한 두께로 표시합니다. 앱 시작은 저장된 Chat/Build/Develop을 우선하고 저장값이 없으면 Chat을 엽니다. 기존 대화·패널·초안은 다시 선택할 수 있으며 목록에 없는 저장 Chat도 캐시를 먼저 표시합니다. Build는 모든 사용자에게 제공합니다.

#### 사용 방법

상단 메뉴는 시작 화면을 열고 목록 탭은 목록만 바꿉니다. 탭 오른쪽 검색으로 목록을 찾고 X로 지우거나 Escape로 닫으세요. 프로젝트 검색 단축키는 현재 화면을 유지하며 Project 목록 검색을 엽니다. 새 Chat은 상단 Chat 메뉴, 새 프로젝트는 Project 시작 화면에서 시작하세요.

입력창 아래 머신 정보에는 CPU와 메모리 사용량만 표시합니다. 디스크 정보는 클릭해 여는 상세 화면에서 확인할 수 있습니다.

#### 사용 방법

### 입력창 아래 머신 정보 위치 정리

입력창 아래 CPU·메모리·디스크 정보를 오른쪽 버전과 머신명 사이로 옮겼습니다. 요약의 디스크 경로를 숨겨 더 간결하게 표시합니다. AI 사용량을 끄고 리소스만 켜도 개발자 기능 설정 아이콘을 사용할 수 있습니다.

#### 사용 방법

기존 리소스 표시 설정을 켜면 자동 적용됩니다. 리소스를 누르면 상세 정보를 확인할 수 있습니다.

### 채팅 입력창 더보기 아이콘 정리

채팅 입력창 안의 더보기 아이콘을 가로 점 세 개로 변경했습니다. 기존 메뉴와 사용 방법은 같습니다.

#### 사용 방법

채팅 입력창의 가로 점 세 개 버튼을 눌러 추가 옵션을 열 수 있습니다.

### 홈 인사 영역 크기 축소

홈의 프로필 이미지와 인사말 크기, 주변 간격을 줄여 더 간결하게 표시합니다. 긴 이름 표시와 프로필 설정 바로가기는 유지합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 이미지나 인사말을 누르면 기존처럼 프로필 설정이 열립니다.

### AI 계정의 ‘제외됨’ 상태 문구 제거

AI 계정 목록의 상태 뱃지에서 ‘제외됨’ 문구를 제거합니다. 다른 상태 안내와 기존 선택 제한·툴팁 안내는 유지합니다.

#### 사용 방법

AI 계정·사용량 목록을 열면 자동 적용됩니다.

### AI 브라우저 진입과 Chat 더보기 위치 정리

대화 위 AI 브라우저 배너를 `AI 브라우저 열기` 버튼으로 줄여 우상단 더보기 왼쪽에 배치했습니다. 개인 Chat도 프로젝트 상세와 같은 위치에서 더보기를 열어 이름 변경·파일·실행 설정 등 기존 작업을 사용할 수 있습니다.

#### 사용 방법

개발자 기능 설정의 `AI 브라우저 버튼 보이기`를 켜면 지원되는 대화의 오른쪽 위에 버튼이 표시됩니다. 대화 작업은 옆의 세로 더보기를 누르세요.

### AI 사용량의 조직계정 표시 간소화

AI 사용량 목록에서 조직이 제공한 계정의 긴 상태 뱃지를 ‘조직계정’으로 표시합니다. 사용량 수치와 로그인 필요 안내, 기존 선택 제한은 유지합니다.

#### 사용 방법

AI 계정·사용량 목록을 열면 자동 적용됩니다.

### Chat 예시를 선택하면 바로 적용

Chat 시작 화면에서 예시를 선택하면 교체 확인 없이 요청과 예시 파일을 준비합니다. 직접 올린 파일은 유지하며 자동으로 전송하지 않습니다.

#### 사용 방법

Chat 시작 화면에서 작업을 고르고 원하는 예시를 누르세요. 입력 내용을 확인한 뒤 전송할 수 있습니다.

### Chat과 Build 시작 화면의 입력 위치 통일

Chat과 Build를 오갈 때 안내 문구와 입력창이 같은 위치와 폭으로 표시됩니다. 창 크기나 아래 추천/프로젝트 목록 길이에 따라 입력 위치가 달라지지 않도록 맞췄습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 사이드바 Chat·Project 메뉴에서 시작 화면을 전환하세요.

## 수정된 문제

### 마지막으로 선택한 AI와 모델 유지

새 대화에서 직접 선택한 AI·모델·강도를 다음 대화와 앱 재시작 후에도 기억합니다. AI를 바꿨다가 돌아오면 각 AI의 마지막 선택을 복원합니다. 일시적인 연결 상태나 조직 모델 제한으로 표시가 바뀌어도 원래 선택과 프로필의 모델을 보존하고, 조건이 해제되면 현재 초안에서도 복원합니다. 자동 선택 대화의 시작을 재시도할 때는 이미 확정한 모델을 임의로 바꾸지 않습니다.

#### 사용 방법

새 대화 입력창의 AI·Model·Effort 메뉴에서 원하는 값을 선택하세요. 별도 설정 없이 자동 적용됩니다.

### 셀프호스트 서버의 작업PC가 내 작업PC로, 같은 이름은 구분되어 보입니다

셀프호스트 서버나 앱 안의 개인 서버에 붙인 작업PC가 "다른 작업PC"로 분류되고 소유자가 계정 ID로 나오던 문제를 고쳤습니다. 이제 그 서버의 작업PC는 모두 "내가 등록한 작업PC"로 보이고 소유자는 "나"로 표시됩니다. 사이드바 아래 작업PC 표시와 그 선택 메뉴에서도 같은 이름의 작업PC가 둘 이상이면 ID 앞자리로 구분합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 셀프호스트 작업PC 연결 명령 안전성 개선

셀프호스트 작업PC 연결 안내에서 서버 주소에 특수문자가 있어도 복사한 로그인 명령이 주소를 안전하게 전달합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 예약 목록의 일부 조회 실패 안내

예약 일부를 읽지 못했을 때 확인된 목록을 유지하고 다시 확인할 수 있도록 안내합니다. 모든 예약을 읽지 못한 경우 예약이 없는 것처럼 예시를 표시하지 않습니다.

#### 사용 방법

예약 메뉴에서 안내 옆의 다시 확인을 누르세요.

### 예약 실행 이력 닫기 후 키보드 위치 복원

예약 실행 이력을 닫으면 해당 예약의 더보기 버튼으로 키보드 포커스가 돌아옵니다. 해당 행이 없어졌다면 상단 예약 버튼으로 돌아옵니다.

#### 사용 방법

예약 행의 더보기에서 실행 이력을 열고 Escape 또는 닫기를 누르세요.

### 예약 저장 확인 후에도 작성 내용 보존

예약 저장 응답을 확인하지 못했을 때 예약 목록을 확인한 뒤에도 요청 내용과 일정을 이어서 볼 수 있습니다. 목록 조회에 실패해도 초안을 열 수 있으며, 저장 여부가 불확실한 동안 중복 등록은 차단합니다. 기존 미확정 초안을 취소하기 전에는 다른 예시 예약을 시작할 수 없어 작성 내용이 덮어써지지 않습니다.

#### 사용 방법

예약 목록 확인 후 상단 이어서 작성을 누르세요. 초안은 현재 계정과 조직의 예약 화면에 머무는 동안 유지됩니다.

### 작업PC 등록 안내가 연결한 서버에 맞게 나옵니다

셀프호스트 서버에 연결한 상태에서 작업PC 등록 안내를 열면, 실제 서버 주소가 들어간 로그인 명령과 서버에서 승인하는 명령이 순서대로 나옵니다. 이전에는 Saycode 클라우드 명령과 `<서버 주소>` 자리표시자가 함께 나와, 따라 하면 다른 서버에 붙거나 승인 단계를 놓칠 수 있었습니다. 셀프호스트에서 쓰이지 않는 등록 코드 생성 버튼도 숨깁니다. 앱 안에서 서버를 실행하는 개인 사용에서도 클라우드 명령은 나오지 않습니다.

#### 사용 방법

설정 → 작업PC → 작업PC 등록에서 안내된 명령을 새 작업PC와 서버에서 차례로 실행합니다.

### 조직 전용 PC에서 앱이 종단간 암호화 전환을 대신 하지 못하던 문제 수정

조직 전용 PC는 조직 키로 보호되는데, 앱이 이 PC를 종단간 암호화로 전환할 때 개인 계정 키와만 비교해 항상 거절했습니다. 그래서 PC가 스스로 전환하지 못한 경우 조직 AI 계정 연결이 `AI_GROUP_CUSTOMER_KEY_REQUIRED`로 멈췄습니다. 이제 이 계정이 실제로 열 수 있는 조직 키로 보호된 PC도 앱이 안전하게 전환합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 시작 준비에서 다시 연결을 누르면 됩니다.

### 조직 AI 계정 적용이 멈추던 문제를 고쳤어요

내장 Saycode 런타임을 `1.1.10-aplus.316`으로 올려요. 조직 AI 계정(관리형 setup-token)이 한 번 개인 계정처럼 저장되면, 이후 다시 연결할 때마다 `AI_GROUP_CREDENTIAL_CONFLICT`나 `AI_GROUP_APPLY_FAILED`로 멈추던 문제를 고쳤어요. 이제 그 계정을 조직 계정으로 다시 저장하고, 사용 중이던 계정이면 계속 사용 중으로 둬요. 앱이 Windows에 직접 설치한 Python 위에서 claude-swap이 돌 때 계정 적용이 `AI_GROUP_SYNC_FAILED`로 실패하던 문제도 함께 고쳤어요.

#### 사용 방법

따로 할 일은 없어요. 앱을 업데이트한 뒤 시작 준비에서 다시 연결하면 돼요.

### 좁은 분할 화면의 AI 계정 목록 잘림 수정

대화 옆에 작업 도구를 넓게 열었을 때 AI 계정 목록의 오른쪽이 가려지던 문제를 수정했습니다. 목록이 현재 대화 영역의 너비에 맞춰 표시됩니다.

#### 사용 방법

### 회사 프록시를 거쳐야 하는 PC에서 claude-swap 설치가 시간 초과되던 문제 수정

Windows 시작 준비에서 uv는 설치됐는데 claude-swap 설치가 시간 초과(`TOOL_TIMEOUT`)로 실패하던 문제를 고쳤습니다. 앱은 회사 프록시와 Windows 인증서를 따르지만, claude-swap을 설치하는 uv는 둘 다 쓰지 않고 바로 접속했습니다. PC에 Python 3.12 이상이 없으면 uv가 GitHub에서 Python을 직접 받으려다 막히기도 했습니다.

- uv도 앱과 같은 프록시와 Windows 인증서 저장소를 사용합니다.
- Python 3.12 이상이 없는 PC에는 앱이 공식 CPython 3.13(NuGet 배포본)을 직접 받아 설치합니다. 고정한 SHA-512와 일치할 때만 설치하고 사용자 Path는 바꾸지 않습니다. uv는 더 이상 GitHub에서 Python을 받지 않습니다.
- 오류 화면에는 Python 준비와 패키지 설치가 별도 단계로 표시됩니다. 실패하면 uv 출력의 마지막 부분이 민감정보를 가린 뒤 setup.log에 남습니다. 설치 제한 시간은 3분에서 10분으로 늘었습니다.
