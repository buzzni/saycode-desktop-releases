## 새 기능

### 대화에서 say플랜 사용량 확인

say플랜으로 실행한 Chat과 프로젝트 대화의 입력창 아래에서 내 플랜 등급(Basic·Plus·Pro), 실행 모델과 이번 달·이번 주·5시간 사용량, 재설정 시각을 확인할 수 있습니다. 창은 항목마다 이름·재설정 시각·사용률을 한 줄에 두고 막대를 아래에 둔 간결한 모양입니다. 플랜 대화에 작업PC 계정의 잔여량이 함께 표시되던 혼동을 줄였습니다.
현재 AI는 대화의 실제 실행 정보로 구분합니다. 다음 요청의 선택값으로 바뀌지 않으며, AI를 확인하지 못한 대화는 임의로 Claude나 PC 사용량을 표시하지 않습니다.

하단 say플랜 버튼은 기존 사용량 버튼과 같은 높이·글자·여백과 호버 영역을 사용합니다.

실행 ID로 AI를 확인하는 오래된 Project 대화는 전송·재시도도 같은 AI를 사용하며, Codex 대화가 Claude 인증으로 잘못 진입하지 않습니다.

#### 사용 방법

플랜으로 실행한 대화를 열고 입력창 아래의 say플랜을 누르세요. 열 때 최신 사용량을 확인하며, 조회 실패 시 다시 확인을 누를 수 있습니다.

### 새 Codex 대화를 조직 정액 플랜으로 시작할 수 있습니다

조직에서 정액 플랜(say플랜) 등급을 받은 구성원은 새 Codex 대화를 시작할 때 실행 방식을 고를 수 있습니다.
"say플랜 · 이번 주 남은 사용량 N%"를 고르면 그 대화는 정액 플랜으로 실행되고, "이 머신의 Codex 로그인"을
고르면 지금처럼 작업PC의 Codex 로그인으로 실행됩니다. 플랜을 쓸 수 없으면 대화를 시작하지 않고 이유를 보여 주며,
작업PC의 Codex 로그인으로 몰래 바꿔 실행하지 않습니다. 플랜 상태를 확인하지 못했고 직접 고른 것도 없으면
시작 전에 "플랜 상태를 확인하지 못해 이 머신의 Codex 로그인으로 시작합니다."라고 알린 뒤 Codex 로그인으로 시작합니다. 상위 모델의 이번 주 사용량이 다 찼으면 gpt-6-luna로
시작한다고 미리 알려 줍니다.

플랜 대화는 대화 위에 플랜 배지가 보이고, 사용량과 재설정 시각을 확인할 수 있습니다. 한도에 닿으면(사용률이 100%가 되기 전이라도 다음 요청을 감당할 수 없으면) 다시 쓸 수 있는 시각과
"구독으로 새 세션"이 나타나 이 머신의 Codex 로그인으로 이어서 대화할 수 있습니다. 플랜 대화는 터미널에서 이어가기를
막습니다.
플랜 대화는 이 PC의 개인 Codex 로그인을 쓰지 않으므로, 개인 Codex 연결을 해제했어도 플랜 대화의 시작·이어가기·재개는
막지 않습니다. 이 머신의 Codex 로그인으로 도는 대화는 지금처럼 확인합니다.

#### 사용 방법

Project에서 새 대화를 열고 AI를 Codex로 고른 뒤, 입력창 옵션 아래의 "대화 실행 방식"에서 고릅니다. 지금 고른 방식을
다음에도 쓰려면 "기본값으로 저장"을 누릅니다. 작업PC의 Saycode 실행기가 정액 플랜을 지원해야 보입니다.

### 에이전트가 사내 LLM으로 자식 대화를 시작

에이전트 CLI에서 배정된 사내 LLM을 자식 대화의 연결로 선택할 수 있습니다. 사내 LLM 대화가 만든 자식은 같은 사내 LLM을 상속합니다. 지원·배정·실행 증명을 확인할 수 없으면 이유를 표시하고 중단합니다.

#### 사용 방법

지원되는 CLI·데몬·서버가 설치된 전용 작업PC의 새 대화에서 `happy agent spawn --agent claude --org-endpoint <id> --prompt <text>`를 사용합니다. 사내 LLM 부모에서는 endpoint 옵션을 생략하면 같은 연결을 상속합니다. 구버전이나 실행 증명 없는 기존 대화에서는 새 대화를 시작해야 합니다. 이 소스 변경만으로 설치된 런타임이 업데이트되지는 않습니다.

### 외부 연동을 이해하고 대화로 돌아가기

연결 후에도 서비스 설명과 계정을 함께 보여 줍니다. 연결 해제는 관리 메뉴에서 확인하고, 대화에서 연 경우 원래 대화로 돌아가 작성 중인 내용을 이어갈 수 있습니다. 자동으로 전송하지 않습니다. 인증 브라우저를 열지 못하면 오류를 알리고 같은 연결 버튼으로 다시 시도할 수 있습니다.

#### 사용 방법

사이드바 외부 연동에서 서비스를 연결합니다. 대화에서 열었다면 원래 대화로 돌아가기를 누릅니다. 연결 해제는 서비스별 관리(⋮) 메뉴에 있습니다.

### 요금제 플랜의 DeepSeek Eco 연결

관리자가 OpenGateway 플랜을 지정하면 say플랜으로 DeepSeek Eco를 사용할 수 있습니다. 기존 OpenAI 플랜 대화는 시작한 모델을 유지합니다. 지원하지 않는 작업PC에는 업데이트가 필요하다고 안내합니다. Eco 대화에는 플랜 사용량을 표시하고 개인 Claude의 터미널 이어가기는 기존처럼 사용할 수 있습니다.

함께 제공하는 Happy CLI 런타임을 1.1.10-aplus.416으로 갱신해 Eco 플랜 실행을 지원합니다.

#### 사용 방법

최신 작업PC에서 새 대화의 사용 연결을 say플랜으로 고릅니다. 관리자가 지정한 공급자와 모델이 적용됩니다. 플랜 대화는 앱 안에서 계속 사용합니다.

### saycode 플랜 한도 초과 시 관리자에게 요청

saycode 플랜 대화에서 플랜 사용 한도를 초과하면 도움이 되지 않던 AI Models 버튼 대신 관리자에게 요청 버튼 하나만 표시합니다. 누르면 조직의 AI 관리자에게 사용량 한도 확인 요청이 전달됩니다.

#### 사용 방법

플랜 한도 초과 안내 아래의 관리자에게 요청을 누릅니다. 요청을 받을 관리자가 없으면 직접 문의하라는 안내가 나옵니다.

## 변경된 기능

### 내부 AI를 배정받지 않은 경우 연결 탭 숨김

조직 관리자가 배정한 내부 AI가 없으면 모델 메뉴에서 내부 AI 탭을 숨깁니다. 이미 선택한 연결의 배정이 회수되거나 기존 내부 AI 대화를 열면 원천 표시와 안내는 유지합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 내부 AI를 배정받으면 입력창 모델 메뉴에 탭이 표시됩니다.

### 내부 AI를 연결 탭 옆에서 바로 선택

내부 AI를 say플랜·AI 계정과 같은 메뉴에서 바로 선택할 수 있습니다. 입력창에는 기존 AI 모델명과 작업 강도 대신 선택한 내부 AI 연결명이 표시되고, 메뉴의 간결한 목록에서 실제 모델과 혼잡도를 확인하고 오른쪽 체크 표시로 선택한 서버를 구분할 수 있습니다. 사용 가능한 AI가 없어도 연결 메뉴와 준비 안내를 함께 제공합니다. 세 연결 탭을 항상 표시하고 사용할 수 없는 항목은 비활성 상태와 사유 툴팁으로 안내합니다. 관련 없는 계정·모델 옵션, 기존 Claude 계정 사용량·복구 표시와 중복 선택창을 정리했습니다.

#### 사용 방법

내 전용 작업PC의 새 대화 입력창에서 모델 메뉴를 열고 내부 AI 탭을 누르세요. 배정된 연결이 바로 적용되며 여러 개면 목록에서 바꿀 수 있습니다. AI 계정이나 say플랜 탭으로 돌아가면 내부 AI 선택이 해제됩니다. 내부 AI 탭으로 돌아오면 마지막 연결이 복원됩니다. 배정이 회수되면 연결과 안내를 유지하므로 다른 연결을 직접 고르세요. 시작한 대화의 연결은 바꿀 수 없습니다. 배정을 불러오지 못하면 메뉴에서 다시 확인을 누르세요. 내부 AI 대화의 컨텍스트 사용량과 압축 기능은 그대로 사용할 수 있습니다.

### 배포 창을 웹과 같은 흐름으로 정리했어요

기존 배포 주소와 마지막 배포자를 한 카드에서 확인하고, 배포 옵션으로 기존 주소 업데이트와 새 배포를 전환할 수 있습니다. 파일 요약·데이터 포함·배포 관리는 고급 설정에 모으고, 빌드 방식은 저장돼 실제 배포에 반영됩니다. 데이터 포함과 덮어쓰기 확인을 같은 화면에서 진행하며, 완료 주소·복사와 단계 설명을 간결하게 표시합니다.

웹처럼 배포 전 코드 검사와 자동 수정, 프로젝트 AI 복구·중단·재개, 저장소 연결과 SSO 코드 작업을 이어갈 수 있습니다. 지원 요청은 접수 결과를 배포 창에 남기고 실패하면 다시 요청할 수 있습니다. 지연된 배포는 확인창을 취소하거나 닫았다 열어도 같은 실행을 확인합니다.

자동 수정으로 바뀐 설정 파일은 기존 파일까지 정리해 배포하고, 타입 검사 자동 우회가 불가능하면 안내 후 기존 빌드 설정으로 계속 진행합니다.

프로젝트 헤더의 배포 버튼 높이를 줄이고 오른쪽 더보기 아이콘과 가운데 정렬했습니다.

#### 사용 방법

프로젝트의 배포를 열고 기존 배포는 배포 업데이트, 별도 주소는 배포 옵션 → 새 배포 진행을 선택하세요. 고급 설정에서 범위·빌드 방식·데이터 포함을 확인하고 데이터 교체 경고는 내용을 읽은 뒤 확인하거나 취소하세요. 진행 중 로그는 바로 보이고 완료 후에는 펼쳐 확인할 수 있습니다. 완료 주소 링크로 서비스를 여세요.

코드 오류가 있으면 AI에게 수정 요청을 누르고, 복구 화면에서 수정 중단·다시 시작·대화 열기를 사용하세요. SSO 오류는 코드 통합 작업 시작, 해결되지 않는 오류는 확인 요청으로 이어가세요.

### 조직 정책으로 실행하지 않은 메시지의 안내 중복 정리

조직 정책이 허용하지 않는 모델이라 메시지를 실행하지 않았을 때, 대화에 남는 자세한 안내와 같은 뜻의 "조직 정책으로 이 메시지를 실행하지 않았어요." 줄이 입력창 위에 한 번 더 뜨던 것을 없앴습니다. 이유와 다시 보내는 방법은 대화 속 안내에서 확인할 수 있습니다. 권한 모드를 줄이거나 허용된 모델로 바꿔 실행한 경우의 입력창 위 안내와 24시간 이상 갱신되지 않음 표시는 그대로입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 진행 중인 대화에서 선택한 내부 AI 연결을 확인할 수 있습니다

내부 AI로 시작한 대화에서 모델 메뉴를 다시 열면, 내부 AI 탭만 선택돼 있고 어떤 연결을 골랐는지는 보이지 않았습니다. 이제 내부 AI 탭 아래에 그 대화의 연결명, 사내망·공개 주소 구분과 모델이 표시되고 입력창 버튼에도 `내부 AI · 연결명`이 보입니다. 그 연결이 더 이상 내게 배정돼 있지 않으면 연결명 대신 확인할 수 없다는 안내가 표시됩니다.

#### 사용 방법

내부 AI로 진행 중인 대화의 입력창에서 모델 메뉴(내부 AI 버튼)를 누르세요.

### 파일 복원지점 확인 실패 안내를 토스트로 바꿈

AI 답변이 시작되거나 끝날 때 파일 복원지점 기록을 다시 읽다가 실패해도 패널이 저절로 펼쳐지지 않습니다. 대신 화면 위쪽에 한 줄짜리 안내 토스트가 한 번 뜨고, 패널 머리줄에는 "최근 확인 실패"가 계속 표시됩니다. 토스트를 닫으면 실패가 이어지는 동안 다시 뜨지 않고, 기록을 한 번 제대로 읽은 뒤 다시 실패할 때만 다시 알려 줍니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 최신 목록이 필요하면 토스트의 새로고침이나 패널의 새로고침 아이콘을 누르세요.

### 플랜 이름을 say플랜으로 통일했어요

한국어 화면의 플랜 이름을 `say플랜`으로 통일했습니다. 사용 연결 탭, 대화 아래 사용량 버튼과 팝오버, 오류 안내와 사용 안내에서 같은 이름을 볼 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 플랜 표시명을 say플랜으로 변경

한국어 화면의 플랜 이름을 say플랜으로 통일했습니다. 사용 연결 탭, 사용량 버튼과 팝오버, 관련 안내에 적용됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 플러그인과 확장 관리 안내를 간결하게 정리

설치된 공식 확장은 이름·용도·상태부터 보여 주고 기술 정보와 권한 관리는 상세에 모았습니다. 업데이트·제거는 관리 메뉴에 있습니다. /plugin 설치 창은 설치·권한 승인·활성화의 의미와 작업PC 권한 범위를 설명합니다.

#### 사용 방법

내 설정 → 개발 → 확장에서 용도를 확인합니다. ID·버전·권한은 상세를 열고, 업데이트·제거는 관리(⋮) 메뉴를 누릅니다. /plugin 설치 때는 권한 설명을 확인하고 각 단계를 진행합니다.

### Desktop의 내 프롬프트를 계정에 안전하게 저장해요

Desktop에서 저장한 내 프롬프트를 클라우드 계정의 암호화된 목록과 동기화합니다. 기존에 이 기기에 저장한 항목은 처음 실행할 때 계정 목록과 합칩니다. standalone은 별도 로컬 저장소만 사용하며 로그아웃해도 목록이 남습니다. 계정 전환 중의 저장이 섞이거나 이관 한도 때문에 기존 항목이 사라지지 않게 했습니다. 조회 중·실패·빈 목록을 구분하고 오류 안내에서 바로 재시도할 수 있습니다.

#### 사용 방법

입력창의 책갈피 버튼에서 내 프롬프트를 여세요. 현재 입력을 저장하면 클라우드 계정의 목록과 동기화합니다. 동기화 실패 시 다시 시도로 재시도하세요. standalone에서는 이 기기에만 저장합니다.

### OpenGateway 모델 선택

조직에서 허용한 OpenGateway 모델을 새 대화에서 선택할 수 있습니다. 플랜은 관리자가 지정한 모델을 사용하고 기존 대화는 시작한 모델을 유지합니다.

#### 사용 방법

새 대화의 사내 LLM 연결에서 사용할 모델을 고릅니다. 관리자가 허용 목록을 바꾸면 모델을 다시 선택해야 할 수 있습니다.

### say플랜 대화에서 큰 파일을 나눠 작성해요

say플랜 대화는 AI 답변 한 번의 길이가 정해져 있어서, 리포트 같은 큰 파일을 한 번에 쓰다가 답변이 중간에 멈추고 같은 실패가 반복될 수 있었어요. 이제 플랜 대화의 AI는 큰 파일을 여러 번에 나눠 작성하도록 안내를 받아요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 플랜 사용 여부를 확인한 대화부터 적용돼요.

## 수정된 문제

### 개인 AI 연결 실패를 다시 로그인하지 않고 복구해요

로그인 뒤 연결 상태를 확인하는 동안 진행 상태를 보여줘요. 조회·저장 실패는 필요한 단계만 다시 시도하며, 취소하거나 작업PC 상태가 바뀌면 이전 결과가 완료로 반영되지 않아요. 브라우저 로그인 대기가 취소되면 다시 로그인을 완료해야 하며, 이미 안내한 실패 원인은 유지해요.

#### 사용 방법

개인 AI 계정 연결에서 조회 실패는 다시 확인, 저장 실패는 다시 저장을 누르세요. 로그아웃이 확인되면 다시 연결로 로그인해요. 확인 중 취소하거나 창을 닫아 원래 작업으로 돌아갈 수 있어요.

### 긴 도구 요청의 승인 판정 수정

보호된 대화에서 도구 요청의 표시 내용이 길다는 이유만으로 승인이 막히던 문제를 고쳤습니다. 실제 요청 크기로 검사하며, 승인할 수 없는 요청은 이유를 표시합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 내부 AI 목록을 사용 연결 탭 위에 표시

내부 AI의 연결 목록과 안내를 다른 AI 탭처럼 사용 연결 제목과 탭 위에 표시합니다. 내부 AI의 모델 선택 상자도 Tab 키로 이동할 수 있습니다.

#### 사용 방법

입력창의 모델 메뉴를 열고 내부 AI 탭을 선택하세요.

### 시작준비의 키보드 이동에서 숨겨진 항목을 건너뛰어요

시작준비에서 화면에 보이지 않는 컴퓨터 제어 디버그 항목에 키보드 초점이 멈추거나 화면 읽기 프로그램이 안내하던 문제를 수정했어요. 선택적인 컴퓨터 제어 준비 동작은 그대로예요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 업데이트 직후 조직 AI 계정 대화가 멈추던 문제 수정

앱을 업데이트한 직후 조직 AI 계정 대화에서 메시지마다 "조직 AI 계정의 사용 권한이나 실행 상태를 확인하지 못해 실행을 멈췄습니다 (CAPACITY_DAEMON_HTTP_404)"가 나오던 문제를 수정했습니다. 이 PC의 작업 실행기가 업데이트를 마무리하는 동안에는 이제 실행을 멈추지 않고, 업데이트가 끝날 때까지 기다렸다가 이어서 실행합니다. 끝내 실행기가 응답하지 않으면 계정 문제가 아니라 실행기 문제라고 안내합니다.

#### 사용 방법

별도 설정 없이 적용됩니다. 기다리는 동안 대화에 안내가 표시되며, 입력과 첨부는 유지되고 언제든 취소할 수 있습니다.

### 여러 창에서 같은 첨부를 동시에 보낼 때 중복 업로드 방지

같은 대화를 여러 창에 열고 동일한 내용과 첨부를 동시에 전송할 때, 진행 중인 첨부가 중복 업로드되지 않도록 수정했습니다. 무시된 창의 초안과 첨부는 유지되며, 완료 후 다시 보내는 동작은 계속 사용할 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 테스트 배포 후 동작 점검 오류를 고쳤어요

직접 고른 배포 주소에서 실제 사이트는 열리지만 마지막 동작 점검이 실패하던 문제를 수정했어요. 최초 배포·재배포·지연된 배포 재확인에 같은 앱과 배포 정보를 사용해요. 서버가 거절한 점검 요청을 불필요하게 반복하지 않아요.

#### 사용 방법

프로젝트 헤더의 배포에서 테스트 배포를 시작하거나 기존 앱을 재배포하세요. 별도 설정은 필요하지 않아요.

### 파일 검색 방식 변경 후 바로 이어쓰기

파일명·내용 검색을 전환한 뒤 포커스가 모드 버튼에 남아 첫 글자가 입력되지 않던 문제를 수정했습니다. 검색어와 선택 범위를 유지해 같은 검색창에서 이어 쓸 수 있습니다. 지원 확인을 기다리는 동안 다른 곳으로 이동하면 포커스를 빼앗지 않습니다. 일반 선택 상자의 방향키·문자 탐색은 선택 상자에 포커스를 유지합니다.

#### 사용 방법

파일 패널에서 내용 검색을 켜거나 끈 뒤 바로 입력하세요. 내용 검색은 기존처럼 Enter를 눌러 실행합니다.

### 프로젝트가 많을 때 자동화 중복 조회 감소

프로젝트를 추가할 때 기존 프로젝트의 GitHub 트리거까지 다시 조회하던 동작을 줄였습니다.
GitHub 트리거가 없는 프로젝트는 불필요한 실행 이력을 읽지 않고, 같은 자동화의 중복 배경
조회를 합칩니다. 직접 새로고침과 변경 후 최신 상태 확인은 유지합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 플랜 공급 모델 자동 허용

관리자가 공급하는 플랜 모델을 조직의 일반 AI 모델 허용 목록과 별개로 사용할 수 있습니다. 플랜 자격과 사용량 한도는 계속 적용되며 개인 구독과 조직 AI 연결은 기존 모델 정책을 따릅니다.

#### 사용 방법

새 대화의 사용 연결에서 API 토큰을 고르면 플랜에서 제공하는 모델을 사용할 수 있습니다.

### ChatGPT 앱에서 보관한 Codex 대화도 Saycode에서 이어서 쓸 수 있습니다

say플랜이나 이 PC의 Codex로 시작한 대화에 다시 메시지를 보내면 "Codex failed to start … is archived"가 뜨고 대화가 시작되지 않는 경우가 있었습니다. 같은 PC의 ChatGPT 앱(Codex)이 그 대화의 Codex 기록을 보관 처리하면 Codex가 이어가기를 거절했기 때문입니다. 대화 복제·되감기도 같은 이유로 실패할 수 있었습니다.

이제 보관된 Codex 기록을 자동으로 복원한 뒤 이어갑니다. 복원된 기록은 ChatGPT 앱의 Codex 목록에 다시 나타납니다.

#### 사용 방법

따로 할 일은 없습니다. 오류가 났던 대화에 다시 메시지를 보내면 이어서 진행됩니다.

### OS 권한 요청 뒤 실제 상태를 다시 확인

컴퓨터 제어의 권한 요청이 끝나면 실제 상태를 다시 읽습니다. 확인 실패 때는 이전 값을 마지막 확인으로만 표시해 현재 허용 상태와 구분합니다. 중복 요청을 막고 다시 확인과 재요청을 구분합니다.

#### 사용 방법

컴퓨터·브라우저 제어 설정의 macOS 권한에서 요청 뒤 상태를 확인합니다. 다시 확인은 OS 요청 없이 상태만 읽습니다. 이 화면은 기존 개발자 기능을 켠 경우에만 표시됩니다.

### say플랜 사용량이 실제로 적용되는 한도만 보여 줍니다

월 한도 하나만 쓰는 조직 플랜에서 사용량 창에 쓰지 않는 `이번 주`·`5시간` 줄이 0%로 보이고, 사용 연결 선택에는 이번 주 남은 사용량이 늘 100%로 보이던 문제를 고쳤습니다. 이제 이런 조직은 `이번 달` 한 줄만 보이고, 남은 사용량도 이번 달 기준으로 보입니다. 한도가 아니라 조직 계약 상태 때문에 플랜을 쓸 수 없을 때는 "한도에 도달했어요" 대신 관리자에게 문의하라는 안내가 나옵니다.

상위 모델(Terra·Sol)이나 Astra로 대화할 때는 그 모델의 이번 주 사용량 줄이 함께 보여, 다른 막대가 남아 있는데 한도로 표시되는 이유를 알 수 있습니다.

#### 사용 방법

대화 입력창 아래 `say플랜` 버튼을 누르면 사용량을 볼 수 있습니다. 별도 설정 없이 자동 적용됩니다.

### say플랜 한도에 도달하면 모델 버튼과 사용 연결에 이유를 보여 줍니다

기본 연결이 say플랜인데 플랜 한도에 도달하면, 새 대화의 모델 버튼에 쓸 수 없는 플랜 모델(예: DeepSeek V4.1 Flash Eco Medium)이 그대로 표시되고 사용 연결에는 "현재 상태에서는 이 연결을 선택할 수 없어요."만 나와 이유를 알기 어려웠습니다. 이제 모델 버튼에는 "say플랜 · 한도 도달"이 표시되고, 사용 연결에는 한도에 도달했다는 이유와 재설정까지 남은 시간, AI 계정으로 바로 시작할 수 있다는 안내가 나옵니다. 플랜 등급·작업PC 지원 같은 다른 이유도 그 이유를 그대로 보여 줍니다. 한도에 도달한 상태로 플랜 대화를 보내면 첫 응답에서 실패하던 대신, 시작 전에 같은 이유를 알려 줍니다. 연결은 자동으로 바뀌지 않습니다.

#### 사용 방법

새 대화 입력창의 AI·모델 메뉴를 열고 맨 아래 사용 연결에서 AI 계정을 누르면 바로 시작할 수 있습니다. 한도가 재설정되면 say플랜을 다시 고를 수 있습니다.

### say플랜 Eco를 별도 AI로 표시하고 저절로 기본으로 고르지 않음

조직 기본값이 say플랜이어도 DeepSeek 같은 Eco 모델이 새 대화의 기본으로 잡히지 않습니다. 내가 say플랜을 기본으로 저장했고 이 작업PC에서 바로 쓸 수 있을 때, 또는 관리자가 say플랜을 지정했을 때만 Eco로 시작합니다. 그 밖에는 내 AI 계정으로 시작합니다. AI 메뉴에서도 Eco 모델이 Claude Code 아래가 아니라 DeepSeek 같은 별도 AI로 보입니다. 저장해 둔 say플랜을 이 작업PC에서 쓸 수 없을 때도 '이 선택을 기본값으로'로 AI 계정을 새 기본값으로 저장할 수 있습니다.

#### 사용 방법

새 대화 입력창의 AI 메뉴 › 사용 연결에서 say플랜을 고르면 Eco 모델을 쓸 수 있습니다. 매번 쓰려면 say플랜을 고른 뒤 기본으로 저장하세요.
