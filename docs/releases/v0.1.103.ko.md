## 새 기능

### 업데이트 진행을 링으로 보고, 다 받으면 자동으로 재시작

업데이트를 내려받는 동안 사이드바 아래 알림(종) 왼쪽에 동그란 링이 생기고 다운로드만큼 채워져서, 거의 다 찼으면 곧 재시작된다는 걸 알 수 있어요. 링에 마우스를 올리면 진행률이 보이고, 누르면 내려 둔 업데이트 카드가 다시 열려요. 다운로드가 끝나면 카드가 다시 열리고 10초 뒤 자동으로 재시작해요. 지금 재시작이나 나중에를 고를 수 있고, 나중에를 고르면 앱을 끌 때 적용돼요. 진행 중인 응답이 끝나길 기다리는 동안에도 지금 재시작을 고를 수 있어요. 예전 실행에서 받아 둔 업데이트로 앱을 켜자마자 재시작하지는 않아요.

#### 사용 방법

업데이트 카드에서 업데이트를 누르고, 사이드바 아래 알림 왼쪽의 링을 확인하세요.

## 변경된 기능

### 새 프로젝트와 기존 폴더 가져오기를 한 창으로

새 프로젝트 창의 기존 폴더 탭을 새 프로젝트 탭에 합쳤습니다. 이름만 쓰면 작업PC에 그 이름으로 새 폴더를 만들어 프로젝트를 만들고(소문자·`-`로 정리, 한글은 그대로), 작업 폴더에서 추가를 누르면 고른 폴더로 바로 만들어요. 첫 폴더가 작업 폴더, 나머지는 추가 폴더가 됩니다. 이 컴퓨터에서는 추가를 누르면 Finder(Windows 탐색기)가 바로 열리고, 다른 작업PC는 폴더 탐색 창이 열려요. 작업 폴더 칸의 작업PC 이름을 눌러 다른 작업PC를 고를 수 있어요. 시작 화면 입력창 아래 칩의 새 프로젝트도 같은 창을 열고, 만든 프로젝트가 칩에 바로 골라져요. 새 프로젝트 창에서는 최근에 작업한 폴더와 여러 폴더 가져오기 링크가 보이지 않아요.

#### 사용 방법

Project → Develop → 프로젝트 만들기(또는 입력창 아래 프로젝트 선택 › 새 프로젝트)에서 이름을 쓰거나 작업 폴더의 추가를 누르세요.

### 세이폼 예시 프롬프트를 칩으로 표시

세이폼의 새 기능 소개, 사용법 안내, 콘티 만들기 예시를 아이콘과 이름이 함께 있는 칩으로 표시합니다.

#### 사용 방법

제작 입력창 아래에서 예시 칩을 누르면 요청이 입력창에 채워집니다.

### 세이폼 입력창에서 AI와 모델 선택

세이폼 시작 화면에서 사용할 AI와 모델을 고를 수 있습니다. 프로젝트와 작업PC 선택은 입력창 밖 왼쪽 아래로 옮겼습니다.

#### 사용 방법

입력창 아래에서 제작 프로젝트를 확인한 뒤 입력창 안의 AI 메뉴에서 모델을 고르고 제작을 시작합니다.

### 시작 화면과 대화 탭을 더 차분하게

시작 화면의 Chat·Project·Develop 탭은 옅은 바탕에 흰(다크 모드는 살짝 밝은) 알약으로, 선택된 글자도 파란색 대신 기본 글자색으로 바뀌었고 탭마다 좌우 여백이 조금 넓어졌어요. 인사말은 "어떤 작업을 도와드릴까요?" 바로 위에 붙어 두 줄로 이어 읽히고, Chat과 Project의 제목 글자 간격이 같아졌어요. 인사말에 마우스를 올리면 배경 없이 글자색만 바뀌어요. 대화·작업 도구 탭에서 선택된 흰 탭에는 옅은 그림자가 생겨 회색 줄과 구분돼요.

#### 사용 방법

시작 화면과 대화 탭에서 바로 보여요. 따로 할 일은 없어요.

### 입력창 위 저장소 바는 처음에 접힌 채로

프로젝트 대화 입력창 위의 저장소 바(브랜치·작업트리 등)가 처음에는 접혀 있어요. 입력창 오른쪽 위 저장소를 눌러 펼치면, 이 기기에서는 다음 대화와 앱을 다시 열어도 펼친 채로 있어요.

#### 사용 방법

프로젝트 대화 입력창 오른쪽 위의 저장소를 눌러 펼치거나 접으세요.

### 헤더 새 대화 버튼을 패널 열기 왼쪽으로

대화 머리글의 ＋ 새 대화 버튼이 오른쪽 패널 열기 버튼 왼쪽으로 옮겨져, 패널 열기 버튼이 맨 끝에 있어요. 프로젝트 대화에서 누르면 그 프로젝트의 새 대화가 새 탭으로 열리고, Chat 대화에서는 지금처럼 시작 화면이 Chat으로 열려요.

#### 사용 방법

대화 머리글 오른쪽에서 ＋ 새 대화 또는 맨 끝의 패널 열기 버튼을 누르세요.

### Chat 작업 폴더 선택: 다른 작업PC 폴더에서도 대화

Chat 입력창 + 메뉴의 "기존 경로에서 시작"이 "작업 폴더 선택"으로 바뀌고, 새 프로젝트 창과 같은 작업 폴더 칸이 있는 창이 열려요. 이 컴퓨터에서는 추가를 누르면 Finder(Windows 탐색기)가 바로 열리고, 다른 작업PC는 폴더 탐색 창이 열려 그 PC의 폴더에서도 Chat을 할 수 있어요. 창의 작업PC 이름을 눌러 다른 작업PC를 고르면 Chat 입력창의 작업PC도 그 PC로 바뀌어요. 홈 밖 폴더는 이 폴더 허용을 거쳐요.

#### 사용 방법

Chat 입력창 + → 작업 폴더 선택 → 추가로 폴더를 넣고 선택을 누르세요.

### Chat과 Project는 같은 입력창처럼

시작 화면의 Chat과 Project 탭(사이드바 Chat·Project 포함)을 오가도 쓰던 글과 첨부가 그대로 따라가고, Project에도 Chat과 같은 내 프롬프트 도구가 있어요. 프로젝트 칩은 Project 탭에만 있어요. 사이드바 Project로 들어오면 Build가 켜진 채로, 시작 화면에서 Project 탭으로 바꾸면 꺼진 채로 열려요. 제목은 프로젝트를 골라도 Chat과 같은 "어떤 작업을 도와드릴까요?"이고, Build가 꺼져 있으면 안내 문구도 Chat과 같으며 프로젝트 없이 보내면 새 Chat으로 시작해요. Build를 켜면 "기획으로 프로젝트 시작해보세요"로 바뀌고 기획부터 시작해요. 꺼진 Build에 마우스를 올리면 "Build를 켜면 기획 단계부터 시작할 수 있어요"가 보여요.

#### 사용 방법

시작 화면에서 Chat과 Project 탭을 오가며 쓰거나, Project에서 프로젝트를 고르거나 Build를 켜고 보내세요.

### Mac에서 Xcode 명령줄 도구 없이 Git을 자동 설치해요

Xcode 명령줄 도구가 없는 Mac에서 시작준비가 Git 단계에서 멈추고 Apple 설치 창을 열라고 안내하던 것을 바꿨어요. 이제 Saycode가 Git만 직접 받아 설치하고 다음 단계로 넘어가요. Xcode 라이선스 미동의나 Xcode 업데이트 필요로 Git이 실행되지 않을 때도 같아요. 이미 Git이 잘 실행되는 Mac에서는 아무것도 받지 않아요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 시작준비에서 다음을 누르면 필수 도구와 함께 Git이 설치돼요. 다운로드에 실패하면 Git 행에 설치 실패가 보이고, Git 오류 상세에서 원인을 확인한 뒤 다시 시도를 누르면 돼요.

## 수정된 문제

### 공개 링크를 만들지 못한 이유를 구체적으로 알려 줍니다

공개 링크를 만들지 못하면 원인과 상관없이 "서버가 이 파일의 공개 요청을 거부했습니다"가 표시되던 문제를
수정했습니다. 이제 작업PC가 보안 강화(strict) 모드인 경우, HTML 파일 형식이 맞지 않는 경우, 파일이 10MB를
넘는 경우, 공개 범위·만료 설정이 맞지 않는 경우, 작업PC에 연결하지 못하거나 파일을 읽지 못한 경우를 각각
구분해 다음에 할 일과 함께 안내합니다.

#### 사용 방법

별도 설정 없이 공개 링크 만들기에 자동 적용됩니다.

### 닫은 시작 패널은 같은 프로젝트의 새 대화에서도 닫힌 채로

프로젝트 시작 패널이 파일·터미널·미리보기인 프로젝트에서 오른쪽 패널을 접으면, 그 프로젝트에서 새 대화를 열어도 패널이 다시 열리지 않아요. 다시 펼치면 그다음 새 대화부터 시작 패널이 다시 열려요. 기획 패널은 지금처럼 대화마다 열려요.

#### 사용 방법

프로젝트 대화에서 오른쪽 작업 도구의 도구 접기를 누르세요.

### 사이드바 프로젝트를 한 번 눌러 바로 펼치고 접기

사이드바 Project 목록에서 다른 프로젝트를 보고 있을 때 펼쳐져 있던 프로젝트를 누르면, 첫 번째 누름은 선택만 되고 두 번째에야 접혔습니다. 이제 한 번 누르면 바로 펼쳐지거나 접히고, 그 프로젝트도 함께 선택됩니다.

#### 사용 방법

사이드바 Project 목록에서 프로젝트 이름을 누르세요.

### 세이폼을 열기 전 미리보기와 영상 도구 준비

세이폼을 열 때 미디어 미리보기 확장과 파일 읽기 권한, 이 Mac의 FFmpeg와 ffprobe를 확인합니다. 준비할 항목이 있으면 제작환경 창에서 상태를 함께 보여 주고, 설치와 재확인이 완료되면 시작 화면을 엽니다.

#### 사용 방법

연동/확장 아래의 세이폼 카드에서 열기를 누릅니다. 제작환경 창이 나오면 준비하고 열기를 누릅니다. 기존 미리보기 확장의 권한을 확인하거나 복구하려면 확장 목록 열기를 누릅니다. FFmpeg 실행 파일의 연결이 풀렸으면 Homebrew로 다시 연결한 뒤 확인합니다.

### 업데이트 뒤 띄운 작업PC 실행기가 기록 없이 꺼지지 않습니다

0.1.102부터 앱이 실행기를 직접 띄우면서, 실행기가 중간 실행 프로그램 아래에서 설치 폴더를 작업 폴더로 잡고 돌았습니다. 이 중간 프로그램이 끝나면 실행기도 함께 꺼져, 기록 없이 연결이 끊기는 일이 있었습니다. 이제 실행기는 예전처럼 홀로 돌고 사용자 폴더를 작업 폴더로 씁니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 이전 세이폼 대화의 영상 미리보기 복원

앱을 다시 설치하거나 다른 기기에서 세이폼 제작 대화를 열면 대화에 저장된 제작 기록과 작업PC의 영상 파일을 찾아 오른쪽 미리보기를 복원합니다.

#### 사용 방법

사이드바에서 이전 세이폼 제작 대화를 엽니다.

### 작업 PC 연결이 꺼진 채 남지 않도록 자동으로 다시 연결

앱이 켜질 때 이 PC의 작업 PC 연결 프로그램을 띄운 뒤, 그 프로그램이 곧바로 비정상 종료되면 앱을 다시 켤 때까지 작업 PC가 오프라인으로 남았습니다. 잠자기에서 깨어나 인터넷이 아직 연결되지 않은 순간에 주로 생겼어요. 이제 앱이 1분마다 확인하다가, 비정상 종료가 두 번 연속 보이면 자동으로 다시 연결합니다. 다시 연결은 정상으로 돌아올 때까지 최대 3번이며, 시도할수록 간격이 길어집니다(약 2분·6분·14분 뒤). 메뉴 막대의 완전 종료처럼 직접 끈 경우에는 다시 켜지 않고, 앱 업데이트 설치가 시작되면 그 뒤로는 앱을 다시 켤 때까지 자동으로 다시 연결하지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### Project 탭에서 고른 프로젝트로 보내면 원본 폴더에서, 만들어진 뒤 이동

시작 화면 Project 탭에서 프로젝트를 골라 보내면, 다른 새 대화에서 작업트리를 켠 적이 있어도 프로젝트의 원본 폴더(로컬 원본 저장소)에서 대화를 시작해요. 대화가 만들어질 때까지 입력창에서 보내는 중으로 기다리고, 만들어지면 사이드바의 새 대화처럼 새 탭으로 그 대화를 열어요. 시작하지 못하면 화면을 옮기지 않고 입력창에 쓴 글을 남긴 채 오류를 보여 줘요. 프로젝트를 고르지 않고 Build가 꺼져 있을 때의 안내 문구는 "Build를 켜면 기획 단계부터 시작할 수 있어요"로 바꿨어요.

#### 사용 방법

시작 화면 Project 탭에서 입력창 아래 프로젝트를 고르고 메시지를 보내세요.

### Windows에서 업데이트 뒤 작업PC 연결 중 뜨던 node.exe 창 숨김

Windows에서 앱 업데이트 후 다시 켜져 이 PC를 작업PC로 연결하는 동안 node.exe 콘솔 창이 뜨던 문제를 고쳤어요. 실행기를 시작할 때 node를 한 번 더 띄우지 않게 했고, 앱이 실행하는 다른 프로그램(알림음, 메모리 대시보드, 채널 연결 등)도 창 없이 실행돼요.

#### 사용 방법

사용자 조작은 없어요. 업데이트 뒤 작업PC 연결 중에 콘솔 창이 뜨지 않아요.
