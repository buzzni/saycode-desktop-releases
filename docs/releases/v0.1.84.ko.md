## 새 기능

### 대화 오른쪽에 도구 아이콘바 표시하기

개발자 기능 설정에서 도구 아이콘 사이드바를 켜면 기존 상단 도구 펼치기 버튼과 같은 세로열에서 파일·터미널·브라우저·변경·미리보기 도구를 바로 열 수 있습니다. 기본은 꺼짐이며 표시를 꺼도 열린 도구와 작성 중인 대화는 유지됩니다.

#### 사용 방법

계정 메뉴 → 개발자 기능 설정 → 도구 아이콘 사이드바 표시를 켠 뒤 설정을 닫고 대화 오른쪽 도구 아이콘을 누르세요. 사용할 수 없는 도구는 비활성으로 표시됩니다.

### 대화 이상 운영 알림

대화 준비·시작·전송 실패, 인증·한도·모델/권한 차단, 빈 응답·부분 답변 정체·응답 중단을 운영팀에 알릴 수 있도록 웹과 공통 진단 경로를 연결합니다. 오류 문구의 비밀값을 가리고 같은 사건의 중복 보고를 줄입니다.

#### 사용 방법

대화 사용법은 같습니다. 운영 서버에 알림 기능이 반영되면 자동 적용됩니다.

### 프로젝트 없이 현재 작업PC 터미널 열기

Chat·Project 시작 화면 상단 오른쪽에서 현재 작업PC의 터미널을 바로 열 수 있습니다. 프로젝트와 관계없이 작업PC 홈 폴더에서 시작하며 화면 하단에서 사용할 수 있습니다. 터미널 바를 드래그해 위·아래·왼쪽·오른쪽에 붙일 수 있고, 나머지 화면을 계속 조작할 수 있습니다. 접었다 다시 펼치면 같은 터미널을 이어갑니다.

#### 사용 방법

연결된 작업PC를 선택한 뒤 Chat·Project 시작 화면 상단 오른쪽 터미널 아이콘을 누릅니다. 터미널 바를 원하는 화면 가장자리의 놓기 영역으로 드래그하거나 ⋮ 위치 메뉴에서 방향을 고릅니다. 아이콘을 다시 누르거나 터미널 우상단 닫기 버튼으로 접습니다.

### 프로젝트 폴더를 ZIP으로 다운로드

프로젝트 파일 목록의 폴더에도 웹과 같은 다운로드 버튼을 추가했습니다. 하위 파일과 빈 폴더를 폴더명.zip으로 저장하며, 큰 파일도 작은 청크로 읽고 저장합니다. 읽기나 저장이 실패하면 미완성 ZIP으로 기존 파일을 덮어쓰지 않습니다.

#### 사용 방법

프로젝트 대화에서 도구 펼치기 → 파일을 열고 폴더 행에 마우스를 올리거나 키보드로 다운로드 버튼에 이동하세요. 다운로드를 누르면 폴더명.zip을 저장할 위치를 고를 수 있습니다. 온라인 작업PC와 최신 Saycode 앱·연결 프로그램(.382 이상)이 필요합니다. 프로젝트 제외 규칙이 적용되며 작업공간을 바꾸거나 파일 도구·목록을 닫거나 접으면 진행 중 다운로드가 취소됩니다.

### 홈 폴더 밖의 기존 폴더도 이 PC에서 허용해 가져올 수 있어요

C 드라이브 바로 아래의 작업 폴더나 D 드라이브처럼 홈 폴더 밖에 있는 폴더는 지금까지 "이 폴더는 열 수 없어요"라는 안내만 나오고 가져올 수 없었습니다. 이제 이 PC에서 앱을 쓰고 있다면 그 안내 옆의 이 폴더 허용을 눌러 확인한 폴더만 열 수 있습니다. 허용한 폴더는 설정에서 언제든 취소할 수 있습니다. 다른 PC의 폴더는 그 PC의 앱에서만 허용할 수 있습니다.

#### 사용 방법

새 프로젝트 → 기존 폴더에서 경로를 입력하고, "이 폴더는 열 수 없어요" 안내의 이 폴더 허용 → 허용을 누르세요. 허용을 취소하려면 설정 → 작업PC → 이 PC에서 허용한 폴더에서 허용 취소를 누르세요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 실행 중인 포트를 프로젝트 설정으로 이동

대화 더보기에 있던 실행 중인 포트를 프로젝트 설정의 개발 → 실행으로 옮겼습니다. 홈 프로젝트 목록에서도 기존처럼 포트를 바로 열 수 있습니다.

#### 사용 방법

프로젝트 설정 → 개발 → 실행에서 실행 중인 포트 번호를 누르세요. 설정창이 닫히고 내장 브라우저와 이 컴퓨터의 브라우저에서 열립니다. 작업PC에서 열린 포트가 확인된 경우에만 표시됩니다.

### 실행 PC의 Saycode 로그인으로 AI 브라우저 준비

기본 개인·전용 PC에서는 실행 PC의 Saycode 로그인으로 AI 브라우저를 준비합니다. 지원 버전에서는 브라우저만 사용하기 위해 조직 관리자 등록이나 지문 확인을 반복할 필요가 없습니다. 입력창의 브라우저 메뉴도 개발자 설정 없이 표시합니다. 공용·추가 보호 환경의 기존 승인 절차는 유지합니다.

#### 사용 방법

실행할 PC에서 Saycode를 켜고 로그인한 뒤 Chat 또는 Project 입력창의 + → 이번 요청에 브라우저 사용을 선택하세요. Google Chrome과 로그인 연결을 지원하는 앱·작업PC 런타임이 필요합니다. 다른 PC에서 실행한다면 그 PC의 Saycode 로그인도 유지해야 합니다. 사이트 로그인과 민감 작업의 승인은 별도입니다.

### 예약 작업 목록의 개수 표시 제거

예약 작업 목록 아래의 ‘N개 표시’ 문구를 제거했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 접속 현황에 현재 선택한 조직 표시

클라우드 데스크톱 접속자의 현재 선택 조직을 웹 접속 모니터링에 표시합니다. 선택 ID만 기존 접속 신호에 포함하며 추가 폴링이나 머신 조회는 하지 않습니다. 프로젝트 정보는 보내지 않습니다.
조직 선택 대기 상태는 개인 공간으로 보고하지 않습니다.

#### 사용 방법

서버/웹과 데스크톱을 함께 업데이트하면 자동 적용됩니다. 여러 접속의 선택이 다르면 가장 최근에 확인된 선택 상태를 사용합니다.

### 터미널 도킹 화면 간소화

터미널을 왼쪽·오른쪽·위쪽에 붙이면 맨 위 터미널 아이콘 줄을 숨겨 화면을 넓게 사용합니다. 아래쪽에 붙였을 때는 기존 아이콘 줄을 유지합니다. 터미널 열기 아이콘은 대화 화면의 도구 펼치기 아이콘과 같은 위치에 맞춥니다.
드래그 중 네 방향의 흰 안내 상자를 제거하고 붙을 위치의 반투명 미리보기만 표시합니다. 전역 터미널의 정상 연결 시 connected 줄도 숨깁니다. 재연결·오류·입력 차단 등 필요한 상태 안내는 유지합니다. PC가 오프라인인 상태에서 닫으면 본문으로 포커스를 돌립니다.

#### 사용 방법

터미널 바를 원하는 가장자리로 드래그해 반투명 미리보기를 확인한 뒤 놓거나 ⋮ 위치 메뉴에서 고릅니다. 터미널 우상단 닫기를 누르면 시작 화면의 아이콘 줄이 다시 나타나며, 다시 열면 같은 위치와 터미널을 이어갑니다.

### AI 답변과 작업 지침을 웹 기준으로 맞췄어요

웹과 같은 쉬운 설명·필요한 질문·작업 절차·선택 언어와 문서 수정/검수 원칙을 사용합니다. 파일 접근·기획 저장·미리보기·배포 등 앱 기능은 데스크톱의 실제 동작을 따릅니다. 개인 Chat의 문서·분석 모드에는 프로젝트 개발 절차를 적용하지 않습니다. 기존 사용자 지침과 기본 지시 사용 여부는 유지합니다.

#### 사용 방법

현재의 전체·개별 지침 설정에 따라 다음 요청부터 적용됩니다. 내 설정 → 일반 → 시스템 프롬프트 → 기본 지시 세부 설정에서 쉬운 설명과 요청 범위, 작업 절차 충돌 방지, 대화 언어를 각각 선택할 수 있습니다. 웹에서 저장한 같은 항목의 선택도 반영합니다.

### AI 메뉴와 사용량 창 안내 간소화

AI 자동 메뉴에서 ‘모델을 고르면 강도를 정할 수 있어요.’ 설명 줄을 제거했습니다. 사용량 창에는 마지막 조회 시각만 ‘N분 전’으로 표시합니다.

#### 사용 방법

사용량 창의 ‘N분 전’ 위에 마우스를 올리면 ‘5분마다 조회’ 툴팁을 확인할 수 있습니다.

### MongoDB 메모리 동기화 주소를 다른 프로젝트에서 다시 채워 줌

한 프로젝트에서 MongoDB 메모리 동기화를 켜면, 다른 프로젝트의 MongoDB 메모리 동기화 카드에 가장 최근에 켠 MongoDB 주소와 데이터베이스 이름이 미리 채워져요. 같은 회사 MongoDB를 쓰는 프로젝트마다 주소를 다시 입력하지 않고 동기화 켜기만 누르면 돼요. 저장한 주소는 이 컴퓨터에 운영체제 키체인으로 암호화해 두고, 로그인한 계정마다 따로 기억하며 Saycode 서버로 보내지 않아요.

#### 사용 방법

내 설정 → 개발 → 메모리에서 다른 대상 프로젝트를 고르면 MongoDB 메모리 동기화 카드에 최근 주소가 채워져 있어요. 그대로 쓰거나 바꿔 입력한 뒤 동기화 켜기를 누르세요. 저장해 둔 주소를 없애려면 카드의 저장한 주소 지우기를 누르세요.

### Saycode 계정으로 로그인하면 공개 링크 확장이 기본으로 설치돼요

Saycode 계정으로 로그인해 쓰면 이 PC에 공개 링크 확장이 처음 한 번 자동으로 설치되고 켜집니다. 따로 설치하지 않아도 AI가 만든 HTML 결과물 옆의 `공개 링크`를 누르면 바로 링크를 만듭니다. 허용하는 권한은 결과물의 공개 링크 만들기 하나뿐이며, 링크는 직접 누를 때만 만들어집니다. 나중에 확장을 끄거나 지우면 다시 설치하지 않습니다. 로컬 사용과 체험 모드에는 적용되지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 끄거나 지우려면 `내 설정 → 개발 → 확장`에서 공개 링크 확장을 관리하세요.

## 수정된 문제

### 개인 PC의 AI 브라우저 화면 안내 수정

개인 PC의 AI 브라우저 콘솔에서 화면 연결 오류 대신 작업 PC의 전용 Chrome 창을 이용하도록 안내합니다. 개인 PC에서 지원하지 않는 화면 보기와 크기 조절은 표시하지 않습니다.

#### 사용 방법

AI가 페이지를 열면 작업 PC에서 Saycode가 연 전용 Chrome 창을 선택하세요. 직접 조작할 때는 콘솔에서 제어권 가져오기를 누르고, 마친 뒤 제어권 반납과 계속 진행을 누르세요.

### 공개 링크 확장 설치 실패 개선

공개 링크 확장 설치 실패 시 인터넷 연결·호환성·차단·복구 필요 상태를 구분해 안내합니다. 이전에 메신저 채널을 제공했던 확장은 삭제·교체 후 재설치와 앱 재시작 뒤에도 미확인 채널 상태를 보호합니다.

#### 사용 방법

HTML 작업물 옆의 공개 링크를 누른 뒤 설치 진행을 선택하세요. 설치에 실패하면 안내된 조치 후 같은 버튼으로 다시 시도할 수 있습니다.

### 공개 링크 확장 설치가 "확장을 준비하지 못했어요"로 실패하던 문제 수정

결과 파일의 `공개 링크` 대화상자에서 `설치 진행`을 눌렀을 때, 메신저 연결 준비가 끝나지 않았으면 "확장을 준비하지 못했어요. 다시 시도해 주세요."가 뜨고 설치가 끝나지 않던 문제를 고쳤습니다. 이제 메신저와 관계없는 확장은 메신저 연결 준비를 기다리지 않고 바로 설치되고 켜집니다. `내 설정 → 개발 → 확장`에서 켜고 끄거나 권한을 바꿀 때도 같습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 기존 실행기 준비 누락으로 막히던 채팅 시작 복구

온라인인 이 컴퓨터의 실행기가 커넥터 전달 준비를 하지 못한 경우, 앱에 포함된 실행기의 버전 확인·준비 절차를 거칩니다. 기존 머신과 대화를 유지하며 연결 정보가 늦게 반영되면 채팅 시작 전에 한 번 다시 확인합니다. 키 잠금·권한 오류나 다른 작업PC에는 이 자동 준비를 적용하지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 이 컴퓨터의 연결 준비가 실패하면 작업PC 설정을 열고 다시 확인을 눌러 재시도할 수 있습니다.

### 내 프롬프트 이름을 한글로 편집해요

### macOS에서 폴더 ZIP 압축 해제 오류 수정

폴더 ZIP 다운로드에서 macOS 보조 파일과 메타데이터 폴더를 제외하여 문서가 풀린 뒤 압축 해제 오류가 표시되는 문제를 수정했습니다. 일반 문서와 숨김 파일은 유지됩니다.

#### 사용 방법

프로젝트 파일 트리에서 폴더를 ZIP으로 다운로드한 뒤 macOS 아카이브 유틸리티로 엽니다.

### OS 권한 확인 뒤 대화의 컴퓨터 제어가 "사용 중"으로 막히지 않아요

컴퓨터 제어 확장의 OS 권한 확인이 Cua Driver를 멈추거나 다시 깨운 뒤, 대화에서 컴퓨터 제어를 쓰면 다른 작업이 화면을 쓰고 있다며 거부될 수 있었어요. 이제 이런 관리 작업은 화면 제어를 차지하지 않아서, 권한 확인 직후에도 대화에서 바로 컴퓨터 제어를 쓸 수 있어요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### Windows 앱 업데이트의 보조 프로세스 판정 개선

Windows에서 앱 보조 프로세스의 명령줄 정보를 읽지 못하면 업데이트 설치가 차단되던 문제를 수정했습니다. 앱이 직접 확인한 소속 프로세스 정보를 함께 사용합니다. 설치를 다시 시도하는 동안 이전 시도의 오류 문구가 계속 표시되던 문제도 수정했습니다.

#### 사용 방법

업데이트를 내려받은 뒤 재시작해서 업데이트 버튼을 사용하세요. 같은 오류로 설치가 계속 막히면 Saycode를 완전히 종료한 뒤 [공식 다운로드 페이지](https://saycode.ai/download)에서 Windows 전체 설치 파일(.exe)을 받아 실행해 수동으로 갱신하세요.
