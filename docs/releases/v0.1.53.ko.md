## 변경된 기능

### 메일·공지문 초안 읽기와 복사

메일과 공지문 초안을 일반 본문으로 끝까지 읽고, 제목과 작성 안내를 제외한 내용만 복사할 수 있습니다. 실제 코드의 펼치기 기능은 유지합니다.

#### 사용 방법

초안을 읽고 일반 버튼 `본문 복사`를 누르세요. 작성 중에는 복사를 기다리고, 실패하면 같은 버튼으로 다시 시도하세요. 너무 길거나 반복되어 일부만 표시된 답변은 기존 대화 복사 버튼으로 원문을 복사하세요.

### 문서 작업의 추가 설치 확인

문서 형식을 선택해 요청할 때 기존 도구를 먼저 사용하도록 안내합니다. 추가 프로그램이나 패키지가 필요하면 이름과 이유, 작업PC와 설치 위치를 설명하고 설치하기·취소로 확인받도록 문서 작성 지침을 변경했습니다. 취소·건너뛰기·무응답은 설치 승인으로 해석하지 않습니다.

#### 사용 방법

필요한 설치 안내를 확인하고 설치하기 또는 취소를 선택한 뒤 보내기를 누르세요. 취소하면 이미 있는 도구로 가능한 작업을 진행하고 어려운 단계는 안내합니다.

### 첫 대화를 더 쉽게 시작하기

배정된 조직 AI 계정은 기본으로 자동 선택하며 계정 변경은 추가 옵션에서 제공합니다. 처음 시작할 때 AI 연결 준비를 확인하고, 연결 문제는 다시 연결 또는 앱 복구 버튼으로 안내합니다. 개인 AI 로그인이 필요하면 AI 계정 연결 버튼으로 브라우저 인증을 시작할 수 있습니다. 준비 중 중복 실행을 막고 작성한 질문과 첨부를 유지합니다.

#### 사용 방법

조직을 선택한 뒤 준비가 끝나면 첫 질문을 입력하세요. 연결 안내가 나타나면 표시된 버튼을 누르고, 브라우저가 열리면 로그인을 완료하세요. 다른 AI 계정을 쓰려면 대화 입력창의 추가 옵션에서 변경할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1457)

### 프로젝트 설정 기본 UI 통일

프로젝트 설정의 모달·일반/개발 메뉴·본문 디자인을 내 설정과 맞췄습니다. 읽기 전용 안내는 설정을 열 때 토스트로 표시해 본문 공간을 유지합니다. 썸네일·시작 AI/패널 등 기존 기능과 권한은 유지됩니다.

#### 사용 방법

프로젝트 설정에서 일반·개발 탭을 선택하세요. 다른 사람이 소유한 프로젝트를 열면 읽기 전용 안내가 토스트로 표시됩니다.

### 프로젝트 설정 메뉴 화면 정리

일반·개발 메뉴의 제목·폼·정보·버튼 스타일을 통일했습니다. 협업·관련 프로젝트의 제목, 공유 범위와 팀 구분, 저장소 작업 버튼 배치를 개선했습니다. MCP 연결 항목을 서버와 설정 종류별로 구분할 수 있게 했습니다.

#### 사용 방법

프로젝트 설정을 열어 일반·개발 메뉴를 선택하세요. 별도 설정 없이 자동 적용됩니다.

### 프로젝트 설정 웹 호환 기능과 탐색 개선

일반·개발 탭 구조를 유지하면서 썸네일 캡처·16:9 이미지 업로드·삭제, 시작 AI/패널 설정과 클라우드 빌드 캐시 정리를 추가했습니다. 웹과 설정 값을 공유하며 서버가 변경을 반영하지 못하면 실패와 재시도를 표시합니다. 프로젝트 이전 메뉴는 제공하지 않습니다.

#### 사용 방법

프로젝트 설정의 일반에서 썸네일·시작 설정을, 개발의 작업PC에서 캐시 정리를 사용하세요. DB/API 시작 패널과 고급 웹 실행 설정은 웹 전용으로 표시됩니다. 현재 대화에서 열어 둔 도구는 유지됩니다.

### 프로젝트 패널과 시작 설정 연동

프로젝트에서 선택한 작업 패널을 시작 패널 설정에 기억합니다. 설정에서 변경한 시작 패널은 현재 대화에도 적용되며 작업 도구를 접으면 대화로 저장됩니다. 새 초안과 대화 복원 시 중복 터미널 생성을 방지합니다.

#### 사용 방법

내 프로젝트에서 파일·기획·미리보기·터미널 패널을 선택하거나 프로젝트 설정의 시작 패널을 변경하세요. 오른쪽 작업 도구를 접으면 다음 대화도 대화 패널로 시작합니다. 공유 프로젝트의 설정 변경 권한은 기존과 동일합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1468)

### AI 연결 문제를 한 곳에서 확인하고 해결

AI 오류 답변에는 AI 연결 설정만 표시합니다. 열면 해당 대화의 AI와 작업PC를 확인하고, 지원되는 개인 Codex 연결은 한 번 자동 복구합니다. 다시 로그인하거나 관리자가 확인해야 하는 경우 필요한 행동 하나를 안내합니다.

#### 사용 방법

오류 답변의 AI 연결 설정을 누르세요. 복구 후 대화 계속하기를 누르면 기존 대화에서 진행할 수 있습니다. 관리자에게 요청은 조직 관리 알림으로 전달됩니다. 자세한 오류와 추가 계정 설정은 펼쳐서 확인할 수 있습니다.

### Codex 자동 적용 전 설치 준비를 보장합니다

조직에 PC를 등록할 때 Claude Code만 준비된 상태에서 Codex 설정을 먼저 적용해 실패하던 문제를 수정했습니다. 이제 두 CLI를 각각 확인하고, 한쪽 설치가 실패해도 원인을 기록한 뒤 준비된 CLI로 온보딩을 계속할 수 있습니다.

#### 사용 방법

별도 설정 없이 조직 시작 온보딩에서 자동으로 적용됩니다. Codex 설치가 실패하면 다음 시도 전에 네트워크·권한 상태를 확인할 수 있도록 진단이 남습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1453)

#### 사용 방법

### Windows 자격증명 저장소 소유권 검사 강화

기존 자격증명 파일·디렉터리가 Windows 토큰의 기본 소유자 그룹에 속한다는 이유만으로 소유권 검사를 통과하던 경로를 제거했습니다. Administrators 소유권은 현재 사용자 프로필 안에서 사용자가 FullControl을 보유하고 거부 규칙이 없는 기존 조건을 충족할 때만 현재 사용자 소유권으로 전환합니다. 보호할 수 없는 경로에서는 기존 자격증명을 덮어쓰지 않습니다. 새 로그인은 메모리 세션으로 계속할 수 있지만, 안전한 디스크 저장이 되지 않았다는 경고를 표시하고 다음 실행 때 다시 로그인하도록 합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. `Credential ancestor permits replacement`가 발생하면 현재 로그인은 유지되지만 자격증명은 저장되지 않습니다. 앱 데이터 폴더 권한을 복구하면 다음 로그인부터 안전하게 저장됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1472)
