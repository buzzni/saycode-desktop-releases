## 새 기능

### 계정 메뉴에서 언어를 바로 바꿀 수 있어요

다크 모드 아래에 현재 언어가 표시됩니다. 한국어, English, 日本語, 简体中文 중 하나를 선택하면 앱 전체 언어가 바뀌고 다음 실행에도 유지됩니다.

#### 사용 방법

사이드바 아래 계정 버튼 → 다크 모드 아래 현재 언어 → 사용할 언어를 선택하세요.

### 클라우드 접속 현황에 데스크톱 사용자 표시

클라우드 로그인한 데스크톱 사용자도 시스템 콘솔의 접속 현황에 표시됩니다. 현재 화면과 최소 머신 정보만 사용하고 프로젝트 이름·경로·내용은 보내지 않습니다. 데모와 로컬 모드에는 적용되지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 서버와 데스크톱 앱이 모두 업데이트된 뒤 시스템 콘솔에서 웹과 데스크톱 접속자를 함께 확인할 수 있습니다.

## 수정된 문제

### 대화 Git 메뉴의 작업트리 중복 제거 방지

대화의 Git 메뉴에서 작업트리 삭제를 빠르게 다시 눌러도 같은 작업을 중복 실행하지 않습니다. 처리 중에는 완료까지, 같은 실행은 최소 0.5초 보호합니다. 확인을 취소하면 바로 다시 시도할 수 있고, 작업PC나 연결된 작업트리가 바뀌면 이전 확인과 늦은 결과를 무시합니다. 변경 파일 보호, 삭제 전 스냅샷과 파일 기록 보존 정책은 그대로 유지합니다.

#### 사용 방법

프로젝트 대화의 Git 메뉴에서 작업트리 영역의 삭제를 누르세요. 앱이 관리하는 작업트리는 기록 보존 확인에서 취소하거나 삭제할 수 있습니다. 복원용 기록까지 즉시 지우려는 경우에만 파일 기록도 즉시 삭제를 선택하세요. 취소 후 새 확인에서는 기본 보존 선택으로 돌아갑니다. 별도 설정 없이 적용됩니다.

### 실행 중이 아닌 대화에서 파일 복원지점 오류 안내가 뜨지 않습니다

끝났거나 정리돼 작업PC에서 지금 실행 중이 아닌 대화를 열면, 연결에 문제가 없는데도 입력창 위에 `파일 복원지점을 불러오지 못했어요` 안내가 떴습니다. 이런 대화에서는 복원할 수 있는 것도 없으므로 이제 안내 없이 패널을 숨깁니다. 실제 조회 실패로 안내가 뜰 때는 오른쪽 위의 닫기 버튼으로 닫을 수 있고, 닫은 뒤에는 같은 대화에서 백그라운드 재조회가 다시 실패해도 안내가 다시 뜨지 않습니다.

#### 사용 방법

Project 대화 입력창 위에 `파일 복원지점을 불러오지 못했어요` 안내가 보이면 오른쪽 위 X(파일 복원지점 알림 닫기)를 누르세요. 다시 확인하려면 닫기 전에 새로고침을 누르거나 대화를 다시 여세요.

### 작업트리 관리에서 같은 삭제의 반복 실행 방지

작업트리 관리에서 처리 중이거나 방금 실패한 같은 삭제의 반복 실행을 막습니다. 무시된 클릭은 확인 선택과 오류를 유지하고, 이전 삭제의 늦은 완료가 다른 PC의 새 대화 연결을 지우지 않게 했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 작업트리 대화에서 파일 복원지점 오류 안내가 반복되지 않습니다

작업트리에서 실행한 대화를 열면 연결에 문제가 없는데도 입력창 위에 `파일 복원지점을 불러오지 못했어요` 안내가 반복해서 떴습니다. 현재 작업PC는 작업트리 대화의 복원지점 정보를 작업트리 없이 기록해, 처음 조회할 때 작업트리 정보가 맞지 않는다고 답합니다. 이 답을 조회 실패로 잘못 보여 주고 있었습니다. 이제 처음 조회에서 이 답을 받으면 안내 없이 패널을 숨깁니다. 작업PC가 작업트리 정보를 맞게 기록하게 되면 패널은 다시 나타납니다.

#### 사용 방법

별도 조작은 없습니다. 작업트리 대화를 열어도 이 이유로는 파일 복원지점 오류 안내가 뜨지 않습니다.

### 조직 계정 상태와 대화 시작 실패 안내 개선

미확인·오래된 사용량이나 계정 연결 거부를 ‘여유 있어요’로 표시하지 않습니다. 조직 계정 준비 실패나 인증 RPC 거부에서도 확인 필요 상태를 유지합니다. 사용 가능한 조직 계정이 없다는 시작 실패는 이유를 바로 안내하고 같은 PC의 사용량 창에도 최근 시작 결과를 표시합니다. 보관 안내의 중복 재시도 문장을 줄였습니다. 주간·단기 전용 Codex 요금제는 미지원 한도와 미확인 값을 구분하며 오래된 계정 관측을 최신 값으로 잘못 표시하지 않습니다.

#### 사용 방법

실패 안내의 ‘AI 사용량’에서 계정 상태를 확인하거나 관리자에게 문의하세요. 요청과 첨부는 유지되며 계정이 준비되면 ‘다시 시도’를 누를 수 있습니다.

### 파일 미리보기의 준비·실패 상태와 HTML 다시 시도를 안내합니다

HTML 미리보기 게시가 실패하면 다시 시도할 수 있습니다. 이미지는 실제로 열릴 때까지 준비 중으로 표시하고, 손상된 파일을 열지 못하면 오류로 안내합니다. 파일을 바꾼 뒤 이전 이미지의 결과를 새 파일의 상태로 표시하지 않습니다.

#### 사용 방법

Project 파일이나 개인 Chat 답변의 파일 링크를 열어 미리보세요. HTML 요청 오류에서는 다시 시도를 누르세요. 고정된 손상 이미지에는 반복 시도를 제공하지 않으며, 원본이 바뀌면 파일을 다시 읽거나 다시 여세요. 기존 파일 읽기 권한과 저장 동작은 유지됩니다.
