## 새 기능

### 입력창에서 Codex 스킬 골라 쓰기

작업PC에 설치한 Codex 스킬을 Saycode 대화에서 검색해 첫 메시지부터 사용할 수 있어요. 선택한 스킬은 입력창 위에 작은 칩으로 표시됩니다.

#### 사용 방법

지원되는 본인 작업PC에서 Codex 대화를 엽니다. 입력창에 `$`와 스킬 이름이나 플러그인 이름을 입력하고 항목을 고릅니다. 스킬 칩을 확인한 뒤 보내기를 누릅니다. 응답 중에 보내면 다음 턴 대기열에 담기고, 대기열에서 요청을 편집할 수 있어요.

## 변경된 기능

### 저장공간 경고는 3GB 미만일 때 표시하고 한 번 닫으면 24시간 숨김

작업PC의 홈 폴더가 있는 디스크에 남은 공간이 3GB 미만이면 대화 입력창 위에 경고를 표시합니다.

#### 사용 방법

경고 오른쪽의 X를 누르면 이 앱의 모든 대화와 창에서 24시간 동안 경고가 숨겨집니다. 작업PC를 바꾸거나 앱을 다시 열어도 유지됩니다.

## 수정된 문제

### 개인 Mac 작업 PC에서 에이전트 브라우저 연결 복구

개인 Mac 작업 PC에서 네트워크를 허용한 샌드박스로 실행한 에이전트가 연결된 ego lite 브라우저를 사용할 수 있습니다.

#### 사용 방법

앱을 업데이트한 뒤 작업 PC의 런타임이 다시 시작되면 적용됩니다.

### 최근 작업물 메뉴의 문서를 한 줄로 표시

개인 Chat의 최근 작업물 메뉴에서 파일명 오른쪽에 저장과 더보기를 표시합니다. 좁은 분할에서는 긴 파일명을 줄여 두 버튼을 같은 줄에 배치합니다. 저장본 열기와 폴더에서 보기는 더보기 메뉴에서 사용할 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.
