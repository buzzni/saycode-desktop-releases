## 변경된 기능

### 이 PC를 종단간 암호화로 자동 전환하고 키 확인까지 끝냅니다

조직이 종단간 암호화를 켠 뒤에도 이 PC가 이전 암호화 방식으로 남아 있으면, 조직 AI 계정 연결이 멈추고

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 조직 AI 계정 연결이 필요하면 "조직 그룹 다시 동기화"를 누르세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1598)

## 수정된 문제

### 답변이 끝났는데도 "작업 중"으로 남던 문제 수정

종단간 암호화 키로 전환한 작업 PC에서 대화하면, 답변이 화면에 다 나온 뒤에도 "작업 중..." 표시와

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 업데이트 후 평소처럼 대화하면 됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/1599)
