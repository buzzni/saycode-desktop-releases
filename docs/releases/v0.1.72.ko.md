## 새 기능

### 같은 AI로 대화 갈래 만들기

진행 중인 대화를 그대로 둔 채, 같은 AI로 지금까지의 대화 기록을 복제한 새 대화를 만들어 다른 방향을 시도할 수 있습니다. 전체 대화를 복제하거나, 앞선 특정 메시지까지만 남기고 갈래를 낼 수 있습니다. 갈래 대화는 새 탭으로 열려 복제된 지난 대화가 그대로 보이고, 머리글의 "갈래 원본" 링크로 원래 대화에 돌아갈 수 있습니다. 두 대화는 같은 작업 폴더를 함께 씁니다.

#### 사용 방법

프로젝트 대화 머리글 오른쪽의 프로젝트 도구(⋮)에서 대화 이어가기를 누르고 "같은 AI로 갈래 만들기"를 고릅니다. 복제할 범위(전체 대화 또는 특정 메시지까지)를 고른 뒤 "갈래 만들기"를 누릅니다. Claude·Codex 대화에서 AI의 응답이 끝난 뒤에 쓸 수 있고, 다른 AI도구로 이어가기는 같은 메뉴의 첫 항목으로 옮겨졌습니다.

### 권한 요청을 Enter·Esc로 바로 응답해요

대화에 권한 요청 카드가 뜨면 Enter로 맨 위 요청을 이번 한 번만 허용하고, Esc로 거절할 수 있습니다. 범위를 고르는 요청(프로젝트 밖 폴더 접근)에서는 Enter가 가장 좁은 `이번 작업만 허용`만 누릅니다. 실수로 허용하지 않도록 입력란에서 친 키, 누르고 있는 키, 요청이 뜬 직후 0.5초 안의 키, 다른 창이나 메뉴·찾기 바가 열려 있을 때의 키는 받지 않습니다. 화면을 나눠 쓸 때는 포커스가 있는 대화의 요청에만 적용됩니다. 키가 통하는 카드의 버튼에는 `Enter`·`Esc` 표시가 붙습니다.

#### 사용 방법

권한 요청이 뜬 대화에서 입력란 밖을 누른 뒤 Enter(허용) 또는 Esc(거절)를 누르세요. 끄려면 내 설정 → 단축키에서 `권한 요청에 Enter·Esc로 응답`을 끕니다.

### 기기 승인 전달을 켠 PC는 키 설정 없이 조직 Claude 계정을 받습니다

조직 관리자가 이 PC에 "기기 승인으로 토큰 받기"를 켜면, Studio가 조직 서명으로 확인한 Claude setup-token을 이 PC에 직접 보냅니다. 이런 PC에서는 계정 키·회사 키 확인, 종단간 암호화 전환, 키 확인 단계와 그 안내를 띄우지 않습니다. 배정에 Codex나 다른 Claude 계정이 함께 있으면 지금처럼 키 설정이 필요합니다.

전달이 멈추면 누가 무엇을 해야 하는지 알려 줍니다. 이 PC에서 조직 기기 확인 마치기, 관리자의 배정서 서명과 기기 승인, 섞인 계정 정리, 기기 키가 바뀌었을 때 다시 승인받기, daemon 업데이트 중 하나입니다.

#### 사용 방법

관리자가 Studio 보안 설정의 기기 승인 카드에서 이 PC를 켜면 자동으로 적용됩니다. 켜지 않은 PC는 그대로입니다.

### 긴 텍스트를 붙여 넣으면 입력창 위에 카드로 접혀요

로그나 코드처럼 25줄 이상이거나 4,000자 이상인 텍스트를 대화 입력창에 붙여 넣으면 입력창이 길게 늘어나지 않고 입력창 위에 카드로 접힙니다. 카드에는 줄 수와 첫 줄이 보이고, 보낼 때는 붙여 넣은 내용 전체가 잘리지 않고 AI에게 전달됩니다. 보낸 메시지에도 같은 카드로 보입니다. 보내기 전 초안, 전송 실패, 대기열에서도 카드가 그대로 남습니다. 대화 제목·목록 미리보기·알림·입력 기록에는 카드 원문 대신 `붙여넣은 텍스트 · N줄`로 짧게 보입니다. 저장해 둔 초안이나 입력 기록이 저장 한도를 넘으면 큰 카드부터 원문 없이 남기고 카드에 그 사실을 표시합니다.

#### 사용 방법

프로젝트 대화나 개인 대화 입력창에 긴 텍스트를 붙여 넣으세요. 카드를 누르면 전체 내용을 펼쳐 볼 수 있고, 카드 오른쪽 위 X로 지울 수 있습니다. 카드를 추가하거나 지운 직후 ⌘Z(Windows는 Ctrl+Z)로 되돌릴 수 있습니다.

### 끊긴 답변을 원인과 함께 보여 주고 이어서 하기로 이어 갑니다

직접 중단하지 않았는데 답변이 중간에 끊기면, 대화 안 안내 줄에서 끊긴 원인을 구분해 보여 줍니다. AI 실행 프로세스가 예기치 않게 끝난 경우와, Claude Code가 답변하던 중에 멈춘 경우를 나눠 보여 줍니다. Claude Code는 이전에 "시작하지 못했어요"로 잘못 표시됐습니다. 같은 줄의 **이어서 하기**를 누르면, AI가 마지막 단계가 끝났는지 먼저 확인한 뒤 이어서 진행하라는 요청이 내 메시지로 보내집니다. 직접 중단한 답변에는 지금처럼 다시 시도만 보입니다.

#### 사용 방법

끊긴 대화의 마지막 안내 줄에서 이어서 하기를 누릅니다. 가장 최근 답변이 끊겼을 때만 보이고, 새 메시지를 보냈거나 응답 중이면 숨겨집니다. 앱 종료나 연결 끊김처럼 원인이 남지 않은 중단에는 나타나지 않습니다.

### 내가 보낸 긴 메시지를 접어서 보여 줍니다

600자 또는 8줄이 넘는 보낸 메시지는 대화 기록에서 처음부터 접힌 채로 보여 다른 내용을 가리지 않습니다. 접힌 메시지도 복사·인용·대화 내 검색은 전체 내용을 기준으로 하며, 붙여넣기 카드와 첨부 파일은 그대로 메시지 아래에 보입니다.

#### 사용 방법

긴 메시지 아래의 `펼치기`를 누르면 전체가 보이고 `접기`로 다시 접습니다. 대화 내 검색으로 접힌 메시지의 결과로 이동하면 자동으로 펼쳐집니다.

### 느린 터미널에서 친 글자를 먼저 보여 줍니다

다른 작업PC의 터미널처럼 응답이 느린 곳에서 타이핑하면, 서버 응답을 기다리지 않고 친 글자를 흐리게 먼저 보여 줍니다.
서버 응답이 오면 일반 글자로 확정되고, 서버가 다른 내용을 보내면 미리 보인 글자는 지워집니다.
응답이 빠른 터미널(같은 PC 등)에서는 나타나지 않고, vim·tmux 같은 전체 화면 프로그램과 한글 입력에는 적용되지 않습니다.
비밀번호처럼 화면에 나오지 않는 입력에서도 한 줄의 첫 글자는 미리 보이지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 끄려면 내 설정 → 개발 → 터미널 → 입력 미리 표시에서 사용을 끔으로 바꿉니다.

### 대화 내용 우클릭 메뉴와 선택한 답변 인용

프로젝트 대화와 사이드바 Chat에서 AI 답변이나 내 메시지를 오른쪽 클릭하면 평소의 편집 메뉴 대신 그 자리에 맞는 메뉴가 열립니다. 선택한 글을 입력창에 인용하거나 복사하고, 링크를 열거나 주소(파일이면 경로)를 복사하고, 코드나 메시지를 복사하고, 대화 내 검색(프로젝트 대화)을 열 수 있습니다. AI 답변에서 글을 선택하면 옆에 작은 `인용` 버튼이 떠서 바로 인용할 수 있습니다. 인용은 `>` 인용 형식으로 그 대화의 입력창 끝에 들어가며 다른 대화의 입력창으로 가지 않습니다.

#### 사용 방법

답변이나 내 메시지 위를 오른쪽 클릭하고 항목을 고르세요. 키보드로는 메시지 안의 링크·버튼에 포커스를 두거나 글을 선택한 뒤 Shift+F10(또는 메뉴 키)을 누르고, 위/아래 화살표와 Enter로 고르고 Esc로 닫습니다. AI 답변에서 글을 선택한 뒤 나타나는 `인용` 버튼을 누르면 입력창에 인용이 들어갑니다. AI가 아직 쓰는 코드·답변은 다 쓰일 때까지 복사가 잠기고, 잠긴 항목에는 이유가 함께 보입니다.

### 대화 속 PR 링크를 앱 안에서 바로 읽기

프로젝트 대화에서 GitHub PR 링크를 누르면 브라우저로 나가지 않고 오른쪽 작업 패널의 `PR` 탭에서 PR의 설명·코멘트·리뷰·리뷰 스레드·커밋을 시간순으로 볼 수 있어요. 같은 사람이 연달아 올린 커밋은 한 줄로 묶이고, 해결됐거나 이전 코드에 달린 스레드는 접혀 있어요. PR이 이 프로젝트의 대화에 연결돼 있으면 그 자리에서 `리뷰 지적 고치기`로 이어 갈 수 있어요. 읽기 전용이라 GitHub에는 아무것도 쓰지 않아요.

#### 사용 방법

프로젝트 대화에 있는 GitHub PR 링크를 그냥 누르세요. Shift를 누른 채 누르면 브라우저로 열려요. 작업트리에 PR이 있는 대화에서는 작업 패널 추가(⋮) 메뉴의 `PR 보기`로도 열 수 있어요. 작업PC에 gh가 설치되고 로그인돼 있어야 해요.

### 대화로 돌아오면 새로 온 메시지부터 표시합니다

대화를 떠나 있는 동안(다른 대화로 옮기거나 다른 앱을 보는 동안) 도착한 첫 메시지 위에 `새 메시지` 줄이 보입니다. 떠날 때 AI가 답하던 중이었고 그 사이 답변이 길어졌거나 끝났으면 그 답변부터 새 메시지로 표시합니다. 프로젝트 대화와 Chat 모두에 적용됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 줄이 화면에 보이는 채로 10초가 지나거나 대화 맨 아래까지 스크롤하면 사라집니다.

### 데스크톱에서 조직 AI 연결에 필요한 암호화키를 확인할 수 있어요

내 설정의 조직 계정 연결 옆에 `암호화키 확인`을 추가했어요. 현재 비밀번호와 보관한 복구 키를 확인한 뒤 조직 AI 연결을 다시 시도해요. 복구 키를 잊었다면 기존 대화와 암호화키를 유지하면서 새 복구 키를 발급받고, 보관 후 다시 입력할 수 있어요.

조직 정책에 따라 인증 앱 코드가 필요할 수 있어요. 추가 로그인이 필요한 계정은 다시 로그인하도록 안내하며, 키 확인만으로 조직 AI 연결을 완료했다고 표시하지 않아요.

#### 사용 방법

내 설정 → 조직 계정 연결 → 암호화키 확인에서 진행하세요. 새 복구 키를 확정하면 이전 복구 키는 사용할 수 없으니 안전한 곳에 보관하세요.

### 변경 탭에서 브랜치 전체 변경 보기

작업트리에서 연 대화의 변경(Review) 목록에서 `브랜치 전체`를 고르면, 브랜치가 갈라진 뒤의 모든 변경을 볼 수 있습니다. 이미 변경기록으로 남긴 변경, 아직 남기지 않은 변경, 새로 만든 파일이 파일마다 한 줄로 함께 나와서 AI가 모든 변경을 변경기록으로 남긴 뒤에도 목록이 비지 않습니다. 목록 위에는 비교 기준 브랜치가, 아래에는 이 브랜치의 변경기록 목록이 표시됩니다. 연결된 PR이 있으면 그 PR의 기준 브랜치와 비교하고, PR을 확인하지 못했으면 목록 위에 그렇게 알려 줍니다. 줄 코멘트는 두 범위에서 같은 줄에 그대로 남습니다.

#### 사용 방법

작업트리 대화에서 작업 패널 추가 → Review를 열고 목록 위의 `브랜치 전체`를 누르세요. 아래 변경기록 목록에서 하나를 누르면 그 변경기록의 파일만 읽기 전용으로 보이고, `전체로 돌아가기`로 돌아옵니다. 비교할 기준 브랜치를 찾지 못하면 `브랜치 전체`는 비활성으로 표시되고 이유가 나옵니다.

### 실수로 닫은 대화 탭 되돌리기

대화 탭을 닫으면 10초 동안 "대화 탭을 닫았어요." 알림이 보이고, 되돌리기로 닫은 탭을 원래 자리에 다시 열 수 있습니다. 여러 탭을 연달아 닫으면 알림 하나로 묶여 한 번에 돌아옵니다. 새 Chat 초안 탭은 쓰던 글과 첨부도 함께 돌아옵니다.

#### 사용 방법

탭을 닫은 직후 알림의 되돌리기를 누르거나 Cmd+Z(Windows는 Ctrl+Z)를 누르세요. 입력창에서 누른 Cmd+Z는 지금처럼 글자 실행 취소로 동작합니다.

### 앱 브라우저에서 고칠 곳을 여러 개 모아 한 번에 보낼 수 있어요

앱 브라우저에서 요소를 고르면 이제 바로 채팅으로 가지 않고 브라우저 아래 주석 트레이에 쌓여요. 항목마다 코멘트를 적고 '수정해 줘'·'질문'·'참고' 중 의도를 고른 뒤, '모두 보내기'를 누르면 번호를 매긴 요청과 스크린샷이 그 브라우저를 연 대화의 입력창에 한꺼번에 들어가요(바로 전송되지는 않아요). 넣을 대화를 찾지 못하면 트레이를 그대로 두고 이유를 알려 줘요. 트레이는 한 줄로 접을 수 있고, 대화를 바꿔도 다른 대화의 트레이와 섞이지 않아요. 앱을 다시 시작하면 비워져요.

#### 사용 방법

앱 브라우저 도구 모음의 요소 선택 버튼을 누르고 페이지에서 요소를 클릭하세요. 예전처럼 하나만 바로 보내려면 트레이가 비어 있을 때 Shift를 누른 채 클릭하세요.

### 앱 브라우저에서 캐시를 무시하고 새로고침할 수 있어요

앱 안 브라우저의 새로고침 버튼을 Shift를 누른 채 클릭하면, 저장된 캐시를 쓰지 않고 페이지를 처음부터 다시 받아 와요. 고친 CSS나 스크립트가 반영되지 않을 때 쓸 수 있어요. 그냥 클릭하면 지금처럼 일반 새로고침이에요.

#### 사용 방법

앱 브라우저 위쪽 도구 모음의 새로고침 버튼을 Shift+클릭하세요. 버튼에 마우스를 올리면 안내가 보여요.

### 예약을 매주 요일이나 한 번만 실행하도록 정할 수 있어요

예약의 반복에 `매주`와 `한 번`이 생겼습니다. 매주는 고른 요일마다, 한 번은 고른 날짜의 시각에 한 번만 실행합니다. 시각은 매일 예약처럼 실행 PC 기준입니다. 한 번 예약은 실행되면 목록에 `완료`로, PC가 꺼져 있는 등 실행 기록 없이 시각이 지나면 `시각 지남`으로 보입니다. 둘 다 `다시 켜기`로 새 날짜와 시각을 정해 다시 실행할 수 있습니다. PC가 꺼져 있어 놓친 회차는 나중에 실행하지 않습니다.

#### 사용 방법

예약 화면에서 새 예약(또는 예약 행 더보기 → 편집)을 열고 반복에서 매주나 한 번을 고릅니다. 매주는 요일 버튼으로 하루 이상과 실행 시각을, 한 번은 날짜와 실행 시각을 정합니다. 시각이 지난 한 번 예약은 그 행의 다시 켜기를 누릅니다. 예약을 실행할 PC의 Saycode가 이 기능을 지원하는 버전이어야 하며, 아니면 편집 창에 업데이트 안내가 보입니다.

### 요소 스크린샷에 펜·사각형으로 표시해 보낼 수 있어요

주석 트레이의 스크린샷 썸네일을 누르면 편집 창이 열려요. 펜(빨강·노랑·파랑)과 사각형으로 표시하고, 지우개·되돌리기(Cmd/Ctrl+Z)·원본으로를 쓸 수 있어요. 적용하면 표시가 들어간 이미지가 첨부되고, 원본은 그대로 남아 다시 열어 고치거나 원본으로 되돌릴 수 있어요.

#### 사용 방법

앱 브라우저 아래 주석 트레이에서 항목의 스크린샷 썸네일을 누르세요. 표시한 뒤 '적용'을 누르면 썸네일에 '표시됨'이 붙어요.

### 작업보드에서 작업PC·자동화·PR 상태로 카드를 거를 수 있어요

작업보드 검색 옆에 `필터`가 생겼습니다. 작업PC(여러 대 선택), 자동화로 만든 대화 숨기기, PR 상태(PR 없음·PR 열림·PR 머지됨)로 보드의 카드를 좁힐 수 있고, 검색과 함께 적용됩니다. 칸의 카드 수와 검색 결과 수도 거른 뒤의 수로 보입니다. 필터를 켜면 버튼에 `필터 n개 적용`이 보이고 옆의 지우기 버튼으로 한 번에 끌 수 있습니다. 지금 열어 둔 대화의 카드는 필터에 맞지 않아도 사라지지 않고 `필터 밖` 표시로 남습니다. 고른 필터는 계정·조직별로 이 컴퓨터에 저장됩니다.

#### 사용 방법

작업보드를 열고 검색창 옆 `필터`를 눌러 원하는 항목을 고릅니다. 모두 끄려면 `필터 n개 적용` 옆의 지우기(X) 버튼을 누릅니다.

### 작업보드에서 카드끼리 선후 관계를 지정해요

작업보드 카드에 "이 카드가 끝나야 시작" 같은 선행 작업을 지정할 수 있습니다. 선행 작업이 완료·PR 병합되기 전에는 뒤 카드를 응답 중으로 끌어 놓을 때 어떤 카드 때문에 막혔는지 이름으로 알려 주고, 오토파일럿도 셀프 리뷰·Commit & PR로 넘어가지 않고 기다립니다. 카드에는 `선행 1/2` 같은 진행 표시가 붙습니다. 오토파일럿을 켠 카드는 지시를 예약해 두면 선행 작업이 끝나는 대로 예약할 때 고른 모델·페르소나로 자동으로 시작합니다. 서로를 기다리는 순환 연결은 거부하고 경로를 보여 주며, 선행 카드나 그 프로젝트를 삭제하면 연결을 정리하고 풀린 카드를 알려 줍니다.

#### 사용 방법

작업보드에서 카드를 눌러 상세를 열고 `선행 작업` 아래에서 카드를 골라 `추가`합니다. 막힌 카드를 응답 중으로 끌어 놓으면 지시 창에서 `그래도 시작`으로 바로 보내거나, 오토파일럿이 켜져 있으면 `선행이 끝나면 시작`으로 예약할 수 있습니다. 연결은 이 컴퓨터에 저장됩니다.

### 작업을 멈추지 않고 묻는 /btw 곁질문

Claude 대화에서 입력창에 `/btw 질문`을 보내면 진행 중인 작업을 멈추거나 대기열에 넣지 않고, 지금 대화를 바탕으로 짧게 답합니다.

- 답은 입력창 위 카드로만 보이고 대화 기록과 이후 대화에는 남지 않습니다.
- 곁질문은 파일을 읽거나 명령을 실행하지 않습니다.
- 쓴 토큰은 카드와 사용량에 함께 표시됩니다.
- Codex 등 다른 AI, 실행 도구가 곁질문을 지원하지 않는 작업PC에서는 메시지를 보내지 않고 이유를 안내합니다.
- 다시 열었거나 멈춘 뒤 쉬고 있는 대화에서는 답하지 않고, 메시지를 보내 대화를 깨운 뒤 다시 물어보라고 안내합니다.

#### 사용 방법

프로젝트 대화나 Chat의 입력창에 `/btw`와 질문을 적고 Enter를 누릅니다. 예: `/btw 방금 어떤 파일을 고쳤어?` AI가 답하는 중이거나 대기열이 가득 차도 쓸 수 있으며, 카드의 닫기(X)로 답을 닫습니다.

### 작업트리·프로젝트 폴더를 에디터로 바로 열기

이 컴퓨터에 있는 작업트리나 프로젝트 폴더를 Cursor, VS Code, VS Code Insiders, Zed, Windsurf 중 설치된 에디터에서 클릭 한 번으로 열 수 있습니다. 마지막으로 연 에디터를 기본 에디터로 기억해 다음부터 바로 엽니다. 다른 컴퓨터(원격 작업PC)의 폴더에는 표시되지 않습니다.

#### 사용 방법

작업트리 목록에서 줄의 에디터로 열기 아이콘을 누르고 에디터를 고릅니다. 프로젝트 폴더는 프로젝트 도구의 `에디터로 열기…`(기본 에디터가 있으면 `<에디터>에서 열기`)나 빠른 열기(Cmd+P)의 `에디터로 열기` 명령으로 엽니다. macOS에서만 사용할 수 있습니다.

### 터미널 출력에서 글자를 찾을 수 있어요

터미널을 클릭한 상태에서 찾기 단축키를 누르면 터미널 오른쪽 위에 찾기 상자가 열려요. 화면과 스크롤해 올라간 출력까지 대소문자 구분 없이 찾아 `3/12`처럼 몇 번째인지 보여 주고, 가장 최근 결과부터 선택해 화면에 보여 줘요. 찾는 동안 새 출력이 나오면 개수를 다시 세요. 아주 긴 출력에서는 화면이 멈추지 않도록 최근 부분까지만 찾고 개수 뒤에 `+`를 붙여요.

#### 사용 방법

터미널을 한 번 클릭한 뒤 ⌘F(Windows는 Ctrl+F)를 누르세요. 찾을 말을 입력하고 Enter로 위(이전) 결과, Shift+Enter로 아래(다음) 결과로 이동해요. 화살표 버튼도 같아요. Esc나 닫기 버튼으로 닫으면 다시 터미널에 입력할 수 있어요. 대화 내 찾기와 같은 단축키라, 내 설정의 단축키 탭에서 바꾸면 둘 다 바뀌어요.

### AI 답변 코드에 언어 표시·복사·줄바꿈과 색 구분, 강조 상자 표시

AI 답변의 코드 상자 위쪽에 코드 언어가 표시되고, 코드만 바로 복사하거나 긴 줄을 상자 안에서 줄바꿈해 볼 수 있습니다. 자주 쓰는 언어(셸, TypeScript·JavaScript, Python, JSON, YAML, SQL, HTML, CSS, Markdown 등)는 색으로 구분해 보여 줍니다. AI가 아직 쓰고 있는 코드는 끝날 때까지 복사가 잠겨 반쯤 쓰인 명령을 복사하지 않습니다. 답변과 Markdown 문서의 `[!NOTE]`·`[!TIP]`·`[!IMPORTANT]`·`[!WARNING]`·`[!CAUTION]` 표시는 아이콘이 있는 강조 상자로 보입니다.

#### 사용 방법

코드 상자 위쪽 오른쪽의 복사 아이콘(코드 복사)을 누르면 코드가 복사되고 잠시 `복사됨`으로 바뀝니다. 그 옆 줄바꿈 아이콘(긴 줄 줄바꿈)을 누르면 긴 줄이 상자 폭에 맞춰 접힙니다. 강조 상자는 별도 설정 없이 자동 적용됩니다.

### AI 사용량 한도에 닿기 전에 입력창 아래에서 알려줘요

AI 잔여량 표시를 켜 두었다면, 지금 대화에서 쓰는 Claude·Codex 계정의 5시간 또는 7일 사용량이 한도에 가까워질 때 입력창 아래 정보 줄에 경고가 나타나요. 사용률과 초기화까지 남은 시간을 함께 보여 줘요. 한 계정이 소진돼도 바꿀 수 있는 다른 계정이 있으면 그 계정 수를 알려 주고, 모든 계정이 막혔을 때만 한도 소진으로 표시해요. 모델 선택 목록에서는 한도에 걸린 모델(예: Fable 주간 한도) 옆에 언제까지 제한되는지 보여 줘요. 조직이 관리하는 Claude 계정을 쓰는 PC에서는 지금 쓰는 계정을 알 수 없어 경고가 나타나지 않아요.

#### 사용 방법

왼쪽 아래 계정 메뉴 → 개발자 기능 설정에서 AI 잔여량 보이기를 켜면 자동으로 적용됩니다. 경고 오른쪽 X를 누르면 같은 단계의 경고는 다시 뜨지 않고, 더 심해지거나 사용량이 초기화된 뒤에는 다시 알려 줘요.

### Chat 입력창이 예약·스킬·커넥터를 먼저 제안해요

Chat 입력창에 "매일 아침 9시에 메일 요약해줘", "매주 월요일 10시에"처럼 반복하거나 정해진 시각의 일을 쓰면 입력란 위에 `예약으로 만들기`가 뜹니다. 누르면 요청 내용과 추정한 일정(매일·매주 요일·한 번·시간 간격)이 미리 채워진 예약 창이 열려, 확인하고 바로 예약할 수 있습니다. 아직 연결하지 않은 Notion·Slack 같은 서비스 이름을 쓰면 `연결하기`가, 기존 대화에서 설치된 스킬 이름을 쓰면 `스킬 쓰기`가 뜹니다. 제안은 한 번에 최대 2개이고 닫기 버튼 없이 글이 바뀌면 저절로 사라집니다. 같은 종류의 제안을 누르지 않고 한 대화에서 세 번 메시지를 보내거나 입력을 지우면 그 대화에서는 다시 띄우지 않습니다. 코드 블록·인용·따옴표 안의 글과 "Weekly Standup" 같은 이름은 제안하지 않습니다.

#### 사용 방법

Chat의 새 대화나 기존 대화 입력창에 요청을 쓰고 잠깐 멈추면 입력란 위에 제안이 뜹니다. 끄려면 내 설정 → 알림 탭에서 `입력 중 제안 보이기`를 끄세요.

### GitHub 이슈를 골라 새 대화 시작

새 프로젝트 대화의 작업트리 방식에 `이슈에서 시작`이 생겼습니다. 저장소의 열린 이슈를 번호·제목·라벨·담당자로 찾아 고르면 이슈 제목·본문·링크가 첫 메시지 초안으로 입력창에 들어갑니다. 초안은 자동으로 보내지 않으며, 보내면 `<이슈 번호>-<제목>` 이름의 작업트리에서 대화가 시작됩니다. 같은 이슈 번호의 작업트리가 이미 있으면 새로 만들지 않고 그 작업트리에서 이어서 시작합니다.

#### 사용 방법

Project에서 새 대화를 열고 `작업트리`를 켠 뒤 옆의 조절 아이콘(작업트리 · 방식)에서 방식을 `이슈에서 시작`으로 바꿉니다. 목록에서 이슈를 고르고 입력창의 초안을 확인·수정해 보냅니다. 작업PC에 GitHub CLI(gh)가 설치되고 로그인되어 있어야 합니다.

### PR 리뷰 지적과 충돌을 버튼 하나로 고치기 요청

열린 PR의 아직 해결되지 않은 리뷰 지적·실패한 체크·병합 충돌을 읽어 고쳐 달라는 요청 하나로 만들고, 그 PR의 대화 입력창에 넣어 줍니다. 해결된 지적은 빼고, 바뀐 코드에 달린 지적은 "이전 코드 기준"으로 표시합니다. 요청은 바로 보내지 않으니 내용을 확인한 뒤 보내면 됩니다. PR이 base 브랜치와 충돌하면 `충돌` 표시와 함께 충돌을 풀어 달라는 요청도 만들 수 있습니다. 그 PR의 대화가 보관돼 없으면 PR에서 시작하는 새 대화가 열립니다.

#### 사용 방법

작업보드에서 PR이 열린 카드의 PR 줄에 있는 `리뷰 지적 고치기` 버튼(충돌이 있으면 `충돌 해결` 버튼)을 누릅니다. 프로젝트 대화에서는 입력창 위 브랜치 메뉴에서 같은 항목을 고를 수 있습니다. 작업PC에 gh가 로그인돼 있어야 합니다.

조직 관리·초대 버튼을 작게 줄이고 시작 화면의 왼쪽 하단으로 옮겼습니다. 현재 조직의 관리자에게만 표시됩니다.

#### 사용 방법

### 시작준비에서 현재 진행 단계를 더 자세히 안내합니다

### 작업트리 일괄 정리에서 남는 이유와 정리 결과를 행마다 표시

오래된 작업트리 일괄 정리를 누르면 작업트리마다 지울 수 있는지, 남겨야 한다면 왜인지(잠김, 실행 중이거나 사용 중인 대화, 열린 PR, 7일 안에 사용, 커밋 안 한 변경, 추적 안 한 파일, 푸시 안 한 커밋, 판정 실패)를 함께 보여 줍니다. 지울 수 있는 작업트리만 기본으로 선택되고, 원하지 않는 항목은 선택을 풀 수 있습니다. 보호된 작업트리는 이전처럼 지울 수 없습니다. 정리 후에는 삭제·보호·실패 건수와 함께 작업트리마다 삭제됨·건너뜀·실패와 그 이유를 보여 주고, 지운 작업트리에서 남은 브랜치 목록을 보여 줍니다. 검사나 정리는 중간에 중지할 수 있습니다.

#### 사용 방법

프로젝트의 브랜치 버튼 → 작업트리 관리 → 오래된 작업트리 일괄 정리를 누르세요. 목록을 확인하고 N개 삭제를 누르면 선택한 작업트리만 정리됩니다. 남은 브랜치는 결과의 브랜치 정리 열기에서 안전하게 정리할 수 있습니다.

### 조직 Claude 사용량을 앱이 열려 있는 동안 계속 확인

조직이 사용량 확인을 맡긴 내 전용 PC는 이제 Saycode가 열려 있고 로그인돼 있으면 창이 가려져 있거나 Claude가 응답 중이 아니어도 조직 Claude 계정의 사용량을 주기적으로 확인합니다. 그래서 사용량 정보가 몇 시간씩 오래된 채로 남지 않습니다. 계정마다 확인 간격은 최소 15분(계정이 많으면 계정 수 × 5분)이고, 조직 전체의 하루 확인 한도가 줄어들수록 모든 PC가 함께 간격을 늘려 여러 PC가 동시에 확인해도 한도를 먼저 다 써 버리지 않게 합니다. 공용 PC는 기존처럼 그 PC에서 Claude가 응답 중일 때만 확인하지만, 창이 가려져 있어도 확인합니다.

#### 사용 방법

### 터미널 링크를 누르면 열 곳을 고를 수 있어요

터미널 출력의 주소(http·https)를 누르면 바로 외부 브라우저로 열리던 것이, 누른 자리에 작은 메뉴가 뜨는 것으로 바뀌었어요. 앱 브라우저에서 열기, 외부 브라우저에서 열기, 주소 복사 중에서 고를 수 있어요. localhost 같은 개발 서버 주소는 앱 브라우저가 미리 골라져 있어 Enter만 누르면 열려요. 다른 작업PC에서 돌아가는 터미널의 localhost 주소는 그 작업PC의 포트로 연결해서 열어요. 이 연결은 HTTP만 다루기 때문에, 다른 작업PC의 HTTPS 개발 서버 주소에서는 앱 브라우저 항목이 이유와 함께 비활성으로 보이고 외부 브라우저가 미리 골라져요.

#### 사용 방법

터미널 출력의 주소를 클릭하고 메뉴에서 고르세요. 미리 골라진 항목은 Enter로 바로 열려요. Esc를 누르거나 바깥을 클릭하면 아무것도 열지 않고 닫혀요. 앱 브라우저에서 열기는 작업 도구 영역의 터미널에서만 보이고, 프로젝트에 열린 브라우저 탭이 있으면 그 탭에서 열려요.

### AI 질문에 숫자 키로 바로 답하기

AI가 선택지를 주며 질문하면 이제 대화 화면 어디에서든 선택지 앞 숫자 키(1~9)로 고를 수 있습니다. 여러 질문 중 하나만 고르는 질문은 고르면 잠깐 뒤 다음 질문으로 넘어갑니다. 마지막 질문에서는 보내기 버튼으로 커서만 옮기고 자동으로 보내지 않습니다. 여러 개 고르는 질문에도 숫자가 표시되고, 위/아래 화살표로 선택지 사이를 옮길 수 있습니다.

#### 사용 방법

질문이 입력창 자리에 나타나면 선택지 앞 숫자 키를 누릅니다. 입력란이나 찾기 창에 적는 중에는 숫자가 글자로 입력됩니다. 여러 개 고르는 질문과 직접 적은 답은 다음을 눌러 넘어갑니다.

#### 사용 방법

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 응답이 끝난 뒤에도 진행 표시가 남아 있으면 백그라운드 작업이 아직 도는 중입니다.

### 보안 설정이 엄격한 Windows PC에서도 작업PC 연결이 유지됩니다

앱에 포함하는 Happy 실행기를 1.1.10-aplus.340으로 올렸습니다.

일부 회사 Windows PC는 보안 설정 때문에 연결 정보를 사용자 로컬 폴더(LocalAppData)에 저장합니다. 이 경우 연결 프로그램의 기기 키 경로가 Windows 경로 길이 한도를 넘어, 연결 프로그램이 시작하자마자 꺼지고 작업PC가 오프라인으로 남았습니다. 이제 기기 키 폴더 이름을 짧게 쓰고, 예전 이름의 폴더는 다음 실행 때 옮깁니다. 옮길 때 기기 키는 그대로 유지되어 조직의 기기 승인도 그대로 이어집니다.

#### 사용 방법

사용자 조작 없이 앱 업데이트에 포함됩니다.

### 보호된 대화에서 자식 에이전트 위임 복구

인증 파일 접근이 제한된 대화에서도 자식 에이전트 정보를 확인하고 위임할 수 있도록 세션 호스트 경로를 추가했습니다. 인증 파일 보호는 유지하며, 연결 오류와 인증 읽기 오류를 구분합니다.

#### 사용 방법

#### 사용 방법

### 아주 긴 한 단어 줄이 있는 파일을 열어도 앱이 멈추지 않음

### 조직 기기 승인을 받은 Windows PC가 다시 연결되지 않던 문제를 고쳤습니다

앱에 포함하는 Happy 실행기를 1.1.10-aplus.339로 올렸습니다.

조직 관리자가 기기를 승인한 Windows PC에서, 앱이나 PC를 다시 시작하면 이 PC의 연결 프로그램이 곧바로 꺼져 작업PC가 계속 오프라인으로 남던 문제를 고쳤습니다. 승인 기록 파일의 경로가 Windows 경로 길이 한도를 넘어 보안 검사가 실패한 것이 원인이었습니다. 이제 파일 이름을 짧게 쓰고, 예전 이름으로 저장된 파일은 다음 실행 때 자동으로 옮깁니다.

이 밖에 예약 실행 재시도, 자동 실행 작업 폴더 복원 같은 실행기 안정성 개선이 함께 들어 있습니다.

#### 사용 방법

### 조직 시작에서 이 PC가 연결되지 않으면 원인을 구분해 알려줍니다

조직 시작 화면에서 이 PC를 등록한 뒤 PC가 온라인으로 보이지 않으면, 지금까지는 `SETUP_CHECK_FAILED`와 함께 "구체적인 원인을 확인하지 못했어요", 실패 단계 "확인 못함"으로만 안내했습니다.

이제 두 경우를 나눠 알려줍니다.

- 이 PC의 연결 프로그램이 시작 직후 꺼졌거나 시작을 끝내지 못했으면 "이 PC의 연결 프로그램이 실행되지 않았어요"(`SETUP_MACHINE_DAEMON_FAILED`)로 안내합니다.
- 연결 프로그램은 실행 중인데 서버가 이 PC를 확인하지 못했으면 "서버에서 이 PC의 온라인 상태를 확인하지 못했어요"(`SETUP_MACHINE_ONLINE_TIMEOUT`)로 안내합니다.

두 경우 모두 실패 단계가 "PC 등록·온라인 확인"으로 표시되고, 진단 정보 복사에도 같은 코드가 들어갑니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 오류가 나면 오류 옆의 상세 보기에서 원인과 다음 조치를 확인하고, 계속 실패하면 진단 정보를 복사해 전달해 주세요.

### 조직 초대 보안 준비의 복구 파일 저장과 다음 단계 개선

내장 조직 관리자에서 복구 코드·복구 키를 파일로 저장할 수 있도록 수정했습니다. 보안 준비의 단계별 주 버튼을 하단 취소 오른쪽에 배치하고, 로그인 복구 코드와 계정 복구 키의 용도를 구분했습니다. 새 키를 만들고 보관한 뒤에는 소유 확인 입력이 바로 열립니다. 기존 키 확인은 보조 항목에서 열립니다. 기기 확인은 한 단계씩 이어지고, 6자리 코드 입력 옆 도움말에서 코드 찾는 방법을 볼 수 있습니다.

#### 사용 방법

조직 관리 → 유저 관리 → 유저 초대에서 보안 준비가 나타나면 복구 코드를 파일로 저장하거나 복사해 보관한 뒤 하단 저장 완료를 누르세요. 이어지는 계정 복구 키는 현재 비밀번호로 만들고 안전하게 보관·재입력한 뒤 펼쳐진 복구 키 확인도 완료하세요. 기존 키가 있다면 보관한 복구 키로 확인을 펼치세요.

### 조직 Claude 계정이 배정대로 정리되고, 사용량이 다 떨어져도 새 계정으로 이어서 작업합니다
