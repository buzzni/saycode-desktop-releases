## 새 기능

### AI도구 메뉴에서 OpenCode 설치 해제

AI도구 메뉴의 Opencode 모델 목록 맨 아래에 `설치 해제`를 추가했습니다. 확인창에서 한 번 더 확인한 뒤 Saycode가 이 컴퓨터에 설치한 opencode를 지우고, AI 목록에서 Opencode를 뺍니다. Saycode가 설치하지 않은 opencode는 지우지 않고 직접 지우는 방법을 안내합니다.

#### 사용 방법

새 대화 입력창의 AI도구 → Opencode → 모델 목록 맨 아래 `설치 해제` → 확인창의 `설치 해제`를 누릅니다. 이 컴퓨터에 opencode가 설치되어 있을 때만 보입니다. 다시 쓰려면 `무료 모델로 시작하기`에서 다시 설치합니다.

### say플랜 한도에 도달한 채 보내면 안내 창에서 다른 방법으로 바로 보낼 수 있습니다

새 대화의 사용 연결이 say플랜인데 한도에 도달한 상태에서 Enter를 누르거나 보내기 버튼을 누르면, 대화를 시작하지 않고 안내 창이 뜹니다. 안내 창은 say플랜을 다시 쓸 수 있을 때까지 남은 시간을 알려 주고, 지금 보낼 수 있는 방법을 함께 보여 줍니다. 작업PC에 AI 계정이 있으면 "AI 계정으로 보내기", 조직이 배정한 내부 AI가 있으면 "내부 AI로 보내기"로 입력한 내용을 그대로 바로 보냅니다. AI 계정이 없으면 "AI 계정 연결하기"로 연결 화면을 엽니다. "확인"을 누르면 안내 창이 닫히고 입력한 내용은 그대로 남습니다. 한도를 늘리려면 조직 관리자에게 문의하라는 안내도 함께 나옵니다. Project·Chat 새 대화와 홈 기획 입력창에 모두 적용됩니다.

#### 사용 방법

say플랜 한도에 도달한 상태(모델 버튼에 "say플랜 · 한도 도달" 표시)에서 새 대화를 보내면 안내 창이 열립니다. 원하는 방법을 누르면 그 연결로 바로 보내집니다.

### say플랜에서 조직이 제공하는 여러 모델 중 골라 새 대화 시작

조직이 say플랜 모델을 여러 개 제공하면 새 대화의 AI 메뉴에서 그중 하나를 고를 수 있습니다. DeepSeek 같은 Eco 모델과 GPT 모델이 AI별로 나뉘어 보이고, 고른 모델에 맞는 AI로 대화가 시작됩니다. 이 작업PC에서 실행할 수 없는 모델은 '업데이트 필요'로 표시되고 고를 수 없으며, 이때는 실행할 수 있는 플랜 모델로 시작합니다. 조직 기본 모델과 다른 AI(예: Codex 기본 조직에서 Claude Code)로 쓰는 새 대화는 내가 say플랜을 기본으로 저장했거나 관리자가 지정했을 때만 say플랜으로 시작합니다. 조직이 더 이상 제공하지 않는 모델로 시작하거나 이어가려 하면 다시 시도하라는 안내 대신 다른 모델로 새 대화를 시작하라고 알려 주고, 조직에 쓸 수 있는 플랜 모델이 하나도 없으면 그 사실을 알려 줍니다. say플랜 메뉴에서 고른 Eco 모델은 Claude Code의 저장된 모델을 바꾸지 않습니다. say플랜 사용량 창에서는 이번 기간 사용량 가운데 모델별 비중도 볼 수 있습니다.

#### 사용 방법

새 대화 입력창의 AI 메뉴를 열고 아래 사용 연결에서 say플랜을 고른 뒤, 위쪽 AI 목록에서 원하는 모델을 고릅니다. 모델별 비중은 플랜 대화 입력창 아래의 say플랜을 누르면 보입니다.

## 변경된 기능

### 개인 Claude 사용이 꺼져 있어 메시지를 보내지 못할 때 안내에서 바로 허용할 수 있습니다

이 PC에서 개인 계정 사용 허용을 꺼 둔 상태에서 조직 계정으로 확인되지 않은 Claude 대화에 메시지를 보내면, 지금까지는 대화 위쪽에 빨간 글자 한 줄만 표시됐습니다. 이제 경고 아이콘과 "개인 Claude 사용이 꺼져 있어 보내지 않았어요" 한 줄 옆에 AI 사용량 창에 있던 "이 PC에서 개인 계정 사용 허용" 스위치가 함께 보여 바로 켤 수 있습니다.

#### 사용 방법

Chat에서 메시지가 보내지지 않았다는 안내가 나오면 새 대화로 시작하거나, 안내 안의 "이 PC에서 개인 계정 사용 허용" 스위치를 켠 뒤 다시 보내세요. 다른 작업PC의 대화에는 스위치 없이 한 줄 안내만 표시됩니다.

### 관리자가 허용한 토큰 방식 내부 AI는 공용 PC에서도 고를 수 있습니다

지금까지 조직이 둔 공용 PC에서는 인증 없는 내부 AI만 고를 수 있었습니다. 이제 관리자가 공용 PC 사용을 허용한 토큰 방식 내부 AI도 공용 PC에서 고르고 대화를 시작할 수 있습니다. 허용하지 않은 토큰 방식은 "관리자가 공용 PC 사용을 허용하지 않은 토큰 방식이에요"라는 이유와 함께 계속 비활성으로 보입니다.

#### 사용 방법

조직이 운영하는 공용 PC로 새 대화를 열고 모델 메뉴의 내부 AI 탭에서 관리자가 공용 PC 사용을 허용한 내부 AI를 고른 뒤 메시지를 보냅니다. 비활성으로 보이면 관리자에게 공용 PC 허용을 요청하세요.

### 권한 요청 Enter·Esc 스위치를 단축키 목록 위로 옮겼어요

내 설정 → 단축키의 `권한 요청에 Enter·Esc로 응답` 스위치가 "이 키는 여기서 바꿀 수 없어요"라고 적힌 기본 단축키 바로 아래에 있어, 끌 수 없는 항목처럼 보였습니다. 이제 스위치를 단축키 검색 위에 따로 두어 기본 단축키와 구분됩니다. 스위치의 동작과 저장된 값은 그대로입니다.

#### 사용 방법

내 설정 → 단축키에서 단축키 검색 위의 `권한 요청에 Enter·Esc로 응답` 스위치를 눌러 끄거나 켭니다.

### 내 설정의 커넥터 화면이 외부 연동과 같은 모양이 됐습니다

내 설정의 커넥터 화면을 사이드바 외부 연동 화면과 같은 모양으로 맞췄습니다. 두 화면은 같은 연결을 보여 줍니다.

서비스 로고와 설명, 연결된 계정이 함께 보이고, 연결된 서비스와 연결할 수 있는 서비스가 나뉘어 보입니다.
연결 해제는 연결된 서비스 줄 오른쪽 관리(⋮) 메뉴에서 고른 뒤 확인합니다.

Figma 디자인 편집, GitHub·GitLab, 커스텀 커넥터는 지금처럼 외부 연동 화면에서 연결합니다.

#### 사용 방법

사이드바 맨 아래 내 프로필(계정) 버튼에서 내 설정을 열고 일반의 커넥터를 누릅니다.
연결할 서비스 줄의 연결을 누르고, 연결 해제는 그 줄의 관리(⋮) 메뉴에서 고릅니다.

### 내장 Happy 런타임을 1.1.10-aplus.422로 올렸습니다

Desktop에 내장된 Happy 런타임을 `1.1.10-aplus.422`로 올렸습니다. 조직 내부 AI 대화에서 조직이 허용한 모델 목록에 없는 모델을 써도 턴이 거부되지 않고, 수동 티어 조직 엔드포인트 대화에는 허용 모델 목록이 계속 적용됩니다. 대화 도중 보낸 메시지(steer)를 앱이 스스로 시작한 턴에서도 받고, 대기열에 오래 머문 메시지를 다시 집어 중복 전송하지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 이미 실행 중인 대화에는 적용되지 않으니, 새 대화를 시작하거나 종료된 대화를 다시 이어가세요.

### 대화 탭 제목과 아래 프로젝트 이름의 시작 위치를 맞췄어요

Project 대화 화면에서 위쪽 탭의 대화 제목과 그 아래 머리글의 프로젝트 이름이 서로 다른 위치에서 시작해 어긋나 보였어요. 이제 두 글자가 같은 세로선에서 시작해요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 로고 옆 실행 중 표시에 입력 대기와 작업보드 입구 더하기

사이드바 맨 위 로고 옆 표시가 숫자만이 아니라 `입력 대기 1 · 실행 중 1`처럼 무엇의 개수인지 글자로 보여 줍니다. 실행 중인 대화가 없어도 내 입력을 기다리는 대화가 있으면 나타납니다. 누르면 `입력 대기` 묶음과 `실행 중` 묶음으로 나눠 대화를 보여 주고, 맨 아래 `작업보드 열기`(⌘⇧A)로 작업보드를 열 수 있습니다. 작업보드 메뉴를 숨겨 두었어도 이 입구는 보입니다. 사이드바가 좁으면 글자 대신 점·도는 아이콘과 숫자만 보입니다.

#### 사용 방법

사이드바 맨 위 로고 옆의 `입력 대기`·`실행 중` 표시를 누르고, 이동할 대화를 고르거나 맨 아래 `작업보드 열기`를 누르세요. 조직이 작업보드 메뉴를 꺼 두었으면 `작업보드 열기`는 보이지 않습니다.

### 모델 메뉴의 연결 탭 위 '사용 연결' 글자 제거

새 대화 입력창의 AI·모델 메뉴 아래쪽 연결 탭(say플랜 · AI 계정) 위에 있던 '사용 연결' 글자를 없애 메뉴를 더 간결하게 했습니다. 남은 사용량 안내와, AI 자동일 때의 '연결 자동 선택' 안내는 표시할 내용이 있을 때만 탭 위에 나옵니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 배포 버튼은 기획안이 만들어진 프로젝트에서만 보입니다

대화 머리글의 배포 버튼이 모든 프로젝트에 보이던 것을 바꿔, 기획으로 시작한 프로젝트에서 대화로 기획안이 만들어진 뒤에만 보이게 했습니다. 내 PC 폴더나 Git 저장소를 연결한 프로젝트처럼 기획으로 시작하지 않은 프로젝트에는 대화 머리글에 배포 버튼이 나오지 않습니다.

#### 사용 방법

기획으로 프로젝트를 시작해 기획안이 저장되면 대화 머리글에 배포 버튼이 나타납니다. 이미 배포한 앱의 관리는 프로젝트 설정 → 배포 저장소에서 계속 할 수 있습니다.

### 변경 패널에서 바로 변경기록을 남길 수 있어요

오른쪽 도구의 변경 패널 아래에 변경기록 메시지 칸과 `변경기록 남기기` 버튼이 생겼습니다. 바뀐 파일을 읽은 자리에서 바로 변경기록을 남길 수 있고, 남긴 뒤에는 변경 목록이 새로 고쳐집니다. 브랜치 메뉴와 `Git 작업` 창에 있던 것과 같은 영역이라 `AI 생성` 버튼도 같은 설정에서 켠 경우에만 보입니다.

#### 사용 방법

프로젝트 대화에서 오른쪽 도구의 변경을 엽니다(⌃⇧G). 기록 안 한 변경 목록 아래에서 담을 파일을 확인하고 메시지를 적은 뒤 변경기록 남기기를 누릅니다.

### 변경 패널을 열면 첫 파일의 차이가 바로 보여요

변경 패널을 열면 파일을 누르기 전까지 빈 화면이던 자리에 목록의 첫 파일 차이를 바로 엽니다. 이미 고른 파일이 있으면 그대로 두고, 목록이 바뀌어 고른 파일이 사라졌을 때만 첫 파일로 옮깁니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 빠른 열기에서 상태 뱃지로 대화를 좁히고 자주 쓰는 명령을 먼저 봅니다

빠른 열기(⌘P) 입력칸 아래에 입력 대기 · 작업 중 · 완료·미확인 뱃지가 생겼습니다. 누르면 그 상태의 대화만 보이고, 다시 누르면 풀립니다. 지금처럼 `b `, `w `, `d `를 입력해도 켜집니다. 입력칸 안내는 "프로젝트, 대화, 파일 검색…"으로 바뀌었고, 입력칸에 마우스를 올리면 `>`로 명령을 찾는다는 설명이 나옵니다.

`>` 명령 목록은 새 대화, 새 프로젝트, 대화 검색, 작업보드, 프로젝트 검색, 사이드바 접기/펼치기, 내 설정 열기처럼 자주 쓰는 것부터 보이고, 화면 나누기 명령 여섯 개는 맨 아래에 묶였습니다. 새 프로젝트와, 프로젝트 대화 화면에서의 변경 열기 명령이 추가되었습니다. 단축키 설정의 이름 "빠른 찾기"는 창 이름과 같은 "빠른 열기"로 바뀌었습니다.

#### 사용 방법

⌘P(Windows는 Ctrl+P)로 빠른 열기를 열고 입력칸 아래 뱃지를 누르거나, >를 입력해 명령을 고릅니다.

### 사이드바 대화 상태를 글자로 보여 주기

사이드바의 Project·Chat 대화 목록에서 상태가 있는 대화는 제목 아래 둘째 줄에 `내 입력을 기다리는 중`, `응답 중`, `완료됨 · 아직 안 열어봄`, `실패함 · 아직 안 열어봄`, `사용자에게 질문 · 답변 대기 중` 같은 상태를 글자로 보여 줍니다. 입력을 기다리는 대화는 기다린 시간(예: `10분 전`)도 함께 보입니다. 마우스를 올려도 이 줄은 사라지지 않습니다. 상태가 없는 대화는 지금처럼 한 줄입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 새 대화 입력창 위 줄에 저장소 상태와 시작 폴더 이름 표시

새 프로젝트 대화의 입력창 위 줄에서 아이콘만 있던 저장소 상태 옆에 `Git 확인됨`·`변경 있음`·`원격 저장소 없음` 같은 상태 이름이 보이고, 폴더 버튼에는 고른 시작 폴더 이름(기본 `프로젝트 루트`)이 보입니다. 폴더의 전체 경로와 `작업트리`의 설명은 마우스를 올리거나 키보드로 초점을 옮기면 툴팁으로 보입니다. 화면을 나누거나 도구 패널을 열어 입력창이 좁아지면 이 글자는 먼저 줄어들고, 더 좁으면 아이콘만 남습니다.

#### 사용 방법

프로젝트에서 새 대화를 열면 입력창 위 줄에서 바로 확인할 수 있습니다. 상태 이름을 누르면 지금처럼 프로젝트 설정의 코드 저장소가 열리고, 폴더 이름을 누르면 시작 폴더를 고를 수 있습니다.

### 입력창 아래 줄에서 사용량이 비어 있는 이유와 작업PC 전체 이름을 보여 줍니다

입력창 아래 AI 잔여량 자리에 값이 없을 때 "—" 대신 "불러오는 중", "로그인 확인 필요", "작업PC 오프라인"처럼 이유가 짧게 보입니다. 마우스를 올리면 자세한 설명이 나옵니다. 이유를 알 수 없으면 지금처럼 "—"가 보입니다. 같은 줄 오른쪽의 작업PC 이름은 열 글자에서 자르지 않고 자리가 허락하는 만큼 보여 주며, 마우스를 올리면 전체 이름이 나옵니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

입력창 모델 버튼에서 내부 AI를 고르면 보이는 아이콘을 서버 모양에서 조직이 직접 운영하는 모델을 뜻하는 칩 모양으로 바꾸고, 주변 버튼과 어울리게 크기를 줄였습니다.

#### 사용 방법

### 작업 마무리 메뉴의 쓸 수 없는 이유를 툴팁으로 보여요

작업 마무리 메뉴에서 쓸 수 없는 항목(작업 리뷰하기·PR 올리기·보관&완료)의 이유가 항목 아래 줄 대신 툴팁으로 보입니다. 메뉴가 짧아지고, 이유는 마우스를 올리거나 화살표 키로 그 항목을 고르면 볼 수 있습니다. PR 올리기의 이유는 작업트리로 시작하는 방법까지 알려 줍니다.

#### 사용 방법

### 작업보드 카드의 오토파일럿 사용 불가 안내를 아이콘과 툴팁으로 줄이기

작업보드에서 오토파일럿을 쓸 수 없는 카드는 `오토파일럿 사용 불가 · 작업트리 필요` 두 줄 대신 카드 아래 도구 줄에 흐린 오토파일럿 아이콘 하나만 보여 줍니다. 이유는 아이콘에 마우스를 올리거나 키보드로 고르면 툴팁으로 보이고, 화면 낭독기도 읽습니다. 카드가 짧아져 한 칸에 더 많은 카드가 보입니다. 조직 정책으로 오토파일럿이 꺼진 카드도 같은 모양입니다.

#### 사용 방법

작업보드 카드 아래의 흐린 번개 아이콘에 마우스를 올리거나 Tab으로 이동하면 쓸 수 없는 이유가 보입니다.

### 화면 곳곳의 영어·옛 용어를 정한 표시 용어로 맞춥니다

브랜치 메뉴 머리글의 "worktree 이름"과 사이드바 대화 행의 아이콘 이름 "Worktree"가 "작업트리"로 바뀌었습니다. 입력창 ⋯ 메뉴의 "Auto Router"는 "모델 자동 선택 (Auto Router)"으로 보입니다. 기획 시작의 "온라인 머신이 필요합니다"는 "온라인 작업PC가 필요합니다"로, 리뷰를 실행할 작업PC가 꺼져 있을 때의 안내는 "작업PC가 오프라인입니다."로 바뀌었습니다. 사이드바 Chat·Project 탭 묶음의 화면 읽기 이름도 "목록"으로 번역됩니다.

#### 사용 방법

### 회사 보안 프로그램이 암호화한 문서도 미리보기로 확인해요

회사 보안 프로그램(DRM)이 PPT·Word·엑셀 파일을 암호화하는 PC에서는 앱이 원본을 읽지 못해 미리보기가 변환 오류로 보였어요. 이제 AI가 문서를 만들 때 남긴 HTML 미리보기가 있으면 그것을 대신 보여 주고, 위에 보안 환경용 미리보기라는 안내를 표시해요. 대신 보여 줄 미리보기가 없으면 보안 프로그램이 암호화한 파일이라 여기서 미리볼 수 없다고 알려 줘요. 다운로드하면 원래 파일 그대로 저장돼요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 프로젝트 파일 목록, AI 답변의 파일 링크, Chat 결과에서 문서를 열면 됩니다.

### AI가 만든 문서를 다음 대화에서도 이어서 고쳐요

AI가 PPT·Word·엑셀 문서를 만들면 그 문서를 만든 방법을 `documents/.sources/` 아래에 함께 남겨요. 다음 대화에서 고쳐 달라고 하면 처음부터 다시 만들지 않고 필요한 부분만 고쳐 같은 파일에 저장해요. 이 문서 작업 규칙은 Chat뿐 아니라 프로젝트 대화에도 자동으로 적용되고, AI 연결 도구가 연결되지 않아도 적용돼요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 끄려면 내 설정 → 시스템 프롬프트에서 문서 작업 지침을 끄세요.

Project 홈 Develop의 최근 프로젝트 줄 오른쪽 새 대화 아이콘이 `새 대화` 글자가 붙은 버튼으로 바뀌었습니다. 답을 기다리는 대화가 있는 프로젝트는 이름 옆에 `입력 대기 2`처럼 그 수가 보입니다. Build와 Develop 탭에 마우스를 올리거나 키보드로 초점을 옮기면 각 탭이 하는 일이 툴팁으로 보입니다.

이제 터미널은 접힌 채로 두고, 무엇이 잘못됐는지는 안내 문구로 알려 줍니다.
자세한 진행 내용이 필요하면 터미널 보기를 눌러 펼칩니다.

### say플랜 사용량의 재설정 날짜를 "12월 1일"처럼 보여요

say플랜 사용량 팝오버에서 이번 달·이번 주 한도가 재설정되는 날짜를 "12. 1."처럼 숫자만 이어 쓰지 않고 "12월 1일 재설정"처럼 월과 일을 붙여 보여 줍니다. 한도에 막혔을 때 "언제 다시 쓸 수 있어요" 안내의 날짜도 같은 형식으로 보입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### say플랜 한도 중에 쓴 AI 계정을 다음 새 대화에도 선택

say플랜이 한도에 도달한 동안 사용 연결에서 AI 계정을 골라 대화를 시작하면, 그 선택을 기억합니다. 이후 이 작업PC에서 여는 새 대화 입력창은 'say플랜 · 한도 도달' 대신 AI 계정으로 시작합니다. 한도가 재설정되면 다시 원래 기본 연결로 시작하고, say플랜으로 대화를 시작하면 기억을 지웁니다.

#### 사용 방법

say플랜 한도에 도달했을 때 새 대화 입력창의 모델 메뉴 › 사용 연결에서 AI 계정을 고르고 대화를 시작하세요. 다음 새 대화부터는 따로 고르지 않아도 AI 계정이 선택돼 있습니다.

### say플랜 한도에 도달해도 탭을 눌러 한도를 확인할 수 있습니다

say플랜 한도에 도달하면 다른 연결(AI 계정, 내부 AI)을 쓰는 중에는 say플랜 탭이 비활성화되어, 마우스를 올려야만 "say플랜 한도에 도달했어요."라는 안내를 볼 수 있었습니다. 이제 한도 도달 상태에서도 say플랜 탭을 누를 수 있고, 누르면 한도 안내와 함께 플랜 등급, 이번 달·이번 주·5시간 사용량, 재설정까지 남은 시간이 표시됩니다. 이때 메뉴는 한도가 없을 때 say플랜을 고른 것과 같은 AI·모델 메뉴를 한도 안내와 함께 보여 주며, 모델은 비활성이라 고를 수 없습니다. AI 계정용 AI 목록·작업 강도·AI 프로필은 AI 계정 탭을 누르면 다시 보입니다. say플랜이 선택된 채 한도에 도달했을 때도 같습니다. 탭을 눌러 한도를 보기만 해서는 지금 고른 연결과 AI도구가 바뀌지 않습니다. 한도가 풀리기 전에는 say플랜으로 대화를 시작할 수 없으며, AI 계정을 눌러 바로 시작할 수 있습니다. 플랜 등급·작업PC 지원·정책처럼 다른 이유로 쓸 수 없는 경우는 지금처럼 탭이 비활성화됩니다.

#### 사용 방법

새 대화 입력창의 AI·모델 메뉴를 열고 맨 아래 사용 연결에서 say플랜 탭을 누릅니다.

### say플랜 Eco 사용량에 토큰 표시

say플랜 Eco 대화의 사용량 팝오버에 이번 달과 이번 주에 쓴 입력·캐시·출력 토큰을 함께 보여 줍니다. Eco는 원가가 낮아 사용률이 0%로 보여 실제로 얼마나 썼는지 알 수 없었습니다. 모델 이름도 제공자 ID 대신 표시 이름으로 보입니다.

#### 사용 방법

Eco 대화 입력창 아래의 say플랜 버튼을 누르면 사용량 아래에 토큰 사용량이 보입니다.

## 수정된 문제

### 개인 사용에서 보관한 Chat도 대화 보관함에서 보관 해제

로그인 없이 개인 사용으로 쓸 때 Chat을 보관하면 사이드바에서는 사라졌지만, 내 설정 → 대화 보관함에는 Project 보관함만 보여 보관한 Chat을 다시 꺼낼 방법이 없었습니다. 이제 개인 사용에서도 Chat 보관함 탭이 나오고, 이 PC에 보관한 Chat을 찾아 보관 해제할 수 있습니다.

#### 사용 방법

내 설정 → 대화 보관함 → Chat 보관함에서 대화 줄의 보관 해제를 누르세요.

### 개인 사용에서 파일 복원지점을 켜면 대화가 시작되지 않던 문제 수정

개인 사용에서 새 대화의 `파일 복원지점`을 켜고 메시지를 보내면 "이 대화를 시작하지 못했습니다"와 함께 checkpoint spawn context 오류가 나고, 다시 시도해도 같은 오류가 났습니다. 파일 복원지점은 Saycode 계정으로 로그인했을 때만 쓸 수 있어 개인 사용에서는 대화를 시작할 수 없었습니다. 이제 개인 사용에서는 스위치가 꺼진 채 비활성화되고 "개인 사용에서는 사용할 수 없습니다."라는 이유가 함께 보입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 파일 복원지점이 필요하면 Saycode 계정으로 로그인한 뒤 입력창 `⋯` 메뉴에서 켜세요.

### 개인 Claude 사용을 꺼 둔 PC에서 say플랜 Eco 대화가 보내지지 않던 문제를 고쳤습니다

이 PC에서 개인 계정 사용 허용을 꺼 두었을 때, say플랜 Eco 모델(예: DeepSeek V4.1 Flash Eco)로 새 대화를 시작하면 첫 메시지가 "이 대화가 조직 계정으로 실행되는지 확인하지 못해 보내지 않았어요"라는 안내와 함께 보내지지 않았습니다. Eco 대화는 이 PC의 Claude 로그인이 아니라 조직의 say플랜으로 실행되므로 이제 개인 Claude 확인에 막히지 않습니다. 이어서 보내기·응답 중 추가 요청·대화 재개도 같은 기준을 따릅니다. 일반 Claude 대화의 조직 계정 확인은 그대로 유지됩니다. 대화가 say플랜으로 실행 중인지 확인하지 못했을 때는 개인 계정 안내 대신 "사용 연결을 확인하지 못했습니다"를 표시합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 고정한 대화만 있는 프로젝트에 "최근 대화가 없습니다"가 뜨지 않습니다

사이드바 프로젝트 아래 대화 목록은 고정한 대화를 위쪽 고정된 대화 목록으로 옮겨 보여 줍니다. 그래서 대화를 모두 고정한 프로젝트, 특히 대화가 하나뿐인 프로젝트에서는 대화가 있는데도 "최근 대화가 없습니다"라고 나왔습니다. 이제 "고정한 대화 N개만 있습니다. 고정된 대화 목록에서 확인하세요."라고 알려 줍니다.

#### 사용 방법

### 내부 AI 목록을 사용 연결 탭 위에 표시

### Git 저장소를 연결하지 않은 프로젝트도 바로 배포
