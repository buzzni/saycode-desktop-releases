## 새 기능

### 내 프로필에서 시작하는 대시보드

프로필 아래에서 오늘 할 일, 고정한 대화와 최근 활동, 동시에 진행 중인 작업을 확인할 수 있어요. 대화와 연결된 작업PC·작업트리·PR이 있으면 같은 행에 표시돼요. 내 활동 분석의 AI 사용 스타일은 이 컴퓨터의 기록으로 계산해요. 공간컨텐츠는 프로젝트 작업 도구에서 열 수 있어요.

#### 사용 방법

buzzni 조직에서 사이드바의 대시보드를 여세요. 화면 편집에서 영역을 숨기거나 배치를 바꾸고, 내 AI 사용 스타일에서 관점을 선택해 근거를 살펴보세요.

### 대시보드에서 프로젝트 동료와 조직 토큰 사용량 확인

대시보드 프로필의 오늘 집계 세 칸을 걷어냈어요. 우리 팀에서 같은 프로젝트의 동료를 확인할 수 있고, 조직 소유자와 관리자는 최근 7일 조직 토큰 사용 순위도 볼 수 있어요.

#### 사용 방법

사이드바에서 대시보드를 열고 같은 프로젝트의 동료에서 프로젝트를 고르세요. 집계 권한이 있으면 조직 토큰 사용 순위에 1.5억토큰처럼 줄인 숫자가 보여요. 숫자에 마우스를 올리거나 Tab으로 이동하면 정확한 토큰 수를 볼 수 있어요.

### 버즈니 전용 영상 제작 확장 세이폼

버즈니 조직에서 숏폼 제작 대화를 시작하고, 오른쪽 전체 너비로 영상을 볼 수 있어요. 영상 아래의 작은 칩으로 버전을 고를 수 있어요. 목록이 길면 칩 위에서 마우스 휠로 좌우를 탐색하고 다운로드 아이콘이 있는 **저장** 버튼으로 영상을 저장할 수 있어요. 수정은 같은 대화에서 요청할 수 있어요. 제작 이력이 있는 프로젝트에는 필름 아이콘이 표시돼요.

#### 사용 방법

사이드바에서 **연동/확장**을 열고 화면 하단 **확장**에서 **buzzni** 배지가 붙은 **세이폼**를 엽니다. 기본 선택인 **새 프로젝트**에서 제작을 시작하면 표시된 macOS 작업PC에 새 프로젝트를 만들고 제작 환경을 연결합니다. 기존 Git 프로젝트에서 만들려면 입력창 아래의 제작 프로젝트 선택 창에서 프로젝트명이나 작업PC 표시 이름으로 찾은 뒤 **제작환경**에서 필요에 따라 그룹을 적용합니다. 영상 요청을 쓰거나 입력창 아래의 예시 카드를 골라 문장을 채웁니다. 내용을 편집한 뒤 오른쪽의 **제작 시작**을 누릅니다. 본인 Mac에 도구가 비어 있으면 제작환경 창에서 **설치하고 제작 시작**을 누릅니다. 영상 도구는 현재 Mac의 Homebrew로 설치합니다. 재생에는 미디어 미리보기 확장과 파일 읽기 권한이 필요합니다.

### 새 대화 제목에서 프로젝트 선택

프로젝트 대화 시작 화면에서 대화할 프로젝트를 확인하고 검색해 바꾸거나 새로 만들 수 있습니다.

#### 사용 방법

프로젝트에서 새 대화를 열고 제목의 프로젝트 이름을 누르세요. 목록에서 대화할 프로젝트를 고르거나 `프로젝트 만들기`를 누르세요.

### 시작 화면에서 프로젝트를 골라 바로 새 대화

시작 화면 입력창 아래 줄에 프로젝트 칩이 생겼습니다. Chat에서 쓰던 글을 그대로 둔 채 프로젝트를 고르면 Project 탭으로 바뀌고, 보내면 그 프로젝트의 새 대화가 시작됩니다. 칩에서 프로젝트를 검색할 수 있고, 새 프로젝트에서 이름만 넣으면 작업PC에 그 이름의 폴더로 프로젝트가 만들어져 바로 골라집니다(기존 작업 폴더를 골라 쓸 수도 있습니다). 프로젝트 없이 작업을 고르면 Chat으로 돌아갑니다. Project 입력창의 보내기 왼쪽에는 Build 버튼이 있어 켜면 기획으로 새 프로젝트를 만들고, 프로젝트를 고른 동안에는 꺼집니다.

#### 사용 방법

대화 위쪽의 새 대화나 사이드바 Chat으로 시작 화면을 열고, 입력창 아래 줄의 프로젝트 선택을 누르세요.

### 외부 연동 화면에서 설치한 확장 열기

외부 연동 화면 하단에 바로 열 수 있는 확장이 표시됩니다. 현재 조직이 버즈니일 때 세이폼 옆에 세이마가 표시됩니다. 세이마에서는 네 가지 질문에 답해 캐릭터를 만들고 공간에서 옮길 수 있습니다. 캐릭터마다 지시, 작성자 설정, 답글 초안을 따로 저장합니다. 다른 창의 저장과 겹치면 입력을 확인하고 다시 불러올 수 있습니다.

#### 사용 방법

해당 확장을 설치하고 활성화한 뒤, 연동/확장 화면 하단의 확장 섹션에서 열기를 누릅니다. 세이마의 만들기를 선택하고 할 일, 말투, 확인 주기, 모습을 고르세요. 캐릭터를 누르면 왼쪽에서 설정이나 검토함을 열 수 있습니다.

### 프로젝트 메뉴에서 다른 폴더를 함께 연결할 수 있습니다

사이드바 프로젝트 메뉴(⋮)에 `폴더 추가`가 생겼습니다. 누르면 `프로젝트 폴더` 창이 열리고, 기본 폴더와
함께 AI가 볼 다른 폴더를 한곳에서 추가하거나 뺄 수 있습니다. 폴더마다 읽기 전용·읽기·쓰기 권한을 고르고
`저장`을 눌러 한 번에 반영합니다. 저장 전에는 아무것도 바뀌지 않고 `취소`하면 고친 내용이 버려집니다.

파일 트리의 `추가 디렉터리`는 `추가 폴더`로 이름을 바꾸고, 권한을 글자 대신 아이콘으로 보여 폴더 이름이
덜 잘리게 했습니다. 등록할 때 용도를 따로 입력하지 않아도 됩니다. 입력창의 `+ › 폴더 추가`(파일 첨부)는
그대로입니다.

#### 사용 방법

사이드바 프로젝트 이름 옆 ⋮ → `폴더 추가` → `폴더 추가`로 폴더 선택 → 필요하면 권한 변경 → `저장`.
파일 트리의 `추가 폴더` 옆 버튼으로도 같은 창이 열립니다. 새 대화나 종료 후 다시 이어간 대화부터 적용됩니다.

## 변경된 기능

### 가운데 대화 탭 줄에 Chat과 프로젝트 대화가 함께 보입니다

개발자 모드의 가운데 대화 탭 줄은 Chat 대화와 열어 둔 모든 프로젝트의 대화를 한 줄에 함께 보여 줍니다. 탭 앞의 작은 아이콘(말풍선은 Chat, 상자는 프로젝트)으로 종류를 구분합니다. 사이드바 위쪽의 Chat·Project는 목록만 바꾸고, 보고 있는 대화와 탭 줄은 그대로 둡니다. 개발자 모드를 끈 화면에서는 사이드바를 Chat과 Project 사이에서 바꾸면 그 종류에서 마지막으로 보던 대화로 돌아가고, 열린 대화가 없으면 그 종류의 시작 화면이 열립니다.

#### 사용 방법

개발자 모드에서 가운데 탭 줄의 탭을 눌러 Chat과 프로젝트 대화를 오가세요.

### 고른 카드와 항목을 중립 회색으로 표시

새 프로젝트 창의 시작 방식 카드처럼 여러 개 중 하나를 고르는 카드·항목이 옅은 파랑 대신 옅은 회색 면과 조금 진한 회색 테두리로 표시됩니다. 새 프로젝트 창에서 고른 카드는 글자도 굵게 보입니다. 고른 항목은 마우스를 올려도 색이 바뀌지 않습니다. 다크 모드도 같은 방식으로 맞췄습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 기존 프로젝트도 대화 상단에서 미리보기

미리보기를 이용할 수 있는 기존 프로젝트에서도 대화 상단에 미리보기 버튼이 보여요. 미리보기 탭을 보고 있을 때는 버튼에 선택 상태가 표시돼요.

#### 사용 방법

프로젝트 대화 상단에서 더보기(⋮) 왼쪽의 미리보기 버튼을 누르세요. 이미 열린 미리보기가 있으면 그 탭으로 초점이 이동해요. 대화 영역이 좁으면 같은 위치에 미리보기 아이콘이 표시돼요.

### 대화 위쪽 맨 오른쪽에 새 대화

대화 화면 위쪽 줄 맨 오른쪽에 새 대화 버튼이 생겼습니다. 개발자 모드를 끈 상태에서도 보입니다. 누르면 시작 화면(Chat · Project · Develop과 입력창)이 Chat으로 열려, 프로젝트 작업 중에도 바로 새 대화를 시작할 수 있습니다. 같은 프로젝트에서 새 대화 탭을 여는 기존 동작은 단축키(⌘T / Ctrl+T)로 쓸 수 있습니다.

#### 사용 방법

대화 위쪽 줄 맨 오른쪽의 새 대화를 누르세요.

### 변경 패널이 변경 내용부터 넓게 보여 줌

작업 패널의 변경을 열면 오른쪽 변경 목록은 닫힌 채 첫 파일의 변경 내용이 넓게 보입니다. 변경 내용은 좌우 비교 대신 한 파일 보기로 먼저 보여 줍니다. 변경 범위 이름은 `기록안함 · 전체 · 턴별`로 짧아져 한 줄에 보이고, 마우스를 올리면 원래 이름을 알려 줍니다.

#### 사용 방법

변경 목록은 변경 탭 오른쪽 위의 프로젝트 파일 버튼으로 열고 닫습니다. 열어 둔 상태는 대화마다 기억합니다. 좌우 비교는 좌우 비교 버튼으로 바꿀 수 있고, 파일을 다시 열면 한 파일 보기로 시작합니다.

### 사이드바 메뉴 이름을 연동/확장으로 변경

서비스 연결과 확장을 찾는 사이드바 메뉴 이름이 외부 연동에서 연동/확장으로 바뀝니다.

#### 사용 방법

사이드바에서 **연동/확장**을 누릅니다. 사이드바를 접은 상태에서는 플러그 아이콘을 누릅니다.

### 시작 화면 위쪽에 Chat·Build·Develop 탭

시작 화면 위쪽 탭에 Chat이 더해져 Chat·Build·Develop 세 탭이 Chat 화면에서도 보입니다. 입력창에서 바로 작업 종류를 바꿀 수 있습니다. 탭은 같은 너비로 더 작아졌고, Chat·Build 입력창은 아래 문서 가이드 줄과 같은 너비로 맞췄습니다.

#### 사용 방법

시작 화면 위쪽의 Chat·Build·Develop 탭을 누르세요. 마지막으로 고른 탭이 다음 시작 화면으로 기억됩니다.

### 시작 화면 Build 탭 이름을 Project로

시작 화면 위쪽 탭이 `Chat · Project · Develop`으로 바뀌었습니다. 이전의 Build 탭과 같은 화면이고, 기획으로 새 프로젝트를 시작하는 동작도 같습니다.

#### 사용 방법

시작 화면 위쪽에서 Project 탭을 누르세요.

### 업데이트 뒤 이 컴퓨터 연결이 더 빨라집니다

앱을 업데이트하거나 다시 켠 뒤 `앱을 다시 시작하는 중입니다` 창에서 이 컴퓨터 연결을 기다리는 시간을 줄였습니다. 지금까지는 작업 실행기를 켜는 준비 프로그램과 작업 실행기가 같은 프로그램 파일을 차례로 두 번 읽었습니다. 보안 프로그램이 새 파일을 검사하는 PC에서는 업데이트 직후 한 번 읽는 데 30초 넘게 걸려, 연결까지 1분 넘게 기다리기도 했습니다. 이제 실행 중인 작업 실행기가 없으면 앱이 작업 실행기를 바로 켜서 파일을 한 번만 읽습니다. 이미 실행 중인 작업 실행기를 새 버전으로 바꿀 때는 진행 중인 작업을 마무리한 뒤 교체하는 기존 방식을 그대로 씁니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 외부 연동 목록에서 연결된 항목 먼저 표시

외부 연동의 AI 계정과 사용 가능한 연동에서 연결된 항목이 각 목록 앞에 표시됩니다. 옅은 녹색 배경과 체크 표시가 있는 `연결됨` 배지로 연결 상태를 확인할 수 있습니다.

#### 사용 방법

사이드바의 외부 연동을 열면 바로 확인할 수 있습니다.

### 작업PC 상세 정보를 목록으로 정리

작업PC 상세 정보에서 각 항목의 이름과 값을 한 행에 나란히 보여 줍니다. 긴 ID와 경로는 값 열에서 줄바꿈됩니다.

#### 사용 방법

내 설정 → 개발 → 작업PC에서 확인할 PC의 상세 정보를 엽니다. 오른쪽 위 × 버튼이나 Escape 키로 닫습니다.

### 커넥터 관리를 외부 연동으로 통합

서비스 연결을 사이드바의 외부 연동에서 관리합니다. 기존 대화의 커넥터 바로가기와 예약 실패의 연결 설정도 외부 연동을 엽니다.

#### 사용 방법

사이드바에서 외부 연동을 열고 서비스 카드에서 연결 상태를 확인하거나 다시 인증하세요. 기존 연결은 계속 사용할 수 있습니다.

### 커스텀 커넥터 영역의 조직별 표시

Desktop 외부 연동의 커스텀 커넥터 영역을 버즈니와 지란 조직에서 사용할 수 있습니다.

#### 사용 방법

버즈니 또는 지란 조직을 선택한 뒤 사이드바에서 외부 연동을 여세요. 서버에서 커넥터 추가를 허용하거나 표시할 커넥터가 있으면 해당 영역이 나타납니다.

다른 조직에서는 [웹 외부 연동](https://saycode.ai/integrations)의 커스텀 커넥터에서 조직 MCP에 로그인하거나 로그아웃할 수 있습니다.

#### 사용 방법

## 수정된 문제

### 개인 채팅에 메시지를 다시 보낼 수 있습니다

개인 채팅에 메시지를 보내면 "이 대화가 속한 프로젝트를 찾지 못했어요. 보관함을 다시 열어 확인해 주세요."라는 오류가 나고, 다시 보내도 같은 오류가 반복되던 문제를 고쳤습니다. 대화를 실행하던 PC 쪽에서 보관된 것으로 표시된 개인 채팅도 이제 보관 표시를 풀고 이어서 대화합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 공용 PC에서 AI가 내가 연 다른 대화를 알아봅니다

회사 공용 PC에서 AI가 같은 프로젝트의 대화 목록을 볼 때, 내가 연 다른 대화를 "내 대화"로
알아보지 못하고 모두 "확인되지 않음"으로 표시했습니다. 매번 20초쯤 기다린 뒤에야 결과가 나오기도
했습니다. Desktop이 대화마다 소유 관계를 처음부터 다시 확인하느라 응답 제한 시간을 넘겼기
때문입니다. 이제 확인은 요청의 시작과 끝에 한 번씩만 하고, 대화는 여러 개를 동시에 읽어 몇 초 안에
답합니다. 확인에 실패하면 끝까지 기다리게 하지 않고 바로 실패를 알립니다.
Desktop을 켠 직후나 꺼진 PC의 대화가 많을 때 몇 분씩 내 대화를 알아보지 못하던 문제도 고쳤습니다.
이제 오래 걸리는 대화를 기다리지 않고 나머지 대화를 바로 연결합니다. 저장된 로그인으로 Desktop을 켠 경우에도
켜자마자 연결을 시작합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. Desktop이 켜져 있어야 합니다.

### 관련 프로젝트 폴더가 있는 대화가 시작됐는데도 실패로 보이던 문제 수정

관련 프로젝트 폴더가 연결된 프로젝트에서 새 대화를 시작하면, 대화는 실제로 시작됐는데도 화면에는 대화 시작 실패로 표시되는 경우가 있었습니다. 작업PC의 실행 도구가 이전 버전일 때 생기던 문제입니다. 이제 그런 작업PC에서는 폴더 연결 결과를 확실히 돌려주는 방식으로 대화를 시작해, 정상적으로 열립니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 동시작업 대화에서도 같은 프로젝트의 다른 대화가 보입니다

작업 폴더를 따로 지정하지 않고 기본 위치를 쓰는 프로젝트에서 동시작업을 켜고 만든 대화는, AI가 대화 목록을 볼 때
자기 대화만 보였습니다. 이제 기본 위치도 프로젝트 폴더로 보고, 같은 프로젝트의 다른 대화를 조회하고 하위 대화를
관리할 수 있습니다. 하위 대화 패널과 응답 중단 연쇄도 같은 범위를 씁니다.

#### 사용 방법

별도 설정 없이 새로 만드는 대화부터 적용됩니다. 업데이트 전에 시작한 동시작업 대화가 새로 띄운 하위 대화는
하위 대화 패널과 응답 중단 연쇄에 보이지 않을 수 있습니다. 그 대화를 새로 만들면 해소됩니다.

### 배정되지 않은 조직 AI 계정은 입력창 아래 사용량에 보이지 않습니다

조직에서 나에게 배정된 AI가 없어도, 이 컴퓨터에 남아 있는 예전 조직 계정(다른 조직의 계정이나 배정이 풀렸지만 아직 정리되지 않은 계정)이 입력창 아래 `AI 사용량`에 "조직 · 계정"과 Claude 사용량으로 보였습니다. 이런 계정은 이 조직의 대화에 쓰이지 않습니다. 이제 내 전용 작업PC에서는 지금 조직에 배정된 조직 계정만 보입니다. 개인 계정과 공용 작업PC의 계정은 그대로 보이고, 이 컴퓨터의 계정은 지우지 않습니다.

#### 사용 방법

따로 할 일은 없습니다. 조직 AI를 배정받으면 그 계정이 입력창 아래에 다시 보입니다.

### 시작 화면 입력창에서도 모델·작업 강도 단축키 동작

Chat·Build 시작 화면과 새 Chat 탭의 입력창에서 Cmd/Ctrl+Shift+M(다음 모델), Cmd/Ctrl+Shift+L(다음 작업 강도)이 동작하지 않던 문제를 고쳤습니다.

#### 사용 방법

시작 화면 입력창에 커서를 두고 Cmd/Ctrl+Shift+M 또는 Cmd/Ctrl+Shift+L을 누르세요. AI를 자동으로 고르는 중에는 바뀌지 않습니다.

### 일반 프로젝트 대화의 모드 탭 정리

대화로 시작하는 일반 프로젝트에서 작업모드 설정만으로 기획·작업 탭이 나타나던 문제를 수정했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 재시작 뒤 업데이트가 적용되지 않았으면 바로 다시 받습니다

업데이트 재시작 뒤 이전 버전으로 다시 열리면, 프로필 메뉴에 "업데이트가 적용되지 않았습니다" 경고만 남고 사용자가 눌러야 다시 받기 시작했습니다. 이제 같은 버전이 다시 확인되면 앱이 바로 다시 내려받고, 메뉴에는 "지난 업데이트가 적용되지 않아 다시 받는 중"과 진행률이 보입니다. Windows에서는 이때 빠른 업데이트 대신 전체 설치 파일을 받습니다. 다시 받은 뒤 `재시작해서 업데이트`를 누르면 됩니다.

#### 사용 방법

따로 할 일은 없습니다. 다운로드가 끝나면 프로필 메뉴의 `재시작해서 업데이트`를 누르세요.

### 조직 공용 환경변수가 프로젝트 대화에 바로 들어갑니다

조직 관리자가 `기본 로드`로 켠 조직 공용 환경변수가, 그 값을 넣기 전부터 있던 프로젝트의 대화에는 들어가지 않던 문제를 고쳤습니다. 이전에는 프로젝트의 `.env` 파일이 다시 써질 때만 값이 전달돼서, 프로젝트 설정에서 환경 마운트를 직접 연결해야 했습니다.

이제 Desktop에서 프로젝트 대화를 시작하거나 다시 열 때마다 서버가 합친 최신 환경변수(조직 기본 로드, 연결한 그룹, 프로젝트 환경변수)를 받아 대화에 넣습니다. 같은 이름이 겹치면 프로젝트 설정에 넣은 값이 이깁니다. `.env` 파일을 손으로 고쳐 같은 이름을 바꿔 두었다면, 이제 서버 값이 그보다 먼저 적용됩니다.

조직 환경변수를 불러오지 못하면 대화는 그대로 시작하고, 이번 대화에 넣지 못했다는 알림을 한 번 보여 줍니다. 보안 강화 모드 작업PC는 서버가 값을 내주지 않아 이번 변경이 적용되지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 조직 정책 안내 표시 정리

입력창 위와 설정의 조직 정책 카드에서 "조직 정책이 24시간 이상 갱신되지 않음" 안내를 없앴습니다. 사용자가 할 수 있는 일이 없는 안내였습니다. 마지막으로 받은 조직 정책은 이전처럼 계속 적용됩니다. 또 모델을 직접 고르지 않아 조직이 허용한 모델로 실행한 경우에는 "허용된 모델로 실행했어요" 안내를 띄우지 않습니다. 직접 고른 모델이 다른 모델로 바뀐 경우에만 안내합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 프로젝트 상단 바로가기를 설정과 권한에 맞게 표시

프로젝트 상단의 기획·작업 모드, 미리보기, 배포 바로가기를 소유 권한과 저장된 설정에 따라 표시합니다. 읽기 전용 프로젝트에 나오던 비활성 배포 버튼을 정리했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 프로젝트의 시작 설정은 프로젝트 설정 → 프로젝트 정보에서 확인할 수 있습니다.

### Chat 시작 예시 카드의 마우스 강조 개선

Chat 시작 예시 카드에 마우스를 올리면 그림과 제목이 강조되고, 카드 아래 배경은 투명하게 표시됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### Windows 빠른 업데이트가 끝난 뒤 실패로 다시 기록되거나 앱이 한 번 더 열리지 않습니다

Windows 빠른 업데이트는 새 버전을 연 뒤 이전 버전 폴더를 지웁니다. 새로 열린 앱도 시작할 때 같은 폴더를 정리하기 때문에 둘이 부딪칠 수 있었고, 그러면 이미 성공한 업데이트가 실패로 다시 기록되고 앱 실행이 한 번 더 일어났습니다. 이제 업데이트가 성공으로 끝난 뒤의 폴더 정리 오류는 기록에만 남고, 결과와 앱 실행은 바뀌지 않습니다.

#### 사용 방법

따로 할 일은 없습니다.

### Windows 작업PC에서도 파일 이름 전체 검색이 됩니다

파일 목록 검색창에서 Enter를 눌러 프로젝트 전체에서 파일 이름을 찾으면, Windows 작업PC에서는 결과 없이 `일부 파일만 확인했습니다`만 보였습니다. 파일 목록을 만드는 명령이 macOS·Linux용 셸 명령이라 Windows에서 실행되지 않았기 때문입니다. 이제 Windows 작업PC에서도 같은 목록을 만들어 이름이 맞는 파일을 보여 주고, 채팅에 나온 파일 이름 링크로 파일을 찾는 것도 같은 방식으로 동작합니다. 파일 내용 검색은 아직 macOS 작업PC에서만 됩니다.

#### 사용 방법

파일 목록 위 검색창에 이름 일부를 입력하고 Enter를 누릅니다.
