## 변경된 기능

### 시작 화면 탭·Build 버튼·프로젝트 만들기 창 다듬기

시작 화면의 Chat · Project · Develop 탭을 인사말 위로 옮기고, 탭을 완전히 둥근 모양으로 바꿨습니다. Project 입력창의 Build 버튼은 할 일 목록 아이콘으로 바뀌어 마이크 왼쪽에 있고, 마이크는 다시 보내기 바로 왼쪽에 있습니다. Project 탭에서 폴더를 고르거나 Build를 끄거나 프로젝트 없이 작업을 골라도 Chat 탭으로 넘어가지 않습니다. 프로젝트 없이 Build를 끄면 프로젝트를 고르거나 Build를 켤 때까지 보내지 않습니다. 입력창 아래 프로젝트 선택 목록은 5개 반 높이까지 보이고 그보다 많으면 스크롤됩니다. 프로젝트 만들기 창에서 이 컴퓨터의 작업 폴더를 추가하면 파일 탐색기가 열리고, 홈 폴더 밖 폴더는 이 폴더 허용을 거친 뒤 만들 수 있습니다. 작업 폴더 영역은 가운데 정렬로 정리했습니다.

#### 사용 방법

시작 화면 입력창 아래의 프로젝트 선택 › 새 프로젝트에서 작업 폴더의 추가를 누르세요.
