## 새 기능

### 내 AI 계정 로그인을 링크 버튼과 인증 코드 입력으로 간편하게

조직 AI 계정 없이 내 계정으로 Claude에 로그인할 때, 터미널에서 직접 명령을 입력하거나 링크를 찾아 누르지 않아도 됩니다. 로그인이 자동으로 시작되고, 나온 로그인 링크는 버튼으로, 인증 코드는 입력칸으로 바로 쓸 수 있습니다. 내 PC에서 로그인 상태를 확인하지 못한 경우에도 "다시 확인" 옆에 로그인 버튼이 나타납니다.

#### 사용 방법

AI 연결 설정에서 로그인을 누르면 "로그인 링크 열기" 버튼이 나타납니다. 브라우저에서 로그인한 뒤 표시되는 인증 코드를 입력칸에 붙여 넣고 "인증 코드 보내기"를 누르세요. 코드가 맞지 않으면 안내와 함께 "다시 시도" 버튼이 나타납니다. 터미널은 "터미널 보기"에서 확인할 수 있습니다.

### 대용량 미디어 파일 스트리밍 미리보기

Mac 작업 PC의 MP4 등 영상·음성 파일을 텍스트로 처리하지 않고 구간별로 읽어 재생하고 탐색합니다. 파일 전체 수신을 기다리지 않으며 패널을 숨기거나 읽기 권한을 철회하면 스트림을 닫습니다. 원본 변경·연결·권한 오류에는 다시 열기를 제공합니다.

#### 사용 방법

호환되는 미디어 미리보기 확장을 설치하고 선택 파일 읽기 권한을 허용한 뒤 파일 패널·작업물에서 영상을 여세요. 확장은 별도 설치가 필요합니다. 재생할 수 없는 코덱이나 지원하지 않는 작업 PC는 원본을 저장해 열 수 있습니다.

### 브라우저에서 개인 AI 계정 연결하기

ChatGPT 또는 Claude 계정을 명령어 입력 없이 브라우저에서 연결할 수 있는 안내 창을 추가했습니다. 온보딩 종료 후와 새 대화를 열 때 공용·개인 AI 계정이 모두 없으면 안내하며, 나중에 연결하도록 닫아도 작성 중인 질문은 유지됩니다.

이 컴퓨터의 계정 연결 상태가 미리 확인되어 있으면 새 대화 화면을 열자마자 안내가 표시됩니다.

내 설정에서는 안내와 연결 버튼으로 개인 계정 연결을 별도 섹션으로 표시합니다. 아래 `연결된 AI 확인하기`에서 공급사 아이콘과 함께 AI·PC를 한 번에 확인할 수 있습니다.

#### 사용 방법

안내 창에서 `내 AI 계정 연결`을 누르고 ChatGPT 또는 Claude를 선택한 뒤 브라우저에서 로그인하세요. `내 설정 > AI 연결 설정 > 내 AI 계정 연결`에서도 열 수 있습니다. 개인 계정은 이 컴퓨터에 연결됩니다.

### 설치한 공식 확장을 새 버전으로 업데이트할 수 있습니다

이미 설치한 공식 확장보다 새 버전이 있으면 확장 카드에 `<버전>으로 공식 업데이트` 버튼이 나옵니다. 파일을 고르지 않고 Desktop이 확인한 공식 파일로 바로 바꾸며, 새 버전이 요청하는 권한은 다시 승인합니다. 이전에는 공식 목록이 설치된 확장을 숨겨서, 예를 들어 Moai 1.0.x를 설치한 사용자는 새 Desktop에서도 1.1.0을 받을 수 없었습니다. 또 프로젝트 도구를 제공하는 확장은 활성화하면 카드에 어디서 여는지(프로젝트 대화의 작업 패널 더보기 메뉴) 안내합니다.

#### 사용 방법

내 설정 → 개발 → 확장에서 확장 카드의 `공식 업데이트`를 누르고, 권한을 다시 승인하세요. 확장이 실행 중이면 먼저 비활성화해야 업데이트할 수 있습니다.

### Moai 작업 보드 확장을 공식 목록에서 설치합니다

확장 관리의 공식 확장 목록에 `Moai 작업 보드 확장`(`buzzni.moai` 1.1.1)이 있습니다. 파일을 직접 고르지 않고 Desktop에 함께 배포된 공식 확장을 바로 설치할 수 있습니다. 1.1.0부터 Moai 보드는 머신 설정이 아니라 프로젝트 대화의 오른쪽 작업 패널 더보기 메뉴에서 열리고, 열면 그 프로젝트의 할 일을 진행 중 · 검토 · 할 일로 나눠 보여줍니다. 할 일을 누르면 같은 탭에서 상태·우선순위·담당자·본문·하위 항목·기록을 볼 수 있고, `← 목록으로`로 돌아갑니다. 머신에서 실행하기 전에 머신과 폴더를 보여주는 확인 창을 거치며, 목록·상세·상태는 앱을 켜 둔 동안 각각 한 번만 묻고 할 일 추가는 매번 묻습니다. 확인 창을 기다리는 동안에는 "시작하는 중… 확인 창이 떠 있으면 승인하세요"로 표시합니다. 프로젝트에 Moai 보드가 없으면 그 머신에서 `moai init`을 한 번 실행하라고 안내합니다.

#### 사용 방법

확장 관리에서 `Moai 작업 보드 확장`을 설치하고 `machine.run` 권한을 승인해 활성화하세요. 같은 화면의 **이 머신에 설치**로 머신에 Moai를 설치한 뒤, 프로젝트 대화의 오른쪽 작업 패널 더보기(⋮) 메뉴에서 `Moai`를 고르세요. macOS(Apple Silicon)와 Linux x64 머신을 지원합니다.

### Slack 답변에 에이전트가 만든 파일 첨부

Slack에서 봇을 멘션해 파일을 만들어 달라고 요청하면, 답변이 같은 스레드에 먼저 올라오고 에이전트가 만든 파일이 그 스레드에 첨부 파일로 이어서 올라옵니다. 세션이 다른 컴퓨터에서 실행 중이어도 되지만, 세션을 실행하는 컴퓨터가 macOS여야 합니다(Linux·Windows에서는 첨부하지 않고 안내만 보냅니다). Desktop 없이 동작하는 채널 호스트에서는 아직 파일을 첨부하지 않습니다. 프로젝트 폴더 밖의 파일, 숨김 파일, 키 파일(`.env`, `.git`, `.pem` 등)과 20MB를 넘는 파일은 보내지 않으며, 한 답변에 최대 5개까지 첨부합니다. 첨부하지 못한 파일이 있으면 몇 개인지 한 줄로 알려 줍니다.

#### 사용 방법

Slack에서 봇을 멘션해 "보고서를 CSV 파일로 만들어 줘"처럼 요청하세요. 이미 만든 Slack 앱은 `files:write` 권한을 추가한 뒤 워크스페이스에 다시 설치해야 합니다. 설정의 메신저 연결에서 새로 만드는 Slack 앱에는 이 권한이 처음부터 포함됩니다.

## 변경된 기능

### 기획모드와 작업모드의 전환 디자인 통일

프로젝트 상단의 기획모드·작업모드를 Chat·Project 전환과 같은 둥근 디자인으로 맞췄습니다. 회색 배경 안에서 선택한 항목이 흰색 표면과 은은한 그림자로 표시됩니다. 다크 테마에서도 테마에 맞는 색상을 사용하며, 미저장 기획 확인과 답변 중 전환 제한은 유지됩니다.

#### 사용 방법

프로젝트 상단에서 기획모드 또는 작업모드를 선택하세요. 방향키로 이동하고 Enter 또는 Space로 전환할 수도 있습니다.

### 모든 채팅 입력창에서 실행 컴퓨터 확인

새 Chat, 홈 기획, 대화 준비 중, 하위 대화와 AI 질문 답변 입력창에도 AI 사용량과 머신정보를 상세 화면과 동일하게 표시합니다. 왼쪽에서 AI 잔여량과 개발 설정을, 오른쪽에서 버전·CPU/메모리·머신명·연결 상태를 확인하며 입력창과의 간격도 줄였습니다. 기존 표시 설정을 따릅니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 사이드바 하단에서 사용자명 확인

사이드바 하단의 조직명 아래에 머신명 대신 로그인한 사용자명을 표시합니다. 작업PC 선택 메뉴의 머신명과 선택 상태는 유지됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 시작 준비 목록에서 컴퓨터·브라우저 제어 단계를 숨겼습니다

컴퓨터·브라우저 제어는 아직 검수 중인 기능이라 시작 준비 목록에서 보이지 않습니다. 이전에는 Windows에서만 숨겼지만 이제 모든 운영체제에서 숨깁니다. 진행 표시도 남은 단계 수에 맞게 줄어들고, 알림 단계에서 바로 첫 프로젝트를 추가할 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 알림이 떠도 대화 상단 위치 유지

작업 안내와 오류를 화면 위에 떠 있는 토스트로 표시하며, 알림이 나타나도 열린 대화 탭을 아래로 밀지 않습니다. 정체 판단의 이유는 해당 토스트 안에서 펼쳐 읽을 수 있고 읽는 동안 자동으로 닫히지 않습니다. 병렬 작업과 보관 그룹은 대화 더보기 메뉴에서 확인합니다.

#### 사용 방법

알림은 닫기 버튼으로 지울 수 있습니다. 병렬 작업은 프로젝트 대화 오른쪽의 더보기에서 `동시작업 그룹`을 열어 확인하세요.

### 작업물 모아보기 화면 정리

작업물 모아보기의 탭과 검색창, 목록 간격을 정리했습니다. 파일명과 출처를 나눠 보여주고 긴 경로는 말줄임으로 표시하며 전체 내용은 마우스를 올려 확인할 수 있습니다. 좁은 창에서도 목록을 스크롤하고 키보드로 범위를 바꿀 수 있습니다. 안내 문구와 전체 프로젝트 탭과 해당 조회 경로를 제거하고 화면의 산출물 표현을 작업물로 통일했습니다. 원본 읽기 미지원 PC에는 지원 안내를 표시합니다.

#### 사용 방법

파일 탐색에서 작업물 모아보기를 여세요. 기존 검색과 원본 파일 열기를 그대로 사용할 수 있습니다.

### 저장한 파일의 더보기 버튼 테두리 제거

파일 저장 후 표시되는 더보기 버튼의 테두리를 제거했습니다. 파일 열기·폴더에서 보기 버튼과 기존 메뉴 동작은 유지됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 조직 AI 계정이 없으면 시작준비의 AI 연결을 건너뛰기

조직에 등록된 AI 계정이 없을 때 시작준비가 더 이상 오류로 멈추지 않습니다. `조직 AI 계정이 없어요` 안내와 함께 `건너뛰기`를 보여 주며, 건너뛴 뒤에는 내 AI 계정을 연결해 바로 시작할 수 있습니다. 연결 실패·시간 초과 같은 실제 오류는 지금처럼 원인과 다시 연결을 표시합니다.

#### 사용 방법

시작준비의 AI 연결 단계에서 `건너뛰기`를 누르세요. 내 AI 계정이 연결되어 있지 않으면 개인 AI 계정 연결 안내가 이어서 열립니다. 조직 관리자가 AI 계정을 등록한 뒤에는 `다시 확인`을 눌러 조직 계정으로 연결할 수 있습니다.

### 프로젝트 설정 상단 제목 영역 정리

프로젝트 설정 창의 상단 아이콘과 중복 제목 영역을 제거해 메뉴와 본문을 위로 올렸습니다. 닫기 버튼과 각 설정 페이지 제목은 유지됩니다.

#### 사용 방법

프로젝트의 설정 아이콘을 눌러 확인하세요. 별도 설정 없이 자동 적용됩니다.

### Codex 모델 혼잡 시 잠시 기다렸다 다시 시도해요

Chat과 Project에서 현재 Codex 모델의 일시적인 혼잡으로 실패하면 카운트다운 뒤 최대 3회 다시 시도합니다. 기다리는 동안 취소할 수 있으며, 기존 대화를 열 때는 자동으로 요청을 보내지 않습니다. 비활성·오프라인 중 발생한 오류는 복귀해도 수동으로 다시 시도하며, 작업 중단 후 자동으로 재개하지 않습니다. 오류 이후 작업까지 확인해 중단 지점에서 이어가도록 요청하고, 정상 답변이 도착하면 이전 오류의 재시도를 취소합니다. 전송 확인이 실패하면 안내를 유지하고, 다른 대화의 진행 중인 재시도와 상태를 분리합니다.

#### 사용 방법

별도 설정 없이 적용됩니다. 카운트다운 옆 ‘취소’를 누르면 중단합니다. 재시도가 끝나면 ‘다시 시도’를 누르거나 입력창에서 다른 모델을 선택하세요.

### PC 공유 설정 버튼 강조

작업PC 설정과 함께 작업 화면의 PC 공유 설정 버튼을 파란색으로 통일해 찾기 쉽게 했습니다.

#### 사용 방법

작업PC 설정 또는 프로젝트의 함께 작업 화면에서 파란 PC 공유 설정 버튼을 누르세요.

### PC 공유 설정에 표준 모달 디자인 적용

PC 공유 설정 창의 제목·본문·버튼 간격과 닫기 버튼 위치를 표준 모달 디자인에 맞췄습니다. 공유 사용자 선택과 오류 후 다시 확인도 같은 창에서 이용할 수 있습니다.

#### 사용 방법

작업PC 설정 또는 프로젝트의 함께 작업 화면에서 PC 공유 설정을 여세요. 별도 설정 없이 자동 적용됩니다.

## 수정된 문제

### 같은 작업PC의 다른 실행기 때문에 Claude 대화가 시작되지 않던 문제를 고쳤습니다

앱에 들어가는 Happy 실행기를 1.1.10-aplus.319로 올렸습니다. 한 작업PC의 같은 사용자 계정에서 실행기가 둘 이상 돌 때, 다른 실행기가 받은 조직 Claude 계정 배정 기록 때문에 이 실행기의 Claude 대화가 모두 "계정 선택 필요" 오류로 시작되지 않던 문제를 고쳤습니다. 이제 각 실행기는 자기가 적용한 배정만 보고 판단합니다. Codex 대화는 원래 영향이 없었습니다.

#### 사용 방법

사용자 조작은 없습니다. 앱을 업데이트하면 적용됩니다.

### 결과물 공개 링크가 미리보기와 같은 작업 폴더를 찾도록 수정

대화가 다른 작업트리로 옮겨 간 뒤에는 미리보기에서 잘 보이던 결과물도 공개 링크를 만들 때 "파일을 찾을 수 없습니다"로 실패할 수 있었습니다. 이제 공개 링크는 미리보기가 파일을 읽는 작업트리에서 파일을 찾습니다. 그래도 파일을 찾지 못하면 어느 작업 폴더를 찾았는지 알려 줍니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 기획 대화 준비 화면의 중복 제목 제거

기획 대화로 프로젝트를 만든 뒤 대화를 준비하는 화면에서 불필요한 ‘새 대화’ 제목을 제거했습니다. 첫 질문과 준비 상태, 실패 시 다시 시도는 그대로 제공됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 업데이트 설치 중에 앱을 다시 열어도 "업데이트 실패"가 뜨지 않음

macOS에서 `재시작해서 업데이트`를 누른 뒤 설치가 끝나기 전에 Saycode를 다시 열면, 아직 바뀌지 않은 이전 버전이 열려 "업데이트가 적용되지 않았습니다" 경고가 떴습니다. 이제 그 사이에 앱을 열면 "업데이트를 설치하고 있어요" 창이 뜨고, 설치가 끝나는 즉시 새 버전으로 다시 열립니다. 2분이 지나도 설치가 끝나지 않으면 현재 버전으로 열지, 종료할지 고를 수 있습니다. 업데이트 안내의 재시작 설명에도 설치 후 자동으로 다시 열린다는 내용을 추가했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 재시작 후에는 앱이 스스로 다시 열릴 때까지 기다리면 됩니다.

### 예전에 등록한 작업PC도 그대로 조직 AI에 연결돼요

기기 연결 기능이 생기기 전(2026년 10월 초 이전)에 등록한 조직 작업PC에서는 조직 AI 연결이 `AI_GROUP_CUSTOMER_KEY_REQUIRED`(암호화 키 준비)에서 멈추고, "다시 연결"을 눌러도 풀리지 않았어요. 이제 시작준비가 같은 PC 정보 그대로 이 컴퓨터를 연결하고 이어서 AI 연결을 확인해요.

- 프로젝트와 대화 기록은 원래 PC에 그대로 남아요.
- 조직 키를 아직 받지 못했으면 PC를 다시 등록하지 않고 조직 키 배포를 기다리는 안내를 보여 줘요.
- 이 PC를 이어서 쓸 수 없으면 "다시 연결" 대신 원인과 다음 조치를 알려 줘요. 고른 조직이 맞는지 확인하거나, 조직 관리자에게 PC 배정 확인이나 새 등록을 요청하라고 안내해요.

#### 사용 방법

따로 할 일은 없어요. 시작준비에서 이 컴퓨터 준비가 끝난 뒤 다음을 누르면 자동으로 이어져요.

### 예전에 설치한 Codex가 깨져 있어도 시작준비가 고쳐서 진행해요

Mac에 예전에 직접 설치한 Codex(예: nvm으로 설치)가 깨져 있으면, 시작준비가 `AI_TOOL_INSTALL_FAILED`(실패 도구: codex)로 멈추고 "다시 시도"를 눌러도 같은 오류가 반복됐어요. Saycode가 Codex를 따로 설치해도 확인과 대화 실행에서는 PATH에 먼저 있는 깨진 Codex가 쓰였기 때문이에요. 이제 깨진 Codex가 있던 그 위치에 다시 설치해서 고친 뒤 이어서 진행해요.

#### 사용 방법

따로 할 일은 없어요. 시작준비에서 AI 도구 설치가 자동으로 이어져요.

### 작업물 모아보기에서 영상·음성 파일 누락 수정

답변에 표시된 MP4 등 영상·음성 작업물이 작업물 모아보기에서 빠지던 문제를 수정했습니다. 폴더 없이 파일명만 전달된 경우에도 원래 대화의 파일을 찾고 열 수 있습니다.

#### 사용 방법

파일 패널의 작업물 모아보기에서 이 대화·이 프로젝트·전체 프로젝트를 선택하거나 파일명으로 검색하세요.

### 작업물 모아보기와 파일 패널 배치 개선

작업물 모아보기 창을 표준 모달 디자인에 맞췄습니다. 닫기 버튼 위치와 여백을 정돈하고, 선택한 범위와 검색 포커스를 파란색으로 표시합니다. 파일 패널에서는 모아보기 버튼과 파일 메뉴가 겹치지 않도록 검색창 옆에 메뉴 공간을 확보했습니다.

#### 사용 방법

파일 탭에서 작업물 모아보기를 열면 자동 적용됩니다.

### 조직 초대 오류 안내와 재로그인 개선

초대 목록을 읽지 못했을 때 새 초대가 있다고 안내하던 문제를 수정했습니다. 확인이 필요한 상태와 실제 받은 초대를 구분합니다. 관리자 초대 수락 후 재로그인이 필요하면 로그인 화면으로 바로 연결합니다.

#### 사용 방법

`조직 초대 확인 필요 · 다시 확인`을 누르고 열린 창에서 `다시 확인`으로 목록을 다시 조회하세요.
관리자 초대 수락 후 재로그인 안내가 나타나면 열린 로그인 화면에서 다시 로그인하세요.

### 파일 패널 목록 스크롤 복구

파일 목록이 패널 높이를 벗어나 잘리고 스크롤되지 않던 문제를 수정했습니다. 일반 목록과 파일이 많은 폴더에서 마지막 항목까지 이동할 수 있습니다.

#### 사용 방법

파일 패널에서 휠이나 트랙패드로 목록을 스크롤하세요. 별도 설정 없이 적용됩니다.

### 파일이 많은 프로젝트의 파일 탐색 속도 개선

파일이 많은 프로젝트에서 화면에 보이는 목록부터 표시하고 폴더 조회를 나누어 처리합니다. 파일 링크 확인이 필요 없는 대화의 자동 파일 탐색을 줄입니다. 파일 열기·검색·다운로드와 이름 변경은 그대로 사용할 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 프롬프트 검색창의 입력 포커스 유지

채팅 입력창의 추가 옵션에서 프롬프트 검색을 열 때 메뉴가 닫히면서 검색창의 입력 포커스를 가져가던 문제를 수정했습니다. 메뉴를 Escape로 닫을 때의 버튼 포커스 복귀는 유지됩니다.

#### 사용 방법

입력창의 추가 옵션에서 프롬프트 검색을 열면 바로 검색어를 입력할 수 있습니다.

### 회사 프록시가 도구 설치를 막으면 시작 준비 오류에 그 원인을 표시

시작 준비에서 회사 프록시가 도구 다운로드를 막아 실패하면, "정확한 원인은 아직 확인되지 않았어요" 대신 실제 원인을 보여 줍니다.

- 프록시가 Windows 로그인 인증을 요구하면 "회사 프록시가 로그인 인증을 요구해 연결하지 못했어요"로, 프록시가 연결을 허용하지 않으면 "회사 프록시가 다운로드나 패키지 서버 연결을 허용하지 않았어요"로 표시합니다. IT 담당자에게 무엇을 요청하면 되는지도 함께 안내합니다.
- 진단 정보에는 막힌 공개 다운로드 서버 이름(예: files.pythonhosted.org)과 HTTP 상태가 남습니다. 그대로 IT 담당자에게 전달할 수 있습니다. 계정·토큰·개인 경로는 여전히 포함하지 않습니다.
- 프록시가 연결을 끊거나 거부한 경우와 앱 다운로드의 연결 오류는 시작 준비 화면에서 네트워크 오류로 표시합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 시작 준비에서 실패한 도구의 오류 상세를 열면 확인할 수 있습니다.

### 회사 프록시가 막아도 Windows에서 claude-swap이 설치되도록 수정

회사 프록시를 거쳐야 하는 Windows PC에서 claude-swap 설치가 `패키지 설치·반영` 단계에서 실패하던 문제를 고쳤습니다. 0.1.66부터 uv도 회사 프록시를 쓰지만, Windows 로그인 계정으로 인증하는 프록시처럼 uv의 접속만 거절하는 회사망이 있었습니다.

- claude-swap에 필요한 패키지 파일 17개(약 3MB)를 앱이 직접 받습니다. 앱의 다운로드는 시스템 프록시와 Windows 로그인 인증을 그대로 따릅니다.
- 받은 파일은 고정한 SHA-256과 일치할 때만 쓰고, uv는 인터넷에 접속하지 않고 그 파일로만 설치합니다.
- 파일을 받지 못하면 오류 화면에 claude-swap 패키지 준비(명령 `cswap`)의 다운로드 단계로 표시됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 시작 준비에서 다시 시도를 누르면 됩니다.

### AI 사용량에서 직접 고른 Claude 계정이 유지되고 자동 계정 순환을 켜고 끌 수 있습니다

Claude 계정 자동 순환이 켜진 PC에서는 AI 사용량 창에서 계정을 직접 골라도 잠시 뒤 다른 계정으로 되돌아갔습니다. 이제 계정을 직접 고르면 자동 순환을 먼저 끄고 고른 계정으로 바꾸며, 순환이 꺼졌다는 안내가 같은 창에 보입니다. 같은 창에 `자동 계정 순환` 스위치가 생겨 언제든 다시 켤 수 있습니다. 자동 순환을 끄지 못하면 계정을 바꾸지 않고, 계정 전환에 실패하면 자동 순환을 다시 켠 뒤 다시 시도하라는 안내를 보여 줍니다.

#### 사용 방법

입력창 아래 AI 사용량을 눌러 Claude 계정 목록을 엽니다. 계정 목록 위의 `자동 계정 순환` 스위치로 켜고 끌 수 있습니다. 선택할 수 있는 개인 Claude 계정이 두 개 이상인 PC에만 표시됩니다.

### Slack 첨부 답변의 대기와 과부하 처리 수정

첨부 요청이 몰려도 먼저 처리 중인 답변의 파일이 누락되지 않습니다. 파일을 읽고 올리는 작업 수를 제한하고, 대기 한도를 넘은 첨부는 실패 안내로 알려줍니다. 텍스트 답변은 계속 먼저 전달됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### Windows 시작 준비 다운로드가 멈췄을 때 다시 시도할 수 있어요

Windows 시작 준비에서 claude-swap 설치 파일 다운로드가 멈추면 10분 제한 시간 안에 설치 실패를 알립니다. 이후 다른 AI 도구 설치가 계속 진행되고, 실패한 설치를 다시 시도할 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 다운로드 시간 초과가 표시되면 네트워크 연결을 확인한 뒤 다시 시도하세요.
