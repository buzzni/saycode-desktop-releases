## 새 기능

### 개인 머신·다중 포트 포워딩

개인 원격 머신에서도 올바른 인증으로 localhost 포트 포워딩을 열 수 있고, 한 프로젝트의 여러 개발 서버 포트를 동시에 유지할 수 있습니다.

#### 사용 방법

프로젝트 미리보기의 로컬 포트 목록에서 필요한 서버 포트를 각각 연결합니다. 활성 터널은 주소별로 열거나 개별 중지할 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/545)

### 대화 목록에서 제목과 프롬프트 검색

프로젝트의 대화 목록에서 대화 제목을 즉시 검색할 수 있습니다. 대화 검색이 활성화된 환경에서는 사용자 프롬프트 내용도 함께 찾아 제목 일치 결과와 통합해 보여줍니다.

#### 사용 방법

프로젝트의 대화 목록 탭을 열고 상단 검색창에 대화 제목이나 이전에 입력한 프롬프트를 입력합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/553)

### 대화창 안에서 이전 메시지 검색

열려 있는 프로젝트 대화에서 사용자 메시지, 에이전트 답변, 도구 실행 결과의 키워드를 검색할 수 있습니다. 현재 화면에 일치 항목이 없으면 필요한 이전 대화만 순서대로 불러오고 첫 결과에서 멈춥니다.

#### 사용 방법

프로젝트 대화 상단의 검색창에 키워드를 입력합니다. 더 오래된 결과가 필요하면 "더 이전에서 검색"을 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/556)

### 보드에서 여러 세션에 같은 지시를 한 번에 보낼 수 있습니다

Agent Board에서 카드를 여러 장 골라 같은 지시를 한 번에 보낼 수 있습니다. 지금까지는 세션마다 카드를 하나씩 옮겨 지시해야 했습니다.

#### 사용 방법

Agent Board에서 Cmd(또는 Ctrl)나 Shift를 누른 채로 카드를 클릭하면 선택됩니다. 카드 위쪽에 나타나는 "일괄 지시" 버튼을 누르고 보낼 내용을 입력한 뒤 전송하세요. 수식키 없이 그냥 클릭하면 지금처럼 카드 미리보기가 열리고, 카드를 끌어 옮기는 동작도 그대로입니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/559)

### 새 대화 실행 옵션을 프로필로 저장하고 원클릭 적용

자주 쓰는 실행 옵션 조합(에이전트·모델·강도·작업 사본 사용 여부)을 이름 붙여 프로필로 저장해 두고, 새 대화 화면에서 한 번에 적용할 수 있습니다. 프로필을 적용한 뒤 옵션을 직접 바꾸면 "수정됨"으로 표시되어, 저장해 둔 조합과 다른 상태로 대화가 시작되는 일을 막습니다. 저장된 프로필은 로그아웃하거나 앱을 다시 켜도 남아 있고, 프로필에 담긴 모델이나 에이전트를 지금 쓸 수 없으면 그 항목만 기본값으로 바꾸고 이유를 알려 줍니다.

#### 사용 방법

새 대화 화면의 실행 옵션 줄에서 원하는 조합을 고른 뒤 "현재 조합 저장"을 눌러 이름을 붙입니다. 다음부터는 같은 줄의 프로필 목록에서 골라 한 번에 적용합니다. 이미 있는 이름으로 저장하면 그 프로필이 새 조합으로 갱신됩니다. 이름 변경과 삭제는 "프로필 관리"에서 합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/530)

#### 사용 방법

프로젝트의 새 대화에서 평소처럼 메시지를 보내면 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/551)

### 업데이트 후 첫 실행에서 새 소식을 한 번 보여주고, 메뉴에서 다시 볼 수 있습니다

업데이트를 받아 새 버전으로 처음 실행하면 그 버전의 릴리스 노트가 한 번 표시됩니다. 같은 버전을 다시 실행할 때는 뜨지 않습니다. 같은 버전이라도 내용이 수정된 노트가 배포되면 다시 한 번 표시됩니다.

#### 사용 방법

업데이트 후 첫 실행에서는 자동으로 표시됩니다. 다시 보려면 상단 메뉴에서 Help → Release Notes를 선택하세요. 새로 설치한 직후에는 아직 받아 둔 노트가 없어 비어 있고, 앱이 업데이트를 한 번 확인한 뒤(설치된 버전이 최신이어도 됩니다) 다음 실행부터 표시됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/559)

### 오토파일럿이 멈춘 이유와 응답 지연 판단 근거를 확인할 수 있습니다

오토파일럿이 중단(blocked)됐을 때, 그리고 응답이 지연되고 있다는 알림이 떴을 때 그 판단의 근거를 볼 수 있습니다. 지금까지는 "왜 여기서 멈췄지?"를 확인할 방법이 없어 판단이 틀린 것 같아도 확인할 수가 없었습니다.

#### 사용 방법

Agent Board에서 중단된 오토파일럿 배지 아래의 "왜?"를 누르면 펼쳐집니다. 응답 지연 알림에서도 알림 아래의 "왜?"를 누르면 같은 방식으로 볼 수 있습니다. 이 기능이 추가되기 전에 중단된 기록에는 근거가 없어 "왜?"가 표시되지 않습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/559)

### 창 제목이 열려 있는 세션과 대기 중인 작업 수를 알려줍니다

지금까지 모든 창의 제목이 "Saycode"로 같아서 macOS 창 전환기(Cmd+Tab 후 Cmd+`)나 독 아이콘 우클릭 목록에서 어떤 창이 어떤 작업인지 구분할 수 없었습니다. 이제 창 제목이 `프로젝트 이름 — 세션 제목` 형태로 바뀌어, 창을 열지 않고도 무엇이 열려 있는지 알 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 독 아이콘을 우클릭하거나 macOS 창 전환기를 열면 바뀐 제목을 볼 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/559)

### 환경변수를 .env 형식으로 한 번에 편집

프로젝트 환경변수 화면에서 `.env` 내용을 한 번에 붙여넣거나 수정할 수 있습니다. 모노레포는 프로젝트 하위 폴더를 여러 개 등록해 각 폴더에 독립된 `.env` 값을 저장하고 동기화할 수 있습니다. 전체 값은 기본적으로 접혀 있어 명시적으로 펼치기 전에는 평문으로 표시되지 않습니다.

#### 사용 방법

프로젝트 설정의 환경변수 탭에서 "전체 .env 내용 보기"를 누른 뒤 기존 `.env` 내용을 붙여넣습니다. 폴더별 값이 필요하면 "하위 폴더 추가"를 눌러 `apps/api` 같은 프로젝트 상대 경로와 해당 폴더의 `.env` 내용을 입력한 다음 저장합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/549)

## 수정된 문제

### 로컬 전용 모드 설치 오류 진단 개선

로컬 전용 모드에 필요한 런타임이 빠졌거나 다른 CPU용 파일이 포함된 설치본은 배포 전에 차단됩니다. 설치본에서 런타임을 찾지 못하면 실행 중인 앱의 버전과 경로를 함께 표시해 이전 앱 복사본이나 손상된 설치를 구분할 수 있습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 오류가 표시되면 안내된 앱 경로를 확인하고 최신 Saycode를 다시 설치합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/547)

### 세션 누적 토큰 사용량 실제 표시

대화 헤더의 누적 토큰 사용량이 실제 값을 받지 못해 항상 비어 있던 문제를 수정했습니다. 이제 답변이 오갈 때마다 사용량이 갱신되어 세션 누적 토큰을 확인할 수 있습니다.

#### 사용 방법

대화를 열고 답변을 한 번 이상 받은 뒤, 대화 헤더 오른쪽의 누적 토큰 표시를 확인합니다. 마우스를 올리면 입력·출력·캐시별 상세 값을 볼 수 있습니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/550)

### 입력 중에도 컴포저 위치가 흔들리지 않습니다

사용량이 한도 경고 상태일 때 컴포저에 표시되는 "추천 질문을 만들지 않습니다" 안내가 입력을 시작하는 순간 사라지면서 대화창이 위로 튀던 문제를 고쳤습니다. 이제 안내는 입력 중이거나 에이전트가 응답 중일 때도 그대로 유지되고, 한도 경고가 풀리면 사라집니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/539)

### 프리뷰에서 화면과 백엔드 연결이 함께 안정화됩니다

원격 프리뷰가 독립된 전용 주소에서 열리고, 프론트엔드의 백엔드 요청은 같은 프리뷰 주소를 통해 전달됩니다. 프리뷰 메뉴는 보이지만 기능 호출이 실패하거나, 로컬 포트 포워딩에서 브라우저가 잘못된 백엔드 `localhost`를 호출하던 문제를 줄였습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 자체 호스팅 관리자는 서버 환경에 맞는 preview routing mode를 설정해야 합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/557)
