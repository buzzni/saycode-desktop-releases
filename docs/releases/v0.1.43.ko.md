## 수정된 문제

### 샌드박스 안의 Git 작업 경로 개선

일반 세션의 Git 설정 허용을 명시하고, 관리형 작업 사본에서 프로젝트의 공유 Git 메타데이터 경로를 전달합니다. 프로젝트 샌드박스를 명시적으로 끈 설정도 daemon에 전달합니다. 체크포인트 보호와 명시적인 Git 설정 제한은 유지합니다.

#### 사용 방법

Happy runtime 1.1.10-aplus.191이 포함된 Desktop으로 업데이트한 후 새 세션에서 적용됩니다. 기존 실행 프로세스의 샌드박스는 바뀌지 않습니다. 기본 Git hook 샘플은 복사하지 않으며, 프로젝트 환경변수로 지정한 Git 템플릿은 유지합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/921)

### 자식 세션 설정과 worktree 원장 권한을 보완합니다

프로젝트 내부에서 앱이 채택한 worktree에도 자식 생성 원장 쓰기 권한을 적용합니다.

#### 사용 방법

업데이트 후 새로 시작한 세션부터 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/927)
