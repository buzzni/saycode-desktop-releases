## 변경된 기능

### 배포 점검 실패 시 배포를 실패로 처리

배포 후 동작 점검이 실패했을 때 성공으로 넘어가지 않고 실패로 처리합니다. 실제로는 뜨지 않은 배포가 성공으로 보고되지 않습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/367)

### 클라우드 프로젝트 고정을 계정과 동기화

클라우드로 로그인한 경우 프로젝트 고정(즐겨찾기)이 이 컴퓨터에만 저장되지 않고 계정에 저장됩니다. 다른 기기에서 로그인해도 같은 고정 목록을 볼 수 있습니다. 로컬 전용 프로젝트의 고정과 대화 고정은 기존처럼 이 컴퓨터에만 저장됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 프로젝트 목록에서 고정하면 계정에 반영됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/364)

## 수정된 문제

### 공유 머신에서 커넥터와 MCP 설정이 빠지던 문제

공유 머신에서 세션을 시작하면 커넥터뿐 아니라 회사·프로젝트 MCP 설정까지 함께 빠지던 문제를 수정했습니다. 앱이 사용하던 연결 방식이 서버에 실제로 존재하지 않는 경로였고, 최신 머신 런타임은 앱이 넘기던 설정 값을 제거하도록 바뀌어 있었습니다. 웹에서 쓰는 것과 같은 방식으로 교체했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/369)

### 공유 머신의 Gmail 커넥터가 사용자별로 분리

공유 머신에서 커넥터의 주체가 실제 세션 사용자가 아니라 그 머신을 처음 등록한 사람으로 잡혀, 다른 사용자도 같은 Gmail 연결을 받게 되던 문제를 수정했습니다. 이제 세션을 시작한 사용자 본인의 연결만 전달됩니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/365)

### 자동화 설정 화면의 버튼 모양이 깨져 보이던 문제

프로젝트 설정의 자동화와 GitHub 트리거 섹션에서 버튼에 테두리와 높이가 적용되지 않아 카드 폭 전체로 늘어나 보이던 문제를 수정했습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/368)

### 정상 진행 중인 대화가 계속 상위 모델에 고정되던 문제

한 번 어려운 요청으로 상위 모델에 올라간 세션이, 이후 쉬운 후속 요청에도 계속 그 모델에 고정되어 있던 문제를 수정했습니다. 대화를 계속하는 한 원래대로 돌아오지 못하는 구조였고, 잘 해결됐다는 사용자의 명시적 반응도 반영되지 않았습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/363)

## 업데이트 시 주의사항

### 공유 머신은 최신 런타임으로 올려야 커넥터가 동작합니다

커넥터 연결 방식이 바뀌면서, 오래된 런타임이 설치된 공유 머신에서는 커넥터가 붙지 않습니다. 이 경우 커넥터 없이 조용히 세션이 만들어지지 않고 업그레이드가 필요하다는 오류로 알려줍니다.

#### 사용 방법

공유 머신에서 커넥터 관련 오류가 보이면 그 머신의 Saycode 런타임을 최신으로 업데이트하세요.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/369)
