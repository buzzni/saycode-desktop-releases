## 새 기능

### 프로젝트 함께 작업

프로젝트에 다른 사람을 초대해 함께 작업할 수 있습니다. 회사 구성원을 여러 명 선택하거나 개인 사용자 이름으로 초대할 수 있고, 참여자 목록 확인과 제거도 지원합니다. 초대받은 사람은 기존과 같은 방식으로 그 프로젝트의 대화를 사용합니다.

#### 사용 방법

프로젝트 헤더의 함께 작업을 눌러 멤버 관리 창을 엽니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/462)

## 수정된 문제

### 알림함이 계정별로 분리

여러 계정을 쓸 때 완료 알림이 계정 구분 없이 섞여 보일 수 있던 문제를 수정했습니다. 이제 알림함과 Dock 배지가 로그인한 계정별로 분리되고, 다른 계정의 알림에는 접근할 수 없습니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/460)

### Git 프로젝트를 선택한 머신에 직접 복제

Git 저장소로 프로젝트를 만들 때 선택한 프로젝트 머신에 바로 복제하도록 수정했습니다. 복제에 사용한 개인 액세스 토큰은 저장소 설정에서 제거하고 오류 메시지에서도 가립니다.

#### 사용 방법

새 프로젝트의 Git 탭에서 저장소와 머신을 선택합니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/461)

## 업데이트 시 주의사항

### 업데이트 시 기존 알림 기록이 초기화됩니다

이전 형식으로 저장된 알림 기록에는 어느 계정의 것인지 정보가 없어, 여러 계정의 알림이 섞여 있을 수 있습니다. 이를 현재 계정의 것으로 잘못 귀속시키지 않기 위해 업데이트 후 첫 실행에서 폐기합니다.

#### 사용 방법

별도 조작은 필요 없습니다. 업데이트 후 알림함이 비어 있는 상태에서 시작하며 이후 알림부터 정상 누적됩니다.

관련 변경: [PR 링크](https://github.com/buzzni/aplus-dev-studio-desktop/pull/460)
