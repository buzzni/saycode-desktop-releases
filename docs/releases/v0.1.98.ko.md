## 새 기능

### 봇 탭에서 예약을 보고 봇에게 예약을 부탁합니다 (실험)

봇 탭 할 일 목록 아래에 **예약** 묶음이 생겼습니다. 봇 프로젝트에 만든 예약 실행이 얼마나 자주 도는지와 다음 실행 시각으로 보이고, 줄에서 바로 일시정지·다시 켜기·지금 실행을 할 수 있습니다(지금 실행은 서버에서 예약을 실행하는 작업PC에서만). **예약 부탁하기**에 "평일 오전 9시에 새 문의 정리해 줘"처럼 적어 보내면 봇의 Home 대화로 부탁이 가고, 봇이 그 대화에 예약을 만든 뒤 무엇을 언제 실행할지 한 줄로 알려 줍니다. 예약 실행 결과는 Home 대화에 쌓이고, 새로운 일이 없으면 봇이 한 줄로 끝냅니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켜고 봇 탭을 엽니다. 목록 아래 **예약**의 **예약 부탁하기**에 반복할 일을 적고 **부탁하기**를 누릅니다.

### 열린 대화 탭을 단축키로 좌우 이동

VS Code·터미널처럼 macOS에서는 Cmd+Shift+[ / ], Windows에서는 Ctrl+PageUp / Ctrl+PageDown으로 열린 대화 탭을 왼쪽·오른쪽으로 옮겨 다닐 수 있습니다. 기존 Ctrl+Tab·Ctrl+Shift+Tab도 그대로 쓸 수 있습니다.

이미 같은 키를 다른 동작에 지정해 두었다면 그 지정을 유지하고 새 동작은 미지정으로 남습니다.

#### 사용 방법

대화 탭이 둘 이상 열린 Project 또는 Chat에서 Cmd+Shift+[ / ](Windows는 Ctrl+PageUp / Ctrl+PageDown)를 누르세요. 끝에서는 반대쪽 끝 탭으로 이동합니다. 키는 내 설정 → 일반 → 단축키의 "왼쪽 대화 탭"·"오른쪽 대화 탭"에서 바꿀 수 있습니다.

### 작업PC 저장공간이 부족하면 대화 입력창에서 안내

작업PC의 홈 폴더가 있는 디스크를 95% 이상 사용하면 프로젝트 대화와 Chat의 입력창 위에 저장공간 경고와 남은 공간을 표시합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 안내 오른쪽의 X를 누르면 이번 부족 상태의 경고를 닫을 수 있습니다.

### Windows 검색에서 작업 폴더를 뺄 수 있습니다

AI가 작업하면서 작업 폴더의 파일을 많이 바꾸면 Windows 검색 색인이 CPU를 계속 써서 PC가 느려지거나 팬이 돌 수 있습니다. 이제 작업PC 설정에서 이 PC의 Saycode 작업 폴더를 Windows 검색 색인에서 뺄 수 있습니다. 켜도 Saycode 안의 검색은 그대로이고, 작업 폴더 안 파일만 시작 메뉴와 파일 탐색기 검색에 나오지 않습니다. 끄면 Windows 기본 색인으로 돌아갑니다. 관리자 권한은 필요하지 않습니다.

#### 사용 방법

내 설정 → 개발 → 작업PC에서 Windows 검색 색인 카드의 "Windows 검색에서 작업 폴더 제외"를 켭니다. Windows에서만 보입니다.

## 변경된 기능

### 개인 AI 계정 연결 화면 정리

개인 AI 계정 연결 첫 화면에서는 `내 AI 계정 연결`을 누르고, 다음 화면에서 ChatGPT나 Claude를 고를 수 있어요. 브라우저 로그인을 다시 열려면 대기 화면에서 `연결`을 누르세요.

#### 사용 방법

연결을 미루려면 오른쪽 위 `닫기` 또는 Esc를 누르세요. 무료 모델은 내 설정 → AI Models → opencode 더보기 → `설치하기`에서 시작할 수 있어요.

### 다른 사람이 등록한 오프라인 작업PC 숨김

‘다른 작업PC’에서 다른 사람이 등록한 것으로 확인된 오프라인 작업PC를 숨겨요. 내가 등록했거나 소유자를 확인할 수 없는 작업PC는 오프라인 상태에서도 볼 수 있어요.

#### 사용 방법

내 설정 → 개발 → 작업PC를 열면 자동으로 적용돼요.

### 봇 줄 호버 카드가 나를 기다리는 할 일도 이름과 이유로 보여 줍니다 (실험)

사이드바 봇 줄에 마우스를 올리면 나오는 카드에 입력을 기다리는 대화뿐 아니라 나를 기다리는 할 일도 최대 3개까지 번호·제목과 이유("질문에 답 필요", "작업트리 대화 요청" 등)로 보입니다. 할 일을 누르면 봇 탭이 그 할 일 상세로 바로 열립니다. 대화가 권한 요청으로 질문·계획 확인·폴더 접근을 물을 때도 이제 "권한 필요" 대신 그 이유가 그대로 보입니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켜고 사이드바 봇 줄에 마우스를 올립니다.

### 봇의 질문 중 답한 것만 먼저 보낼 수 있습니다 (실험)

봇이 한 할 일에 질문을 여러 개 남겼을 때 모두 답하지 않아도 **답한 것만 보내기 (2/3)**처럼 고른 답만 먼저 보낼 수 있습니다. 답하지 않은 질문은 할 일에 그대로 남습니다. 봇은 이제 질문을 쉬운 말로 한 줄씩 쓰고, 파일 이름이나 코드 대신 무엇인지 설명하며, 추천하는 선택지를 표시합니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켜고 봇 탭에서 질문이 있는 할 일을 엽니다. 일부 질문에 답한 뒤 **답한 것만 보내기**를 누릅니다.

### 봇이 코드 작업을 작업트리 대화로 시작하거나 요청합니다 (실험)

봇이 코드를 고쳐야 하면 봇 폴더 원본을 건드리지 않고 작업트리 대화를 직접 시작해 할 일에 연결합니다. 봇 폴더에 커밋하지 않은 파일이 있어 직접 시작할 수 없으면, 그 할 일을 **나에게 요청**으로 옮기고 작업트리 대화를 요청합니다. 이때 할 일 상세에 "봇이 작업트리 대화를 요청했어요"가 보이고 **작업트리에서 맡기기**가 주 버튼이 되어 한 번에 시작할 수 있습니다. 할 일 상세에는 연결된 대화가 응답 중인지, 나를 기다리는지와 그 대화의 PR(번호·상태)도 보이며, PR을 누르면 브라우저에서 열립니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켜고 봇 탭에서 할 일을 엽니다. 봇이 요청한 할 일은 **작업트리에서 맡기기**를 누릅니다.

### 봇이 필요한 연결을 버튼으로 안내합니다 (실험)

봇이 하는 일에 아직 연결하지 않은 서비스(메일, Slack, 드라이브 등)가 필요하면, 메뉴 위치를 길게 설명하는 대신 어떤 연결이 왜 필요한지 한 줄로 말하고 그 아래에 커넥터 설정을 여는 버튼을 붙입니다. 버튼을 누르면 내 설정의 커넥터 화면이 열립니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 봇 대화에 연결 버튼이 보이면 눌러서 연결합니다.

### 봇이 할 일 파일을 조금 틀리게 써도 앱이 고쳐 읽습니다 (실험)

봇(AI)이 할 일 파일의 번호를 글자로 쓰거나, 상태를 "todo"·"completed"처럼 다른 낱말로 쓰거나, 시각을 빠뜨려도 이제 봇 탭과 사이드바가 그 할 일을 읽습니다. 봇 탭을 열어 두면 고친 내용을 파일에 한 번 저장하고, 할 일 활동에 "앱이 파일 형식을 고쳤어요"를 남깁니다. 앱이 고칠 수 없는 파일은 봇 탭 아래에 파일 이름과 이유가 보이고, **봇에게 고쳐 달라고 하기**를 누르면 봇의 Home 대화로 고칠 파일과 이유를 보냅니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켜고 봇 탭을 엽니다. 읽을 수 없는 파일이 있으면 목록 아래 안내의 **봇에게 고쳐 달라고 하기**를 누릅니다.

### 새 대화에서 ChatGPT·Claude 연결과 모델 선택

새 대화의 AI 계정 탭에 ChatGPT와 Claude 메뉴가 표시됩니다. 연결된 AI의 하위 메뉴에는 모델이 표시됩니다. 연결 전인 AI는 이 컴퓨터에서 개인 계정을 연결할 수 있을 때 `연결하기`를 표시합니다.

#### 사용 방법

새 대화 입력창에서 `AI도구` → `AI 계정` → `ChatGPT` 또는 `Claude`를 엽니다. 모델을 선택하거나, 이 컴퓨터에서 `연결하기`를 눌러 해당 AI의 연결 창을 엽니다.

### 새 봇의 첫 대화가 짧아집니다 (실험)

새 봇을 만들면 봇이 긴 보고 대신 한 문장 인사와 질문 하나로 먼저 말을 겁니다(예: "어느 메일함이나 채널의 문의를 볼까요?"). 답하면 바로 작은 일 하나를 하고, 기억에 무엇을 저장했는지 한 줄로 알려 줍니다. 앱이 봇에게 보내는 설정 문구는 이제 내가 쓴 메시지처럼 보이지 않고 **봇 설정 메시지** 한 줄로 접혀 있으며, 눌러서 펼칠 수 있습니다. 새 봇 창의 템플릿 설명에는 봇이 처음 물어볼 **첫 질문**이 함께 보입니다.

#### 사용 방법

개발자 기능 설정에서 **봇 보이기 (실험)**를 켜고 봇 섹션의 **+** → **새 봇…**으로 봇을 만듭니다.

### 외부 연동의 AI 계정 연결 버튼 간소화

외부 연동에서 이 컴퓨터에 로그인된 Claude·ChatGPT 계정의 `Saycode에 다시 연결` 버튼을 `연결`로 바꿨어요.
ChatGPT 로그인 복원 안내에도 같은 버튼 이름을 표시해요.

#### 사용 방법

외부 연동의 AI 계정에서 Claude 또는 ChatGPT 옆의 연결을 누르세요.

### 이전·다음 대화 이동 기본 키를 Ctrl+Shift+[ / ]로 변경

사이드바 순서대로 이전·다음 대화를 여는 기본 키가 Option+Shift+[ / ](Windows는 Alt+Shift+[ / ])에서 Claude·Codex 앱과 같은 Ctrl+Shift+[ / ]로 바뀌었습니다.

이 키를 직접 바꿔 두었다면 바꾼 키가 그대로 유지됩니다. Ctrl+Shift+[ / ]를 이미 다른 동작에 지정해 두었다면 그 지정을 유지하고 이전·다음 대화는 미지정으로 남습니다.

#### 사용 방법

사이드바에서 대화를 연 상태에서 Control+Shift+[ 또는 Control+Shift+](Windows는 Ctrl+Shift+[ / ])를 누르세요. 예전 키를 계속 쓰려면 내 설정 → 일반 → 단축키에서 "목록의 이전 대화"·"목록의 다음 대화" 키를 다시 지정합니다.

### 작업PC 선택 목록 디자인 통일

작업PC 선택 모달에서 계정 메뉴와 같은 PC 목록을 볼 수 있습니다. 내가 등록한 작업PC와 다른 작업PC가 나뉩니다. 다른 PC가 모두 공용이면 공용 PC로 표시됩니다. 각 행에 모니터 아이콘과 연결 상태 표시가 나옵니다.

#### 사용 방법

입력창 아래의 작업PC 이름을 누른 뒤 원하는 PC를 고릅니다. 현재 작업PC는 해당 그룹의 맨 위에 체크로 표시됩니다.

### 첫 화면의 AI 계정 연결 안내 간소화

개인 사용 또는 조직 AI가 등록되지 않은 관리자 화면에서 사용할 AI가 없으면 입력창 아래에 내 AI 계정 연결 버튼 하나가 표시됩니다.

#### 사용 방법

Chat 또는 Build의 입력창 아래에서 내 AI 계정 연결을 누르고 연결할 AI를 고르세요.

### AI 계정 연결 아이콘 통일

새 대화, 시작준비, AI Models 등에서 AI 계정을 연결하거나 다시 연결하는 버튼에 같은 플러그 아이콘을 표시합니다.

#### 사용 방법

플러그 아이콘이 있는 AI 계정 연결 버튼을 누릅니다.

### Happy CLI 런타임 갱신

AI 사용량을 보낼 때 그때 쓴 AI 로그인의 플랜 등급(Claude Max 20x, ChatGPT Plus 등)과 5시간·주간 남은 한도를 함께 보냅니다. 조직 관리자는 조직 콘솔 AI 사용량의 구성원 탭에서 구성원별 플랜과 남은 한도를 볼 수 있습니다. 작업PC를 이전한 뒤에도 Studio 서버 경로 기능이 정상 동작합니다.

#### 사용 방법

앱을 업데이트한 뒤 작업 PC 런타임이 새 버전으로 다시 시작되면 적용됩니다.

### Happy CLI 런타임 갱신 (대화 후 CPU 사용 감소)

Claude 대화를 마친 뒤 약 15분 동안 작업 PC가 5초마다 계정 관리 도구를 실행해 CPU를 쓰던 문제를 줄였습니다. 이제 읽은 계정 목록을 잠시 다시 쓰고, 사용량 측정을 켜거나 계정이 바뀌면 바로 새로 읽습니다.

#### 사용 방법

앱을 업데이트한 뒤 작업 PC 런타임이 새 버전으로 다시 시작되면 적용됩니다.

## 수정된 문제

### 끝난 백그라운드 작업 때문에 완료 알림이 늦거나 작업보드가 계속 돌던 문제

Claude가 띄운 백그라운드 작업의 완료 알림이 대화 기록에 남지 않으면(대화 요약으로 사라졌거나 작업이 알림 없이 끝난 경우), 작업이 끝났는데도 완료 알림이 최대 30분 늦게 오고 작업보드 카드와 Quick Open에 "백그라운드 작업 중"이 계속 보였어요. 이제 Claude가 실행 중인 작업이 없다고 알려 오면 작업보드와 Quick Open에서도 표시가 꺼지고, 5초 뒤 완료 알림이 와요. 작업이 남아 있는지 기다리는 자동화(오토파일럿·PR 지킴이·셀프 리뷰)는 지금처럼 대화 기록을 기준으로 판단해요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 끝난 백그라운드 작업이 계속 "백그라운드 작업 중"으로 보이던 문제

Claude가 띄운 백그라운드 작업의 완료 알림이 대화 기록에 남지 않으면(대화 요약으로 사라졌거나 작업이 알림 없이 끝난 경우), 아무 작업도 돌지 않는데도 사이드바 대화 줄과 대화 탭에 "백그라운드 작업 중"이 계속 보였어요. 이제 Claude가 실행 중인 작업이 없다고 알려 오면 그 표시가 꺼져요. 작업보드 카드와 완료 알림은 지금처럼 대화 기록을 기준으로 판단해요.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 대화 소유권 증명(실험)을 켠 채 관련 프로젝트가 있는 대화를 만들면 실패하던 문제를 고쳤습니다

개발자 기능 설정의 대화 소유권 증명(실험)을 켜고 관련 프로젝트 폴더가 있는 프로젝트에서 새 대화를 만들면, 작업PC에서는 대화가 시작됐는데 앱에는 "이 대화를 시작하지 못했습니다 / Malformed additional directories result from daemon."이 보였습니다. 이제 작업PC가 알려 준 관련 폴더 처리 결과를 그대로 받아 대화가 정상으로 열립니다. 작업PC의 Happy 런타임도 이 결과를 보내는 버전이어야 합니다.

#### 사용 방법

내 설정 → 개발자 기능 설정에서 대화 소유권 증명(실험)을 켠 뒤, 관련 프로젝트가 있는 프로젝트에서 새 대화를 만들면 됩니다.

### 대화 입력창 아래 연결 상태 정리

기존 대화의 사용 연결 확인이 실패하면 화면 위 토스트에 `다시 확인`을 표시합니다. 공용 PC의 계정 자동 전환 지원 여부가 미확인인 경우 입력창 아래에서 안내를 생략합니다.

#### 사용 방법

연결 확인 실패 알림에서 `다시 확인`을 누르면 현재 대화의 사용 연결을 다시 조회합니다.

### 배정이 모두 풀린 조직 AI 계정이 이 PC에서 정리됩니다

조직 관리자가 AI 그룹 배정을 모두 풀어도 예전에 받은 조직 AI 계정이 이 PC의 계정 목록에 남을 수 있었습니다. 이제 앱이 시작될 때와 "조직 계정 연결하기"를 누를 때, 서버가 알려 주는 회수 대상만 이 PC에서 지웁니다. 개인 계정과 회사 공용 AI 인증은 지우지 않고, 배정된 계정이 있으면 지금처럼 연결하기를 눌렀을 때만 연결합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 연결한 ChatGPT 계정으로 Codex 대화를 시작할 수 있어요

외부 연동에서 ChatGPT 계정이 연결돼 있어도 작업PC가 기존에 설치된 구형 Codex를 먼저 실행해 대화가 멈추는 경우가 있었습니다. 이제 개인 Codex 대화를 시작할 때 외부 연동에서 확인한 설치를 우선 사용합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 예약 화면을 열면 예약 목록이 바로 보입니다

프로젝트가 많은 계정에서 앱을 막 켠 뒤 프로젝트의 예약 화면을 새로고침하면 목록이 1분 넘게 비어 보일 수 있었습니다. 앱이 시작할 때 모든 프로젝트의 예약을 한꺼번에 확인하느라 화면에서 요청한 읽기가 뒤로 밀렸기 때문입니다. 이제 지금 보고 있는 화면의 예약 읽기를 먼저 처리하고, 시작할 때의 확인은 몇 개씩 나눠서 합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 외부 연동 카드의 위치 유지

AI 계정과 서비스는 연결한 뒤에도 외부 연동의 같은 자리에 표시됩니다. 연결 상태와 관리 메뉴는 각 카드에서 확인할 수 있습니다.

#### 사용 방법

사이드바에서 외부 연동을 열고 AI 계정 또는 사용 가능한 연동에서 원하는 카드를 찾으세요. 상단 검색과 새로고침은 두 목록에 적용됩니다.

### 작업PC 재등록 뒤 암호화 자동 복구

같은 작업PC를 다시 연결한 뒤 키가 확인되지 않아 새 대화를 시작할 수 없는 경우를 고쳤습니다. 새로 준비된 키가 서버의 기존 키와 달라도, 로컬 백업의 이전 키가 서버 봉투와 확인 기록에 모두 일치하면 자동 복구합니다. 응답을 마친 대화는 열어 둔 채 복구하고, 실행 중인 작업이 있으면 안전한 시점에 다시 확인합니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다. 전환 후 웹에서 새 키 확인을 요청하면 작업PC와 웹에 표시된 지문을 비교해 확인하세요.

### 조직 Claude 계정이 배정되지 않은 PC가 1분마다 계정 상태를 읽지 않습니다

내 작업 PC로 등록된 PC는 조직 Claude 계정의 사용량을 모으려고 1분마다 이 PC의 AI 계정 상태를 읽었습니다. 배정된 조직 Claude 계정이 없어도 읽었고, 한 번 읽을 때마다 계정 관리 도구가 세 번 실행돼 쉬고 있는 PC에서도 CPU를 쓰고 팬이 돌 수 있었습니다. 이제 배정된 계정이 있을 때만 읽습니다. 배정된 계정의 사용량 수집은 그대로입니다.

#### 사용 방법

별도 설정 없이 자동 적용됩니다.

### 종료된 터미널을 한눈에 알아볼 수 있어요

터미널의 셸이 끝나면 마지막 프롬프트와 커서가 그대로 남아 있어, 아직 쓸 수 있는 터미널처럼 보였어요. 종료 사실은 머리줄 오른쪽 끝의 작은 회색 글자로만 표시됐어요. 이제 셸이 끝나면 터미널 위쪽에 `종료됨`과 종료 코드, `다시 열기` 버튼이 함께 뜨고, 남은 출력은 흐리게 표시되며 커서도 사라져요. 하단 터미널에서는 종료된 셸의 탭 이름 옆에 종료 표시가 붙어서, 지금 보고 있지 않은 탭이 끝난 것도 알 수 있어요.

#### 사용 방법

셸이 끝난 터미널에서 `다시 열기`를 누르거나 Enter 키를 누르면 같은 자리에 새 셸이 열려요.

### 확장 업데이트 안내가 설정 화면을 가리지 않아요

이전 확장 API를 쓰는 확장이 여러 개 있어도 화면 위에 알림이 쌓이지 않아요. 해당 확장 카드에 `업데이트 필요` 표시가 붙어요. 창을 좁혀도 권한 철회 버튼이 카드 밖으로 밀리지 않아요.

#### 사용 방법

내 설정 → 개발 → 확장에서 카드를 확인하세요. `상세 · ID, 버전, 권한 관리`를 펼치면 사용 중인 확장 API와 지원 종료 안내를 볼 수 있어요.

### say플랜 이용이 끝나면 다음 행동을 안내해요

무료 이용이나 쿠폰이 소진·만료되면 새 대화의 say플랜 탭에서 이유를 확인할 수 있습니다. 플랜 상태에 따라 앱에서 플랜을 문의하거나 웹에서 결제를 신청하고 유료 Basic을 재개할 수 있습니다. 문의하는 동안 대화 초안과 AI 연결은 유지됩니다.

#### 사용 방법

홈·Chat·Project의 새 대화에서 AI·모델 메뉴 → say플랜을 엽니다. 플랜 문의를 누르고 상황에 맞는 블록 하나를 고른 뒤 확인을 누르면 지원팀에 문의가 전달됩니다.
