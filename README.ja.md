| 🗣️ **一文でアプリになる** | 🗂️ **エージェント艦隊を一つのボードで** | ✅ **レビュー → コミット → 完了まで** |
|:---|:---|:---|
| 欲しいものを伝えるだけで、エージェントが**あなたの Mac 上で**本物のコードを書いてコマンドを実行し、回答の下に**変更されたファイルのカードと結果のプレビュー**をすぐに表示します。 | Claude · Codex · Grok · opencode の複数の会話を**カンバン形式の作業ボード**で指揮します。カードをドラッグ&ドロップすれば、次の指示やレビュー依頼が送られます。 | **作業を完了**メニューひとつで、レビューから Commit & PR まで進み、終わった会話は**アーカイブ&完了**で整理されます。 |

> **v0.1.91 — 一段と落ち着いた画面、計画から始める会話。** v0.1.81 以降の 10 リリースでの主な変化:
>
> - **新しいスタイルの落ち着いた画面** — v0.1.89 ですべての画面のスタイルを新しく統一しました。作業ボードはウィンドウ幅 1440px でも6列が一画面に収まり、プロフィールメニューの**言語**から 한국어 · English · 日本語 · 简体中文 をすぐに切り替えられます。
> - **🧭 計画モード · コンテキスト圧縮** — 入力欄の **⋯ → 計画モード**をオンにすると、AI がファイルを編集する前に**計画カード**を先に見せ、**作業を開始**を押して初めて作業します。入力欄の下のコンテキストゲージ(`N%`)を押すと内訳が見られ、**会話を圧縮**で長い会話を縮められます。
> - **下部ターミナル · ファイルの直接編集 · 会話に貼り付け** — **⌘J** でどの画面でも下にターミナルを開き、ファイルをタブで開いてそのまま編集して **⌘S** で保存し、コードやターミナルの出力は **⌘L**、ファイルは `@` で会話に貼り付けます。
> - **応答中も思いのまま** — AI が回答している間に送ったメッセージを**キューに入れる · 今すぐ反映 · 中断して送信**から選べ、**メッセージ送信キー**(Enter / ⌘Enter)も決められます。アカウントメニューの**開発者モード**で、会話を複数のタブで開き、最大 4×4 のウィンドウに分けて見られます。
> - **💸 有料アカウントなしで無料スタート** — 有料の AI アカウントがなくても **無料モデル(opencode)** ですぐに始められます。無料モデルは OpenCode が期間限定で提供しており、モデルごとにデータの扱いが異なります([ガイドブック](https://buzzni.github.io/saycode-desktop-releases/guidebook/en/#205-how-much-can-i-use-free-models)、英語)。
> - **組織・ログイン専用** — モデルメニューの**使用する接続**で、組織が割り当てた **saycode プラン**(定額プラン)と**内部AI**(社内 LLM)を選び、所有するクラウドプロジェクトは**デプロイ**ボタンでテスト・本番に公開します。

## なぜ Saycode なのか？

社員はすでに ChatGPT や Claude で素早く働いています。しかし、サブスクリプションと API 契約は部署・個人ごとに
散らばり、誰がどのモデルをどれだけ使っているか会社にはわかりません。**制限すれば生産性が止まり、
野放しにすれば統制を失います。** 成果物は個人の PC に残ったまま、退職とともに消えていきます。

Saycode は**モデルと競合する製品ではありません。** チームがすでに知っている最新モデルをそのまま使いながら、
組織に必要な管理・セキュリティ・デプロイをその上に加える**運用レイヤー**です。

| | 個人で直接契約する場合 | **Saycode で一緒に使う場合** |
|---|---|---|
| アカウント・コスト | 個人ごとの支払い・アカウントが分散し、管理者は利用状況を把握できない | **同じモデルを中央管理・監査・コスト統制のもとで利用** |
| プロンプト・成果物 | 個人アカウントに紐づき、退職すると消える | **組織の資産として蓄積 — 担当者が変わっても引き継がれる** |
| モデル選択 | 一つのモデルに縛られ、より良いモデルが出ても切り替えにくい | **リクエストごとに最適なモデルを自動選択、ベンダーロックインなしで新モデルをすぐ利用** |
| コード・データ | 外部クラウドへ流出 | **会社が指定した作業PCに常駐 + エンドツーエンド暗号化(E2EE)** |
| 複数エージェントの運用 | チャットウィンドウをひとつずつ Alt-Tab | **カンバン型の作業ボードで艦隊全体を一画面で指揮** |
| 成果物 | レビュー待ちのブランチ | **作業を完了 → レビュー → Commit & PR → 社内 URL へデプロイ** |

一人で使うなら、個人契約が正解です。**組織で一緒に使う瞬間、必要なものが変わります。**

### 会社の管理者が実際にコントロールする4つのこと

| | 何を | どうやって |
|---|---|---|
| **誰が使えるか** | アカウント・シート | 従業員ごとにアカウントを発行・回収します。会社が持つ AI サブスクリプションや API を誰に割り当てるかも会社が決めます。異動・退職時は即座に回収。 |
| **どの AI を使えるか** | モデル・作業PCポリシー | チーム・作業PCごとに使える AI を選んで開放し、個人ごとに例外を設定できます。会社アカウントでシングルサインオン(SSO)。 |
| **どれだけ使っているか** | 利用量・コスト | 誰がどれだけ使い、コストがいくらかかったかを一画面で確認。予算上限に近づくと通知し、超えると自動停止。 |
| **何が起きたか** | 監査ログ | 誰がいつ何をしたかの記録が残ります。検索してファイルへ書き出せます。 |

### 私たちが先に導入し、測定しました

Buzzni の開発組織が Saycode 上で開発・運用しながら実測した結果です。

| **49%** | 単純なリクエスト **~90%** | 日常的な作業 **~80%** |
|:---:|:---:|:---:|
| 月間 AI 実行コスト削減 — 作業量はそのままに、コストだけを削減 | 誤字・文言修正は軽量モデルが処理 | 機能実装・リファクタリングは中位モデルが処理 |

> 測定条件: Buzzni 開発組織 35名 · 2026年6〜7月 · サブスクリプション・API 実行コスト基準 · 同一作業量を維持。
> ターンあたりの削減率は全体の削減率とは異なる指標です。お客様の環境での削減率を保証するものではなく、
> 導入初月に一緒にベースラインを測定します。

## Agent IDE(Orca など)とは何が違うのか？

[Orca](https://www.onorca.dev) のようなツールは **Agent IDE** であり、開発者のコーディングループに
集中しています — worktree 単位での並列エージェント実行、diff、レビュー、エディタとの深い統合。その領域を
非常によくこなしており、一部は組織単位の導入とガバナンスまで提供します。そのループが皆さんの課題であれば、
良い選択です。

Saycode が向き合う問いは異なります。エージェントがコードを作り終えた*その後*に始まる問いです:

> **Agent IDE は開発者がより多くのエージェントを動かせるようにします。
> Saycode はそのエージェントが作った成果物を会社の資産にします。**

| | Agent IDE(Orca など) | **Saycode** |
|---|---|---|
| 主な焦点 | 開発者のコーディングループ | **会社のデリバリーループ** — 制作 → レビュー → デプロイ → 共有 → 引き継ぎ |
| 管理の単位 | Repo · worktree · エージェントセッション | **組織 · チーム · プロジェクト · 作業PC · シート · デプロイ済み成果物** |
| 「デプロイ」の意味 | エージェントツールを組織に安全に導入・展開すること | **作った成果物をチームが開く社内 URL でサービスすること** |
| 一般的なゴール | レビューを経て Git にマージされた変更 | **共有・引き継ぎ可能な、実際に稼働中の社内サービス** |
| AI モデルコスト | 利用量の追跡、アカウント切り替え | **難易度ベースの自動ルーティング + サブエージェント委任 — 組織全体で49%削減を実測** |
| 届く相手 | 主に開発者 | **会社の全構成員** — 開発者、企画者、運用担当者 |

両者は並列エージェント、worktree、リモート実行、ローカルファーストのセキュリティという点で重なっています。
したがって、それらは選択の決め手にはなりません。Saycode がその上に加えるのは**運用レイヤー**です:

- **会社の所有権** — プロジェクト、セッション、企画ドキュメント、作業PCは個人のノート PC ではなく組織に
  帰属します。担当者が退職したりチームを異動しても、成果物は検索でき、引き継がれます。
- **社内デプロイ** — ワンクリックで固定の社内 URL(SSL 自動)にデプロイされます。成果物は
  レビュー待ちのブランチではなく、チームが今日すぐ開ける実際のツールになります。
- **共有・引き継ぎ** — 同僚が閲覧し、複製し、磨き上げ、変更を反映し直します。他のチームが完成させた
  プロジェクトは作り直す対象ではなく、出発点になります。
- **コスト運用** — リクエストの難易度に応じて最も安価で適切なモデルへ自動ルーティングし(セッションが
  行き詰まったときだけ上位モデルへ昇格)、機械的なサブタスクはより軽量なモデルのサブエージェントに
  委任し、これらすべてが中央管理された組織共用PCの上で動きます。メッセージごとにどのモデルが
  なぜ選ばれたかがバッジで表示されます。会社全体の AI コストを「確認する」のではなく「運用する」のです。

**いつ何を使えばいいか:** 自分のリポジトリで最も深い並列エージェントコーディング体験を求めるなら、
Agent IDE も良い選択です — 両方を併用しない理由もありません。AI が作ったソフトウェアが
**会社のインフラ**になること — 社内にデプロイされ、チーム間で共有され、引き継ぎを経ても生き残り、
コストまで管理される — それが目標なら、それが Saycode が解決する課題です。

### ほかにも

- ⌨️ **入力欄の生産性** — 空の入力欄で **↑** を押すとこの会話の過去の依頼を呼び出し、ブックマーク型の**マイプロンプト**でよく使う依頼を保存(ログインするとアカウントに保存されるので別の PC でも使えます)、`@` でファイル・Git の変更(`@diff`)・別の会話を参照、`/recap`・`/btw`・`/usage`、長文貼り付けはカードに折りたたみ
- 🛟 **ファイルチェックポイント** — 新しい会話の `⋯` でオンにすると(macOS・Linux の作業PC)、エージェントがファイルを変更する前の状態を残し、ファイルごとのプレビューを経て安全に復元でき、自分のメッセージから**この時点にファイルを戻す**こともできます *(v0.1.91 の個人利用では、オンにすると会話が始まりません)*
- 🧭 **プロジェクトハブ** — 新しい会話の `⋯` → **プロジェクトハブに設定**すると、同じプロジェクトの別の会話が終わった知らせや質問をまとめて受け取れます(プロジェクトごとに一つ)
- 🔁 **会話を続ける** — **プロジェクトツール (⋮) → 会話を続ける**で、**別の AI ツールで続ける**(Claude ↔ Codex)か、**同じ AI で分岐**
- 🔎 **会話検索とクイックオープン** — ⌘⇧F でこの PC のインデックスから過去の会話を検索し、⌘P でファイルやコマンドをすばやく開く
- 🤖 **オートパイロットと自動品質検証** — 作業ボードのカードのオートパイロットがレビューし、要件ごとの根拠を確認してから初めて PR へ進み、PR ウォッチが CI の失敗・レビュー指摘・コンフリクトをエージェントに指示 *(PR ウォッチは GitHub が必要)*
- 🗓️ **予約** *(ログイン)* — 決まった時刻に AI に仕事をさせる: *「毎日午前9時に昨日の PR を要約して」*。タイムゾーンを確認でき、結果は通常の会話として蓄積され、Telegram・Slack にも届きます
- 🧪 **アプリ内ブラウザー · プレビュー · 要素への注釈 · AI ブラウザー** — 画面の要素を指して直す機能は v0.1.91 ではまだ調整中のため、一部の組織にだけ先行提供されています(個人利用・一般アカウントには表示されません。今は言葉で説明するか、画面キャプチャ・`@`・⌘L で指して依頼してください)
- 🔔 **通知と Webhook** — 完了・入力リクエストの通知は再起動後も残り、開発自動化でセッションイベントを署名付き Webhook として自分のエンドポイントに送信
- 📄 **リッチなファイルビューア** — Markdown・HTML・PDF・DOCX をアプリ内でレンダリングし、CSV/TSV は表で、大きなメディアはストリーミングで開く
- 🔐 **セキュリティの既定値** — チャットとターミナルのエンドツーエンド暗号化、パスキー/TOTP MFA *(チーム)*、コードとデータは自分の作業PCに

## インストールと初回起動

### macOS

1. **[Releases](https://github.com/buzzni/saycode-desktop-releases/releases/latest)** から最新の DMG をダウンロード(Apple Silicon — Intel Mac 用の x64 DMG も同じページにあります)
2. DMG を開き、**Saycode** を Applications にドラッグ
3. 起動すると最初の画面はログインフォームです。画面下部で**言語**を選べます(한국어 · English · 中文 · 日本語)
4. 開始方法を選びます
   - **個人で使う → 確認** — ログインなしでこの PC ですぐに開始(会話とプロジェクトはこの PC にだけ保存され、終了するときはプロフィールメニュー最下部の**個人利用を終了**)

   - **セルフホストサーバーに接続** — 自分のサーバーで `saycode server connect` により受け取った接続コードを貼り付けて**接続**

| 第1週 · ベースライン | 第2〜3週 · 実利用 | 第4週 · 結果報告 |
|---|---|---|
| 現在の AI 利用・コストのベースライン測定、対象部署と PoC シナリオの選定 | 実際の業務に適用し、利用量・コストを実測、ポリシー・権限設定を検証 | 有効化率・コスト・ポリシーの動作結果を整理し、本導入の見積もりを算出 |

PoC 期間は1ヶ月無料。期間中に発生するモデル利用料はお客様の契約に従います。

AI モデルを転売するツールではありません。すでにお使いの AI 契約をそのまま接続し、管理と実行環境に
対するシート料金のみをいただきます。
